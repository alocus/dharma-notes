## 1. 本講概要

本講是《佛說阿彌陀經》系列第九講，前三分之一（〔行94-376〕）是正宗分的最後收尾，後三分之二（〔行378-967〕）整講進入流通分。法師開場先複習序分、正宗分已講完，正宗分分依報、正報，正報就是阿彌陀佛的無量光教我們信願持名〔行94-104〕。第一段（〔行105-177〕）以《楞嚴經》二十五圓通、文殊菩薩選圓通偈「此方真教體，清淨在音聞」為前導，說明娑婆世界耳根最利、觀音菩薩耳根圓通與此方因緣最深；法師並以孔子述而不作類比佛陀49年靠音聲說法，強調「諦聽」是聞法的根本態度〔行150-168〕。第二段（〔行170-249〕）法師引一部平時少講的《觀佛三昧海經》，以窮人偷寶瓶、身死寶瓶不壞（印心不壞）的譬喻，補足上一講「一心不亂・意不顛倒・繫念不亂」的義理，並重申文成印壞、自性彌陀唯心淨土。第三段（〔行214-336〕）法師以《楞嚴經》大勢至菩薩念佛圓通章為軸心，完整展開三個譬喻：一人專念一人專忘（若逢不逢）、母子相憶（如母憶子）、都攝六根（淨念相繼），中間插入台南將軍鄉老阿婆與法師師公慧三長老站立往生的實例。第四段（〔行336-376〕）法師講持名念佛的具體修法（金剛念、自念自聽、三根循環都攝六根），引《妄盡還源觀》攝境歸心真空觀・從心現境妙有觀為理論依據，〔行374-376〕正宗分正式圓滿，法師預告：這可能是他最後一次講《佛說阿彌陀經》。

第五段起（〔行378-967〕）整段是流通分六方佛的展開，這是本講篇幅最大、也是全系列第一次的密法會通。法師先請師姐完整誦讀鳩摩羅什意譯的六方佛全文（〔行378-428〕），然後用一段明末公案破題：密藏道開禪師（紫柏老人門下、憨山老和尚同門）在《如來淵源考》裡說「五方五明王皆同源一體，名號雖殊，其體卻同，皆源自於毘盧遮那」〔行437-490〕；法師藉此帶出唐密傳承史（善無畏傳胎藏界、金剛智傳金剛界、不空傳惠果、惠果傳日本空海為東密、最澄結合天台為台密），以及中國唐密文革後僅存的四部法（準提法、大悲咒、穢跡金剛咒、尊勝佛母）——法師特別指出本禪苑正屬於護法部穢跡金剛法脈，傳承自師公慧三老和尚〔行490-528〕。接著法師引蓮池大師《阿彌陀經疏鈔》一段話：「毘盧遮那內心自受用成於五智，其中妙觀察智即阿彌陀佛，此即華藏與淨土，乃二如來之同土也」，以此為全講的理論核心〔行550-580〕，並詳細畫出金剛界五方佛曼荼羅圖（中央毘盧遮那法界體性智、東方阿閦佛大圓鏡智、南方寶生佛平等性智、西方阿彌陀佛妙觀察智、北方不空成就佛成所作智），說明五智是眾生本具、只因迷而扭曲成阿賴耶識、末那識、六識〔行609-698〕。最後法師逐尊解釋六方佛每一個名號，指出全部都是自性功德的不同面向的稱謂，一句「阿彌陀佛」等於總持十方諸佛的稱讚與庇佑，以「禪淨密都不二」「唯心淨土，自性彌陀」作結〔行952-967〕。

貫串全講的三條主線：

1. **五智同源說：所有名相、所有佛號，都是毘盧遮那內心自受用流出的五智的異名**〔行550-698〕。法師以蓮池大師《阿彌陀經疏鈔》引智覺（永明延壽）「總持三十七佛皆毗盧遮那一佛所現」一段為根據，畫出金剛界曼荼羅，把六方佛的每一個名號都拆解回五智其中一智，最終收攝於「妙觀察智即阿彌陀佛」一句。
2. **音聲與諦聽是了生死的唯一入手處，因為佛與眾生都是靠音聲成就的**〔行105-168、306-312〕。法師以文殊菩薩選圓通偈「此方真教體，清淨在音聞」、孔子述而不作、《六祖壇經》學法無益不識本心・法達三千遍法華公案，反覆說明沒有諦聽就沒有開悟，跟學問無關。
3. **一心不亂的具體操作，全在大勢至菩薩念佛圓通章的三個譬喻裡**〔行214-336〕。一人專念一人專忘說明真心常住而妄心背離；母子相憶說明信願已足者只需一句佛號提醒；都攝六根說明持名念佛就是舌根念、耳根聽、意根入的三根循環——法師以此收束整部正宗分。

## 3. 核心概念

| 概念 | 法師的解釋〔行〕 | 經教連結 |
|---|---|---|
| 此方真教體，清淨在音聞 | 文殊菩薩在楞嚴會上選圓通時所說：娑婆世界耳根最利，所以真正的教體清淨在聞性、在音聲；佛49年說法全靠音聲，不做文字記載，因此諦聽（無我執、無分別意見地聽）是聞法的根本〔行110-127〕 | ✓ CBETA T0945（見§9） |
| 印心不壞 | 出自《觀佛三昧海經》窮人偷寶瓶喻：身體會敗壞，寶瓶（自性功德）永不敗壞；念佛者的這顆心就是寶瓶，此心是佛、即心即佛，不是嘴巴念佛而已（法師口誦「印心不壞」，經文原作「心印不壞」，見§法師所述）〔行183-210〕 | ✓ CBETA T0643（見§8、§9） |
| 一人專念一人專忘 | 《楞嚴經》大勢至菩薩念佛圓通章第一舉例：一人一直憶念、一人完全不理會，兩人若逢不逢、若見未見——真心（本來常住）與妄心（一直背離往外）的關係，眾生迷的狀態就是若見未見、若逢不逢而已（法師口誦「譬如二人」，經文原作「譬如有人」，見§法師所述）〔行216-226〕 | ✓ CBETA T0945（見§8、§9） |
| 母子相憶 | 第二舉例：十方如來憐念眾生如母憶子，子若逃逝雖憶何為；只要眾生憶佛念佛，現前當來必定見佛、去佛不遠、不假方便自得心開——法師強調憶佛（第六意識的憶）與念佛（當下這顆真心）的層次之別〔行254-291〕 | ✓ CBETA T0945（見§8、§9） |
| 都攝六根 | 第三舉例，也是大勢至菩薩念佛圓通章的結論：佛問圓通，我無選擇，都攝六根，淨念相繼，得三摩地斯為第一；法師具體操作示範：舌根念阿彌陀佛→耳根聽進去→入意根，三根循環，這稱為都攝六根〔行291-364〕 | ✓ CBETA T0945（見§8、§9） |
| 五智 | 毘盧遮那內心自受用流出的五種智慧，眾生本具：法界體性智（中央，毘盧遮那，即《妄盡還源觀》自性清淨圓明體）、大圓鏡智（東方，阿閦佛，本心）、平等性智（南方，寶生佛）、妙觀察智（西方，阿彌陀佛，能分別而不執著）、成所作智（北方，不空成就佛，前五識完成五塵的作用）；迷了以後五智扭曲為阿賴耶識、末那識（我執）、第六意識（分別）、前五識〔行609-698〕 | 蓮池大師《阿彌陀經疏鈔》引智覺（永明延壽）義理，非逐字經文引誦，見§8、§10 |

## 4. 故事・公案

### 4.1 《觀佛三昧海經》窮人偷寶瓶：印心不壞

法師為補足上一講「一心不亂・意不顛倒・繫念不亂」的義理，引出一部平時少講的經典——《觀佛三昧海經》。經中有一個譬喻：有一個窮人偷了王子的一個寶瓶，眾人追捕他，他逃到樹上，樹承受不住他的身體重量，他從樹上掉下來——在掉落的過程裡，他情急之下把寶瓶吞了下去；落地後（法師以「重力加速度」形容）這個窮人終於摔死了。死後身體腐壞，可是他吞下的寶瓶卻不壞，而且寶瓶發出的光明連毒蛇都害怕、都逃離。佛陀舉這個例子後告訴阿難：「住於念佛者」，就是吞下寶瓶的那個人——各位聽仔細，窮人吞下寶瓶，身體雖敗壞，寶瓶卻不壞，大放光明，連毒蛇都逃離；佛陀說這就是「念佛者」的意思，念佛不是嘴巴的那個唸佛，而是當下這顆心是佛，此心是佛、即心即佛，達摩祖師《血脈論》也一直在講這個道理。「印心不壞」是說這光明普照的心永遠不會損壞，這是講我們的自性功德——每一個人心中都有這個無價珍、摩尼寶珠，只是自己不知道而已〔行175-210〕。

（經核對 CBETA T0643《觀佛三昧海經》，原文為「復次阿難！譬如有人貧窮薄福……得王寶瓶擎持逃走……貧人見已吞王寶印，持瓶冠頭以手覆面……時六黑象以鼻絞樹令樹倒躄，貧人落地身體散壞唯金印在，寶瓶現光諸蛇見光四散馳走。」佛告阿難：「住念佛者心印不壞，亦復如是！」——經文原作窮人吞下的是「王寶印」（印綬）而非整個寶瓶，樹倒是六隻黑象用象鼻拉倒的，法師的複述在細節上略有簡化與加工〔重力加速度、吞下整個寶瓶〕，屬於譬喻的教學性轉述，核心「住念佛者心印不壞」的教證意涵與經文相符，法師口誦順序略有出入，見§法師所述。）

### 4.2 台南將軍鄉老阿婆與師公慧三長老站立往生

法師講到淨土十三祖全部都是禪師（慧遠、善導、永明延壽、蓮池、蕅益、截流、省庵、印光、徹悟等）時，舉出兩個他親眼見聞的例子：台灣台南將軍鄉有一位不認識字的老阿婆，一生只會念「阿彌陀佛」，往生時竟然是站著往生的；到目前為止法師聽到站著往生的例子有兩個，另一個就是法師的師公慧三長老，也是站著往生。法師強調：這位將軍鄉的老太婆雖是下下智（不識字、什麼都不懂），卻有上上根——因為她念阿彌陀佛的當下意不顛倒，念念分明卻內心毫不執著，世間一切她不掛在心上，這就是《金剛經》「應無所住而生其心」入地菩薩的境界，也就是六祖的功夫；懂得念佛法門的人是無上甚深微妙禪，不懂的人喊破喉嚨也枉然〔行228-244〕。

### 4.3 密藏道開禪師、紫柏老人與憨山老和尚

法師為解釋六方佛「名雖假名，德是實德」的道理，引出明末一位大禪師密藏道開禪師的公案。密藏道開是明朝四大高僧紫柏老人的門下（明四大高僧為蓮池大師、憨山大師、紫柏老人、蕅益大師）。紫柏老人五歲才會開口說話，有一天他母親帶他出門，碰到一位異僧，這位出家人看了紫柏老人一眼便說「以後你必然出家而成為大德」，紫柏老人聽完這番話後馬上就會開口講話了。紫柏老人性格好強、豪氣，時常佩劍打抱不平；有一天聽到人家拜八十八佛的佛名，便發願出家，具足三壇大戒後，只要看到出家人受戒卻不守戒律（尤其吃肉）他會當場喝斥。後來紫柏老人與憨山老和尚（法名德清）相約在嶗山見面談禪，兩人惺惺相惜、相當契心——法師特別提到清末民初活到120歲的虛雲老和尚，本來的法名也叫德清，有一天在廣東看到憨山老和尚不壞的肉身，儼然掉淚，有人說「德清見德清」，莫非虛雲老和尚就是憨山老和尚的再來人。後來憨山老和尚在明神宗萬曆年間因牽連皇太后政爭，被誣為私設寺院（古代寺院皆須皇家設立），充公到嶺南；紫柏老人在北京京城奔走營救，又因為替全國礦工爭取免稅權利，得罪當道，最後紫柏老人入獄，受到錦衣衛與東廠嚴酷拷打，他自知「此方已不可留」，最後坐化而亡。當時紫柏老人提倡集合大藏經，主編就是密藏道開大師；紫柏老人反對當道時，密藏道開曾勸他「此是娑婆，娑婆本來就是五濁，我們隨緣而行，你可以罷手而歸」，紫柏老人不聽，密藏道開便離開了紫柏老人，此後下落不明，但留下他關於佛號自心顯現的洞見——著有《如來淵源考》，說「五方五明王皆同源一體，名號雖殊，其體卻同，皆源自於毘盧遮那」〔行437-490〕。

### 4.4 蓮池大師與文殊菩薩化身童子問答：蓮池之池

法師講到蓮池大師是大徹大悟的古佛再來，連文殊菩薩都要來親自考驗他。文殊菩薩化身一位童子，赤著腳、腳上還帶著泥污，去見蓮池大師。蓮池大師看到這個小孩子，就問他：「你一定久經塵勞才到這裡來，你看你的腳還帶著這麼多淤泥。」童子（文殊菩薩化身）回答：「我帶著淤泥要來試試看，連池的池深不深。」蓮池大師馬上回答：「蓮池之池非常深，你不怕淹死你就跟我嗆聲。」童子（文殊菩薩）便說：「我兩手托虛空，我一腳踏到底。」蓮池大師聽完便向他頂禮——這是兩尊佛（古佛再來者）相見的對話方式。法師以此說明：末法時期仍然有正法，諸佛菩薩寧願眾生如母憶子，除非因緣未到，否則祂們一定會留下來為末法眾生演述正法，因為祂們不捨眾生〔行528-536〕。

### 4.5 黃蘗禪師三巴掌點醒唐宣宗

法師講到十方諸佛皆是自心顯現、拜佛就是拜自己自性佛時，引用黃蘗禪師（古佛再來）的公案。唐宣宗還是太子時曾與黃蘗禪師同住一寺，有一次看到黃蘗禪師在禮佛，便問他：「你不是常說『能禮所禮性空寂，感應道交不思議』嗎？既然一切無相，為什麼還要拜偶像呢？」黃蘗禪師聽完，第一次給他一巴掌；唐宣宗再問一次「不是一切無相嗎？」，黃蘗禪師又給他一巴掌；唐宣宗說：「你這個出家人怎麼這麼無理！」黃蘗禪師再給他第三巴掌。三巴掌點醒了唐宣宗。後來唐宣宗毀佛又恢復佛法後，本想把黃蘗禪師命名為「太粗和尚」（因為他出手太粗魯），後因宰相建議，改名為「斷際禪師」（際指三際：過去、現在、未來不可得）。法師以此說明：你對一個人尊敬，就是對自己尊敬；你對一個人生氣，就是對自己的處罰——一切都來自你的內心，這正是十方諸佛皆自心顯現的道理，你尊敬諸佛的名號，等於尊敬你自己的自性佛〔行797-803〕。

**義理深入：**

六方佛這一段，鳩摩羅什意譯為東西南北上下六方（玄奘異譯作十方），文字看似最多，法師卻認為這是全經最重要的密法會通關鍵——因為佛的名號雖然多達恆河沙數，但「德是實德」，全部名號指向同一個自性功德。法師的推演邏輯是：先由密藏道開禪師《如來淵源考》「五方五明王皆同源一體，皆源自於毘盧遮那」破題，再引蓮池大師《阿彌陀經疏鈔》「毘盧遮那內心自受用成於五智，其中妙觀察智即阿彌陀佛」為理論核心，最後把六方佛的每一尊佛名，逐一拆解回五智的其中一智——阿閦鞞佛系列拆解到東方大圓鏡智（本心），無量壽佛系列拆解到西方妙觀察智（阿彌陀佛本身），師子佛系列拆解到自性法身之用，梵音佛系列拆解到本心的圓滿具足。這個解讀方式的深意在於：六方佛不是外在真實存在的許多不同的佛，而是同一個自性功德，用不同的名相從不同角度描述——這正是法師開場所說「此方真教體，清淨在音聞」的收尾：你諦聽這麼多佛名，最後聽懂的不是「有多少尊佛」，而是「原來全部都是我自心的顯現」。

「一切諸佛所護念經」一段，法師給出這一講最重要的結論性義理：一句阿彌陀佛之所以能滅八十億劫重罪，不是因為外在有一尊佛來救贖，而是因為自他不二——你念一句阿彌陀佛，等於念了十方所有的諸佛（因為祂們同源於毘盧遮那），十方諸佛也都是念阿彌陀佛成佛的，所以祂們讚嘆阿彌陀佛，其實也是在讚嘆自己、讚嘆你的本心。這把整部經從第08講「一心不亂」的個人修持義，進一步推展到「自他不二、法界一心」的密法層次，也呼應法師開場所說：這可能是他最後一次講《佛說阿彌陀經》，所以要把最深的義理和盤托出。

2. 法師於〔行183-210〕多次引《觀佛三昧海經》「住念佛者心印不壞」一句時，口誦語序倒轉作「印心不壞」。經CBETA核驗，T0643原文明確作「心印不壞」（心在前、印在後）。
3. 法師於〔行550-580〕引蓮池大師《阿彌陀經疏鈔》「毘盧遮那內心自受用成於五智，妙觀察智即阿彌陀佛」一段話時，將整段話直接歸為蓮池大師自己所說。經CBETA核驗，X0424原文明確標示這是蓮池大師引用「智覺」（即永明延壽禪師諡號）之語（「智覺云：……」），蓮池是贊同轉述者，非原創者。法師轉述的義理與原文相符，但省略了引語的出處歸屬。
4. 法師於〔行586-588〕稱達摩祖師《血脈論》裡「一直在講」修密求感應、念佛求庇佑都是邪法。經CBETA核驗，T2009全篇查無此句逐字對應；《血脈論》確實反覆強調「即心是佛，離心外覓佛終不可得」的義理，與法師轉述的精神一致，但法師所引的具體措辭不見於經文本身，屬法師的意引概括。

連結要點：蓮池大師《阿彌陀經疏鈔》引智覺（永明延壽）之語，說毘盧遮那內心自受用流出五智，中央法界體性智不動，東南西北四方各流出一智；法師據此把六方佛的每一個名號都拆解回這五智之一，收攝於「妙觀察智即阿彌陀佛」——五智是眾生本具，只因迷而扭曲為阿賴耶識（本來大圓鏡智）、末那識我執（本來平等性智）、第六意識分別（本來妙觀察智）、前五識（本來成所作智），修行的方法就是轉識成智，回歸本來面目〔行609-698〕。

### 10.4 一心不亂到自他不二：正宗分收尾與流通分的義理遞進

| 教證來源 | 內容 | 法師的鋪陳 |
|---|---|---|
| 《楞嚴經》大勢至菩薩念佛圓通章 | 都攝六根，淨念相繼，得三摩地斯為第一 | 〔行291-317〕正宗分收尾：一心不亂的具體修法在於三根循環持名念佛 |
| 密藏道開《如來淵源考》 | 五方五明王皆同源一體，皆源自於毘盧遮那 | 〔行477-490〕過渡橋樑：從「一心」推展到「一切名相皆同源」 |
| 蓮池大師《阿彌陀經疏鈔》引智覺語 | 毘盧遮那內心自受用成於五智，妙觀察智即阿彌陀佛 | 〔行550-580〕理論核心：阿彌陀佛在五智座標中的確切位置 |
| 《佛說阿彌陀經》六方佛 | 十方諸佛出廣長舌相稱讚阿彌陀佛不可思議功德 | 〔行952-960〕總結：自他不二，稱讚阿彌陀佛即是稱讚自己的本心，也是十方諸佛稱讚自己 |

連結要點：這四條教證構成本講從「一心不亂」（個人修持義）推展到「自他不二」（法界一心義）的完整論證鏈——法師先在正宗分收尾把一心不亂講到最具體的操作層次（三根循環），再用一段明末公案打開「名相皆同源」的視野，接著用蓮池大師的話定住阿彌陀佛在五智體系中的位置，最後回到經文本身，用「十方諸佛互相稱讚」收束整個論證：你念一句阿彌陀佛，滅罪的原理不是外求，而是自他本來不二〔行291-960〕。

## 11. 日常實踐

1. **練習諦聽的態度：聽經聞法時放下第六意識、第七意識的意見與分別，單純地聽**，法師強調這跟學問無關，只跟願不願意諦聽有關，利根的話三年就能大徹大悟〔行125-158〕。
2. **練習三根循環持名念佛**：舌根念出「阿彌陀佛」，耳根聽自己念出的佛號，讓佛號入意根，如此循環，這就是都攝六根的具體操作，晚上睡覺可用金剛念（默念、舌根不動）〔行338-364〕。
3. **以「一人專念一人專忘」自我檢視**：問自己是否讓妄心一直往外攀緣、不理會常住的真心；只要願意回頭，母子（真心與自己）歷生不相違遠〔行216-263〕。
4. **禮佛時觀想「能禮所禮性空寂」**：拜佛不是向外求，而是拜自己心中顯現的那尊佛；尊敬他人（包括拜佛）就是尊敬自己的自性，這樣的禮佛才是真正的禮佛〔行787-803〕。
5. **以「德是實德，名是假名」看待所有佛菩薩名號的差異**：不必糾結於名相多寡或表面差異，重點是體會每一個名號背後所指向的同一份自性功德〔行434-436、826-952〕。

## 12. 延伸・參

- 本講〔行374-376〕正式圓滿正宗分，並預告這可能是法師最後一次講《佛說阿彌陀經》，全講後三分之二篇幅罕見地以唐密五方五佛、金剛界曼荼羅正面會通阿彌陀經流通分，是全系列目前為止密法色彩最濃的一講，建議與第08講一心不亂的具體修法合併對讀。
- 參問：法師提出「六方佛的每一個名號都是自性功德的異名」，並用五智座標把數十個佛名逐一還原——這留給讀者一個可操作的自我檢驗問題：當你念誦六方佛的名號時，是把它們當作「外在真實存在的許多佛」，還是能體會到法師所說「全部都是我自心的顯現」？法師說「你稱讚阿彌陀佛，十方諸佛就庇佑你、稱讚你」，這句話如果脫離「自他不二」的前提去理解，會不會退回到向外祈求的層次？這是本講留給讀者最深的思考題。
