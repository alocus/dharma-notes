## 1. 本講概要

本講是《佛說阿彌陀經》系列第六講，法師自述「淨土經我講經到現在第十四年」〔行1049〕。全講分兩大段：前三分之一（〔行96-374〕）延續上一講已誦讀過的依報經文（七寶欄楯羅網行樹・七寶池・八功德水・眾鳥說法・微風吹樹），以《大智度論》四悉檀（世界悉檀・為人悉檀・對治悉檀・第一義悉檀）作為總收束，並插入《金剛經》「如來有五眼」的長段開示——從師姐十餘年前初聞五眼而心生退轉的夢境公案，展開肉眼、天眼、慧眼、法眼、佛眼五層見地，並以COVID-19疫情、兩次世界大戰為例說明「常」而非「無常」的五濁惡世實相，中間穿插法師自身六年前罹患多發性骨髓瘤（後轉骨髓癌末期）從「求死」到「入假隨緣」的心路示現，以《彌陀要解》空假中一心三觀收攝。〔行375〕法師正式請師姐誦經，進入正報「彼佛何故號阿彌陀」至六方佛讚嘆（僅誦東方段，「好先到這裡」暫停）。後三分之二則是全講見地最深之處：以父親閩南語偈「日亦夢，夜也夢，夢到最後皆是空，只有阿彌陀佛有希望」起，逐字解「阿彌陀」三字橫遍十方（無量光）、豎窮三際（無量壽）即是眾生自己的法界體、自己的本心；再以「因德而名」說明持名如何以彌陀萬德莊嚴自心之本覺；最後用近三分之一篇幅，依《無量壽經甄解》道隱法師所立，講善導大師從四十八願中拈出的五願核心（十一必生願・十二光明無量願・十三壽命無量願・十七諸佛讚嘆願・十八十念必生願），以蕅益大師「六信」（信自・信他・信因・信果・信事・信理）貫串「唯心淨土，自性彌陀」之宗旨，末段以持名即是入流亡所、量子糾纏為科學類比，一心不亂與自心迴向作結。

貫串全講的三條主線：

1. **五眼與四悉檀是同一把鑰匙，用來破除「肉眼／天眼」層次的世間見**〔行203-341〕。法師指出同一件COVID-19或同一場戰爭，肉眼看是無常、天眼看是因果報應、慧眼看是緣起性空、法眼看是凡所有相皆是虛幻、佛眼看則情與無情皆是阿彌陀佛所現——見地決定一生的幸福與否，五眼的差別不在神通，而在是否入了本心。
2. **阿彌陀三字是密語，因德而名，無量光無量壽正是眾生自心本具的法界體，非彌陀所獨有**〔行477-642〕。法師用「橫遍十方」「豎窮三際」交織成法界體，指出這個法界體既是西方極樂淨土的依正二報，也是一切眾生的依正二報，持名念佛正是藉彌陀萬德莊嚴喚起自己本覺的萬德莊嚴，本始不二，生佛不二。
3. **十八願十念必生的門檻極低，卻能圓證三不退，關鍵全在至心信樂（六信）而非事修的多寡**〔行666-1081〕。法師用善導大師五願核心、阿闍世王五逆罪仍上品中生的案例、以及「毀謗正法」是唯一真正的障礙，說明淨土法門是易行道中的圓頓法，取乎其上（易經語）才能真正把握往生。

## 4. 故事・公案

### 4.1 師姐十餘年前的五眼之夢

法師講《金剛經》如來五眼時，提到一位師姐十幾年前第一次來聽經，聽到「五眼」便不以為然，心想「又講什麼，跟什麼眼有什麼關，開什麼天眼」，以為天眼只是一種神通，聽完第二堂課就沒有再來。所幸她做了一個夢：夢見法師穿著白衣站在那邊走過，她好像被問到有兩條路可以走，法師告訴她走哪一條，那條路走起來非常平坦、沒有障礙，另一條路則泥濘不堪。因為這個夢，她下一次又來聽經，從此十幾年完全沒有缺席，法師講什麼經她就聽什麼經。法師以此說明：這個夢境是真是假並不重要，「以假歸真」，若沒有這個夢她就不會來聽經，聽了才生起信心，因為她要保任住佛性，這對她有真實之利〔行203-207〕。

### 4.2 法師自身罹癌的示現

法師講到COVID-19與五濁惡世之常時，提及自己六年前得到一個罕見疾病的癌症。他坦言六年前的心境是「只有一條路，而且是我很想祈求的一條路」——因為聽佛陀講世間是苦，又聽老子講「吾有大患，患吾有身」，極想擺脫色身及色身周邊的親屬牽絆，因此六年前沒有看醫生、也沒有做任何治療，甚至一度瀕死，因而體會到「靈魂已經離開色身，才知道死沒有那樣可怕，原來離開色身靈魂才會自由」。當時是護法居士們希望他留下來，他才願意接受治療。六年後癌症復發，這一次他選擇接受醫生的治療——他強調這不是貪生怕死，而是體悟到「空假中」：六年前想離開人世，是進入「空」；但當時尚未能體悟「空假合一」；這一次接受治療，是「入假」——隨緣而非隨便，因緣滅則滅、因緣生則生，當體即空、了不可得；進入假而不離空，就是「中」，這才是圓滿的一心三觀。法師直言：這六年的逆境、對他的讚嘆與毀謗（包括雜誌登過的），原來都是佛示現要來成就他，「沒有它的逆境、沒有它的逆緣，我怎麼成就我自己」〔行287-292、318-341、1051-1055〕。

### 4.3 父親「日亦夢，夜也夢」的閩南語偈

法師敘述前幾天去見他的父親（法師稱他「老菩薩」，已出家，時年九十七歲，農曆年剛過）。父親用閩南語跟他說了一句話：「日亦夢，夜也夢，夢到最後皆是空，只有阿彌陀佛有希望。」法師聽了心生歡喜，說「我知道他的見地了，他的心一定會往生西方極樂淨土」，因為這句話講出了「人生宛如一場夢」的見地——夢裡明明有六趣，覺後空空無大千；夢到最後什麼都沒有，唯獨阿彌陀佛是真實的依歸。法師強調：如果以後有人聽到這句話而能體會，這一定是大開悟的人，開悟一定往生〔行444-459〕。

### 4.4 蓮花色比丘尼被提婆達多打死

法師講如來肉眼「見人不會認錯」時，提及佛陀神通第一的弟子蓮花色比丘尼的公案：提婆達多要忤逆佛陀時，蓮花色（神通第一）出面跟提婆達多講真理，提婆達多因是佛的堂弟、身材高大，一拳往蓮花色的眼睛打下去，蓮花色比丘尼眼球被打出、當場昏倒而死。法師指出：佛陀具有大神通，難道不知道嗎？佛陀只講一句話：「緣滅，一切緣起」——重點不在色身，蓮花色已經悟到法身，正如孔子所說「朝聞道，夕死可矣」，色身是體相用之「用」，眾生有需要才留下，不能為了不留下而不留下，那是斷滅相〔行824-829〕。

### 4.5 阿闍世王五逆重罪仍上品中生

法師講十念必生願除五逆及誹謗正法的例外時，舉阿闍世王子為例：他因提婆達多煽動，用政變方法把父親頻婆娑羅王關起來餓死（殺父）；又把母親韋提希夫人幽禁（殺母，母親用蜂蜜讓父親延命，被發現後亦被關）；又與提婆達多勾結，從山上丟大石頭要害佛（出佛身血，韋馱菩薩以金剛杵擊裂石塊，仍砸到佛腳流血）；又間接殺害支持佛的阿羅漢——犯了五逆重罪中的四項。可是阿闍世王子最後往生西方極樂淨土，上品中生。法師指出關鍵在於他後來「悟無生」：《妙法蓮華經》中記載阿闍世王子帶領眷屬（含兩千餘人）也去聽《妙法蓮華經》，可見他已入本心，五逆罪雖重，但「了則業障本是空」，端坐念實相就是大懺悔〔行793-796、942-946、1071-1075〕。

### 4.6 李炳南老居士的疑惑：萬修萬人去，為何一萬人不到一兩人往生？

法師談十念必生願「至心信樂」的重要性時，回憶四十年前跟隨老師楊政河（台大哲學系、《華嚴經》專家）去拜見李炳南老居士（淨空老和尚之師，台中蓮社影響深遠）。李炳南老居士說：「現在的人，一萬個人不到一兩個往生。」法師當時就覺得奇怪——為什麼念佛風氣比現在盛，往生的人卻這麼少？這個疑問一直放在心裡，直到好幾年前，有出家眾告訴他兩位很用功念佛、準備往生的出家眾，臨終時卻沒見到阿彌陀佛來接，心生惱恨、死得不明不白。法師由此更加肯定：「口念彌陀心散亂，喊破喉嚨也枉然」，淨土法門是本心的法門，不是口頭唸誦的數量問題〔行856-868〕。

**義理深入：**

「彼佛何故號阿彌陀」一段，是全講見地最深的核心。法師沒有停在字面的「無量光、無量壽」，而是用「橫遍十方」與「豎窮三際」兩條軸交織成一個「法界體」——橫是空間的超越（無量光不受光速限制，「站在世界的角度光的速度很快，可是它橫遍十方，換句話說它超越了時間超越了空間」），豎是時間的超越（無量壽不是活多久的問題，而是過去現在未來全部超越）；這個橫豎交織而成的法界體，「不但是彌陀的身土，也是一切眾生的法界體」——換句話說，阿彌陀經所講的依報正報，其實就是眾生自己的依報正報，只是我們不知道。法師特別強調這不是比喻上的類推，而是「你可以自己做實驗：你眼睛張開也好閉著也好，你看你的心有多大」——這正是把抽象的「無量光無量壽」轉化為可以當下體證的觀法。

十念必生願一段，法師特別點出「一心不亂」不是持名數量的累積，而是「至心信樂」，也就是入本心。這一點解答了他在李炳南老居士處留下的疑問（見§4.6）：往生比例低，不是因為法門不夠殊勝，而是絕大多數人「口念彌陀心散亂」，沒有真正契入本心；反過來，只要真正入本心，「乃至十念」，甚至一念，也能往生——這正是「門檻很低，可是達到圓滿究竟」的「殊勝中的殊勝」。

六方佛讚嘆一段（僅東方），法師沒有停在字面讚嘆功德的鋪陳，而是拆解出諸佛讚嘆的三重對象：讚嘆法藏比丘本願、讚嘆念佛之人、也讚嘆佛自己成佛所用的同一個法門——這把「諸佛讚嘆」從單純的莊嚴敘述，轉化成一個「自己也在被讚嘆之列」的邀請：念佛之人正在做諸佛自己也做過的事。

## 10. 法脈會通

### 10.1 五眼與四悉檀對照：同一件事，見地不同

```
                 同一件事（COVID-19 / 世界大戰 / 阿彌陀三字）
                              │
   ┌─────────┬─────────┬─────────┬─────────┬─────────┐
  肉眼        天眼        慧眼        法眼        佛眼
（世俗諦）  （因果報應）（緣起性空）（當體即空）（情與無情皆佛）
   │           │           │           │           │
戴口罩打疫苗  瘟神因果    condition   凡所有相    何處不是西方
（隨順眾生）  報應說       具足而生    皆是虛幻    何處不是清泰故鄉
```
連結要點：五眼不是神通層級的差異，而是「入本心的深淺」；如來五眼凡夫本具，只是沒開——見地決定一生的幸福與否〔行203-286〕。

### 10.2 阿彌陀名號二義與六信對照：從「是什麼」到「如何信」

| 阿彌陀名號二義 | 對應之信（蕅益六信） | 法師的鋪陳 |
|---|---|---|
| 無量光（橫遍十方） | 信自：我這一念心非白非黃非赤，覓之不可得，卻能造千如百界，一切國土都是我心的變現 | 〔行477-541、904-1006〕 |
| 無量壽（豎窮三際） | 信因・信果：我願意入本心是因，往生淨土是果；種瓜得瓜，種豆得豆 | 〔行1003-1010〕 |
| 因德而名（阿彌陀＝法藏比丘本願所成之德） | 信他：信釋迦如來所說不虛，信十方佛皆讚嘆此法門 | 〔行544-604、995-1001〕 |
| 十念必生（第十八願） | 信事・信理：真有西方極樂淨土，非莊生寓言；事理圓融，理事無礙 | 〔行1022-1069〕 |

連結要點：法師沒有把「名號釋義」和「信願行」當作兩個獨立主題，而是讓阿彌陀三個字的兩重意義（無量光・無量壽），逐步映照到六信的每一個信項——「這個法界體不但是彌陀的身土，也是我們眾生的法界體」正是六信最終要落實的那一句〔行534-541〕。

### 10.3 十八願的核心地位：從《無量壽經甄解》道隱法師之論到善導大師五願

```
《無量壽經》四十八願
        │
   道隱《甄解》：若十八願是實，則其餘四十七願皆是權
        │
   善導大師拈出五願核心：
        │
   ┌────┼────┬────┬────┐
  十一願  十二願  十三願  十七願  十八願
 (必生願)(光明無量)(壽命無量)(諸佛讚嘆)(十念必生)
        │
   十八願＝核心中的核心：至心信樂，乃至十念，
   唯除五逆及誹謗正法（五逆仍有阿闍世例外，
   唯毀謗正法無可救——因毀謗正法即否定自己
   本具的覺性）
```
連結要點：法師用這個「權實層層收攝」的架構，說明四十八願看似平列，實則有輕重次第，最終全部收攝到「至心信樂」四個字——這也是他解答李炳南老居士疑問（見§4.6）的教理根據：往生比例低，不是法門的問題，是眾生沒有真正契入「至心」〔行666-733、845-1020〕。

## 11. 日常實踐

1. **持名時觀想「因德而名」**：念「阿彌陀佛」不是喊口號，而是藉彌陀萬德莊嚴喚起自心本具的萬德莊嚴，持名的當下即是以彌陀的莊嚴來莊嚴自己的本覺〔行558-560、596-604〕。
2. **遇到COVID-19、天災人禍等逆境時，練習五眼次第自問**：這件事用肉眼看是什麼（世俗諦的應對）？用天眼看是什麼（因果）？用慧眼看是什麼（緣起性空）？用法眼看是什麼（凡所有相皆是虛幻）？用佛眼看是什麼（情與無情皆是佛的示現）？藉此練習從世間見一路提升到第一義見地〔行261-286〕。
3. **面對逆境或重病時，體會「入假不離空」**：法師自身接受醫療的示現說明，入世隨緣做事（假）不妨礙契入本心（空），兩者圓融即是「中」——不必用「消極不作為」來證明自己看破，也不必用「積極治療」來否定自己已經契悟〔行335-341〕。
4. **念佛時檢視是否「至心信樂」而非計數**：十念必生願的重點不在念了多少遍，而在有沒有入本心；「一心不亂」是擦到邊就可以了，練習在持名時放下「能所」（有一個來救我的阿彌陀佛、有一個我被救的凡夫），直接讓念頭與佛號相應〔行1021-1022、1097-1098〕。
5. **日常以「我在念自己的本心」取代「我在求外在的佛來救我」的心態**，因為十方諸佛護念的是「已經在呼喚自己本心」的人，這個人已經是「賢聖」，不是因為念佛的次數多而被眷顧〔行636-640〕。

## 12. 延伸・參

- 延續第05講〔行341-609〕依報三段的四悉檀分析，本講〔行107-374〕是同一教理架構在名號段之前的收束複習，建議合併對讀。
- 下一講（第07講）預期正式進入「一心不亂」的詳細開示（法師於本講末〔行1097-1098〕預告：「下個禮拜要講很重要的一心不亂，以及教你們怎麼念佛」），以及六方佛讚嘆剩餘五方（南、西、北、下、上）。
- 參問：法師說「這個法界體不但是彌陀的身土，也是一切眾生的法界體」〔行534-536〕——若依報正報本是眾生自心的法界體所現，那麼「往生西方」與「當下入本心」在究竟義上有沒有先後之別？這是本講留給讀者的一個參問。
