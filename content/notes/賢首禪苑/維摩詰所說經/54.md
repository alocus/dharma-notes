## 1. 本講概要

本講是〈菩薩行品第十一〉的**圓滿講**。承第53講，體佛法師續講佛對九百萬香積國菩薩開示的**「有盡無盡解脫法門」**，把核心八字——**「不盡有為，不住無為」**——逐句釋盡，並在結尾回讀「又具福德故不住無為……是名盡無盡解脫法門，汝等當學」整段，收於九百萬菩薩「散華供養、歎未曾有、忽然不現還到彼國」，最後帶出〈見阿閦佛品第十二〉首句「汝欲見如來，為以何等觀如來乎」〔行251–1174〕。

全講以三段大架構貫穿：

1. **開場：以《大乘寶要義論》立「聽經聞法」的地位**〔行80–247〕。法師引北宋·法護譯《大乘寶要義論》（T1635）序文「人身難得，剎那間得成勝法更難……若知此也，不作思惟而作利益事，此生虛來而已」，配「盲龜浮木」譬喻，論證能「逢如來清淨教法、勇猛信心、聽聞納受」須具二條件——**人身難得、正法難聞**（已供養無量諸佛），為後文「有為/無為」定調。

2. **修行總圖：四魔對治→熱度公式→六種無為**〔行256–544 / 921–1131〕。複習四魔（煩惱魔／五陰魔／死魔／天魔）以智慧觀對治；再以「350度信心 → ×6 六度 → ×(4+6) 身心 → ×4 三毒 → 八萬四千」的「熱度算式」把成佛過程數量化；最後以世親《百法明門論》（T1614）「小乘七十五法／大乘二空」與**六種無為**（虛空・擇滅・非擇滅・不動滅・受想滅・真如）判定唯「非擇滅無為＝聽聞熏習」是菩薩修法、唯「真如無為」是真無為。

3. **經文逐句：不盡有為・不住無為**〔行721–1226〕。以《諸法無行經》「一切有為法即是無為法」、龍樹《中論》「世間與涅槃無有少分別」、清·溥畹《金剛經心印疏》「但有一法即是有為」三重佐證「有為即無為」，再把〈菩薩行品〉「謂修學空不以空為證……觀諸法虛妄……而不虛福德禪定智慧」三十餘句逐一判為「有為觀／無為體」，收束於**「為一切所應為，而心恆處無為」**。

全講中心口訣：**在有為中用無為心，不離夢而喚醒夢中人，即是菩薩。**

## 4. 故事・公案

### 4.1 盲龜浮木——當人身之難〔行110–113〕
佛舉喻：大海中有一隻沒有眼睛的盲龜，一百年才浮上海面一次；海上飄著一塊浮木，木上蛀了五個孔。盲龜百年一浮，恰好碰上這塊隨風飄流的浮木，且龜頭與四腳竟都套進了五個孔洞裡——機率之微，正喻「當人身」之難。法師以此配《大乘寶要義論》「人身難得」，再進一層：得人身後又能「剎那間得成勝法（頓圓法）」者，更是難中之難。
**核驗**：喻出《大乘寶要義論》T1635 引《雜阿含經》「有一眼龜居其水內，壽命無數百歲……可能得值浮木孔邪？諸苾芻言：不也。世尊！」✓ CBETA T1635。

### 4.2 燃燈佛授記——本得本證故不與授記〔行141–143〕
法師回想《金剛經》：釋迦未成佛時，於燃燈佛座下。燃燈佛之意——若你認為「有佛可得、你會成佛、可以證」，便不與授記；因為「本得本證」，你若還有一個「得」與「證」，即是頭上安頭。正因釋迦「無所得無所證」，燃燈佛乃與授記：「汝於來世當得作佛，號釋迦牟尼。」
**核驗**：《金剛經》T0235 授記語意 ✓（原文作「以實無有法得阿耨多羅三藐三菩提，是故然燈佛與我授記」）。法師轉述無誤。

### 4.3 勝意比丘・喜根比丘——誹謗圓頓法，文殊曾下地獄〔行556–599〕
出《諸法無行經》：昔有二比丘，**喜根比丘**入圓頓法，主張「貪瞋癡三毒即是菩提性（煩惱即菩提）、三毒無障礙」——因為三毒是妄心，妄心是假，假所引發的貪瞋癡亦假，本心本無障礙。**勝意比丘**修頭陀行、成就十二頭陀、入四禪八定，卻不認同，認為貪瞋癡是應遠離、應廢除的，遂**一直誹謗**喜根比丘。因這一念「障礙心」（排斥佛的圓頓法），勝意比丘墮地獄，久劫不聞如來清淨教法；直到有一天聽到喜根比丘無量劫前所說的一偈，善根顯現、懺悔讚歎，剎那間轉身。——這位勝意比丘的後身，正是今日與佛對話的**文殊師利菩薩**；而喜根比丘早已成佛。文殊自述此段因緣，即《諸法無行經》之由來。
**法師點睛**〔行568–589〕：即使對方真是外道，你「認為他是外道」而以之障礙自己，你還是障礙——「假裝正義來作批判，你還是障礙」；歷史上多少戰爭都以「正義」為名而兩敗俱傷。
**核驗**：公案出《諸法無行經》T0650（姚秦·鳩摩羅什譯）；喜根比丘偈「凡夫畏佛法，去佛法甚遠……一切有為法，即是無為法」✓ CBETA T0650（詳§9）。

### 4.4 施主一顆米，披毛戴角還——講法不許夾一絲利益〔行574–582〕
法師以「相上因果」自警：站在相上有因就有果，「吃人一斤要還人十六兩」。故「地獄門前僧道多」——僧道多者，正因講法有目的性、有利益性。「施主一顆米，若不了道業，披毛戴角還。」法師自陳：講經說法連一點利益之求都不行，連想蓋佛寺、蓋不起來就蓋不起來，「反正都假的」；除非對方真以誠心、入空性來供養，否則稍有作意心絕不能接受，否則佛法會急遽衰微、混亂。
**核驗**：「施主一顆米，披毛戴角還」為叢林常誦警句（傳為古德語），非某一根本經之定句，此處作 ※ 未定於根本經；「地獄門前僧道多」同屬俗諺警語。

### 4.5 無著世親兜率聞法——彌勒講《金剛經》要義〔行897–905〕
法師述法相宗淵源：無著菩薩入定時，上升兜率天，聽彌勒菩薩講《金剛經》要義；出定後告訴弟弟世親（天親），世親聞後大徹大悟，遂把彌勒所講《金剛經》的心論作成偈語與論述，傳到中國，由菩提流支翻譯。此論即《金剛般若波羅蜜經論》。其中最有名的一偈——「廣大第一常，其心不顛倒；利益深心住，此乘功德滿」——法師言「只要記得這段話，你真的就開悟了」。
**核驗**：偈確在《金剛般若波羅蜜經論》T1511「論曰……偈言：廣大第一常，其心不顛倒，利益深心住，此乘功德滿」✓ CBETA T1511（天親菩薩造・元魏菩提流支譯）。**辨正**：此論為**天親（世親）造、菩提流支譯**；法師一處口語作「世親菩薩翻譯的來講」，應是「世親**造**、菩提流支**譯**」。又法師誦作「貫真貫實…廣大第一常」，「貫真貫實」四字canon無有（※ 為轉述/OCR異文，見§9）。

### 義理深入

**一、「不盡有為・不住無為」為何是娑婆菩薩的獨門法。** 法師扣住本品的敘事脈絡：九百萬菩薩隨維摩詰化身自香積佛國而來，香積國「都進入本心、皆永恆不生滅、平平等等」，**根本無從開發慈悲心**〔行268–274〕。唯有在娑婆五濁惡世（見濁‧劫濁‧煩惱濁‧眾生濁‧命濁），眾生「取得人身難得、能聞正法難聞」，菩薩才能「逢五濁而行菩薩心」，故諸佛讚嘆〔行256–276〕。這正是「不盡有為（不離夢／娑婆）」與「不住無為（不停於空、不取涅槃）」在本品中的**具體所指**——它不是抽象的中道語，而是佛對「香積國沒有的狀況」所開的殊勝法，並以「汝等當學」勸九百萬菩薩學娑婆之道。

**二、「觀×而不×」的統一讀法。** 法師給了一把總鑰匙：句中「觀／修學」都是**有為**（「但有一法即是有為」，見§9心印疏），而被觀的無常/苦/無我/寂滅/空無等都是**無為**；於是每一句都是「有為觀＋無為體」的同時並存，恰對《心經》「色不異空，空不異色」——有為＝色（有變化），無為＝空。菩薩不偏空（聲聞）、不偏有（凡夫），取「水平」〔行605–780〕。此讀法把三十餘句從「零散德目」還原為**一條「有為無為不二」的貫線**。

**三、「代眾生苦」的重新定義。** 「觀於寂滅而不永滅」「而以行法教化眾生」在法師手中被讀成一則實踐命題：眾生在夢中受苦，最好的救法是**喚醒**，而非在夢裡給他什麼（「夢見老虎不必派武松，醒來就夠了」）〔行786–806〕。故「代眾生苦」＝說法喚醒夢中人；前提是自己先知「這是夢」——「你自度不了去度人，叫痴人說夢話」。這把「不住無為」從教理落到「講經說法即最大代苦」的行門。

**四、「本願未滿」的張力——本成佛而未圓滿。** 法師特別停在「本願未滿，而不虛福德、禪定、智慧」〔行857–863〕：眾生「體性而言是佛，習性而言未圓滿」，「古鏡還沉泥，泥不去則不能照人」，故仍需福慧雙修。他由此接出全講的修行次第（六種無為），說明「漸次法的修行」仍稱有為，卻是「透過有為進入無為」的必要橋樑——這解決了「本來是佛，為何還修」的弔詭。

## 10. 法脈會通

### 10.1 有為即無為——四路一輻

法師本講的核心論證是「有為法即是無為法」，他用四路把它焊死（承§8連結地圖），四路皆歸「色空不二」：

```
        有為＝無為（一際・無有異故）
   ┌─────────┬─────────┬─────────┐
 諸法無行經   中論      金剛經     心印疏
 偈頌直斷    二際無差   賢聖以無為  定義有為/無為
   │         │          法而差別    │
   └── 色不異空・空不異色（心經公式）──┘
              │
       鏡與影像：鏡（無為/本心）現影像（有為/世界）
       影像不離鏡，鏡不離影像→世界即法界（唯心所現）
```
**連結要點**：世間際＝涅槃際＝世界＝法界＝有為＝無為（色）不異空——「一際，無有異故」。菩薩因此「不用離開有為，也不需住無為」。

### 10.2 六種無為＝一張修行判教圖（form-matches-content）

法師把《百法明門論》六無為排成一條「由淺入深、唯末是真」的修行判教梯，並各繫其「修者身分／所墮境界」。這是本講最結構化的教學，須以表＋梯呈現：

```
真如無為  ← 眾生本具・證而無證・唯一真無為（菩薩/佛）
   ↑（由此變現以下五種）
非擇滅無為 ← 菩薩乘：聽聞熏習，無斷而斷（如染香人）  ← 佛要教的
────────────────────────────────────────────
不動滅無為 ← 四禪天：捨念（人為壓念），色界最高      ┐
受想滅無為 ← 無色界非想非非想天：捨得更徹底           ├ 皆「捨念」，似涅槃非真
擇滅無為   ← 聲聞乘：以正智斷煩惱（證我空未證法空）    ┘
虛空無為   ← 第六意識想出的「清淨」（非真無為）
```

| 六無為 | 是否真無為 | 誰在修／所墮 | 何以非真（法師釋） | 〔行〕 |
|---|---|---|---|---|
| 虛空無為 | 否 | 第六意識所變 | 「虛空無障礙、清淨」是你第六意識想出來的清淨，仍有能想 | 1032–1048 |
| 擇滅無為 | 否（偏空涅槃） | 聲聞乘 | 以正智「擇」而斷煩惱，把煩惱當真才要斷；只證我空未證法空 | 1049–1065 |
| **非擇滅無為** | **菩薩正修** | **菩薩乘** | 不另擇法，靠不斷諦聽如來清淨教法，自然除阿賴耶妄種，無斷而斷 | 1066–1089 |
| 不動滅無為 | 否（相似） | 四禪天 | 人為捨念、壓念，苦樂不受；念再起仍下墮輪迴 | 1090–1100 |
| 受想滅無為 | 否（似涅槃） | 無色界非想非非想天 | 捨受、想更徹底，仍是「壓」；出定即再輪迴 | 1101–1111 |
| **真如無為** | **唯一真無為** | 眾生本具 | 不須修證、不斷不滅、本來如是；餘五皆由它變現 | 1123–1131 |

**連結要點**：前五無為「其實還是有為」（虛空是第六意識、擇滅有能斷、不動/受想是壓念）；唯「非擇滅（熏習）」是菩薩修因、「真如」是所顯果。故法師一講到底強調「聽經聞法」——它就是非擇滅無為的操作法。真如無為之證有二門：**了達二空**＋**遠離遍計所執（放下執著至人法俱空）**＝「應無所住而生其心」〔行1129–1141〕。

### 10.3 百法明門論的心色二法收攝

```
百法（五位）
 心法(8) ── 眼耳鼻舌身意 + 末那 + 阿賴耶
 心所法 ── 依八識而起之附帶（煩惱/喜/悲…無質礙）
 色法 ── 心現出「有質礙」之物質影像（茶杯/身）
 不相應行法 ── 非心非色非心所（時間/空間；一旦與你相關→轉心所法）
 無為法(6) ── 見 10.2
        └─ 究竟：色法亦心法 → 心色不二 → 「百法明門論即大乘心法」
```
**連結要點**：法師判「小乘七十五法（證人無我，法猶實有）／大乘一一法中了達二空（人法俱無我）」——後者即《金剛經》「通達無我法者，斯名菩薩」，與《圓覺經》「離身心幻垢者即是菩薩」互證〔行943–958〕。

### 10.4 「佛有的我們都有，佛沒有的我們卻有」

法師收於一句總攝全講的口訣〔行949–953〕：**「佛有的我們都有（佛性、覺性——心佛眾生三無差別）；佛沒有的我們卻有（貪婪、嫉妒、妄想——把虛幻當真）。」** 修行即修「佛沒有而我們有」的那一分：知其虛幻、不受干擾，即「若能轉境即同如來，若被境轉即是凡夫」。

## 11. 日常實踐（可操作）

1. **以「善思惟」把聽來的法變成自己的**〔行165–172, 554〕：聽經後必用觀照般若思惟，思惟到「自己告訴自己：真的就是這樣」為止，才能身體力行；否則只是文字般若、口頭禪。禪那＝「思惟修」。
2. **四魔即起即以智慧觀對治**〔行321–357〕：煩惱魔→觀煩惱本空（不斷而觀）；五陰魔→照見五蘊皆空（五蘊即五假）；死魔→觀本心不死（Amṛta 甘露＝阿彌陀，身心幻垢會死、本心不死）；天魔（傲慢）→觀一切眾生平等（因緣所生法即空，無可驕無可卑）。
3. **把六度做成「無所住」的六度**〔行392–451〕：布施/持戒/忍辱/精進/禪定日常本在做（搭計程車、消費、守規矩、勤勞、不亂心），差的只是「應無所住而行」的般若；前五度是盲，第六度是眼，缺眼即「虛來此生」。
4. **對身心幻垢的具體練習**〔行343–365, 453–474〕：把肉身當車／眼鏡／碗筷——壞了換新、不必哭三天；記住「本心恆久遠，一顆永流傳」（那一顆＝阿彌陀）。知「身心幻垢者即是菩薩」（圓覺經）。
5. **「非擇滅」熏習法——不斷諦聽**〔行1066–1089, 1143–1147〕：不用刻意斷煩惱，靠「不斷的如是我聞、依教奉行」自然除阿賴耶妄種；此即「以幻取幻（三摩缽提）」——用佛經幻化的真如本智，剋掉你妄心的幻。每週聽、善思惟。
6. **對外一律讚歎，守自己原則**〔行568–590〕：別人如法不如法是他家的事；「你認為他不如法，放在心裡讓自己不如法，是最愚蠢的修行人」。不以「正義」之名批判——那還是障礙自己。
7. **講法／布施不夾一絲利益求**〔行574–582〕：「施主一顆米，披毛戴角還」；蓋不起佛寺就蓋不起，反正都假；有作意心的供養絕不接受，否則佛法衰微。
8. **代眾生苦＝喚醒，不在夢裡給物**〔行786–806〕：眾生夢中受苦，最好的救法是說法喚醒（不派武松）；前提是自己先確知「這是夢」，否則痴人說夢。
