## 1. 本講概要

本講屬〈觀眾生品第七〉。體佛法師以「一句話貫串全品」的方式，把〈觀眾生品〉的骨幹揭出：**度眾生的整套操作，是一條由「生死畏」逆推到「無住為本」的因果鏈**，而「從無住本，立一切法」正是本品——乃至整部《維摩詰經》——的圓教根據〔行132-136〕。

法師今日的教學結構分三層：

1. **逆推法鏈的複習**〔行45-135〕：眾生如幻 → 仍須度眾生 → 以正念（不生不滅之本心）度 → 度眾生須示現身 → 有身則欲貪 → 虛妄分別 → 顛倒想 → **無住為本 → 無住則無本 → 從無住本立一切法**。此鏈即《楞嚴》「妙明真精妙心所變現」的同一義〔行132-134〕。
2. **一則印心公案**〔行143-374〕：以《五燈會元》「**秦跋陀**禪師勘**竺道生**」為證——色/空、涅槃之因，關鍵在「眾微未聚之前是什麼」「涅槃的因是什麼」，答案即《楞嚴》「性色真空」＝《心經》「色即是空」。中間並附一段完整的**魏晉南北朝譯經史架構**，說明「秦」（前秦／姚秦）、鳩摩羅什入華的因緣〔行184-258〕。
3. **本品經文正解**〔行376-972〕：**維摩詰**丈室「天女散花」全段——花著不著、心戒重於相戒、「言說文字皆解脫相」、「婬怒癡性即是解脫」、「無得無證」——並以《諸法無行經》「貪欲是涅槃」、天台智者《止觀》「貪瞋癡為菩提」、《永嘉證道歌》「無明實性是佛性」等圓法互證。

**貫串全講的一句話**：一切法（山河大地、身心、乃至貪瞋癡、文字、天華）都是「從無住本」所立的虛幻相；知其為佛性所顯的幻相而不受其縛，又借此幻相度化幻化眾生，即入「不即不離」的本心〔行966-969〕。

## 4. 故事・公案

### 4.1 秦跋陀禪師勘竺道生（本講主公案）〔行152-374〕 ✓CBETA X1565《五燈會元》

**背景**：法師先介紹**竺道生**——**鳩摩羅什**門下「關中四傑」之一（另三為**僧肇**、**僧叡**〔逐字稿作「曾叡」〕、**道融**）。竺道生倡「一切眾生皆有佛性，一闡提亦可成佛」，在魏晉南北朝竟遭高僧大德公開排斥，被迫南下；自講之際「生公說法，頑石點頭」的典故由此而來，後入**慧遠**〔廬山〕結社為大傑，往生〔西方極樂淨土〕上品上生〔行156-179〕。

**公案本文**（《五燈會元·秦跋陀禪師》）：秦跋陀遠來見竺道生，問：

1. **色空義**——生曰「眾微聚曰色，眾微無自性曰空」。師追問「**眾微未聚，喚作甚麼？**」——生罔措（無法回答）〔行264-294〕。
2. **涅槃義**——生曰「涅而不生，槃而不滅，不生不滅故曰涅槃」。師問「這箇是如來涅槃，那箇是法師涅槃？」（即問**涅槃之因**）——生又罔措〔行296-300〕。
3. **勘驗**——師拈起如意問「還見麼？」生曰見；擲於地問「見麼？」生曰「見如意墮地」。師斥：「觀公見解，未出常流，何得名喧宇宙？」拂衣而去〔行304-306〕。

**點破（因中色空／果上色空）**：其徒追問，師曰「汝師秖說得**果上色空**，不會說得**因中色空**」——「一微空故眾微空，眾微空故一微空；一微空中無眾微，眾微空中無一微」〔行306, 322〕。

**法師的詮釋**：竺道生所說的「空」是「因緣所生法、一變就變的現象界的空」；秦跋陀問的「空」是「真心本性的空」——即《楞嚴經》「**性色真空**」。眾微未聚之前、涅槃之因，都是那「能立一切法」的真心本性。竺道生只認得真空、不認得妙有（不知妙有是真空所變現），故層次未圓〔行308-330〕。此案答案落在《楞嚴》性色真空＝《心經》色即是空〔行374-381〕。

> **附註**：CBETA《五燈會元》原文作「**生法師**」，未明書「竺道生」；法師依傳統認定此「生」即竺道生。學界對此人是否確為竺道生有異說——此為法師的認定，保留其說並註明原典用字。

### 4.2 神秀與六祖菩提偈〔行534-554〕 ✓CBETA T2008《六祖壇經》

法師重提：神秀是真長者、修行極好，但停於一觀念——「身是菩提樹，心是明鏡台，時時勤拂拭，勿使惹塵埃」，其法是修到「一塵不染」，然「染了又拂拭、拂拭了又染」，百千萬劫做不到〔行536-539〕。六祖直入本心——「菩提本無樹，明鏡亦非台，本來無一物，何處惹塵埃」，是「**無塵可染**」〔行540〕。一塵不染是聲聞乘（有對象可修）；無塵可染是「無所住」的菩薩，故五祖傳衣缽於六祖，寧虛位以待〔行542-544〕。呼應天女散花——**維摩詰**與諸大菩薩無所染，聲聞乘則須修到一塵不染〔行544-548〕。

### 4.3 常不輕菩薩〔行853-855〕 ✓CBETA T0262《法華經》

法師以之對照「增上慢」的反面：常不輕菩薩見人必頂禮、稱其為佛菩薩，被罵仍頂禮稱佛菩薩；佛授記其未來成佛、成就淨土，讓昔日輕視、誤解他的菩薩到此淨土成佛——顯菩薩之慈悲胸懷〔行853-855〕。

### 4.4 趙州「老僧八十猶行腳」〔行896〕

法師引**趙州**和尚證悟語「老僧八十猶行腳」「原來得來全不費工夫」，證主動權都在自己、回頭是岸〔行896〕。

### 4.5 地藏・觀音倒駕慈航〔行53-61〕

法師以**地藏菩薩**「地獄不空誓不成佛」、示現與鬼道地獄眾生一樣的相（非在地獄享特權，特權者是閻羅王）、**觀世音菩薩**「應以何身得度即現何身」，說明菩薩偉大在「真做給你看」、與眾生感同身受，不高眾生一等——如法國大革命前貴族嘴憐憫而自享安樂，無法感動百姓〔行53-72〕。

## 8. 本經解義（維摩詰所說經逐段）

本講的兩大經文段落，皆〈觀眾生品第七〉之連續文：（A）「生死畏 → 無住為本」逆推法鏈；（B）「天女散花」對話。以下按經文次第列出。

### 8-A 逆推法鏈（依如來功德之力 → 從無住本立一切法）

| 維摩原句〔行〕 | ✓CBETA T0475 | 體佛法師釋義（逐句） | 在本品脈絡之定位 |
|---|---|---|---|
| 「菩薩於生死畏中，當依如來功德之力。」〔行76-79〕 | ✓ | 菩薩憑什麼倒駕慈航與眾生同受苦？靠如來功德——而如來即「我心中的如來」，外如來即內如來，無內無外〔行79-85〕 | 度眾之力源 |
| 「當住度脫一切眾生。」〔行87-91〕 | ✓ | 依如來功德力就靠心力，靠心力即廣度眾生；能度眾生即成佛，眾生與佛三無差別。度「一切」眾生（無對象），故大到不可形容＝摩訶 | 力的落實處 |
| 「欲度眾生，除其煩惱。」〔行96-108〕 | ✓ | 廣度即是修「習性」（非修佛性）；碰到頑固眾生正是修正方向——包容原諒，撐大心量 | 度的內容 |
| 「當行正念。」又問：「云何行於正念？」答曰：「當行不生不滅。」又問：「何法不生？何法不滅？」答曰：「不善不生，善法不滅」〔行110-118〕 | ✓ | 「正」即入法界；正念＝不生不滅之本心。「善」即「正」（非世間善惡）；到此〈觀眾生品〉本可句號，但圓滿處要回頭 | 度的方法 |
| 「善、不善孰為本？」答曰：「身為本。」又問：「身孰為本？」答曰：「欲貪為本」〔行120-122〕 | ✓ | 度眾須示現身；有身則以身為我所有而欲貪，此即我見 | 逆推之始 |
| 「欲貪孰為本？」答曰：「虛妄分別為本。」又問：「虛妄分別孰為本？」答曰：「顛倒想為本」〔行122-126〕 | ✓ | 無正念故虛妄分別，把假當真而欲貪；虛妄分別成顛倒見（想） | 惑之次第 |
| 「顛倒想孰為本？答曰：無住為本。」〔行126-128〕 | ✓ | 顛倒想以「無住」為本；無住即無所住，同上文「不生不滅」 | 逆推之樞 |
| 「無住則無本。文殊師利！從無住本，立一切法。」〔行128-134, 384-385〕 | ✓ | 無住已到頭、無本為本（沒有本了），即第一義諦、即本心；此「無本」又能「立一切法」——同《楞嚴》「妙明真精妙心所變現汝心及山河大地」 | 全品／全經之圓教根據 |

**完整經文（T0475，逐字稿於行384-385僅引末二句，補足全鏈）**：
> 文殊師利又問：「生死有畏，菩薩當何所依？」維摩詰言：「菩薩於生死畏中，當依如來功德之力。」文殊師利又問：「菩薩欲依如來功德之力，當於何住？」答曰：「菩薩欲依如來功德力者，當住度脫一切眾生。」又問：「欲度眾生，當何所除？」答曰：「欲度眾生，除其煩惱。」又問：「欲除煩惱，當何所行？」答曰：「當行正念。」又問：「云何行於正念？」答曰：「當行不生不滅。」又問：「何法不生？何法不滅？」答曰：「不善不生，善法不滅。」又問：「善、不善孰為本？」答曰：「身為本。」又問：「身孰為本？」答曰：「欲貪為本。」又問：「欲貪孰為本？」答曰：「虛妄分別為本。」又問：「虛妄分別孰為本？」答曰：「顛倒想為本。」又問：「顛倒想孰為本？」答曰：「無住為本。」又問：「無住孰為本？」答曰：「無住則無本。文殊師利！從無住本，立一切法。」

**義理深入**：法師強調，此逆推鏈是〈觀眾生品〉——乃至整部《維摩詰經》——的大要：「你這一品推得出來，我恭喜你，整部《維摩詰經》的大要你已經抓住了」〔行78-79〕。它是一條「真如門→生滅門」再折回的路：先入本心之不生不滅（真如門），又「以身為本」重回生滅門度眾（生滅門），故此經是「性相不二、止觀不二」的圓滿究竟品〔行118-120〕。而「無住則無本、從無住本立一切法」是整鏈的樞紐——無住即無所住的真心本性，它「以無本為本」卻能立一切法，這正與《楞嚴》的「妙明真精妙心所變現」同一義；一切貪瞋癡、山河大地、乃至下文的天華與文字，都是「從無住本」所立的幻相〔行132-134, 880-882〕。

**完整經文（T0475，天女散花全段，逐字稿散引於行386-957）**：
> 時維摩詰室有一天女，見諸大人聞所說法，便現其身，即以天華散諸菩薩、大弟子上。華至諸菩薩，即皆墮落，至大弟子，便著不墮。一切弟子神力去華，不能令去。爾時天女問舍利弗：「何故去華？」答曰：「此華不如法，是以去之。」天曰：「勿謂此華為不如法。所以者何？是華無所分別，仁者自生分別想耳！若於佛法出家，有所分別，為不如法；若無所分別，是則如法。觀諸菩薩華不著者，已斷一切分別想故。譬如人畏時，非人得其便；如是弟子畏生死故，色、聲、香、味、觸得其便也。已離畏者，一切五欲無能為也；結習未盡，華著身耳！結習盡者，華不著也。」舍利弗言：「天止此室，其已久如？」答曰：「我止此室，如耆年解脫。」舍利弗言：「止此久耶？」天曰：「耆年解脫，亦何如久？」舍利弗默然不答。天曰：「如何耆舊大智而默？」答曰：「解脫者無所言說，故吾於是不知所云。」天曰：「言說文字，皆解脫相。所以者何？解脫者，不內不外，不在兩間；文字亦不內不外，不在兩間。是故，舍利弗！無離文字說解脫也。所以者何？一切諸法是解脫相。」舍利弗言：「不復以離婬、怒、癡為解脫乎？」天曰：「佛為增上慢人說離婬、怒、癡為解脫耳；若無增上慢者，佛說婬、怒、癡性，即是解脫。」舍利弗言：「善哉，善哉！天女！汝何所得？以何為證？辯乃如是！」天曰：「我無得無證，故辯如是。所以者何？若有得有證者，即於佛法為增上慢。」舍利弗問天：「汝於三乘為何志求？」天曰：「以聲聞法化眾生故，我為聲聞；以因緣法化眾生故，我為辟支佛；以大悲法化眾生故，我為大乘。舍利弗！如人入瞻蔔林，唯嗅瞻蔔，不嗅餘香。」

**義理深入**：法師特別點出，全段須「法界」的角度讀——天女是法界的示現、其散花亦是無為法界中的示現（無為法界不會變成有為之物，若有相亦是幻相令你顯發），不可誤解為真有一場實體天華灑落〔行458-462〕。花著不著的分判，指向本品第一義理：**維摩詰**與諸大菩薩「已入本心，本心是法界無所相，故不被相干擾」，聲聞乘因有對象（畏生死、有分別）而被相所著〔行966-969〕。至「言說文字皆解脫相」與「婬怒癡性即是解脫」，法師視為《維摩詰經》「又一高峰」、與《諸法無行經》「貪欲是涅槃」同一究竟義——三毒、文字、天華都是「從無住本」所立的幻相，知其為佛性所顯而不縛、又借之度眾，即入「不即不離」的本心〔行843, 966-969〕。

## 10. 法脈會通（法師的交叉引證網）

### 10-A 核心等式：性色真空 ＝ 色即是空 ＝ 因中色空

本講的思想樞紐是一條「同義鏈」，把家經與各旁徵串成一體：

```
   從無住本立一切法（維摩 T0475）
            │ 無住＝無所住之真心本性，能立一切法
            ▼
   性色真空（楞嚴）─────────┐
      性(心)產生色，色不離性  │ 同一義
            │                 ▼
   色即是空、空即是色（心經 T0251）
            │
            ▼
   因中色空（五燈會元 X1565 秦跋陀）
      眾微未聚之前＝能立法之性；竺道生只到「果上色空」
```

**連結要點**：竺道生的「空」＝現象界因緣所生的空（果上）；秦跋陀／楞嚴／心經的「空」＝能立一切法的真心本性（因中）。同一「空」字，層次天壤——這是全講反覆敲打的分水嶺〔行308-330〕。

### 10-B「婬怒癡性即是解脫」的四經互證

天女此句（維摩 T0475）由四處圓法共同照明：

| 維摩本句 | 法師援引 | 該引文如何詮釋本句 | ✓CBETA |
|---|---|---|---|
| 佛說婬怒癡性即是解脫〔行857〕 | 《諸法無行經》喜根菩薩偈 | 「貪欲是涅槃，恚癡亦如是」「菩提與貪欲，是一而非二」——三毒即佛性所顯 | ✓T0650 |
| 同上 | 《永嘉證道歌》 | 「無明實性即佛性，幻化空身即法身」——無明本性是佛性 | ✓T2014 |
| 同上 | 天台智者《摩訶止觀》 | 「貪瞋癡為菩提」；福薄之人於幻化中造罪，不得已修止觀以除三毒——對治屬漸次，圓頓則直觀三毒即佛性 | 法師轉述 |
| 離婬怒癡為解脫（對增上慢人）〔行857-859〕 | 《法華經》常不輕菩薩 | 平等視人人是佛（無增上慢）之反例對照 | ✓T0262 |

**連結要點**：對「增上慢人」（用功而無平等心）佛權說「離三毒」（漸次止觀、對治）；對「無增上慢」者佛實說「三毒性即解脫」（圓頓止觀、即幻即真）。權實二說，同出一佛〔行857-920〕。

### 10-C「文字皆解脫相」的性色會通

```
  解脫者（性・心）──不內不外不在兩間
        │  性色不二
  文字（色・相）────不內不外不在兩間
        │
        ▼  故「無離文字說解脫」「一切諸法是解脫相」
  真佛不說法 → 變現報化(幻化)佛 → 以娑婆最利之「語言文字」度幻化眾生
        （彌勒偈：應化非真佛，亦非說法者）
```

**連結要點**：舍利弗「沉默不答」是怕講出被糾正的「作意」；天女點破——文字是性所顯的色，講出來也是解脫相，不必離文字。真佛雖不說法，為度幻化眾生仍變幻化佛、用語言文字（娑婆以音聞為教體，故觀音耳根圓通）〔行773-819〕。

### 10-D 一塵不染 vs 無塵可染（聲聞／菩薩）

```
  聲聞乘：身是菩提樹，心是明鏡台，時時勤拂拭 → 一塵不染（有對象可修，染了又拂）
  菩薩：  本來無一物，何處惹塵埃          → 無塵可染（無所住，天女散花而不著）
```
**連結要點**：花著大弟子、不著諸菩薩，正是此二境界之別；六祖入本心得衣缽，與天女散花同一義〔行534-548〕。

## 11. 日常實踐

1. **碰到頑固的人，就是修習性的現場**〔行98-106〕：認為對方頑固是「我認為」；第一次任憑、原諒、包容最難，過了這一關，「肉也沒少一塊，還得輕鬆、得對方尊敬」，心量就撐大了。
2. **生氣的當下回本心**〔行888-892〕：聽到刺耳話要生氣時，覺知這一剎那的氣場、能量、現出的虛幻相「不真實」，當下就入本心——不必漸次、不必方便。
3. **端坐念實相，是名真懺悔**〔行350-352, 650-652〕：罪業是「你的觀念（色）」，拿不出來；把虛妄相回歸真心即空。一句佛號能滅重罪，是把「罪的色」融入本性——不靠宗教情操（情操必退轉），靠見地。
4. **心戒重於相戒**〔行440-457〕：相上戒隨環境變（不著華、穿染衣、緣來則應）；真正的戒是心不生分別（尸羅四義：清涼無煩惱、安穩、寂滅回本心）。
5. **不畏生死，五欲無能為**〔行491, 528〕：知生死是假（如影子胖瘦不必在意），則色聲香味觸不得其便。
6. **負能量要「拿出來」才能轉**〔行644-648〕：如車須開到修車廠；把煩惱（無形、本假）觀念一變即成虛空，「為什麼不做？」
7. **講經前把聽者視為佛**〔行713〕：「你沒把大家當作佛，怎麼教人成佛？」——這才是無增上慢。
8. **珍惜法緣、不可退轉**〔行169-173〕：如頭已洗、髮理一半須理完；此程度若退轉，再輪迴未必得人身、未必再聞法。
