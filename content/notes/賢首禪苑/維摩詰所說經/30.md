## 1. 本講概要

本講是〈觀眾生品〉的核心：文殊師利與維摩詰的**一段十二重逐層問答**，從「慈悲喜捨」一路逼問到「從無住本，立一切法」。體佛法師以此串起全經的中心命題——**既知眾生是幻，菩薩為何仍要度眾生？又如何度？**

法師的答案主線是：

1. **度幻眾生，須以「幻」的智慧度**——不是給物質，而是以「寂滅・無所生」的智慧告訴眾生「一切是幻」，令其除煩惱。此即「真實慈」，展開為**慈悲喜捨**四無量心（第29講講「慈」，本講講「悲・喜・捨」）。〔行227–289〕
2. **度眾生必入生死**——菩薩須示現色身、與眾生同受生死，故「當依如來功德之力，當住度脫一切眾生」。功德之力的具體操作，法師引《海慧菩薩所問經》的**五想・斷六事**加以落實。〔行338–465〕
3. **逐層逼問見本源**——文殊步步追問：善不善→身→欲貪→虛妄分別→顛倒想→無住→**無住則無本**。層層抽回到「無住的本心」，最後「從無住本，立一切法」——真空能現妙有。〔行559–744〕
4. **緣起即法身**——為印證「立一切法」，法師以三部冷門而深要的經典收束：**《造塔功德經》**的法頌舍利（緣生偈）、**《稻稈經》**的內外緣起（見緣起即見法，見法即見佛）、**《大日經疏》**的「法無自性，本無所起，猶如淨虛空」，並以**馬勝比丘→舍利弗→目犍連**因緣生偈得度的故事作眼目。〔行843–1159〕

貫穿全講的一句總持是開場所引**《楞伽經》**的四法——**空、無生、無二、（無/離）自性相**，法師謂「總攝一切佛及一切經典」。〔行31–98〕

## 2. 大綱

```
一、開場總持：《楞伽經》四法 = 一切經之總攝〔行31–98〕
   ├ 空（空有不二，真空妙有）— 鏡子喻
   ├ 無生（虛幻相非永恆）
   ├ 無二（能所不二，本是不二非修來）
   └ 無自性相（相皆虛幻，變化多端）
   └ 悟此四法 = 八地不動地菩薩智

二、觀眾生品核心問答：慈悲喜捨〔行100–297〕
   ├ 幻師作幻人 → 我/人/眾生/壽者 四相皆幻（承29講，接《金剛經》破四相）
   ├ 既幻,何必度? → 不度只入偏真涅槃（聲聞乘），大乘必度
   ├ 慈：以寂滅・無所生故（29講已講）
   ├ 悲：所作功德與眾生共之（引《永嘉證道歌》住相布施 vs 無為實相）
   ├ 喜：有所饒益,歡喜無悔（法喜非世樂）
   └ 捨：所作福祐,無所悕望（不求回報 → 入地菩薩）

三、德/得二字析義：無眾生則無德〔行297–337〕
   └ 拆「德」（雙人＝我與眾生）、「得」（寸＝心）→ 無所得而得真得

四、菩薩入生死的抉擇與資糧〔行338–520〕
   ├ 兩條路：往生淨土受訓 vs 有把握者直接倒駕慈航
   ├ 生死有畏 → 當依如來功德之力 → 當住度脫一切眾生
   ├ 《海慧菩薩所問經》五想（自=醫/法=藥/聞者=病/如來=善士/正法永住）
   └ 斷六事（嫉妒・自讚・舉人過・疲厭・吝法・吝財）

五、除煩惱的方法：正念 = 不生不滅〔行496–620〕
   ├ 度眾生 → 除其煩惱（非物質幫助,佛法非世間法戲論）
   ├ 正念 = 入法界（六祖：正=入法界,邪=入世間）
   ├ 不生不滅 = 不善不生,善法不滅（善≠善惡之善,＝入本心）
   └ 唯識轉識成智：第六意識分別 → 妙觀察智（五方五佛=阿彌陀）

六、十二重逼問：從無住本立一切法〔行559–851〕
   善不善→身→欲貪→虛妄分別→顛倒想→無住→無住則無本→從無住本立一切法
   └ 以身為本 = 菩薩須示現色身（維摩詰真病;耶穌釘十架;佛陀托缽）

七、緣起即法身：三經一疏收束〔行843–1159〕
   ├ 馬勝比丘→舍利弗→目犍連 緣生偈得度（故事）
   ├ 《造塔功德經》：身骨舍利 / 法頌舍利（緣生偈）
   ├ 《稻稈經》（不空譯）：內緣起 / 外緣起,見緣起即見法即見佛
   ├ 《雜阿含》：緣起法非我作非餘人作,法界常住,此有故彼有
   └ 《大日經疏》（一行記）：法無自性→本無生→猶如淨虛空
   └ 總歸：無住則無本 → 從無住本立一切法（本講功課）〔行1149–1162〕
```

## 4. 故事・公案

### 4-1 馬勝比丘・緣生偈──舍利弗、目犍連相繼得度〔行889–905〕

> **敘事（法師所述）**：佛在說阿含部時，要弟子背誦所講的「緣生法」，集起來的偈語稱為「緣生偈」。佛的一位殊勝弟子**馬勝比丘**背誦緣生偈甚有感受，成為開悟的聖僧。
>
> 當時有一位外道，號稱「一切外道之師」，身世顯赫、學問淵博的婆羅門，公認外道中「智慧第一」——他就是後來佛十大弟子中**智慧第一的舍利弗**。舍利弗有一天遇見馬勝比丘，馬勝比丘為他說「緣生偈」；舍利弗一聞，「非常契心、非常感動」，當下悟道而**得淨法眼**。
>
> 舍利弗問：「這偈是你自己悟的嗎？」馬勝比丘答：「這是我的老師（釋迦牟尼佛）悟到而教我們的。」舍利弗說：「能講出這句話的，我要稱他世尊；他若沒講這番話，我沒辦法得淨法眼。」於是他步行去見佛陀，以佛為師、求剃度，成為尊者舍利弗，加入僧團為首列比丘之一。
>
> 舍利弗有位能示現神通的好朋友**目犍連**，很懷疑：「你公認智慧第一，為何拜這個人為師？」舍利弗便為他說緣生偈，目犍連一聽**掉了眼淚**，說「這才是宇宙真相」，要舍利弗帶他去見佛陀。佛見他，知是「數世的因緣」，為他剃度。舍利弗與目犍連從此成為佛陀教團的兩位首要人物——「他的道理就是從緣生偈而來」。

- **意義**：法師以此故事點出——一句「緣生偈」即能令智慧第一與神通第一者言下得度，正是本講「見緣起即見法」的活證。
- **核驗**：舍利弗因聞馬勝（阿說示，Aśvajit）比丘說緣起偈而得法眼、目犍連隨之出家，為佛傳共說；緣起偈「諸法從緣生…」見多部律經（如《四分律》等）。故事情節屬佛傳/律傳，判 ✓（傳承相符，非單一經文可框限）。

### 4-2 商朝以人祭神為「大善」──世間善隨時代變〔行586–594〕

> **敘事**：法師（自言「我學歷史的」）舉：三千多年前夏商周的「善」與今日不同。商朝人「最高尚的思想就是祭拜祖先」（中國祭祖之俗即從殷商來）；更遠古祭祖靈**用人**——「殺人祭神是最高禮」，在當時「那個時代是大善者」。此風一直到孔子時代才被摒棄，改以牲畜（羊牛豬等五牲）代替；到今天又提倡拜素、拜水果。

- **意義**：同一件事，不同時代不同想法——證「世間善是隨時間會改變的」，故佛法所講「不善不生」的善不是善惡之善，而是「入本心／不入本心」。**永恆不變者才值得學，即佛法。**〔行594〕

### 4-3 耶穌被釘十字架──菩薩忍眾生不能忍之苦〔行676–680〕

> **敘事**：法師論「菩薩必示現色身、與眾生同受生死、且比任何眾生更激烈地經歷苦難以感動眾生」時舉：耶穌示現當時人世間最大的酷刑，「是菩薩的再來人，不要有宗教上的束縛」。被釘十字架時說「天父啊，用我的血洗刷眾生的罪惡」，其心完全在眾生。若一個傳遞正道者被釘時「呼天搶地、請饒恕我」，「算什麼菩薩」——真正菩薩是「忍眾生不能忍的苦」，這是身教的示範。

- **意義**：與維摩詰「真的生病」、佛陀「示現托缽・空無所有」並列，說明「以身為本」——**唯有同身，才能感同身受地度化有身的眾生**。〔行680–688〕

### 4-4 一行大師──世間天才與《大日經疏》〔行1097–1107〕

> **敘事**：法師介紹《大日經疏》作者一行大師：他是能通金剛界與胎藏界兩者的大師，世間法也是天才——「1952年的那個行星（小行星）是用一行大師的名字來命名」，他當時已算出行星運作、算出地球到行星的高度，是中國第一個把國土面積測量出來的人。唐玄宗要試他，他自謙「我沒什麼才華，可是過目不忘」；玄宗把宮中冊子（連太監的冊子）讓他翻過一遍，他「一字不漏」地背出，令皇帝感動。晚年他為《大日經》作疏，即《大日經疏》。

- **意義**：法師以此鋪陳《大日經疏》「緣起性空」一段的份量與可信；並提唐武宗毀佛致密法在中國失傳、賴空海大師帶到日本。〔行1092–1094〕
- **核驗**：《大毘盧遮那成佛經疏》確為唐・一行記 ✓ CBETA T1796。一行（俗名張遂）為唐代天文曆算家（造《大衍曆》），史載其博聞強記，與敘述相符。

### 義理深入

**（一）四無量心以「寂滅慈」為體，慈悲喜捨是一事之四面。** 法師強調：慈（29講）是「以寂滅、無所生故」告訴眾生一切是幻；悲是把此智慧「與眾生共之」；喜是眾生因此得饒益而生的「歡喜無悔」；捨是這一切「無所悕望、不求回報」。四者不是四種行為，而是同一顆度化心的四個側面——「第一個慈放在最前面…寂滅就是我們的本心本來寂滅，而得悲喜捨、無所生故」。〔行317–319〕能如此即「入地菩薩」。〔行289〕

**（二）「德」與「得」的拆字，是「無眾生則無佛」的漢字印證。** 法師以「德」從「彳（雙人）」——「依靠在兩個人：我跟眾生」，說明沒有（假的）眾生就沒法回歸本心成德；「得」的「寸即心也」（方寸＝心），故真得是「無所得而得」的回歸本性之得（即《心經》「以無所得故」）。此拆字服務於§8第5句「當住度脫一切眾生」的義理：**菩薩之德、佛之成就，皆繫於眾生。**〔行297–331〕

**（三）十二重逼問是一條「妄盡還源」的下溯與回歸。** 法師點明問答有一個「很重要的轉折」：前段（1–9）由本心順講到不生不滅、慈悲喜捨；第10句「以身為本」起，忽然「抽回來」到有身的現實面，再一路下溯：身→欲貪→虛妄分別→顛倒想→無住→無住則無本。「中間省略，直接回到本心」。〔行731〕最後「從無住本立一切法」再從真空現妙有——**下溯到底是無明的根（無住即本心），回歸則是本心能生萬法。** 法師以《六祖壇經》「何期自性本自清淨…能生萬法」、《證道歌》「無明實性即佛性，幻化空身即法身」印證，並直指**「煩惱即菩提」是同一件事**——「波浪就是大海」，不是修到斷煩惱，而是見地上知煩惱是虛幻相、不受干擾，當下即回歸本心。〔行771–815〕

**（四）「無住則無本」＝《華嚴》自性清淨圓明體，不可再問。** 法師收束：無住是「最後一關」，「已經沒有再本下去」，即《妄盡還源觀》的「自性清淨圓明體」，其本源「你不能再問下去」。而它的體用是「海印森羅常住用」——鏡子當下即現影像，法爾如是、無時不刻。真空（無住本心）一定示現妙有（森羅萬象），此即「從無住本立一切法」。〔行858–876〕

## 10. 法脈會通

### 10-1 「從無住本立一切法」的跨經印證網（本講中心）

```
                《維摩詰經》〈觀眾生品〉
                無住則無本 ── 從無住本 ── 立一切法
                （真空／本心）      （現妙有／森羅萬象）
        ┌───────────┬───────────┬──────────┬──────────┐
   《六祖壇經》    《證道歌》     《華嚴經》    《稻稈經》   《大日經疏》
  何期自性本自清淨  無明實性即佛性  自性清淨圓明體  見緣起即見法  法無自性→本無生
  能生萬法        幻化空身即法身  海印森羅常住用  見法即見佛    →猶如淨虛空
  （本心能生一切） （幻身即法身）  （體用一如）   （相即法身）  （緣起即空即本心）
```

**連結要點**：五處引文都在說同一件事——**真空（無住／本心）能現妙有（一切法），而妙有無自性、當下即真空。** 法師的推法是：一切法→顛倒想→…→無住則無本（下溯到本心），再「從無住本立一切法」（本心現萬法）；煩惱即菩提（波浪即大海），非修斷而是見地。

| 維摩本句 | 法師援引 | 該引文如何詮釋本句 | 核驗 |
|---|---|---|---|
| 從無住本立一切法 | 《六祖壇經》何期自性…能生萬法 | 「無住」即自性、本心，能立一切法 | ✓ T2008 |
| 立一切法（現妙有） | 《證道歌》無明實性即佛性、幻化空身即法身 | 一切法（幻化空身）當下即法身 | ✓ T2014 |
| 無住則無本 | 《華嚴》自性清淨圓明體、海印森羅常住用 | 無住是本源不可再問，其用是常住現森羅 | ✓（《妄盡還源觀》體用；一切唯心造 T0279） |
| 立一切法＝緣起 | 《稻稈經》見緣起即見法即見佛 | 森羅（緣起相）即法身佛 | ✓ T0710 |
| 無住＝空＝本心 | 《大日經疏》法無自性→本無生→淨虛空 | 緣起無自性即空，淨虛空喻不動本心 | ✓ T1796（撮意，見E30） |

### 10-2 唯識轉識成智・五方五佛（除煩惱的操作結構）〔行604–614〕

法師講「不善不生」的操作時，帶入金剛界轉識成智——這是結構性教學，保留其對應軸：

```
   前五識 ── 第六意識 ── 第七意識(末那,我執) ── 第八識(阿賴耶)
     ↓轉        ↓轉           （四大煩惱常相隨）        ↓
  成所作智    妙觀察智      （不讓它加入即不我執）    大圓鏡智
  不空成就如來 阿彌陀如來                            阿閦如來
                （寶生如來＝平等性智）
```

| 識 | 轉成之智 | 五方五佛 | 本講用途〔行〕 |
|---|---|---|---|
| 第六意識（分別） | 妙觀察智 | 阿彌陀如來 | 分別不加我執＝妙觀察智＝「一句阿彌陀佛」＝阿彌陀功德〔行604, 614〕 |
| 第七意識（我執） | 平等性智 | 寶生如來 | 我執令煩惱；不加入即不煩惱〔行606, 608〕 |
| 第八識 | 大圓鏡智 | 阿閦如來 | 〔行606〕 |
| 前五根 | 成所作智 | 不空成就如來 | 〔行606〕 |

**連結要點**：「不善不生，善法不滅」的實修＝把第六意識的「分別」轉成「妙觀察智」（觀察紅是紅、飯不是沙，但無愛憎取捨、無我執）——妙者「凡所有相皆是虛妄」，即一句阿彌陀佛，即阿彌陀如來功德。這正是「去西方修什麼？就修這個、訓練這個」的內涵。〔行610–614〕

### 10-3 內緣起／外緣起（《稻稈經》結構）〔行990–1027, 1033–1045〕

```
   外緣起（身外無情器物：山河大地、鋼杯、富士山、AI/奈米）
      │  此有故彼有 · 因緣和合而生、因緣離散而滅
      ▼  入本心
   內緣起（六根出→接觸六塵→現象界）  ← 此有故彼有(想到即現)、此無故彼無
      │  本來無心 → 一念不覺生三細(振動) → 有心 → 有六根 → 觸六塵(＝法)
      ▼
   凡夫：認六根為「我」(人我)、認六塵為「法(我)」→ 十足眾生
   菩薩：六根非我(人無我)、六塵非我(法無我) → 無我＝無生法忍
      → 通達無我法者即是菩薩摩訶薩（《金剛經》二次印證）
```

**連結要點**：外緣起一入本心即成內緣起，這是「法爾如是」非修來（雜阿含「非我作非餘人作，法界常住」）。凡夫把六根當我、六塵當法我；菩薩證人無我、法無我即見法身——「見緣起（相）即見法（法身），見法即見佛」。故《稻稈經》的結論「內外緣起不分」與《金剛經》「通達無我法者即真是菩薩」相扣。〔行1069–1079〕

## 11. 日常實踐

1. **煩惱現前，先「拿出來看」。** 法師的禪宗最究竟法：你說煩惱到受不了，「你拿出來給我看」——根本拿不出來，可見是假；煩惱不是延續性而是片段性（如底片可抽掉），一抽即轉念。〔行52–58〕
2. **用二十二祖偈轉念、亦作臨終正念。** 「心隨萬境轉，轉處實能幽，隨流認得性，無喜亦無憂」——不是唸文字，是用本心去觀、與本心相應；配《華嚴》「一切唯心造」，臨終記得即不墮三惡道、發願即生淨土。〔行60–70〕
3. **行慈悲喜捨的自我檢查。** 慈（以寂滅智告訴眾生一切是幻）／悲（功德與眾生共之）／喜（眾生得饒益而歡喜無悔）／捨（無所悕望、不求回報）——「你這一生在做什麼，有沒有符合？」〔行291–293〕
4. **度眾生是「除其煩惱」，不是給物質。** 物質救濟是世間善、可讚歎，但別把它當菩薩志願而混淆佛法與世間法。〔行509–517〕
5. **五想安身（生死有畏中的資糧）。** 把自己當醫生、佛法當藥、聞者當病人、如來當善士、令正法永住——如來功德之力即由此顯。〔行401–416, 457〕
6. **斷六事（尤其戒律要義）。** 不嫉妒（怕人勝我）、不自讚功德、不舉人之過（斷人慧命是無間果報）、不疲厭（數數宣說）、不吝法、不吝財。〔行420–465〕
7. **正邪一線：入法界為正，入世間為邪。** 一切你關注、在意、執著的都是影像（邪）；差之毫釐失之千里，決定這輩子修佛成不成。〔行529–543〕
8. **「一句阿彌陀佛」的正解。** 不必執定要唸出聲——見地上知「六塵全是影像、干擾不了我」，當下即阿彌陀佛（妙觀察智）；口念心散亂則枉然（蕅益／中峰之意）。〔行549–554, 614〕

## 12. 延伸・參

- **前後講**：承第29講（〈觀眾生品〉開端「眾生如幻」與「真實慈・寂滅慈」）；本講止於「從無住本，立一切法」，**天女散華段留待第31講**。〔行140, 1149–1162〕
- **本講三經一疏（可延伸研讀）**：《造塔功德經》T0699（法頌舍利）、《稻稈經》T0710（內外緣起）、《雜阿含》T0099（緣起法界常住）、《大日經疏》T1796（緣起性空）。
- **參問**：既然「無住則無本」——本心不可再問其本源，那麼「一念不覺」如何從無本的本心「振動」而起？法師以「本來無心，因有振動（一念不覺生三細）而有心、有六根」〔行1039〕作答；試就此參：**若本心無本、法爾如是，「不覺」是有始還是無始？** 這正是「從無住本立一切法」留給修行人的活句。
