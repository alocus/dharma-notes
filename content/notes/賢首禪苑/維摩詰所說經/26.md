## 1. 本講概要

本講進入《維摩詰經》第六品〈不思議品〉的開頭。體佛法師先以三講的篇幅回顧全經前五品的結構（心淨國土淨→弟子品→菩薩品→文殊問疾品），再引**黃檗禪師《傳心法要》**的一段話，說明文殊、普賢、觀音、勢至、維摩詰五位大士「皆是表法」，其本德「皆在每個人一心當下」〔行28-93〕。

主文從**〈不思議品〉開篇**切入：文殊所將八千天子發菩提心後，舍利弗見室中無床座，起念「這麼多菩薩弟子當坐何處」；維摩詰「知其意」（不待舍利弗開口，此即「不思議」），反問「仁者為法來耶？求床座耶？」由此逼出全講的核心命題——**什麼是「求法者」**〔行99-133〕。

維摩詰以一連串「非有…之求／不著…求／非求法也」的遮遣句，層層剝除：非求五蘊、非求界入、非求三界、不著佛法僧三寶、無求四聖諦、法無戲論、法名寂滅／無染／無行處／無取捨／無處所／無相／不可住／不可見聞覺知／無為——結穴於「於一切法，應無所求」〔行330, 566, 628, 699, 860〕。

體佛法師在遮遣之間，橫向引入大量教證以詮「什麼叫法」：**羅什大師**釋「解脫＝應念即成」、「不思議＝能然而不知所以然」；**僧肇大師**釋「解脫＝自在心」；**永嘉《證道歌》**「心是根、法是塵」；**彌勒《辨法法性論》**「虛妄分別、見二及名言、惟計分別」；並自創「**一棵樹**」的譬喻（樹根＝覺性／佛性、樹幹＝覺知／一心、樹葉果實＝千差萬別的念），會通慧遠「執一守中」、法化報三身、念佛回歸本心〔行142-534〕。末段補入**《入如來德智不思議境界經》**文殊為除蓋障菩薩說的「勝解五法」（空／無生／無滅／無對治／不可記說），並以**《六祖壇經・定慧品》**「無念」「臥輪—惠能偈」「見聞覺知不染萬境」收尾，最後埋下伏筆：維摩詰將問文殊「何等佛土有好上妙師子之座」，留待第27講〔行703-1040〕。

**貫串線**：全講只講一件事——**求法者「於一切法應無所求」**；而「應無所求」的所以然，就是「法本來如是（法爾如是）、法無二元、法即一心之顯現」，故不待「求」、不待「修」，唯待「勝解／頓悟」。

## 4. 故事・公案（全敘）

### 4-1 三祖僧璨—四祖道信「誰縛汝」〔行155-158〕
體佛法師以此證「解脫＝應念即成」。當年的道信對三祖說：「有東西綁住我。」三祖連看也不看他一眼，走過去只丟一句：「**誰綁你？**」道信當下開悟。師點出：沒有實際的東西綁住你（心是綁不了的），束縛只是「我心所現的影像」，一旦了知它是影像，「應念即成」，一念頓悟的當下就解脫了——「誰綁我們？自己綁自己啊」。
- 屬性：禪宗傳承公案。體佛法師稱「三祖—道信」；按禪宗燈錄，此「誰縛汝」對答的定型版本傳為**四祖道信參三祖僧璨**（另有僧璨參二祖慧可「乞和尚為我懺罪／將罪來與汝懺」的同型公案）。※公案定型於燈錄（如《景德傳燈錄》），非CBETA T-series根本經，故不列入經證核驗表。

### 4-2 慧遠「執一守中」・道安命為首座〔行438-450〕
體佛法師講淨土宗初祖慧遠的開悟因緣。東晉五胡十六國之際，高僧輩出：先有**佛圖澄**（浮圖澄），為菩薩再來、專現神通，因當時石虎、石勒等君王暴虐，不得不以神通阻其殺戮、救中國許多人；佛圖澄示現涅槃時囑弟子「神通只為適當時機而用，往後仍要以法為要」——故有**道安**大師出。道安弟子甚多，其中**慧遠**出家才三年，道安卻命他「為上座（首座）」向師兄們講法。眾人不服：「憑什麼？出家三年，又在古代嚴格戒制之下！」道安答：因為慧遠已能講出「**執一守中**」——他已入本心了。師釋：慧遠已知一切千差萬別的分別相，都是從「覺知的樹幹」引生；而入本心覺知之心「是無量壽、是無量光」，即阿彌陀佛，故慧遠提倡淨土、持名念佛，就是要時時保住「執一守中」的這一顆本心。
- 屬性：淨土宗史傳/禪門公案（歷史人物：佛圖澄、道安、慧遠）。※史傳非經典，不列經證核驗。

### 4-3 老子「三士聞道」〔行541-562〕
體佛法師引《道德經》分三根器：**上士聞道，勤而行之**（上根者聽到本心圓滿法，當下入本心，時時警惕、日日而行）；**中士聞道，若存若亡**（把它種在腦子裡，仍用大腦，「一歷耳根，永為道種」，偶爾才拿出來用）；**下士聞道，大笑之**（「無稽之談！」不屑一顧）。並以孔子「**朝聞道，夕死可矣**」印證上士——一旦聞道，本來就是本心、平等無差別，便不再在意虛幻的生命。師感嘆末法之世下士居多，然只要能點醒一人覺性，「無盡燈」便能再點醒無量人。
- 核驗：老子語 ✓ 見於 T2103《廣弘明集》所引；孔子語為《論語・里仁》，非佛典。

### 4-4 六祖—陳惠明「不思善不思惡」〔行694〕
師以此證「回歸覺性則一切平等」。陳惠明將軍跪求六祖：「仁者，能否教我一招回歸本心？」六祖只講一句：「**不思善，不思惡，正與麼時，那箇是明上座本來面目？**」師釋：一落入「什麼是善、什麼是惡」的固執，便害己害人；回歸一心，樹葉萬般顏色興衰皆不離本心，一切平等。
- 核驗：✓《壇經》T2008（另《無門關》T2005亦錄此公案定型句）。

### 4-5 臥輪偈 vs 惠能偈〔行937-940〕
師講「真如能起念，故不能斷念」時舉此。臥輪禪師自陳：「**臥輪有伎倆，能斷百思想**」——其修法是斷念，因念妨礙他。惠能立即反破：「**惠能沒伎倆，不斷百思想**」——因真如自性本能起念、起相用，是自然現象，「你要斷什麼？」
- 核驗：✓《壇經》T2008，行357-365。原偈：「臥輪有伎倆，能斷百思想，對境心不起，菩提日日長」／「惠能沒伎倆，不斷百思想，對境心數起，菩提作麼長」。

### 4-6 畢陵伽婆蹉「無痛痛覺」〔行953-957〕
師講「不染萬境」的實證，舉《楞嚴經》二十五圓通中畢陵伽婆蹉：他乞食途中被毒刺傷足，舉身疼痛，卻由此覺悟——「**雖覺覺痛，覺清淨心無痛痛覺**」（師口語作「有覺覺痛…可是無痛痛覺」）：身體再怎麼痛，傷害不了覺性；身痛心不痛。師以自身重病現身說法：得癌症身痛，而心之覺性不痛。
- 核驗：✓《楞嚴經》T0945行722。師之口語為paraphrase，詳見§9。

### 義理深入（依維摩本文之脈絡）

**（一）床座之問即「不思議」的當機示現。** 體佛法師特別點出「作是念…知其意」的張力：舍利弗因悟「開口便錯、動念即乖」而寧可只在心裡起念，不料維摩詰「知其意」——不待言語即知其心，這正是本品名為「不思議」的第一個當機示現：**心與心之間不假名言的直接照了**。於是「什麼是求法者」不是抽象論題，而是從一個具體的「無床座、當何坐」的窘境逼出來的——維摩詰把一個「求座」的世俗念，翻轉成「求法」的究竟問〔行119-133〕。

**（二）九重遮遣是一條「由粗到細」的剝除鏈。** 維摩本文的遮遣有內在次第：先遮身心之最粗者（軀命→五蘊→界入→三界，此四者皆「有為的存在」層層擴大同一虛妄）；次遮宗教修證之所依（三寶→四聖諦，此二者是行人最易「著」的神聖對象）；再遮法性本身的九個面向（寂滅/無染/無行處/無取捨/無處所/無相/不可住/不可見聞覺知/無為）。體佛法師的貫串點是：**每一句「若行…是則…非求法也」的句式，都在說「法本來已是如此，你再去求／行／著一個，就是頭上安頭」**——故結穴必然是「於一切法應無所求」〔行578-702〕。

**（三）「應無所求」與「而生其心」是一體。** 全講最深的一著在末段：維摩詰剛講完「應無所求」，立刻問文殊「何佛土有好上妙師子之座」——體佛法師把它扣回《金剛經》「應無所住而生其心」：**無所住（＝無所求）不是死寂斷滅，而正是妙用（問座、取座、神變）得以自在生起的前提**〔行990-992〕。這就把〈不思議品〉的「遮」（應無所求）與其後的「顯」（取須彌燈王佛座的不可思議神變）接成一氣——遮遣到底，才有真正的妙有神變。這也是師預告27講「不可思議」神變的伏筆所在〔行1006-1018〕。

**（四）五百天子得法眼淨的定位。** 師特別揀別：得法眼淨的是「天子」而非菩薩——因菩薩本來法眼淨，不足為奇；天子在聽眾中層次最低（仍在三界、屬天道），連他們都因「不著佛法僧、無求四聖諦、應無所求」這番純大乘遮遣而得法眼淨，正反顯此法「不待修一個什麼、不待布施持戒禮拜，只把純本心法講完，天子即得法眼淨」的殊勝〔行1030-1034〕。

## 10. 法脈會通（連結圖）

### 10-1 「什麼是法」——三家詮釋會通同一「一心」

```
                     ┌───────────────────────────────┐
                     │   維摩詰：求法者「於一切法應無所求」  │
                     │        （法本來如是，故不待求）      │
                     └───────────────┬───────────────┘
        ┌───────────────────────────┼───────────────────────────┐
   永嘉《證道歌》                 起信論（馬鳴）                 彌勒《辨法法性論》
   心是根・法是塵                法＝眾生心                    法相＝虛妄分別
   （能現／所現，鏡上痕）       （法即是心）                 見二及名言・惟計分別
        │                            │                            │
        └──────── 皆歸：法是「一心（覺知）」之顯現，能所不二 ─────────┘
                                     │
                          羅什：解脫＝應念即成 ／ 不思議＝能然而不知所以然
                          僧肇：解脫＝自在心（心本無礙）
```
**連結要點**：三家（永嘉/起信論/辨法法性論）詞異而旨同——**法皆是「一心」之所現，能（心）所（法）不二**；故「求法」不是向外攀求一個對象，而是回歸能現的一心。

### 10-2 「一棵樹」總譬——會通覺性・念佛・三身・唯識

```
      千萬樹葉·果實（春夏秋冬變化萬千）
        ＝ 念念成形·差別相（彌勒：惟計分別／六粗：智相→相續→執取→計名字→起業→業繫苦）
        ＝ 凡夫「計」在此，故輪迴          ← 大腦（六·七二識：分別·我執）
                    ▲
                    │ 一→多
      ┌──────── 樹幹（唯一支）────────┐
      │   ＝ 覺知 ＝ 一心 ＝ 般若智      │  ← 慧遠「執一守中」；一心不亂；都攝六根
      │   ＝ 阿彌陀佛（無量壽·無量光）   │  ← 念「南無阿彌陀佛」＝回歸樹幹
      │   ＝ 報身（盧舍那）             │
      └────────────┬──────────────┘
                    │ 性現心
              樹根（覓之不可得而能現百界千如）
                ＝ 覺性 ＝ 佛性 ＝ 毘盧遮那 ＝ 法身
```
**連結要點**：樹根（覺性/法身/毘盧遮那）→樹幹（覺知一心/報身/阿彌陀）→樹葉（差別念/化身/釋迦）——**法化報三身同一身**（蓮花生）；早課「供養清淨法身毘盧遮那佛、圓滿報身盧舍那佛、千百億化身釋迦牟尼佛」即此。修行即「當大腦念頭起，當下回歸樹幹（覺知/南無阿彌陀佛/準提咒三密相應）」，則差別相自落〔行456-536〕。

## 11. 日常實踐

1. **當念頭起，當下回歸「樹幹」**：不在樹葉（差別相）上做文章，一起心動念即回到「覺知的一心」——口訣即「南無阿彌陀佛」（無量壽光即本心），或結準提印、誦準提咒（三密相應：身印＋咒音＋覺知），久之成習則自然回歸〔行520-536〕。
2. **看破→放下（止觀）**：觀＝看清楚真相（相皆虛幻、影像干擾不了我）；止＝放下。煩惱皆自找，皆「我心所現的影像」，了知是影像即「痕垢盡除」〔行81-85, 149-153〕。
3. **不中第二支箭**：身痛時，覺知「有覺覺痛，而覺性無痛」——身痛而心不隨之痛，不讓身痛引出心痛（畢陵伽婆蹉之證）〔行953-957〕。
4. **見聞覺知而不染萬境**：六根照常起用（該想就想，念是「用」不是要斷），但不被覺受牽走——「真性常自在」；不斷百思想，而不執百思想〔行217-219, 939-959〕。
5. **以「勝解」代替「修到」**：不必「修到空/無生/無滅」——你本來就空、就無生；承擔「本自具足」，不自輕「我做不到、太深了」〔行753-760〕。
6. **不斷人慧命**：對「講本心法者」不可故意擴大其缺點令眾知（斷人慧命，罪不可赦）；能記說解脫之法者，應助人助己〔行820-826〕。
