## 1. 本講概要

本講是「一個關節、兩品交接」的一堂課。**關節是「意生身」**——體佛法師承第28講，把〈不思議品〉的真正結論鎖定在此：為什麼舍利弗坐不上須彌座？因為他尚未入意生身。法師依《楞伽阿跋多羅寶經》佛說「三種意生身」（三昧樂正受／覺法自性性／種類俱生無行作）建立一條**修證次第**，並反覆對比「意生身（以智為身，菩薩身）vs 靈魂（以五蘊為身，凡夫身）vs 法身（無相本體）」三層。〔行11–248〕

由此讀完〈不思議品〉末段：**十方作魔王者多是住不可思議解脫菩薩**，以方便力乞人手足耳鼻乃至妻子珍寶，「往試之，令其堅固」；凡夫下劣不能如是，「譬如龍象蹴踏，非驢所堪」。法師以〔密勒日巴〕受馬爾巴折磨、以及現代「得癌症＝意生身菩薩的考驗」印證：**魔即本心之鏡，外無真魔**。〔行316–505〕

後半進入**第七品〈觀眾生品〉**：文殊問「菩薩云何觀於眾生」，維摩詰答「譬如幻師見所幻人」，一連串「如水中月……如無因之火」的幻喻，結穴於「眾生如幻」。法師以《金剛經》「實無眾生得滅度者」、彌勒「廣大第一常」四心、乃至量子物理學之父普朗克「宇宙母體＝振動＝心相」來會通「眾生是虛幻的概念」。〔行506–690〕再答文殊「云何行慈」——**行真實慈者，即為如幻眾生說「眾生如幻」之法**，並以《涅槃經》雪山童子捨身求「生滅滅已，寂滅為樂」的故事解「寂滅慈」，以《成實論／瑜伽師地論》「屍羅四義（清涼‧安穩‧安樂‧寂滅）」解「不熱慈」，以大珠和尚《頓悟入道要門》會通六度波羅蜜皆歸「俱捨／無所起／無所念／離相／無所住／遠離戲論」，收於「慈悲喜捨」四無量心皆是入本心。〔行801–1431〕

一句話貫串全講：**大小空間、長短時間之所以不二，唯意生身做得到；而入意生身的第一關，只是「一切唯影像→入三昧樂正受」。**

## 4. 故事・公案

### (1) 馬爾巴折磨〔密勒日巴〕，示現「魔王」以堅固弟子〔行434–442〕
法師以此印證「住不可思議解脫菩薩……現作魔王……令其堅固」。二世紀（法師語，藏傳實際為十一世紀，見§5）西藏大譯師馬爾巴尊者，門下上根弟子多得傳法，**唯獨〔密勒日巴〕什麼都不教**，只叫他蓋房子。古代無器具，〔密勒日巴〕從山下推石塊上去，蓋成一座房，馬爾巴二話不說全部摧毀，命他重蓋；第二次、第三次、第四次，十多年間所蓋的房子全被摧毀，**〔密勒日巴〕連一句埋怨都沒有**。最後馬爾巴傳他大手印，噶瑪噶舉之法成就，〔密勒日巴〕遂成藏傳佛教極重要的傳承。法師的收攝：「以當時看，大家都覺得馬爾巴不是魔王嗎？只有魔王才會做這種事——可是他折磨〔密勒日巴〕的心，讓他沒有任何懷疑。」這正是「往試之，令其堅固」的活例。〔行434–442〕

### (2) 雪山童子捨身求半偈「生滅滅已，寂滅為樂」〔行1050–1114〕
出《大般涅槃經》聖行品（✓ CBETA T0374），法師用以解「行寂滅慈」。往昔一劫，有婆羅門修行者名雪山童子，為求正道入雪山苦行，日食極少，以鹿皮禦寒。一日忽聞空中一聲：「**諸行無常，是生滅法**」，童子聞此半偈心生大歡喜，四向顧視，唯見一相貌極醜陋的羅剎。童子想：能講此偈者必曾供養無量諸佛、受諸佛教真理，「凡所有相皆虛幻，不可以相取人」，遂勇敢問羅剎其餘半偈。羅剎云自己飢餓已久，唯食人肉、飲人熱血方能溫飽；童子即發願：只要你說完後半偈，我當以此身供養你食。但要求先說偈、且容他把偈刻在不磨滅的岩石樹木上（令正法永住），再受身。羅剎乃說：「**生滅滅已，寂滅為樂**」。童子刻偈已，脫衣自投樹下獻身，將墮之際，羅剎現出原形——原來是大梵天子（釋提桓因），於空中接住其身，稽首懺悔：「我為考驗你真實善根故示現此相。」由此舍身之行，雪山童子的功德超越同修的彌勒菩薩，先成賢劫第四尊佛——**那雪山童子就是今日的世尊釋迦牟尼佛**。法師點題：這就是佛的最後遺教，也是「寂滅」二字最詳盡的出處。〔行1050–1114〕

### (3) 大象戴瓔珞、羅漢托空缽（有福無慧）〔行1008–1016〕
法師以此公案說「智慧才是最重要」。某國王有一頭座騎大象，人人見之行禮，因牠是國王的坐騎。另有一位阿羅漢，與這頭大象前世本是師兄弟。這位阿羅漢當年是自了漢、未曾布施，卻有智慧、破了身見而證阿羅漢；而那位師兄弟當出家人時一直布施供養、卻無智慧，命終投胎為大象。**故「大象戴瓔珞，羅漢托空缽」**——阿羅漢出去托缽沒人供養（因前世未布施），大象披瓔珞受人禮敬（因前世多布施），但畢竟一為畜生、一為聖者。阿羅漢去告訴大象前世因緣，大象聽後撞壁而死。收攝：布施得福、無慧墮畜（三惡道之「有福報者」）；「純情即墮」，唯智慧能了生死。〔行1008–1016〕

### (4) 佛因忍辱先於彌勒成佛（歌利王割截身體）〔行151–156〕
法師以此說「長處於三毒、長養於白法」。本彌勒佛應先成佛，但釋迦於某一劫被歌利王割截身體，「無我相、無人相、無眾生相、無壽者相……不生瞋恨」，憑此忍辱功德，遂超越彌勒菩薩，成為賢劫第四佛（彌勒為第五）。所引《金剛經》經文 ✓ CBETA T0235。〔行151–156〕

### 義理深入

**魔王試菩薩——「令其堅固」是全段的樞紐。** 法師把〈不思議品〉這末段讀成一堂「境界考」：菩薩觀眾生如幻在後，但先要能經得起「乞手足乃至妻子珍寶」的逼迫。他刻意把經文的古代清單（象馬車乘、金銀琉璃）翻譯成當代（賓士車、存款、房產、配偶），目的不在文學，而在讓聽者親自對號入座——**你放不放得下，不是理論，是實際做做看**。而「非驢所堪」一句被法師讀成一條戒律式的界線：這是大菩薩的方便門，凡夫力量不夠不可效尤（你討人一個腦要還幾個腦？）。最後以「夫如者不二不異」（本屬〈彌勒章〉，法師在此借用）點出**魔所作、人所受皆假，故無因果可畏**——這是意生身菩薩的智慧，不是凡夫可援引的免責。〔行316–505〕

**觀眾生如幻——「多出一個不存在的」是法師的統一讀法。** 維摩詰那一長串幻喻，法師沒有逐一訓詁，而是抓住一個結構：每一喻都是「在本有的數目上多安一個根本不存在的」——第六陰（本五蘊）、第七情（本六情）、十三入（本十二）、十九界（本十八）、無色界之「色」、須陀洹之「身見」、阿羅漢之「三毒」。**多出來的那一個，正如「眾生」這個概念本身：本無，卻被執成有。** 由此他接《金剛經》「實無眾生得滅度者」與「眾生眾生者，即非眾生，是名眾生」，把〈觀眾生品〉的「如幻」與《金剛經》的「破四相」焊成一體，再引普朗克「宇宙＝振動＝母體（心相）」作科學旁證——**一切唯心所現，無一真實，故眾生如幻**。〔行506–690〕

**行慈——真實慈的內容竟是「告訴眾生：你是幻」。** 這是本講最反直覺、也最核心的一轉：文殊追問「眾生既假，如何行慈」，維摩詰答「菩薩作是觀已，自念我當為眾生說如斯法，是即真實慈也」。法師把「如斯法」明白點成「說眾生就是如幻」這句話——**最大的慈悲不是給世間的好處，而是把「一切皆假、令心靈安定」的實相宣說出去**，這正是他自己「從妄盡還源觀講到現在，堂堂都在講我們是假的」的自我定位。接著他用《涅槃經》雪山童子、《楞嚴》耳根圓通「入流亡所→寂滅現前」、屍羅四義、六度會通，層層說明「寂滅慈」如何是入本心；最終慈悲喜捨四心皆歸一句：**入本心才是真正的慈、真正的悲；用腦筋所發的是生滅法之願，會變；本心所發是本願，法爾如是不改。**〔行801–1431〕

### 意生身三次第（結構圖）——本講的修證階梯

法師以《楞伽》佛說三種意生身建一條上升的次第，並對應維摩詰之神通與淨土層次：

```
法身（無相本體）——本具，眾生與佛同，不會用
   │  令法身產生妙用 = 意生身（以智而得，非修得）
   ▼
 ① 三昧樂正受意生身   →「以無所受受諸受」，一切影像不染 → 已入地
        │  現在入之，西方任遨遊；往生百分百把握
   ▼
 ② 覺法自性性意生身   → 入一切佛剎、眾生剎，得自性自在 → 能妙用
        │  即實報莊嚴土；維摩詰彈指納三萬二千須彌座於斗室
   ▼
 ③ 種類俱生無行作意生身 → 成立淨土，示現一切 → 第十地（法雲地），近佛
           如藥師12願／彌陀48願，皆本願、無作意，法爾顯發
```

### (C) 真供養 / 六度 / 慈——皆歸「無所起之心」

```
真供養（慈氏師子吼經）：無佛想·無法想·無眾想·無補特伽羅想·無自他想 → 以無心而心作意
        │  同一心
六度（大珠·思益）：布施=俱捨 · 持戒=無所起 · 忍辱=無所念 · 精進=離相 · 禪定=無所住 · 般若=遠離戲論
        │  同一心
慈悲喜捨（維摩觀眾生品）：慈=入本心 · 悲=功德與眾生共 · 喜=饒益無悔 · 捨=福祐無所悕望
```
**連結要點：** 三組看似不同的法（供養、六度、四無量心），法師一律收在「本心無所起（無所住/無所念/離相/遠離戲論）」一點上——這就是本講「無眾生可度而行慈」的操作定義：不是壓抑、不是斷什麼，而是**知道一切皆幻、心無所起地作意去說如幻之法**。

## 11. 日常實踐

1. **一切唯影像的隨機練習（入三昧樂正受第一關）。** 眼前坐著的人、遇到的事，當下提起「這是我心中現的影像」，第二步「不對影像佔有、執著」——就這樣而已，不必壓抑、不必躲深山。〔行93–97〕
2. **當下自我考驗四問。** 有沒有為小事慌張／計較／不安？有沒有拿過去懊惱、拿驕傲安慰、把未來憧憬天天掛心而追逐？若還有，就是尚未「過去心／未來心不可得」。〔行107–111〕
3. **罵人即罵己、惡人即惡己。** 站在意生身（自他不二）角度，一切從你心出發——這不是「忍耐不罵」，而是知道道理後「哪有人天天罵自己」。〔行300–306〕
4. **逆境即考題的觀想。** 若遇癌症化療、財散、眷屬離，作一觀想：「原來這是意生身大菩薩對我的考驗」，只留兩個字——感恩；如此則「道業必成」。〔行450–464〕
5. **聽經是為往生「那一刻」預先訓練。** 一心不亂／都攝六根＝三昧樂正受＝入意生身第一階，非臨終才臨時發揮；平時聽經明理，那一刻才啟動得出。〔行180–186〕
6. **持戒回歸「清涼不熱」。** 真持戒不是拿標準挑別人毛病而天天發脾氣，而是自己「不受煩惱干擾」的清涼——你自己清涼，才能給眾生清涼。〔行1165–1167〕
7. **六度落在「俱捨一切煩惱」。** 沒有外在條件布施時，內在做得到：俱捨一切煩惱即最大布施；於法無所起即真持戒；無所念即真忍辱；離相即真精進。〔行1266–1276〕
8. **辨別本願與腦筋之願。** 發心捐產、行善，若隔天遞減（三分之二→一半→五分之一→發心就好），那是腦筋（生滅法）；本心所發之願法爾如是、不改——以此檢驗自己的發心。〔行1364–1368〕

## 12. 延伸・參

- **關聯講次：** 第28講（意生身之提出、不思議品）為本講直接前承；本講讀完〈不思議品〉並開啟第七〈觀眾生品〉，慈悲喜捨與「生死有畏，菩薩當何所依」留待第30講。
- **一參問：** 維摩詰說「無眾生可度」，卻又要菩薩「行慈悲喜捨」度眾生——若眾生皆如幻、無一真實可度，那麼「為眾生說『眾生如幻』之法」的那個「說」與「聽」，本身是不是也如幻？既如幻，這場說法的意義何在？（提示：法師的答——「入本心才是真正的慈；不入本心全是世間法」〔行1372〕。試以「因地成／果地成」與「本心即寂滅」自參。）
