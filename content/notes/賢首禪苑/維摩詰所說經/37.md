## 1. 本講概要

本講是《維摩詰經》十四品進程的樞紐：前八品講完，今日正式跨入被智者大師視為天台大徹大悟之關鍵的**第九品〈入不二法門品〉**〔行356〕。體佛法師先以近三分之二篇幅做一次「入本心」式的總複習，把前八品串成一條**入不二**的伏線，再逐段解說入不二品開場的前五位菩薩。

全講的「through-line」有三條，彼此交織：

1. **權實二諦的框架**——一切大乘經皆為「入不二法門」，未入不二者為權法（世俗諦），入不二者為實法（勝義諦）；實法「開口成兩橛、揚眉落二三」，不得不藉權法而顯〔行15-38〕。
2. **前八品即入不二的層層鋪墊**——佛國品(心淨國土淨)→方便品(受諸異道不毀正信)→弟子品→菩薩品(心佛眾生三無差別)→問疾品→不思議品(不思議薰・不思議變)→觀眾生品(觀緣起即見法)→佛道品(菩薩行於非道而通達佛道)〔行48-321〕。
3. **一套可操作的修證次第**——體佛法師從吉藏《中觀論疏》提煉出「**觀→定→保任(警覺)→忍(無生法忍)**」四階次第，貫穿五位菩薩的每一種「不二」〔行471-500、849-859〕。

核心口訣：**「全真成妄、全理成事」＝不思議薰、不思議變**；**「入而不入」＝不二＝無等等＝本心**〔行255、336-344〕。

## 2. 大綱

- **一、權實二諦總論**〔行13-38〕
  - 大乘經全講入不二；權（世俗諦・因緣所生法）／實（勝義諦・不可思議）
  - 「開口成兩橛，揚眉落二三」；佛無法可說是名說法；佛以一音而說法，眾生隨類得解
- **二、鳩摩羅什與「留惑潤生」**〔行42-47〕
  - 七佛譯師；玄奘譯《大般若》「以結受身」→後人稱「留惑潤生」，即維摩詰精神
- **三、前八品總複習（入不二的伏線）**〔行48-321〕
  - 佛國品：心淨國土淨、自性彌陀唯心淨土〔行48-77〕
  - 方便品：受諸異道，不毀正信；正信＝本心〔行107-132〕
  - 弟子品：十大弟子唯迦葉發菩提心〔行148-158〕
  - 菩薩品：呵彌勒——心佛眾生三無差別、眾生本受記〔行161-176〕
  - 問疾品：示疾以大悲、與眾生同類〔行181-191〕
  - 不思議品：《楞伽》不思議薰、不思議變＝全真成妄／全理成事〔行193-257〕
  - 觀眾生品：觀緣起即見法、見法即見佛〔行259-275〕
  - 佛道品：菩薩行於非道而通達佛道；三毒師利；入大海取寶〔行277-321〕
- **四、正式入第九品〈入不二法門品〉**〔行334-358〕
  - 「入」＝入而不入；不二＝無等等（《心經》）；方便有多門，歸元無二路

- **五、逐段解說（前五菩薩）**〔行360-1034〕

  - ③不眴：受不受為二 → 畢竟空不可得（孟子眸子、曾國藩相人）〔行645-689〕
  - ④德頂：垢淨為二 → 順於滅相入本心（大腦＝六七識 vs 大圓鏡智）〔行691-919〕
  - ⑤善宿：是動是念為二 → 六祖「無相為體・無住為本・無念為宗」〔行921-1034〕

## 3. 核心概念

| 概念 | 體佛法師的解說〔行〕 | 經教連結（已核驗） |
|---|---|---|
| **權法／實法（世俗諦／勝義諦）** | 因緣所生法皆世俗諦（權）；不可思議的自性功德為勝義諦（實）。實法一開口即「成兩橛」，不得不以權顯實〔行15-38〕 | 《金剛經》佛無法可說是名說法（義）✓ T0235 |
| **開口成兩橛・揚眉落二三** | 只要開口、動念、揚眉，即落入二元；故馬鳴教「離文字相、離言說相、離心緣相」〔行24-28、132〕 | 《大乘起信論》離言說相等（義引，馬鳴造，論非本講核驗對象） |
| **留惑潤生（以結受身）** | 徹悟菩薩故意保留惑（無明）來受生死身，與眾生同類度化；即維摩詰精神〔行42-47〕 | 《大般若經》玄奘譯「以結受身」（義） |
| **不思議薰・不思議變** | 《楞伽》：無明能薰炙真如而成妄、變異；真如堅實無為卻可被薰而變，故不思議＝全真成妄、全理成事〔行195-257〕 | 全真成妄之理另以《華嚴》眾生本具如來智慧德相印證 ✓ T0279 |
| **真妄不二／全真成妄** | 妄從真變現（水結成冰，水質不變）；真可變妄、妄可回真，故真妄不二〔行211-250〕 | 冰水喻；《圓覺》知幻即離 ✓ T0842 |
| **入而不入（不二）** | 「入」是不得不用的語言，實義為入而不入、當下即是；不二非有一個「二」，是平等，連平等亦放下〔行334-344〕 | 《心經》無等等（真平等）✓ T0251 |
| **無等等** | 連「平等」也放下才是真平等，即不二、即本心；《心經》大神咒、大明咒、無上咒、無等等咒〔行338-342〕 | 《心經》✓ T0251 |
| **無生法忍** | 法本不生（幻相故），既不生哪有滅，不生不滅即無生法忍，即本心中道義〔行398、607-609〕 | 維摩詰法自在段 ✓ T0475 |
| **四階修證次第：觀→定→保任(警覺)→忍** | ①般若觀（五蘊皆空、六喻十喻）②入定（畢竟空不可得）③保任・受三昧耶戒（不怕念起只怕覺遲）④忍＝認定，證無生法忍〔行471-500、849-859〕 | 吉藏《中觀論疏》修證步驟（義）；《金剛經》六喻 ✓ T0235 |
| **無念（六祖宗旨）** | 非斷念（念如瀑布不可斷），而是「念真如自性」——安住真如則所現皆幻相，不受干擾，故無塵勞煩惱〔行959-1025〕 | 《壇經》無念為宗・無相為體・無住為本 ✓ T2008 |
| **性・心・念** | 自性(體，寂滅、常寂光) → 一念不覺生三細，性起動成「本心」(妙用) → 六根六塵六識起，本心變「念」(差別相、妄心)〔行981-1006〕 | 《楞嚴》一念不覺（義）；三字皆從「心」 |
| **五蘊≠五類** | 五類是外境（外五樣），五蘊是回歸到心的隱藏幻影；干擾人的是五蘊（心中影像）非五類〔行515-516、889-902〕 | 《心經》照見五蘊皆空 ✓ T0251 |

## 4. 故事・公案

**① 僧肇定中見世尊招二如來（本經緣起）**〔行144-145〕
體佛法師引僧肇大師（羅什門下）之說：僧肇在定中覺悟——世尊左右手各招一尊如來進入娑婆，一位招來的是本為如來、轉為菩薩度眾的**文殊師利**，一位招來的是金粟如來所示現的**維摩詰居士**，二人共演《維摩詰經》，度化無量眾生，尤其度聲聞乘。此說用以點出維摩詰的本地與本經的「雙簧」結構。

**② 維摩詰呵彌勒——心佛眾生三無差別**〔行161-167〕
菩薩品中，彌勒菩薩對眾宣說「釋迦牟尼佛授記給我，我是賢劫五佛，我得到授記」。維摩詰隨即詰問：你得授記，不要以為有什麼特殊因緣、特殊階級——心佛眾生三無差別，既然佛與眾生無差別，你能受記成佛，為什麼眾生不能受記成佛？若認為只有你能受記，你已失佛的平等性。此語令彌勒退卻反省，不敢再言。體佛法師以此帶出「眾生本受記、眾生本成佛」（《圓覺》始知眾生本成佛），並舉《法華》連提婆達多亦授記成佛為證。

**③ 大珠慧海「自家寶藏」**〔行79-83〕
大珠慧海禪師往參馬祖，求佛法。馬祖道一問：「自家寶藏不顧，拋家散走作什麼？」慧海問：「哪個是慧海自家寶藏？」馬祖答：「即今問我者，是汝寶藏，一切具足，更無欠少，使用自在，何假向外求覓？」——「本自具足，不假外求」一句，令大珠當下頓悟，遂發願侍奉馬祖六年。體佛法師以此破斥「念佛期待彌陀來接而假外求」之落空。

**④ 大珠慧海「飢來吃飯，睏來眠」**〔行475-478〕
有人問大珠：如何用功修行？答：「飢來吃飯，睏來即眠。」問者不服：「一切人總如是，同師用功否？」答：「不同。他喫飯時不肯喫飯，百種須索；睡時不肯睡，千般計較。」——差別在「著相／不著相」。體佛法師藉此解永嘉「覺即了，不施功」：修行即在日常生活不著相，非另立時辰儀軌。

**⑤ 臥輪偈 vs 六祖偈**〔行677-681〕
臥輪禪師作偈：「臥輪有伎倆，能斷百思想，對境心不起，菩提日日長。」眾人跪讚。有人舉似六祖，六祖搖頭，另作一偈：「惠能沒伎倆，不斷百思想，對境心數起，菩提作麼長。」體佛法師以鏡喻釋之：鏡子哪有伎倆？緣來則應、緣去不留，出現就出現，如何拒絕影像？「不即不離」才是真六祖、真佛法，臥輪「斷百思想」是斷滅相、修行最差勁之法。

**⑥ 孟子「眸子瞭焉」與曾國藩相人**〔行650-657〕
解第三位「不眴菩薩」（眴＝眼球跳動＝不定；不眴＝入大定）時，體佛法師引《孟子》：「胸中正，則眸子瞭焉；胸中不正，則眸子眊焉。」——心正者眼球不晃、炯炯有神。再舉曾國藩用人如神：先看眼神、次看走路、三看坐相；坐而搖動不定者即不可用。用以說明「不眴＝定」的相狀。

**⑦ 智者大師讀入不二品，天女散花儼然未散**〔行356-358〕
天台智者大師閱讀此〈入不二法門品〉時入定，靈山會上天女散花儼然未散——體佛法師以此標明這一品是天台大師大徹大悟之關鍵，講此品時天龍八部皆在聆聽。

**⑧ 佛陀六年苦行與五比丘拒佛**〔行706-714〕
佛陀二十九歲前出家，六年大苦修，最後覺悟苦行是錯誤方法。得道後對五比丘說法，五比丘起初全部拒絕、認為佛陀變心。佛陀本欲示現真正涅槃（非偏空涅槃），一句「眾生皆具如來智慧德相，只因妄想執著不能證得」已把佛法講完；經天人一再苦求住世，才決定留下，先教聲聞有相法（苦集滅道、十二因緣），第二階段方等即講《維摩詰經》以反轉聲聞心。用以說明維摩詰「佛教不來，金粟菩薩由你來教」的角色。

**⑨ 演龍法師「緣影」**〔行750-752〕
埔里演龍法師臨往生時說「我不演了，我叫做緣影」，筆名即「緣影」——因了知一切二元對待皆是心的緣影（幻相）。體佛法師讚其入本心，謂其往生兜率天彌勒內院，待龍華三會來度眾。

**⑩ 駭客任務（Matrix）喻本心**〔行973-977〕
體佛法師以電影《駭客任務》（大陸譯《黑客帝國》，英文 matrix）喻自性：主角手一撥人就倒，那不是現象界而是心裡境界；matrix 本不動，卻設一虛擬環境（心界）在其中變來變去，正如自性本不動、一念不覺而生萬象。並讚該片武術指導袁和平，謂欣賞藝術須有佛法方能看懂內涵。

### 義理深入（依經文脈絡，體佛法師之讀法）

**（1）前八品是一條「入不二」的伏線。** 體佛法師強調：〈入不二法門品〉不是孤立的一品，而是前八品「總結」〔行13〕。佛國品立「心淨國土淨」，先確立淨土即在本心〔行48-77〕；方便品「受諸異道，不毀正信」示現居士隨緣，正信即本心〔行107-132〕；弟子品、菩薩品分別對聲聞與菩薩（呵彌勒）點破「眾生本受記、三無差別」〔行148-176〕；問疾品示疾以大悲〔行181-191〕；不思議品借《楞伽》「不思議薰、不思議變」立「全真成妄、全理成事、真妄不二」〔行193-257〕；觀眾生品以「觀緣起即見法、見法即見佛」把本心落到事相眾生上〔行259-275〕；佛道品「菩薩行於非道而通達佛道」是正宗分的樞紐句〔行284〕。八品層層逼近，才使入不二品的三十二種「不二」不再只是文字。

**（2）「入」的自我消解。** 體佛法師拈出品名第一字「入」作文章：若有「入」必對「出」，故「入」實為「入而不入」，當下即是即不二〔行334-337〕；「不二」也非有一個「二」可對，是平等，而連「平等」都須放下，故《心經》以「無等等」為真平等〔行338-342〕。此即「方便有多門，歸元無二路」——門雖多而所歸之本心唯一〔行344-348〕。

**（3）五位菩薩＝一套次第的五種入口。** 體佛法師反覆說：法自在（生滅）、德守（我我所）、不眴（受不受）、德頂（垢淨）、善宿（動念）雖題目不同，用的是同一套「觀→定→保任→忍」四階次第〔行685-689〕。每一組「二」都是鏡中差別相，先以般若觀見其為幻（觀）、知畢竟空不可得（定）、時時警覺不即不離（保任）、終至認定不動（忍＝無生法忍）。故五門同歸一門，正是「入不二」的活示範。

**（4）善宿「動念」段是全講的收攝。** 體佛法師以六祖「無相為體、無住為本、無念為宗」貫釋善宿菩薩，把「性→心→念」的生起（自性本不動，一念不覺生三細，起動成本心之妙用，六根六塵六識起而成念）鋪成一條下行的緣起鏈〔行981-1006〕；再以「念真如自性」為回歸之道——不斷念（念如瀑布不可斷）而念真如，則所現皆幻、不受干擾，即「不動則無念，無念則無分別」〔行1015-1031〕。動與念看似二，其實同是自性波動之一事，故不二。

> 「道則心藏無價珍，無價珍，用無盡，利物應機終不悋。三身四智體中圓，八解六通心地印。上士一決一切了，中下多聞多不信。」
> 「無明實性即佛性，幻化空身即法身。」（〔行783〕法師引，證道歌前段）

體佛法師以之印證：修行不在有為法（覺即了不施功）；住相布施縱生天福，力盡復墜；唯入無為實相門一超直入如來地〔行760-847、963-967〕。

## 10. 法脈會通

體佛法師解入不二品第一位「法自在・無生」時，不是孤說維摩，而是拉出一條**橫貫般若・中觀・淨土・禪的「無生／不二」大網**。下圖示其連結：

```
                    維摩詰〈入不二品〉法自在菩薩
                    「生滅為二 → 無生法忍」〔行365〕
                                │
      ┌──────────┬───────────┼───────────┬──────────┐
   龍樹《中論》   吉藏《中觀論疏》  《心經》     《金剛經》    《圓覺》
   八不緣起      「佛雖說八法    觀→五蘊皆空  應無所住     知幻即離
   善滅戲論      束歸於無生」   六不        凡所有相皆虛妄  不即不離
   〔行404-448〕 〔行465-471〕  〔行502-527〕 〔行450-916〕 〔行622-675〕
        │            │            │            │            │
        └────────────┴─────┬──────┴────────────┴────────────┘
                            ▼
              四階修證次第（吉藏＋法師提煉）
        觀（般若）→ 定（畢竟空不可得）→ 保任/警覺（三昧耶戒）→ 忍（無生法忍・八地不動地）
                            │
                   六祖「無念為宗」〔行929〕＝ 善宿「不動則無念」〔行926〕
                            │
                 永嘉《證道歌》「覺即了不施功／一超直入如來地」〔行781〕
```

**維摩本句 → 法師援引 → 該引文如何詮釋本句** 對照表：

| 維摩本句 | 法師援引 | 該引文如何詮釋本句 | ✓CBETA |
|---|---|---|---|
| 生滅為二，法本不生（法自在） | 《中論》八不 | 生滅來去一異常斷皆因緣戲論幻相，滅戲論即入不二 | ✓ T1564 |
| 得此無生法忍（法自在） | 吉藏《中觀論疏》「束歸於無生」 | 八不最終歸於一個「無生」，故經典只講悟無生 | 義引 T1824 |
| 得此無生法忍（法自在） | 《心經》觀自在 | 「觀」為入無生之第一關；五蘊皆空即幻相 | ✓ T0251 |
| 我我所為二（德守） | 《圓覺》妄認四大／六塵緣影 | 我是妄認，本來無我；無我則無我所 | ✓ T0842 |
| 受不受不可得，無取無捨（不眴） | 《圓覺》知幻即離 | 知幻即離＝不即不離，故無取無捨 | ✓ T0842 |
| 垢淨為二，順於滅相（德頂） | 《楞嚴》妙明真心中物／大圓鏡智 | 垢淨是大腦（六七識）判斷之幻相，滅相＝寂滅＝本心（大圓鏡智） | ✓ T0945 |
| 是動是念為二，不動則無念（善宿） | 《壇經》無念為宗 | 不動＝回本心，念真如自性則所現皆幻不受擾＝無念 | ✓ T2008 |
| 通達此者入不二（善宿） | 《華嚴》眾生皆具如來智慧德相 | 通達即「自於身中得見如來廣大智慧與佛無異」 | ✓ T0279 |

**連結要點**：五位菩薩題目各異（生滅／我我所／受不受／垢淨／動念），法師以「**鏡中差別相**」統攝為同一結構，再以同一套「**觀→定→保任→忍**」次第通貫；橫向則般若（心經・金剛）、中觀（中論・吉藏）、如來藏（圓覺・楞嚴・華嚴）、禪（壇經・證道歌）全部匯歸「入本心」一門——正應「方便有多門，歸元無二路」〔行344〕。

## 11. 日常實踐（可操作的四階次第）

體佛法師明言此四階「請各位依次來行」，並謂最佳道場不是極樂而是娑婆「非道」，因六根天天接觸六塵才練得出無生法忍〔行547-601、849-859〕。

1. **觀（般若智慧）**：碰緣時先起般若觀，照見一切差別相（受不受、垢淨、順逆、鹹淡…）皆是五蘊幻影、鏡中花水中月，非外五類；干擾我的是心中影像。可用《金剛經》六喻（夢幻泡影露電）隨觀一樣〔行488-495、849〕。
2. **定（不即不離）**：知其畢竟空、不可得，故無取（取不得）、無捨（本幻不須捨），不即不離，令心安住〔行910〕。
3. **保任・警覺（受三昧耶戒＝本心戒）**：時時警覺住，「不怕念起，只怕覺遲」；一失手（動怒、取捨、忍耐）即大懺悔——「罪從心起將心懺」，回歸本心即滅罪〔行494-565、853-859〕。範例：家人語氣、菜太鹹，覺其為覺受幻相，「吃而不吃」、以柔軟語令眾生歡喜〔行567-575〕。
4. **忍（無生法忍）**：保任純熟，八風吹不動，連「保任」也不須，主動入本心，覺性自反應——「認即忍」，證無生法忍，即八地不動地菩薩、花開見佛悟無生〔行543、859〕。

補充實踐提醒：
- **勿假外求**：念佛而期待彌陀來接是「假外求」會落空；自性彌陀唯心淨土，臨終見佛亦是自心顯現〔行54-77〕。
- **悟後起修**：無悟而修是盲修瞎練、徒勞無功；先開般若智慧（悟）方能真修〔行113-117、585-591〕。
- **住相布施只生天福**：布施而住相，縱大亦如仰箭射虛空，力盡復墜；當入無為實相門〔行814-826〕。

## 12. 延伸・參

- **本講關聯**：承第36講（大珠慧海「自家寶藏」〔行79〕）；第九品〈入不二法門品〉後五位菩薩（善眼「一相無相」起）留待**第38講**開展〔行927〕。
- **可延伸探究**：
  - 三十二菩薩／文殊總結／維摩詰默然的「壓軸」結構，可與《楞嚴經》二十五圓通（觀音耳根、勢至念佛、彌勒識大）對讀〔行373-381〕。
  - 吉藏《中觀論疏》「束歸於無生」與四階次第的原文出處（T1824），值得覆核法師提煉之精確度。
- **一參問**：五位菩薩題目不同（生滅／我我所／受不受／垢淨／動念），體佛法師卻說「同一套次第、同歸一門」。那麼若真是「不二」，這三十二種「說」與維摩詰最後的「默然無言」，是二、是不二？——你能不落文字、不落「我懂了」而當下承當嗎？〔行356、412〕
