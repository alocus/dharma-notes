## 1. 本講概要

本講是「佛國品·序分」的正式開講，通貫「修德→性德」兩層：

- **承前（修德）**：複習第2講「三萬二千菩薩」所具的四大修德——**大智本行、悉皆成就、總持、辯才無礙**，並以《華嚴經》「奇哉！一切眾生皆具如來智慧德相，但以妄想執著不能證得」定調「大乘之『大』＝眾生本具」〔行164-206〕。
- **啟後（性德）**：由當機眾**寶積長者子**（與五百長者子，皆在家眾）獻七寶蓋、蓋合為一遍覆三千大千世界，帶出寶積讚佛**十八偈**，讚歎佛之性德〔行302-712〕。
- **貫穿全講的教眼**：《華嚴經·夜摩天宮品》**覺林菩薩偈**（後半十偈：「譬如工畫師…一切唯心造」），逐句開演「大種（性）→心→佛→眾生」的一體關係，是本講最重的一段「觀法」〔行722-1055〕。
- **本講的通貫口訣**：開講必唱的「**從來真是妄，今日妄即真，但復本時性，更無一法新**」，以及「**方聽無生曲，始聞不死歌；今知當體是，翻恨自蹉跎**」，用以印證「全修即性、全妄即真」〔行30-58, 108-146〕。

一句話總攝：**修德是三萬二千菩薩累劫所現的相，性德是佛（＝本心）本具的體；而『心如工畫師，能畫諸世間』——山河大地、十方淨土、乃至地獄，全是自心所造，見緣起幻相即見自心，見自心即見佛。**

## 4. 故事・公案（全敘事）

### 4.1 智者大師、永嘉大師 因《維摩經》大徹大悟〔行13〕
體佛法師複述第1講史實：天台智者大師與永嘉大師，皆因《維摩經》而大徹大悟。此經自東漢傳入，於魏晉南北朝玄學時代盛行——當時因政治因素，名士入山修行（如竹林七賢之風），正是藉《維摩經》「空有不二」之義而契入。以後天台、禪、華嚴、乃至淨土之要義，皆自《維摩經》經義引諭而出。（*為第1講回顧，屬史實陳述。*）

### 4.2 波斯匿王聞「無生曲、不死歌」〔行42〕
體佛法師以「方聽無生曲，始聞不死歌」引出《楞嚴經》公案：波斯匿王本畏死，佛於楞嚴會上告訴他「你不會死，你有一個無量壽」。王當下悟到——因為無生即無滅，故本不會死。體佛法師以此印證：眾生本無生（非修來），一旦聞此「無生曲」，即知「不死歌」，當下降伏四魔。

### 4.3 龐居士一家「難／易／不難不易」公案〔行120-124〕
唐末龐蘊居士講「學佛難」——他是從「習性」角度看，習性太重故難。其妻龐婆婆卻講「學佛易」——很容易呀。其女龐靈照（體佛法師稱其為「大菩薩來」）則說「不難亦不易」。體佛法師點出：難處在「沒有聽到真正的正法，且會懷疑正法」，故曰「正法難聞」；然而從投胎往生淨土的角度看，「其實不是我們想像那麼難，欲得三摩，當下就是」。

### 4.4 六祖獵人隊十五年〔行237, 1032-1036〕
體佛法師舉六祖惠能為例：六祖已入本心後，仍在獵人隊中隱修十五年，所學者即「入本心以後如何應付隨緣的萬境」——即在境界考驗中保任本心。並藉此點出：在獵人隊「地位最卑下」最容易生氣，故「被人指揮者生氣還差不多，專門指揮人家的還生氣，那是萬藥不可救」，勉人自省業障。

### 4.5 善財童子五十三參〔行239〕
體佛法師指出：善財童子五十三參，每一參之前必先講「我已發菩提心」——意即「我已入本心，我是來參訪五十三位菩薩，看你們隨緣當下如何認得性」。故真正的參學，是藉環境考驗本心，非向外求法。

### 4.6 須菩提前身——小龍被金翅鳥所叼〔行442-444〕
體佛法師講《維摩詰經》第十品主角、亦即《金剛經》解空第一的**須菩提**之前身因緣：須菩提前身是一條小龍，被金翅鳥（迦樓羅）叼上去欲食，小龍自知死路一條、內心恐懼，遂發願「以後我要聆聽大覺者的聲音，讓我活在娑婆世界永無畏懼」。以此因緣，數次投胎後即成《金剛經》主角解空第一的須菩提。

### 4.7 慧遠致書鳩摩羅什問淨土——「唯心淨土·自性彌陀」〔行126-132〕
體佛法師複述講《阿彌陀經》第一堂課的內容：淨土宗初祖慧遠大師在江西廬山，鳩摩羅什大師在西安，古代交通不便、慧遠未能親謁，遂以書信往返請問淨土義（載於《大乘大義章》）。慧遠問西方極樂淨土如何、何人是阿彌陀佛；羅什大師（正是《維摩詰經》譯者，對淨土瞭若指掌）的回答總歸一句：**唯心淨土、自性彌陀**——淨土在一切眾生心中，沒有一天離開。體佛法師以此對治「近代標榜淨土宗卻與真正祖師淨土宗講不一樣」之流弊。

### 4.8 覺林菩薩偈破地獄——閻羅王震驚〔行724-728〕
體佛法師講《地藏菩薩本願經》晚課前必誦「夜摩天宮覺林菩薩偈」之典故：有一人入地獄時，念了此偈末句（「應觀法界性，一切唯心造」一路的偈），地獄竟化成蓮花池，閻羅王震撼，問他念的是什麼，答「我念的是夜摩天宮品（華嚴覺林菩薩偈）」。故此偈亦名「破地獄真言」——因了知地獄相亦自心所造之虛幻，不理它則「地獄自成空」。

### 4.9 真言宗入唐三大士與唐武宗毀佛〔行281-289〕
體佛法師鋪陳密教（真言宗）在中國的一段史：那爛陀寺於笈多王朝末、印度大乘晚期成為真言宗中心，時有「三大士」入唐——**善無畏**帶《大日經》、**金剛智**帶《金剛頂經》、最後**不空**將大日經（胎藏界）與金剛頂經（金剛界）發揚光大、合成一統。以後日本空海（弘法大師）到中國全盤接收帶回日本。而唐武宗毀佛時，真言宗第一個被毀滅；但「別密」（準提、穢跡金剛等單獨傳承的密咒）依然留下。至五代（907-960）之後、北宋（960-1127），法天菩薩來譯《妙臂菩薩所問經》時特用「咒師」一詞，即因當時真言宗雖已被毀、別密仍存之背景。

### 義理深入（維摩自身脈絡）

**（一）序分「表法」總綱——三萬二千菩薩名皆說自心修德。** 體佛法師的維摩讀法，核心在「不把經典唸過去」：維摩序分列三萬二千菩薩名，不是點名冊，而是「本心的每一種修德妙用」的表法清單。等觀（空）、不等觀（假）、等不等觀（中）三菩薩即三觀次第；常舉手＝無畏印、常下手＝與願印（阿彌陀接引）；帝網／梵網＝忉利天與大自在天之網，網目大小不一喻緣起法各各不同而不離性空。文殊列末因是〈問疾品〉當機、彌勒列末因是未來佛——「龍華三會所說亦是此經法義」，即維摩此經預告了未來佛的教眼。這一段確立了全經的閱讀法：**維摩所列的一切境相，皆須「收歸自心」讀，方是大乘究竟法（心法）**〔行345-417〕。

**（二）寶蓋合一——維摩用「現瑞」立「心即法界」的正義。** 序分的關鍵神變是「五百寶蓋合一、遍覆三千界，三千界乃至十方諸佛說法悉現蓋中」。體佛法師指出：這不是炫神通，而是維摩經在用文字般若（指月的手指）指出「寶蓋即我心」——你閉眼隨經文唸，香山、寶山、日月星辰、天宮龍宮乃至十方諸佛說法即現心中影像，「除非你不專心」。由此直接導出維摩經全經的骨幹命題——**心淨則國土淨、唯心淨土·自性彌陀**：西方極樂十萬億佛土既現於寶蓋（心）中，則往生淨土即當下回歸本心。這也正是〈佛國品〉之所以命名「佛國（淨土）」、並影響後世淨土宗的根由〔行526-595, 138〕。

**（三）寶積十八偈——當機眾以「在家身」讚出佛的性德。** 維摩此經主角有三（維摩、佛陀、文殊），當機眾卻是在家的寶積與五百長者子，以呼應維摩居士的在家相。體佛法師強調：寶積能用十八偈完整讚出佛的性德（「能善分別諸法相，於第一義而不動」「佛以一音演說法，眾生隨類各得解」「不著世間如蓮華」），可見**寶積已入等覺法位**——「不然不能了解佛真正的性德」。序分至此，由三萬二千菩薩的「修德」轉入佛的「性德」，正是本講「修德→性德」的樞紐；下講方入〈佛國品〉正宗分（心淨則國土淨之詳答）〔行602-712, 1055〕。

## 10. 法脈會通（連結圖）

### 10.1 本講核心等式鏈——「大種＝性＝心＝佛＝眾生」

```
   華嚴 覺林偈（教眼）              維摩 序分（本經）
   ┌───────────────┐            ┌──────────────────┐
   │ 大種 = 自性功德(性)│            │ 寶蓋 = 我心 = 法界 │
   │   無差別          │            │ 三千界/十方諸佛說法 │
   │      ↓ 因境有      │            │   悉現寶蓋(心)中    │
   │ 心(工畫師)本無生   │──────────→│  ∴ 唯心淨土·自性彌陀 │
   │      ↓ 隨緣妙用    │            └──────────────────┘
   │ 諸法/五蘊(色)虛妄取異相           ↑
   │      ↓             │       羅什答慧遠：淨土在眾生心中
   │ 心佛眾生三無差別    │            〔行128-138〕
   │  佛=覺  眾生=迷     │
   │      ↓             │
   │ 一切唯心造 → 見緣起幻相即見心即見佛
   └───────────────┘
```
**連結要點**：覺林偈的「大種→心→畫」次第，與維摩「寶蓋（心）現三千界」是同一個「心即法界」的命題；羅什「唯心淨土」的答問是這條鏈落在淨土宗上的果。法師全講即用覺林偈為「觀法」，去讀維摩的寶蓋神變。

### 10.2 「總持」二門——修佛兩條路（結構圖＋表）

```
              總持 (陀羅尼 dhāraṇī = 經典法義之結論 = 本心)
              ┌────────────────┬────────────────┐
          顯 (可說)                          密 (不可說)
          陀羅尼 = 經教/經典                  曼陀羅 mantra = 咒語
              │                                │
   「本心」講得出來的部分                 「本心」唸出來令共振的部分
              │                                │
   例：六祖「不識本心學法無益」        例：唵嘛呢叭咪吽 (Mani=摩尼寶珠=本心)
                                              準提咒(Cundi=準提=真心)、叭咪=蓮花
              └──────── 皆在念「本心」 ───────┘
```
**連結要點**：法師把「總持（辯才無礙之本）」拆成顯（經教）／密（咒語）二門，二者皆念本心；並以此定義《妙臂經》「咒師」＝真正的陀羅尼師（能講出正念本心、兼藏曼陀羅），非民間「化骨咒」之咒〔行218-297〕。

### 10.3 五方五佛·阿彌陀＝妙觀察智

法師解「十方諸佛說法亦現寶蓋中」時，特標阿彌陀與娑婆因緣最深〔行567-571〕：

```
           = 西方極樂淨土 之教主
```
| 方位 | 佛 | 識→智 | 淨土 | 出處〔行〕 |
|---|---|---|---|---|
| 西 | 阿彌陀（甘露王）如來 | 第六意識→妙觀察智 | 西方極樂淨土 | 〔行569-571〕 |

**連結要點**：法師以「妙觀察智」定位阿彌陀，是把「唯心淨土」再落到密教五方五佛的方位圖上——西方＝妙觀察智＝阿彌陀＝極樂，仍歸「現於寶蓋（心）中」。

## 11. 日常實踐（可操作）

1. **時時觀照，念念分明**：修行不是「另做什麼」，而是在「念念要起煩惱的當下，知道它是幻影」；能如此即真修行〔行114-116〕。做法：起煩惱時問「是誰在煩惱？→識在煩惱→受法塵（心中塵相）干擾而已，與外在人事物無關」，當下不理即「降伏鏡裡魔軍」〔行484-490〕。
2. **降四魔的一念**：當你了知「本來無生、故不會死」，煩惱魔／欲魔／身魔／死魔一時俱降，天魔波旬亦奈何不得〔行46-50〕。
3. **從耳根「聞中入」**：娑婆耳根最利，故要聽經聞法、把握「當下」；此為得三摩地的門路，非可代以文字自看〔行82-99〕。
4. **五蘊皆空的用法（生氣時）**：「我要生氣——生氣是我心中所現塵相，我怎會被它干擾？」當下放下即不生氣；不是求某地讓你不生氣（「你喜歡生氣，到哪都喜歡生氣」，是心境非環境）〔行900-902〕。
5. **作佛事＝隨緣扮演角色＋無住布施**：凡從心顯現者皆佛事；你投胎每一天都在布施——即使向人要錢，也讓對方種福（雙方得利才叫布施）；罵人即損己、利人即利己〔行1024-1049〕。
6. **禮佛的正見**：頂禮是「能禮所禮性空寂，感應道交不思議」——拜的是自心佛（藉外相引出心中那一個），非拜下去偶像就顯靈幫你〔行982-984〕。
7. **上廁所勿聽經**：心未至清淨處，明知不淨處則盡量不帶經／手機進去聽，也不差那幾分鐘〔行425-427〕。
8. **回家功課**：把覺林菩薩十偈記起來、時常觀照——「保證你把『心佛眾生三無差別』見到，佛就是心」〔行1055-1057〕。
