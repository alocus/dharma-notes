## 1. 本講概要

本講是〈香積佛品〉（第十品）的收束。劇情：**維摩詰居士**化身菩薩往香積國，向香積佛乞得「眾香缽飯」帶回〔娑婆世界〕，九百萬香積國菩薩隨飯而來，欲見我世尊如何度化剛強眾生〔行14–18〕。全品主軸仍是**菩提心**——香積國「聞香即悟」，那個「香」不是鼻所聞的香，而是**心香＝本心＝本覺＝佛性**，故香積國全境即是菩提心〔行20–23〕。

體佛法師的教學結構分三大段：

1. **前導·涅槃本心**〔行24–253〕：以《涅槃經》迦葉菩薩問「不見善不作，唯見惡可作」偈為軸，確立「若聞涅槃性而信之，必斷一切煩惱、必得阿耨多羅三藐三菩提」——並藉「犯五重罪者 vs 久修善根者聞而信之無差別」、「恆沙劫聞而不解者何以不能斷煩惱」兩問，導出**佛性／如來祕密藏性眾生本具**的圓頓見。
2. **維摩正文·娑婆難化**〔行253–508〕：逐句釋「得是三昧者，菩薩所有功德皆悉具足」到「此土眾生剛強難化…以一切苦切之言乃可入律」，說明娑婆是「不昧因果」的現象界（世俗諦），世尊隱其無量自在之力、示現劣應身、以貧所樂法度眾。
3. **淨土會通·十事善法**〔行514–882〕：以**蕅益大師《彌陀要解》**貫串（唯心淨土、自性彌陀、六信、念佛三昧＝寶王三昧、五濁轉四德），再逐一釋「娑婆十事善法」（六度＋除八難、大乘度小乘、諸善根濟無德、四攝），收於「此土菩薩一世饒益眾生，多於彼國百千劫行」。

貫穿的一句總持：**「娑婆修行一日一夜，勝彼淨土百千劫行」**〔行251, 312, 879–882〕——受苦有價、功不唐捐，故當發菩提心、當下承擔本具佛性。

## 4. 故事・公案（全文敘事）

### 4.1 迦葉問偈——「不見善不作」的徵問〔行33–180〕（✓《涅槃經》T0374）

《涅槃經》正文以**迦葉菩薩**與世尊的對話為軸。佛將入涅槃，弟子皆哭、皆捨不得，因眾人從「世界的角度」看世尊的色身；佛卻告訴大家：色身不是涅槃，涅槃是常住·不變異·無盡·決定的佛性〔行31〕。

迦葉就佛先前所說一偈提問：「世尊！如佛說偈：『不見善不作，唯見惡可作。是處可怖畏，猶如險惡道。』如是所說，有何等義？」〔行42–45〕請世尊再作文字般若的交代。

體佛法師以**倒裝句**解此偈：「不作」＝你沒有碰到真正圓滿的善知識；沒有善知識叮嚀，你便「不見善」——不見性、不知道有一個永恆決定的涅槃性、佛性、阿耨多羅三藐三菩提〔行50–60〕。「善」是本自存在、圓滿無缺失的那個（何期自性本自清淨，非修來）。反之「唯見惡可作」——沒有善知識，就唯有沉浸在世間二元對待（惡＝二元化，非善惡之惡）的現象裡，乃至誹謗大乘，於是「是處可怖畏，猶如險惡道」，在六道乃至三惡道輪轉不已、出不來〔行70–83〕。

佛接著說涅槃有無量功德、如摩尼寶珠用之不竭、常住不變異〔行95–105〕。若有眾生**聞而信**此涅槃，涅槃光即射入其毛孔，雖未發菩提心，然已種下菩提因緣，後必得阿耨多羅三藐三菩提〔行108–113〕。

**迦葉第一問**〔行114–135〕：若有人犯五重罪（殺母·殺父·殺阿羅漢·出佛身血·破和合僧），聽聞涅槃性而信、種下菩提因緣，這樣一位與一位「久修善根、長期修善行」者相比，有無差別？——佛以譬喻答：**千年暗室，燈一亮照樣光亮，與暗多久無關**〔行125〕；聞信之功德平等無差別（佛性本來清淨）〔行211〕。

**迦葉第二問**〔行128–180〕：佛又曾說「人於恆河沙等佛所發心，聞大涅槃不解其義。若不解義，云何能斷一切煩惱？」〔行138〕若聽聞涅槃而不知其理，煩惱怎能斷？佛答：「除一闡提，其餘眾生聞是經已，悉皆能作菩提因緣。」〔行139〕——關鍵在：**此人已於無量劫供養無量諸佛**，故今生得聞、且能信；「福薄之人不能聞之，何況信之」〔行161, 176–178〕。唯有「大人」（供養無量諸佛的菩薩）能知此「大事」——即**如來祕密藏性、佛性、涅槃性**〔行164, 180〕。

法師以此連結《金剛經》：「若人能信（信般若、信自性、信金剛），此人已於無量諸佛所種諸善根」〔行231〕，與涅槃性一致，故可直入圓頓法。

### 4.2 百丈野狐公案——不昧因果〔行357–385〕

法師講「世間果報是因果」時，提醒「你是大修行者，仍會落入這個道理」，引**百丈禪師野狐公案**〔行357〕。一位大修行者因答學人「大修行人不落因果」一句錯話，墮五百世狐身。他來問百丈禪師（真正的大覺悟者、大智者）：大修行者到底要不要受果報？百丈答「**不昧因果**」（不離開因果），一句點醒，狐身脫落〔行361〕。

法師辨析：公案的狐狸真假不是重點，重點是法義〔行358〕——「**不昧因果**」是就現象界／世界而言：凡走過必留痕跡，有因必有果；「**不落因果**」是就法界／空性而言：現象界的因果我受，但**心不落因果、不受其干擾折磨**，此即三昧、即本心〔行363–367〕。這就是「以無所受受諸受」：心無所受（因果罪福是假），然現象界受諸受〔行367〕。小乘阿含說「身受心不受」，大乘則說「以無所受受諸受」〔行377〕。佛陀一生受提婆達多九難、山推巨石傷足流血、放狂象、最終示現吃毒蘑菇入滅，色身受痛而大悲本心始終不動〔行369–377〕——即此理。

### 4.3 蕅益大師「百無一益，唯常發菩提心」〔行594–603〕

法師以**蕅益大師（1599–1655）**貫串淨土會通段。蕅益自謙「我一生百無一益」（實太客氣），唯獨一事：「常發菩提心」——他能「忘卻自身，捨己從人」，故「不愧於三世諸佛」〔行594–599〕。菩提心含三心：大悲心·直心·深心〔行601〕。而蕅益所謂「菩提心」，法師點明其實就是**念佛三昧**〔行603〕——非口念，是當下承擔本具的覺悟涅槃妙心。印光大師（淨土十三祖、大勢至菩薩再來人）曾贊蕅益：「非觀音即彌陀之再來人」，其《彌陀要解》為淨土宗最重要著作〔行524〕。

### 4.4 常不輕菩薩〔行571–575〕（引《法華經》）

法師講「承擔佛性→自不暴棄→不敢暴棄人」時，引《法華經》**常不輕菩薩**〔行571〕：因他知自己有佛性、也知一切眾生皆是佛，見任何眾生一定頂禮；不管別人如何罵他、毀他，他絕不改變做法，因「眾生皆是佛」，故名常不輕。《法華經》說這位常不輕菩薩即是今日的釋迦牟尼佛〔行573–575〕。能常不輕，方能隨順四眾、速淨六根。

### 4.5 韋陀菩薩·破相·三洲感應〔行834–842〕

講「八難」之北俱盧洲時，法師講**韋陀菩薩**：古佛寺必寫「三洲感應」〔行834〕。韋陀菩薩手持金剛杵，是「破相菩薩」，其偈「凡所有相皆可破，唯虛空不破」〔行834–836〕——什麼相都可破，唯虛空破不了，故金剛杵表破相之要。韋陀菩薩是賢劫千佛最後一個成佛，因眾生都著相，故他示現破相、最後成佛〔行836–838〕。四大部洲中南贍部洲·東勝神洲·西賀牛洲有佛法（三洲感應），唯**北俱盧洲**福報極大卻無佛法，故投生於此是八難之一〔行838–840〕。

### 義理深入（依經文脈絡）

**「聞香即獲三昧」與娑婆的張力**。維摩以「聞香得一切德藏三昧」開場，法師點出香＝本心＝三昧，眾生本具。這定下全品的對照軸：香積國是純勝義諦、純法界，沒有現象界折磨，故「聞香即成就」；娑婆是「不昧因果」的現象界，勝義諦不離世俗諦，故非以苦切之言不能入律〔行386–391〕。維摩答文殊之問，正是要讓九百萬菩薩看清這差別，從而讚歎世尊「隱無量自在之力、以貧所樂法度眾」的偉大。

**二元果報長串的用意**。那一長串「是…是…報」，法師強調是「世俗諦／因果」的完整鋪陳——身口意造罪、殺盜淫妄貪瞋癡各有其報，乃至「是世間，是涅槃」。維摩把娑婆現象界的全貌攤給香積菩薩看：這裡真的有地獄餓鬼畜生（心現），真的凡走過必留痕。這不是否定佛性，而是說娑婆眾生「活在二元世俗諦」，故佛不得不依二諦說法（龍樹二諦框架，法師繫大智度論，實中論偈）〔行306–310, 429〕。

**「隱其無量自在之力，乃以貧所樂法度脫眾生」是本品的悲心核心**。法師反覆申說：世尊佛性與香積佛一模一樣，卻甘願隱藏無量功德、示現與眾生一體的劣應身（會生病、會流鼻涕、會死時痛苦），只為告訴我們「有一個不生不滅的佛性」。這回扣第五品問疾品「以大悲故而生病，眾生病故菩薩病」〔行469〕。「勞謙」二字——既示劣應身，又對眾生極謙卑——是娑婆大菩薩的特性。由此導出「一世饒益勝彼國百千劫」的鼓勵：受苦有價、功不唐捐。

**「十事善法」＝菩薩四德「代眾生苦」的具體化**。維摩把「菩薩在娑婆的本德」落實為十事，法師以賢首《妄盡還源觀》菩薩四德（隨緣妙用·威儀有則·柔和質直·代眾生苦）為框架，指出「代眾生苦」不是替眾生受痛、代付錢，而是「令眾生了解實相真義以解其煩惱」〔行749〕。十事之核心是六度，而六度的靈魂是般若——無般若則前五度皆盲、執之成「狂」（諸法無行經），皆世間善善人善事而已，與成就無關〔行759–801〕。

## 10. 法脈會通（本講的連結網）

### 10.1 一條總持等式：涅槃性＝三昧＝本心＝念佛三昧＝寶王三昧

本講最大的會通，是把三部經／一部要解的核心名相打通成一個等式——講者反覆說「50講開頭《涅槃經》所講的，跟蕅益的念佛三昧一模一樣，都在講本心」〔行634〕。

```
      《涅槃經》            《維摩詰經》           《彌陀要解》(蕅益)
      涅槃性                 三昧                  念佛三昧＝寶王三昧
   常住·不變異·             得是三昧者              一切三昧從此出、
   無盡·決定=佛性     ─►    功德皆悉具足     ─►     流入此；至圓至頓
        │                      │                      │
        └──────────────────────┴──────────────────────┘
                          都是「本心／本具佛性」
                   ↑ 承擔本心 ↑          ↑ 以無所受受諸受 ↑
               《六祖壇經》何期自性本自具足    《楞嚴》若能轉物則同如來
               《證道歌》幻化空身即法身        《金剛經》應無所住而生其心
```

**連結要點**：三部不同宗（涅槃／般若不二／淨土）的頂點名相，指的是同一個「眾生本具、不假外求、當下承擔」的本心；證入的關竅是「無所住／以無所受受諸受」（鏡不受染）。

### 10.2 圓頓兩門：般若門 ⇌ 涅槃門（不二）〔行233–247〕

```
   般若門                        涅槃門
   《金剛經》                     《涅槃經》
   無我 ── 真空 ─── 不二 ─── 真我 ── 妙有
   通達無我法者即是菩薩            常樂我淨的真我＝佛性
        └── 真空即妙有、無我即真我，同一事、二門著重點不同 ──┘
```
**連結要點**：入「無我」到極處，剩下的就是「真我」；真空即妙有。故講《維摩》而借《涅槃》，是「從另一角度更加肯定世尊所示的同一佛性」〔行244〕。

### 10.3 五濁 → 淨土四德的「當下轉」（蕅益·觀法）〔行696–718〕

```
  五濁惡世（相/現象界）    ── 當下頓得一心·轉 ──►    淨土四德（本心妙用）
  ─────────────────                              ─────────────────
  劫濁（時劫苦難）        ───────────────────►    清淨海會（佛菩薩世界）
  見濁（偏見邪見）        ───────────────────►    無量光（般若智慧/空性）
  煩惱濁                  ───────────────────►    常寂光（涅槃四德·常樂我淨·法身）
  眾生濁（四大色身）      ───────────────────►    蓮花化身（本心示現，不生不滅）
  命濁（有限生命）        ───────────────────►    無量壽（涅槃無盡）
                    └─► 轉一個全部來：當下即阿彌陀佛、即西方極樂淨土 ◄─┘
```
**連結要點**：這是可操作的「觀法」——不待往生，就在此心轉五濁為四德，「當下不就是淨土」〔行710〕；此即《彌陀要解》最重要的一句、亦即〈佛國品〉「心淨則佛土淨」的實修版。

### 10.4 六度 ⇌ 般若之眼（慧海《頓悟入道要門》釋）〔行781–806〕

| 六度 | 一般（有為·世間行） | 慧海禪師·本心義釋 | 少般若則 |
|---|---|---|---|
| 布施 | 捨財 | **俱捨**——捨心中一切煩惱（煩惱畢竟不生即涅槃） | 計較功德大小、以盲導盲 |
| 持戒 | 守規矩 | **於一切法無所起**（屍羅四義：清涼·寂滅·安靜·安穩；有為戒→無為戒） | 持戒狂、輕蔑他人、不得菩提 |
| 忍辱 | 忍耐 | **於一切法無忍無辱**（一切是空性假相） | 比誰能忍、以盲導盲 |
| 精進 | 苦幹 | **於一切法離相**（相干擾不了我） | 比誰精進、輕慢他人 |
| 禪定 | 打坐 | **於一切法無所住·離諸戲論** | 比誰有定 |
| 般若 | — | **無所住＝不二＝能所不二＝空**（法界＝無能無所） | ——無此則前五皆盲 |

**連結要點**：般若是「眼」，前五度是「盲」；「以盲導盲」則落世間、成「狂」（諸法無行經）。真布施＝俱捨煩惱＝涅槃；真持戒＝回歸本心之無為戒。統歸四概念：**無所住·不二·無生·無自性相＝法界**〔行786–787〕。

### 10.5 淨土會通：唯心淨土·自性彌陀（蕅益·六信）〔行526–551〕

```
             淨土從何來？── 唯心（心變現）
                  │
      度我者是誰？── 自性彌陀（自心取自心，何來外在）
                  │
   往生與否 = 信願之有無      六信：信自·信他·信自性他·信事·信理·信因·信果
                  │                    │
          心淨則國土淨 ◄──────── 信因(心淨)→信果(國土淨)
```
**連結要點**：淨土不假外求（來自我心），故「往生不難」〔行534〕；一切功德以「信」為最（華嚴），一切罪以「疑」為最——不疑即當下承擔本具佛性〔行561–567〕。

## 11. 日常實踐（可操作）

1. **認取那一個**：先信「我有一個常住·不變異·無盡·決定的涅槃性／佛性，與佛無二」——「不識本心，學法無益」，不認取則盲修瞎練〔行184〕。
2. **聞而信**：涅槃性一聞而信，即種菩提因緣，必斷煩惱、必得菩提；不必先斷惑再信——「千年暗室，燈一亮照樣光亮」〔行108–125〕。
3. **以無所受受諸受**：因果來就來（現象界不昧因果），心不落因果、不被境轉——學鏡不學底片〔行367, 381–383〕。
4. **五濁當下轉四德**（觀法）：遇劫難轉清淨海會、遇偏見轉般若無量光、遇煩惱轉常寂光、觀色身為蓮花化身、觀生命為無量壽——「轉一個全部來」〔行700–716〕。
5. **念佛三昧的真義**：口念「南無阿彌陀佛」是為回歸「當下承擔覺悟涅槃妙心」的三昧，非為念而念、非為求接引；真回歸覺性必入三昧〔行613–621〕。
6. **六度必配般若之眼**：布施先俱捨煩惱、持戒回歸無為戒、忍至無忍無辱、精進在離相、禪定在無所住離戲論；不執五度、不輕慢他人（免「狂故」）〔行781–801〕。
7. **常不輕行**：承擔自己佛性→自不暴棄→不敢暴棄人（人人是佛）→頂禮眾生、隨順四眾→速淨六根、速消業障〔行569–591〕。
8. **代眾生苦（四德）**：不是替眾生受痛，而是令眾生了解實相真義以解煩惱；以四攝（布施·愛語柔軟語·同事平等·利行）成就眾生〔行749, 874–876〕。
9. **珍惜娑婆難修之處**：娑婆一日一夜勝淨土百千劫；受苦有價、功不唐捐，故當精進發菩提心〔行251, 312, 879〕。
