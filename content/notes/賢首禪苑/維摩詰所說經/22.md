## 1. 本講概要

本講屬〈文殊師利問疾品第五〉，是「維摩詰與文殊師利的高手對話」正式展開的一講。全講可分兩大板塊：

- **前半（維摩本經正文）**：文殊代佛探病，一問一答四個核心問題——(1)**病因**（你為何病）、(2)**空義**（此室何以空無侍者）、(3)**侍者**（果真無人侍奉否）、(4)**病相**（病是身合心合、四大何大）——最後導出**如何慰喻有疾菩薩**的十句法要。〔行59-506〕
- **後半（引經旁證）**：法師以《心經》詮空空、以永明延壽《宗鏡錄》「全眼見色、全耳聞聲」詮「不隨不壞」、以《大寶積經·妙慧童女會》文殊問妙慧的五番問答詮初發心菩薩之殊勝、以孔子師項橐（《三字經》「昔仲尼，師項橐」）作東西呼應、以《大般涅槃經》「憐愍世間大醫王」偈讚初發心。〔行232-995〕

**貫串線（through-line）**：**「眾生病則菩薩病」的大悲，與「空空（以智空達本空）」的般若，合為大乘菩薩的一體兩面**；而這一體兩面的最終落點，是鼓勵一切**有疾菩薩（重病者、初發心者）**——身雖無常而不厭離於身、留此假身教導眾生、當作醫王療治眾病。法師特別提示：本講與21、23、24、25共約五講，「可以單獨抽出來給重病者、生命垂危者、年老者聽，給他很大的鼓勵」。〔行87-89〕

**開場的頓法基調**：法師先以大珠慧海《頓悟入道要門論》「頓除妄念，全消人我，畢竟空寂，與佛等齊……不離此身已得解脫」開講，定調——佛法是頓法，妄念不是「有想法」而是「誤會一切法為真實」的執著，故除的是執著、非除念頭。〔行14-48〕

## 4. 故事・公案（完整敘事）

### 4.1 菩薩品四菩薩不敢答，維摩一開口皆聆聽（複習）〔行101-105〕

法師複習前面〈菩薩品〉：維摩詰曾令四位入地以上、等覺層次的菩薩「不發一語」——第一位**彌勒菩薩**（講受記）、第二位**光嚴童子**（講道場含義）、第三位**持世菩薩**（波旬來見）、第四位**善德長者子**（講法會）。維摩詰一開口，四位高菩薩「只能站在那邊聆聽」，連即將補位成佛的彌勒都從頭到尾不發一語。以此反襯：唯有同為如來的文殊（龍種上尊如來），才是「高手對高手」，能與維摩對答。〔行101-116〕

### 4.2 百業經·果嘎勒嘎（俱伽利）誹謗二尊者墮無間地獄〔行594-644〕

法師以《百業經》一則因緣，解「說悔先罪，而不說入於過去」（須懺悔業障、業不因過去而消）。

**緣起**：有一比丘名**果嘎勒嘎**（漢譯音，即經律中之「俱伽利/俱迦利」），本為提婆達多弟子，後隨佛出家，嚴守戒律、在一方教化。他屢次邀請佛的兩位大弟子——**目犍連**、**舍利弗**——到其僧團助化。二尊者答應，但立一條件：不得公開（以免妨其修行）。〔行597-601〕

**發展**：時有一婆羅門子欲隨果嘎勒嘎出家，果嘎勒嘎以「父母未許、佛有戒律」拒之。後果嘎勒嘎因事遠行，僧團暫交舍利弗、目犍連。婆羅門子稱父母已許，二尊者慈悲為其剃度；此子出家後竟證阿羅漢，其座下多人亦證果。二尊者見教化已成，遂解散僧團而去。〔行601-608〕

**轉折**：果嘎勒嘎歸來見僧團空無一人，心生懷疑怨恨，沿二尊者足跡追問究竟。途遇大雨，一牧羊女先入山洞躲雨，繼有一牧男入而復出；二尊者亦入洞避雨。果嘎勒嘎追至，恰見牧羊女衣冠不整跑出、二尊者坐於洞中，遂指責二尊者與牧羊女有染。二尊者解釋，果嘎勒嘎不信，並挾解散僧團之恨，四出宣傳「二尊者破戒、所證皆假」。〔行611-619〕

**佛的燈喻**：佛聞而召果嘎勒嘎誡之：目犍連、舍利弗清淨與否，非你所見所聞所知；你若傳之，將斷人慧命（因二尊者能教化比丘證阿羅漢）。佛設喻：**暗室中有人執燈而入，室中人皆隨明燈出去，豈會先問執燈者持戒否、是好是壞？只要跟著明燈走就對了**。〔行621-625〕

**結局**：果嘎勒嘎不聽，繼續宣傳，惡名滿城。不久身生惡瘡、如火焚燒。臨終佛與二尊者仍勸其懺悔，他不但不悔，反大罵二尊者，死墮無間地獄受苦。目犍連以神通偕舍利弗入地獄探視、勸其放下即可出火坑，果嘎勒嘎仍懷恨大罵。二尊者稟佛，佛告其宿世因緣：果嘎勒嘎過去生亦是婆羅門子，曾被此二尊者（前生）誹謗，故今生一報還一報。縱二尊者已證阿羅漢，仍應「假使百千劫，所造業不亡，因緣會遇時，果報還自受」。〔行627-635〕

> 法師由此帶出《圓覺經》成就三要件：一者善知識（明燈）、二者懺悔業障、三者三法（奢摩他/禪那/三摩缽提；持咒念佛即三摩缽提，以幻取幻）〔行637-639〕。

### 4.3 百丈野狐·不昧因果（連帶提及）〔行594〕

法師以「就好像百丈禪師跟那個狐仙他們的對話一樣」點出：**修行人「不昧因果」**——大修行人並非沒有因果、果報一樣現前；以為「大修行人不會有因果」是錯誤的。此為「不落因果／不昧因果」野狐公案之引用，用以印證上則。〔行594〕

### 4.4 妙慧童女八歲問十事·目犍連頂禮·文殊問妙慧五番〔行682-889〕

**緣起**：佛在靈鷲山（耆闍崛山）說經，座中一八歲長者女**妙慧童女**起而問佛十事（如何從一佛土至一佛土、如何於如來前坐蓮花座、臨終如何見佛等）。佛就每問各答四法，共**四十行**。〔行682-690〕

**目犍連頂禮**：妙慧發誓四十行若缺一行則欺誑如來，言畢天地震動、天雨妙花、天鼓自鳴。神通第一的**目犍連尊者**即向佛頂禮，並向這位八歲初發意童女頂禮，讚其「初發意菩薩能發此心，受我目犍連頂禮」。〔行716-720〕

**文殊問妙慧五番**（法師以此顯「初發心菩薩之殊勝」，文殊為長者、妙慧為八歲，且妙慧竟是文殊過去世之師）：〔行729-882〕

1. **住何法而發此願？**——妙慧喊「文殊啊！你怎會有這種想法？（莫作是念）」以《金剛經》「應無所住而生其心」反詰：於法界中無所住，何來住不住。〔行737-750〕
2. **何謂菩提？**——「菩提即覺也，覺即心也，無分別即菩提」；菩提如明鏡，明鏡不分別。〔行753-759〕
3. **何謂菩薩？**——「知法如虛空相，即是菩薩」；了法如虛空、心如虛空無障礙者即菩薩。〔行759-763〕
4. **何謂菩提行（菩薩行）？**——「知法如陽焰、如谷響」者，即是菩提行（=菩薩行）。法師以《圓覺經》普眼章「證如幻影像故……感得無方清淨、虛空覺所顯發」相印。〔行771-789〕
5. **依何密意而說？**——「不見一法有密與非密」。文殊追問：若無密意，凡夫豈非皆行菩薩道？妙慧呵斥：你還分別凡夫與菩提嗎？「皆同一法界相，不取不捨，無有成壞」。〔行797-817〕
6. **能了此義者其數幾何？**——妙慧妙答：「若干幻化心心所量，若干幻化眾生能了斯義」——眾生皆心所幻化，心一體悟則一切幻化眾生皆了；如《金剛經》恆河沙眾生心「如來悉知悉見」。〔行819-859〕
7. **幻化本無，何有心心所法？（心的本質是什麼）**——「法界亦爾，非有非無，乃至如來亦復如是」——心即法界，本自具足佛性（非無=真如門）、能生萬法（非有=生滅門），法爾如是。〔行867-880〕

**結局**：文殊大讚，反向佛頂禮。佛言妙慧已於過去發菩提心經三十劫（先文殊而發），且令文殊住無生法忍。佛授記妙慧當來成佛，號**殊勝功德寶藏如來**。文殊乃向妙慧頂禮。〔行882-889〕

### 4.5 孔子師項橐（《三字經》「昔仲尼，師項橐」）〔行725-942〕

法師以此為妙慧童女的東方呼應——「初發心菩薩／小孩子的智慧震撼長者」。並提「有人說孔子是文殊菩薩的再來人，雖無證據，可同理可證」（法師明言無證據，僅類比）〔行825-827〕。

**設定**：孔子五十五歲周遊列國，至莒國。馬車行至一處，眾小孩皆避，唯一七歲小孩**項橐**（相傳為項羽之祖先）不避，用泥巴在路中間捏了一座「城堡」。〔行901-911〕

**第一難（城堡讓車）**：孔子下車問何以擋路。項橐反問：「是城堡讓馬車，還是馬車讓城堡？」孔子只得繞城而行。〔行909-911〕

**第二難（馬踏幾下）**：子路不甘，故意問一耕田老農「你一天鋤頭用了幾下」。老農語塞，項橐替父反問子路：「你的馬從剛才走到這，馬蹄踏了幾次？」子路答不出。孔子下車，知此小孩非等閒之輩。〔行913-919〕

**第三難（一夜星辰）**：孔子回頭出題，若答出則以五十五歲之身拜其為師：「天之廣、地之大，一夜之間有多少星辰？一季（一茌）生多少五穀？」項橐答：「天之高不可測、地之廣不可量，可是**天有一夜星辰、地有一茌五穀**」。〔行921-937〕

**法師的悟點**：此答與妙慧「能了斯義者幾何→莫作是問，眾生皆心所幻化」同一機——**星辰在我心裡、五穀是我心幻化的地**，數目就是「那麼多」，如恆河沙、如來悉知悉見。孔子（若即文殊）低頭鞠躬，已悟此心法。〔行933-937〕

**第四難與結局**：項橐反問孔子「人的眉毛有幾根？」孔子不能答，遂以仲尼之身拜項橐為師——即《三字經》「昔仲尼，師項橐，古聖賢，尚勤學」。〔行939-941〕

### 義理深入（本經自身脈絡）

**(一)「病因—空義—侍者—病相—慰喻」是一條連貫的大悲—般若軸。** 法師的讀法緊扣本品次第：維摩開口就把「病」定義為大悲的示現（從癡有愛→眾生病則菩薩病→以大悲起）。接著文殊四問，看似逐一拆解「空室、無侍、病相」，實則層層逼出同一結論——空要在眾生心行中求（大悲的對象）、侍者即魔與外道（大悲不捨的場域）、病相不離四大（大悲的肉身代價）。因此本品的「空」始終不是斷滅的空，而是**為度眾生而入生死、入諸見、入四大的空**；般若（空空）與大悲（不捨）在維摩身上是一件事。〔行120-190,374-498〕

**(二)「以空空」是本品最難、也最關鍵的一句。** 法師把它讀為**方法論的宣示**：文殊代表「已知本空」的境界，維摩代表「須給眾生一個下手處」的菩薩教法。故第一個「空」是可操作的智空（後得智／始覺／無分別空），第二個「空」是所歸的本空（根本智／本覺）。這就解釋了後面「空何用空、空可分別耶、空當於何求」三問——都在回應「既然本空，為何還要一個空」：因為眾生不知，菩薩必須以無分別的智空，把眾生從迷帶回本空。維摩的「分別亦空」正是收煞：連這個能分別的智空，其性亦空，故不落「有一個空可得」的邊見。〔行205-373〕

**(三)慰喻十句是「不厭離、不畢竟」的中道生命觀。** 每一句都是「說A、不說B」的雙遮結構：肯定身的無常苦無我空寂（不欺誑病者），卻遮止「厭離、樂涅槃、畢竟寂滅」的消極滑落。法師點出這正是本品給有疾菩薩的核心——**留著這無常的假身，作醫王、教眾生，把生命最後的價值用到最後**。這也回扣了維摩自身「不離四大而生病」的示現：菩薩自己就是這樣活的。〔行506-669〕

## 10. 法脈會通（連結網）

### 10a. 大乘起信論二門架構——本講的義理骨幹〔行132-188〕

法師以《大乘起信論》「一心二門」為白板架構，把維摩「空義」對話定位其中：

```
                        【一心】（本心／自性清淨）
                          │
        ┌─────────────────┴─────────────────┐
    真如門（本自空寂）                  隨緣生滅門（隨緣起生滅）
      = 空 = 本無 = 實空                   = 有 = 三界
      = 根本智 = 本覺                       │
      = 維摩「本空」                    ┌────┴────┐
                                    分段生死          不生不滅之「有」
                                    生老病死           = 佛淨土（有相：七寶池八功德水）
                                    = 三界（貪瞋癡）    = 阿彌陀西方極樂 / 阿閦妙喜 / 香積國
                                    ↑ 從癡有愛而來        ↑ 從心淨國土淨·信願行而來
```

**連結要點**：三界與佛淨土都是「因緣而來、都有相」，差別只在「隨什麼緣」——三界隨「癡愛」緣、佛淨土隨「心淨（信願行）」緣。淨土在淨土的菩薩，知眾生病，仍「隨緣生滅門再入三界」度化——這正是維摩「不捨生死、不動諸見」的示現。〔行180-188〕

## 11. 日常實踐（可操作的takeaway）

1. **除執著，不除念頭**：念頭是心的妙用，不可斷；要除的是「以假為真的執著」。看到一相、聽到一句話、想像一件事，覺察自己是否把它「當真並擴大」（生氣會更生氣、快樂會更快樂而後破滅），這就是妄念。〔行19-27,122-125〕
2. **不隨不壞（可以每天練）**：見色聞聲，不「隨」（不被境牽動取捨）、不「壞」（不刻意破相毀相或壓抑）。以走在陽光下的「影子」為所緣——不去掉它、不害怕它、不隨它，如是即離二見、契中道。〔行288-306〕
3. **以空空的下手處**：知道「一切法本空」還不夠（那是佛的境界）；老實用一個「智空／無分別」的觀（如念佛、持咒、觀種子字，屬三摩缽提「以幻取幻」），把自己從迷帶回本空。〔行205-296,637-639〕
4. **給重病者（含自己）的鼓勵**：身無常是事實，但**不厭離於身**——留著這假身教導、利益眾生，盡人事聽天命，活得有勇氣。弘一大師「小病從醫，大病從死」可作面對疾病的中道態度。〔行551-585〕
5. **懺悔業障，不諉過於人**：業「不因過去而消」（假使百劫，果報還自受）。生病時修「說悔先罪」——懺悔而不執「過去已了」；同時要怪就怪自己（癡愛是自心妄念所造，非別人給的）。〔行166-167,585-593〕
6. **成就三要件（《圓覺經》）**：親近善知識（明燈）、懺悔業障、修奢摩他／禪那／三摩缽提。〔行637-639〕
7. **敬初發心如佛想**：對初發意菩薩、對一切有情要生起一切智心（恭敬心）、平等大慈大悲，普皆迴向。初發心最難也最尊——不可妄自菲薄。〔行706-714,965-978〕

### 一參問
維摩詰「一切眾魔及諸外道，皆吾侍也」——若魔與外道都是我度化的場域、都是我的侍者，那麼在你今天的生活裡，哪一個最令你「樂生死」的貪著、哪一個最令你「樂諸見」的偏執，正是你此刻要「於生死不捨、於諸見不動」去轉化的「侍者」？〔行374-410〕
