## 1. 本講概要

本講是《維摩詰經·弟子品第三》的收官講。十大弟子中前八位已於前講講畢，本講接續講**第九位羅睺羅**（論出家）與**第十位阿難**（論如來法身），並以此為第五品〈文殊師利問疾品〉的引子作結〔行11〕〔行603-605〕。

全講的**通貫主軸**是一個字：**無生**——「若悟無生理，三界自消亡」。體佛法師開場即以中國維摩式的在家大德**龐居士（龐蘊）**之偈揭出此軸〔行17-26〕，再貫穿羅睺羅段「真出家＝入本心／無為法／涅槃」〔行287-289〕、阿難段「如來即法身，非思欲身」〔行657-659〕，最後以《六祖壇經·無相頌》「努力自見莫悠悠」總結〔行851〕。

兩段各有一個核心翻轉：
- **羅睺羅段**：維摩詰破「出家有利、有功德」之說——「無利、無功德，是為出家」〔行240〕。真出家不是身相之出家，而是**發阿耨多羅三藐三菩提心**（＝入本心）〔行413-421〕。
- **阿難段**：維摩詰破「如來身有小疾」之見——「如來身者，金剛之體」〔行618〕、「諸如來身，即是法身，非思欲身」〔行657〕。最後空中聲曰「取乳勿慚」，點出**中道義**：法身無疾，色身仍隨五濁而現、仍須牛乳〔行752〕。

穿插的兩大結構性教學：**大寶積經「四法失菩提心」**（本講首次開講，體佛法師自言出家以來從未講過）〔行491-556〕，與**發菩提心（三菩提心：行願／勝義／三摩地）**及其密教的五方五佛→五智曼荼羅〔行460-489〕。

## 4. 故事‧公案（完整敘事）

### 4.1 龐居士投財於江‧「善事不如無事」〔行15-28〕
體佛法師以龐居士（龐蘊）開場，稱其為當時的維摩詰。龐蘊是馬祖道一的弟子、六祖法脈的在家大德，與傅大士（彌勒再來）並列為中國史上兩位來歷極高的居士。渡江時，龐蘊帶著太太、女兒龐靈照、兒子到南方，將所有錢財、家產全部投入江中。旁人問他：這麼多錢為何不拿去做善事？龐蘊答一句名言：「**善事不如無事**」——他已看出世間是幻化無常，故所有塵勞於他無負擔。體佛法師以其偈作全講總綱（見§8末）。

### 4.2 耶輸陀羅懷胎六年‧羅睺羅之身世〔行110-124〕
羅睺羅是佛之子。佛的妻子耶輸陀羅懷羅睺羅**六年**才誕生——體佛法師強調「這不是寓言，是歷史」。佛陀出家後六年方生子，印度皇家因此譁然，疑耶輸陀羅不貞。淨飯王須有公道。耶輸陀羅向公公淨飯王陳情：佛陀出家前她已懷孕，佛陀出家後她食不下嚥、幾乎不眠、捨大床而臥冰冷地面，故胎兒雖未死卻不成長，一直懷在腹中；直到她放下夫妻之愛、轉為祝福世尊，身體養分細胞方活躍，胎兒重新活躍而得生。淨飯王請名醫耆婆檢驗，認為有理；小孩生出與世尊相似度極高，確是佛子。經典另載其宿因：羅睺羅某世曾**堵住老鼠出口**，如是因如是果，故此世出胎延滯六年〔行122-124〕。（體佛法師：相上的因果，因果不爽。）

### 4.3 《佛說出家功德經》‧鞞羅羨那王子〔行154-231〕（本講最大插講）
羅睺羅為長者子說出家功德，所依即《佛說出家功德經》。體佛法師大意全講：

佛在毘耶離城托缽時，見一城中王子**鞞羅羨那**，出身高貴、身旁盡是絕色美女、日日欲樂。佛入三昧，告阿難：此王子**七日後必亡，且必墮地獄**。阿難問如何救之，佛言其與佛有緣可救，遂遣阿難進城相告。阿難是剎帝利、佛之堂弟，鞞羅羨那開城禮迎。阿難三請方說（第一、二請故意不說，第三請王子跪而請時才說——體佛法師借此教「給人真理，須待對方專心信受才說，否則講也無用、反招誹謗」）〔行168-173〕。

阿難告：七日後必死墮地獄，因你淫亂過度、心已荒廢入不了本心（「心易放難收，平原走馬」）。王子顫抖而問解法。佛開藥方：**出家一日一夜，受持淨戒**。王子接受，卻因習氣談條件——「讓我再享樂六天，第七天再出家可以嗎？」（體佛法師：人的習性如此）。佛早已交代阿難應允。王子六天欲樂不改，第六天傍晚告父母（其父為小國國王），眷屬同意，遂於一日一夜持淨戒。七日一過，鞞羅羨那仍暴斃而死——「死亡之路不能逃過，可是後面的輪迴會有不同的結果」〔行182-184〕。

眷屬與阿難回問佛：鞞羅羨那今歸何處？佛開示其**六欲天輪迴、往返七次**的果報，一日一夜出家之福：

| 天 | 身分 | 壽 |
|---|---|---|
| 四王天（北方多聞天王之子） | 天王之子 | 500歲 |
| 忉利天（帝釋天王之子） | 玉皇上帝之子 | 1000歲 |
| 夜摩天王之子 | 天王之子 | 2000歲 |
| 兜率天（外院天王之子） | 天王之子‧聞彌勒內院菩薩說法，起「不足惜」之滿足心，種佛因入第八識 | 4000歲 |
| 自在天王之子 | 天王之子 | 8000歲 |
| 他化自在天王之子（六欲天最高） | 天王之子，所求皆滿 | 16000歲 |

如是六欲天往返**七次**，第七次後投胎人間富貴家，中年後聞聖者說「苦空無我、四諦、十二因緣」，捨欲樂而**證辟支佛果**，往返三界度無量眾生〔行203-215〕。

佛末後兩喻顯出家功德無量：(1) 在他世界無量劫出家，不如在娑婆世界出家一日一夜——他世界之功德僅娑婆一日一夜的十六分之一〔行225-227〕；(2) 供養無量阿羅漢之功德，亦僅娑婆一日一夜持淨戒者的十六分之一〔行227-229〕。體佛法師指出：**八關齋戒（一日一夜）的由來即本此經**〔行231〕。並強調真義不在戒相（勞工、受刑人皆易做到日中一食、不臥大床），而在「淨戒」之**淨**（回歸本心）與**戒**（尸羅四義：寂滅、安靜、清涼、安穩），令心生清涼〔行305-313〕。

### 4.4 邵雍判神秀‧六祖不受戒即得法〔行247-357〕
宋代理學家**邵雍**（在家人，作先天易‧先天圖）有名言：「**能伏塵境是真境，未了僧家是俗家**」〔行249〕。體佛法師以此判神秀「時時勤拂拭，勿使惹塵埃」——神秀仍有「一個我在勤拂拭、一個灰塵要除」，落在有為法，見地不見性，故五祖不傳法脈〔行347-349〕。又講六祖公案：六祖二十四歲、尚未受戒，於印宗座下以「不是風動、不是幡動、仁者心動」顯本色，印宗當下為之剃度、頂禮三拜、請其上座說法（體佛法師讚印宗「不用講經即得功德，真高僧本色」）〔行351-357〕。

### 4.5 馬祖「是心是佛」與大梅‧梅子熟了〔行707-713〕
馬祖道一（佛之法脈）只教弟子大梅一招「**是心是佛**」，大梅參後赴他方教誨。馬祖遣侍者試探，告大梅「馬祖近日說『是心不是佛，佛不是自心』」。大梅答：「這老禿驢！『是心是佛』是真理，如今怎越老越不對，說『是心非佛』？」侍者回報，馬祖跳起：「**梅子熟了**！」大梅遂成真法脈。（體佛法師以此印「是心是佛、是心作佛」之不動——月可熱、日可冷，眾魔不能壞真說。）

### 義理深入（依段）

**（一）羅睺羅段：出家的三重定義層層深入。** 體佛法師指出維摩對「出家」給了層層遞進的三個定義：第一，出家＝**無為法**（無利無功德，能伏塵境是真境）〔行274〕；第二，出家＝**入涅槃／入本心**（處於涅槃、六祖「不識本心學法無益」）〔行287-289〕；第三，究竟義——出家＝**發阿耨多羅三藐三菩提心**〔行413〕。這三層不是並列，而是同一件事的深淺：無為法即涅槃、涅槃即本心、本心即菩提心。故維摩對「有利有功德」的破，不是否定出家的福報（鞞羅羨那六欲天往返七次是真福報），而是點出**福報不是功德、身相不是真出家**——「身出家、心不出家」是偽沙門，「心出家」才是維摩式的在家菩薩，發菩提心不退者才是真出家〔行299-301〕。此段在本品脈絡中，是把「出家」從制度性儀式提昇為本心見地的宣示。

**（二）勸長者子發心：真出家的門檻降到「一念發心」而果位登到「與佛無異」。** 父母不聽不得出家（此戒至今猶然，體佛法師自述因配偶不簽字、又逢官司，故遲至某年方出家）〔行397-401〕。維摩並不勉強長者子身出家，卻把真出家的門檻收攝為一句：**發阿耨多羅三藐三菩提心，是即出家，是即具足**〔行413〕。「具足」＝與佛本無異，因菩提心即本心、眾生本具、未曾消失（六祖「何期自性本自具足」）〔行435〕。體佛法師由此接入三昧耶戒二戒（平等戒「心佛眾生三無差別」、本誓戒「度無量眾生因與眾生本一體」）〔行438-442〕，再接大乘起信論三心與發菩提心論三菩提心，把「發心」的內涵展開為體相用的完整結構（見§10）。

**（三）阿難段：如來法身與中道義——本講的最高翻轉。** 阿難因愛佛、急於取牛乳而詣婆羅門家、晨朝早乞，兩處都違了維摩的平等乞食〔行607-614〕。維摩由此切入：你見的是「思欲身」（色身），未見「法身」。法身是無相之身、金剛之體、過於三界、諸漏已盡、無為不墮諸數〔行657〕，故無疾無惱。但此教若止於此，修行者易走一邊——「法身重要、色身不理，病也不看」——那又不中道〔行754〕。故維摩說完後，空中聲曰「取乳勿慚」：佛出五濁又入五濁，示現的生滅身仍須牛乳、仍會示現小疾乃至大疾（佛陀最後拉肚子、腰痛、膝痛、食毒蕈而示涅槃）〔行902〕。體佛法師以此立**中道義**：大修行者生病仍當看醫生、盡人事聽天命，只是心不染著〔行756〕。此段是弟子品的收筆，也是第五品〈文殊問疾品〉的引子——連如來都示現有疾，才有下品「以疾說法」的展開。

## 10. 法脈會通（連結圖）

### 10.1 「真出家」的層層等式（羅睺羅段核心）

```
維摩：「無利、無功德，是為出家」（T0475）
        │
   ┌────┴─────────────────────────────┐
   │  出家 = 無為法 = 入涅槃 = 入本心 = 發菩提心 │  ← 體佛法師：同一件事，深淺不同
   └────┬─────────────────────────────┘
        │
  ┌─────┼───────────────┬──────────────┐
  ▼      ▼               ▼               ▼
金剛經           六祖壇經           大寶積經         邵雍
「一切賢聖以      「不識本心，       身心四出家：      「能伏塵境是真境，
 無為法而有       學法無益」        身+心出家=最上；   未了僧家是俗家」
 差別」T0235      T2008            心出家(身不出)=    → 判神秀落有為
                                  在家菩薩=維摩式；  → 判六祖見性得法
                                  身出家(心不出)=偽沙門
```
**連結要點**：維摩對「出家」的破立，體佛法師以四條經教之網收攏——金剛經證「無為法」為聖賢差別之本、六祖證「本心」為出家之實、大寶積經證身心四句判真偽、邵雍一句作judgment之尺。四者共指一義：出家在見地（本心），不在身相。

### 10.2 發菩提心 = 體相用（起信論）= 三菩提心（發菩提心論）

```
大乘起信論(T1666,馬鳴造)三心      發菩提心論(T1665,傳龍樹,不空譯)三菩提心
─────────────────────           ──────────────────────────
直心（本心）……… 體 ────────────── 三摩地菩提心（絕對本心/禪那/大定）… 體
深心（般若相）… 相 ────────────── 勝義菩提心（回歸本心/見空性/大智）… 相
大悲心（代眾生苦）用 ────────────── 行願菩提心（利益安樂眾生/大悲）… 用
                                      │
                       合稱「摩訶衍」（大乘心含體相用）
```
**連結要點**：體佛法師將二論會通——起信論的直心/深心/大悲心，即發菩提心論的三摩地/勝義/行願三菩提心，一為體、一為相、一為用；發菩提心論更深一層在「三摩地菩提心」，須三密相應加持方能圓滿（見10.3）。

### 10.3 三摩地菩提心 → 五方五佛五智曼荼羅（T1665，密教）

八葉白蓮一肘門，炳現阿字素光色 → 觀白月輪（初一→十六漸圓＝本心圓滿）→ 十六大菩薩 → 五方五佛五智：

```
                    北方  不空成就佛 ── 成所作智（羯磨智）
                          │
   西方 阿彌陀佛      中方 毘盧遮那佛      東方 阿閦佛
   妙觀察智(蓮華智) ─ 法界體性智(本) ─ 大圓鏡智(金剛智)
                          │
                    南方  寶生佛 ──── 平等性智（灌頂智）
```

| 方位 | 佛 | 由成之智 | 別名 |
|---|---|---|---|
| 東 | 阿閦佛 | 大圓鏡智 | 金剛智 |
| 南 | 寶生佛 | 平等性智 | 灌頂智 |
| **西** | **阿彌陀佛** | **妙觀察智** | 蓮華智／轉法輪智 |
| 北 | 不空成就佛 | 成所作智 | 羯磨智 |
| 中 | 毘盧遮那佛 | 法界體性智 | 為本 |

**連結要點**：此圖直出 T1665 canon（唐·不空譯）。體佛法師以「觀月輪初一→十六漸圓」喻本心由三密加持而圓滿；阿字「本不生」為發起本心之種子。西方阿彌陀＝妙觀察智＝蓮華智，正接本講「導歸極樂＝導歸本心」之軸（§3、§8阿難段）。

### 10.4 如來法身的等式（阿難段核心）

```
維摩：「諸如來身，即是法身，非思欲身」（T0475）
        │
   ┌────┴──────────────────────┐
   │  如來 = 法身 = 無相之身 = 本心 = 阿彌陀 = 西方  │
   └────┬──────────────────────┘
        ▼                          ▼
  觀無量壽經(T0365)            馬祖/大梅(T0475外·禪門)
  「諸佛如來是法界身，          「是心是佛、是心作佛」
   遍入一切眾生心想中；          → 梅子熟了
   是心作佛，是心是佛」          → 龐居士「彌陀在此處，何處覓西方」
```
**連結要點**：阿難段「如來即法身」由觀無量壽經「法界身遍入眾生心想」印證——法身在每個眾生心裡；再由馬祖「是心是佛」、龐居士「彌陀即我心」收攝，故「一頓飯時間周遊佛土」（阿彌陀經）因佛土皆法界身、不離自心。

## 11. 日常實踐（可操作）

1. **碰境即提「有覺覺痛‧無痛痛覺」**〔行68-72〕：身痛、被誹謗時，觀「痛（覺受）動不了覺性（本體）」，覺性不受幻相干擾——這是行(信解行證的行)，不是壓抑忍耐。
2. **知幻即離＝不即不離**〔行327-329〕：念頭、影像升起是正常（想是體相用的用，開車、經營都要想）；不必斷念，只需知其為幻相而不被攀緣束縛——「緣來則應，應了則不與之攀緣」〔行831〕。
3. **守四法不失菩提心**〔行491-556〕（大寶積經）：(一)不欺誑師長（已受經法而不恭敬）；(二)不令他疑悔（不對正法/大乘法說「這不是重點、旁門左道」）；(三)不訶罵誹謗發菩提心者/講大乘者而廣其惡名；(四)不以諂曲心（著相之心）教人著相。犯此四，本具菩提心即遮，「忘失菩提心而行一切善事皆是魔事」。
4. **發菩提心即真修行**〔行413〕〔行438〕：發阿耨多羅三藐三菩提心（心佛眾生三無差別的平等見）即是出家、即與佛無異；不執「我天天念佛幾遍、拜山幾遍、捐錢做善事」為修行（那頂多是福報）。
5. **中道對待色身**〔行754-756〕：大修行者生病仍當看醫生、盡人事聽天命，只是心不染著——勿以「修行者本色」拒醫。
6. **在自己的業中修，不把業當障**〔行843-851〕：工作照做、事業家庭照做（在家人各行各業依然如是；出家人守出家戒），本心一定要安住——「努力自見莫悠悠」，莫蹉跎時間。
