## 1. 本講概要

本講是《維摩詰經》佛國品的正式導入。體佛法師先以約一小時把上一講的**大乘佛教史觀**完整複習並補足，再切入經文本體——**佛國品序分**「與大比丘眾八千人俱，菩薩三萬二千……如是一切功德，皆悉具足」這段對三萬二千菩薩的功德總讚〔行274–286、860–1084〕。

全講的貫串線是一句話：**「淨土在心，心即法界」**〔行305–312〕。法師反覆用一個核心譬喻——**大種／螢幕**——來統攝全部經文：一切六根六塵六識、一切淨土地獄、一切善惡罪福，都只是「大種（自性、空、毘盧遮那）」這面唯一螢幕上變現的頻道影像〔行611–645〕。因此佛國品第一品要講「心」，而序分那一長串菩薩功德，其實**句句都在描寫「入了法界、見了大種的菩薩」的本具功德，也就是在講我們自己**〔行372、872〕。

法師以自身「多發性骨髓瘤癌症末期」的示現貫穿全講〔行299、1015–1019〕，扣緊維摩居士「示疾」的主題：身病是四大自然現象、是假的，真正的病是「不知兩種根本」的心病〔行301、762〕。

**兩大理論支柱**（本講最核心的兩段引經）：
1. 《楞嚴經》**「不知兩種根本」**——生死根本（攀緣心）與菩提涅槃元清淨體（識精元明）〔行345–346、482〕。
2. 《華嚴經》覺林菩薩偈**「大種無差別」**——一切唯心造、色色不相知〔行503–506、611〕。

序分經文則是把這兩個支柱「翻譯」成三萬二千菩薩的具體德相：師子吼、不請之友、降四魔、六（七）波羅蜜、辯才無礙、為大醫王……法師逐句對回本心。

## 4. 故事・公案

### 4.1 安世高度同參道友——宮亭湖大蟒蛇〔行96–146〕

安世高本是**安息國（今伊朗、阿富汗一帶）太子**，捨王位出家修聲聞法。他有一位**同參道友**，修行雖好卻**瞋恨太大、動不動不耐煩**〔行101〕。安世高屢屢警告他：「你瞋氣太過，貪瞋癡的瞋必現因果，死後必受醜陋之形。」並對他**發願**：「因有師兄弟因緣，我必然要度你。」法師在此插一句要點：**願力一出來即是因，最後必得果，因果不爽**〔行103〕。

安世高**第一次由海路到中國**，在廣州一處紛擾的市集看人打架，去看究竟時，其中一人**舉刀無緣無故往安世高頭上一砍**，安世高當場往生〔行105–108〕。那砍他的人與他無冤無仇，是**砍錯了人**——但這正應了安世高「與中國人有緣、被殺」的宿業〔行108、113〕。

安世高**再投胎又成為安息太子**，因已得宿命通，知過去在中國被殺、緣還在中國，遂再度讓出王位出家，**第二度來到中國**，行至江西**宮亭湖**（法師自問是否即今洞庭湖，文字記載作「宮亭」，存疑不強斷）〔行113–114〕。

宮亭湖畔有一座著名廟宇，供奉的神明**瞋力太大**：凡上岸供養他的過湖平安；心懷不敬、不供養而過湖的必遭天災〔行118–123〕。此事百試不爽，人人上供。安世高路過，以宿命通認出**這廟主正是自己過去生的同參道友**——當年警告他「不改必得醜陋之形、雖有神通仍受此果」的話全部應驗〔行123–125〕。

安世高上岸指出他的缺點，同參道友竟然**接受**（因知安世高曾發願來度他）。安世高請他現原形，他起初怕嚇人，經安世高勸「你既已懺悔、罪障已除」，遂現出**大蟒蛇**之形〔行127–129〕。安世高再提醒「修行人貪瞋癡必須放下」，大蟒蛇接受，並告白心願：**我雖位居神明享眾人祭拜、有此福報，但我不要了，要捨去此生命，隨靈性提升回歸菩薩無生法忍**〔行131–137〕。他請安世高將廟方眾人供養的財產**拿去供養三寶、另建佛寺，令大乘佛法在中國流行**，說完便在後山示現往生〔行137–139〕。

法師補述：**江西「蛇村」之名即由此典故而來**（大蟒蛇死後大身軀留在該處）〔行139〕。隔天安世高尚在遊湖，那神明**現出一美男子、神采奕奕、身相光明**，向安世高頂禮——他已成為**入地的菩薩**〔行142–143〕。法師點題：**當下懺悔的力量有多大——大蟒蛇在剎那間回頭是岸而變成菩薩**〔行143〕。此後安世高在江南一帶譯經，尤以介紹**安那般那**入中國最為系統〔行144–146〕。

### 4.2 達磨參「父母未生前誰是我」〔行388–394〕

有一位禪者告訴達磨：「去悟——悟什麼？**你是誰？父母未生你之前誰又是你？父母生你以後誰又是你？**」達磨為參此句，**不惜放棄王位、出家**〔行388〕。法師以此帶出《楞嚴》兩種根本：你以為身體生出來才叫生、壽命到才叫死，卻不知裡面另有一個（本心）；因不知，便攀緣身體、認身體為生死，於是永遠離不開生死〔行394〕。

### 4.3 佛佛道同・知音難尋〔行563〕

法師以「知音難尋」引申：世間夥伴縱共事，「你在想什麼我怎麼會知道」，人善變；直到有一天全部見性、性性相同，就不用再找知音了——這才叫「佛佛道同」〔行563〕。（此為法師以生活譬喻引出「大種無差別、心佛眾生三無差別」之義，非獨立公案，附此存錄。）

### 4.4 法師自身示疾——體佛即九十六歲老菩薩〔行519、1015–1019〕

法師述及去年往生、享壽九十七歲的「老菩薩」（其九十六歲時身體仍很好），由此得一啟示：**「我就把自己認作是九十六歲的體佛，那明年死與我何相干」**〔行519〕。又自陳出家前講《金剛經》曾「噴血」，今多發性骨髓瘤癌症末期，問痛不痛「當然痛」，但**毫無畏懼**——靠的是安那般那調息，與**降伏死魔、身魔、本無生**的體悟〔行1015–1019〕。此段呼應維摩「示疾」與序分「蓋諸大眾得無所畏」。

### 義理深入（依經文脈絡）

**（一）序分為何全是本具功德的翻寫。** 法師的關鍵判讀是：這一長串菩薩功德「全部都是一個等覺菩薩、入地菩薩的功德才有」，「而它是每一個菩薩本具的功德」〔行372〕。因此序分不是外於我們的讚辭，而是**把「識精元明本自具足」翻寫成三十餘句具體德相**——「請問這不是在講我們嗎？在講我們啊，是我們現在才認識而已」〔行872〕。這把佛國品序分從「莊嚴場面描寫」提升為「本心功德清單」，是本講讀維摩序分的獨到定位。

**（二）「如是我聞」＝反聞聞自性，是全序分的門檻。** 法師把證信序的「如」訓為「平等、本性」，「我聞」訓為「反聞聞自性」，於是聽維摩經的當機者「並不是一個耳朵聽聽就好」，重點在自性（即《華嚴》大種）〔行832–834〕。他接六祖「不識本心，學法無益」〔行834〕與「性相一如、沒有相不足以起性、沒有性相無用」〔行838〕作結：**證信序即已要求聽者以本心相應，否則後文功德句句與己無干。** 這是把序分讀成「修行入口」而非「歷史記錄」。

**（三）三方對談的殊勝與佛國品的「淨土在心」。** 法師指出此經之奇在**三方對話**：主角維摩詰（金粟如來再來、於阿閦國為等覺菩薩助阿閦如來弘法）、文殊師利（七佛之師）、加上世尊金口註解〔行852–856〕，「全部都是最頂尖的高手」。而佛國品之所以第一，是因「淨土在心、心即法界」〔行305–312〕：一部戲、一部書的開頭即重點（如善財五十三參第一參講淨土、二十五圓通第一圓通、地藏經先念覺林菩薩偈），故序分（本具功德）與正宗分（文殊問疾）之間，實由「心＝法界＝大種」一線貫穿。法師並預告：真正正宗分是**文殊菩薩問疾品**，維摩經因維摩居士示疾而起——正與法師自身示疾相印〔行297–301〕。

**（四）降四魔與七波羅蜜——序分德相的「操作化」。** 「降伏魔怨」被法師拆成一條**可操作的次第**：悟無生（不是修、是體悟）→欲魔（煩惱本無生，不必壓制而自幻滅）降→身魔（身假）降→死魔（無生哪會死）降→天魔（波旬因你愛此三者才能欺負你，你不愛則奈何不了你）自降〔行918–938〕。「方便及方便力」則被讀為六波羅蜜之外、僧肇後加的第七度，以《大日經》「方便為究竟」與吉藏「方者理正、便者隨緣」定其義〔行969–979〕——序分的德目至此不再是名相羅列，而是「如何用於降魔度生」的修證綱領。

## 10. 法脈會通

### 10.1 全講中樞等式：一切歸「大種」

法師把本講所有引經串成**一條等式**，指向同一物：

```
識精元明（楞嚴）＝ 元清淨體＝菩提＝涅槃
      ＝ 大種（華嚴覺林偈）＝ 空（心經）
      ＝ 毘盧遮那（遍一切處）＝ 螢幕（法師譬喻）
      ＝ 自性＝本心＝真心＝法界＝法性
      ＝ 息（安那般那不生不滅）＝ 佛性
      ＝ 阿彌陀（超越時空・心淨國土淨）
```
**連結要點**：這一物「沒有一天離開我們」，只是被「攀緣心（生死根本）」遮蓋（失本明＝掩蓋非失去）〔行581〕；一切經典每堂課都在講它，「不講這個叫外道」〔行360〕。

### 10.2 兩種根本 ↔ 一念不覺三細 ↔ 六根六塵（起信論會通楞嚴）

法師用《起信論》「一念不覺生三細」來註解《楞嚴》「識精元明，能生諸緣緣所遺者」，再落到六根六塵：

```
             真心本性（識精元明／大種）── 本自清淨，眾生本具
                     │  一念不覺（波動·境界的境）
                     ▼
      ┌──────────────────────────────┐
      │  ①業相（波動·無明業相）                      │  ← 一念不覺生三細
      │  ②轉相＝能見相＝【見分】                     │
      │  ③境界相＝所現相＝【相分】                   │
      └──────────────────────────────┘
              │                        │
        見分 ↓                    相分 ↓
   六根（眼耳鼻舌身意）        六塵（色聲香味觸法）
              │   根塵相對
              ▼
     六識（眼界識…意界識）→ 判斷愛憎 → 攀緣心 → 枉入諸趣（生死）
              │
        「緣所遺者」：見分相分再怎麼緣，永遠緣不到本性 → 心行處滅、言語道斷、不可思議
```
| 楞嚴（本講支柱一） | 起信論援引 | 該引文如何詮釋楞嚴句 | ✓CBETA |
|---|---|---|---|
| 「用攀緣心為自性者」 | 「以心生則種種法生」六粗攀緣 | 攀緣心即三細之後六粗之執取分別 | T1666 ✓ |
| 「識精元明，能生諸緣」 | 「依不覺故生三種相」 | 諸緣＝見分（能見相/轉識）＋相分（境界相/現識） | T1666 ✓ |
| 「緣所遺者」 | 「心不見心，無相可得」 | 諸緣（見相二分）緣不到能生它的本性 | T1666 ✓ |

### 10.3 六方佛・一佛即千佛（螢幕頻道→阿彌陀→西方）

法師以「螢幕—頻道」解阿彌陀經六方（十方）佛出廣長舌相：

```
   東方佛 ─┐
   南方佛 ─┤
   西方佛 ─┼─ 各出廣長舌相、遍三千大千、說誠實言
   北方佛 ─┤        │
   上方佛 ─┤        ▼   一佛即千佛，只是頻道不同
   下方佛 ─┘   同一個【螢幕＝大種】── 凡夫只看頻道，不知螢幕唯一
                     │
              入本心＝心淨國土淨 → 往生一刻「南無阿彌陀佛」→ 西方極樂（最後歸宿）
```
**連結要點**：地藏經地獄眾相、阿彌陀經十方淨土，都是同一大種（螢幕）變現的異相；故念地藏經前須先念《華嚴》覺林菩薩偈入法界，否則落入「迷信、宗教色彩」〔行615–629〕。

## 11. 日常實踐

1. **安那般那調息治身安心**〔行152–199〕：先「安那（出息）」觀想把身體病痛、業力、攀緣氣息呼出（即懺悔）；呼吸之間經「空檔（息＝空性＝佛性）」再入息（清淨新鮮）。數息由急促（風）→緩和（氣）→自然（息）三階，越練越慢，讓心安靜、氧氣遍佈細胞。
2. **觀煩惱本無生以永斷煩惱**〔行918–924〕：不要「斷了又來」地壓制煩惱；佛法是「悟」不是「壓」——體悟煩惱本是虛幻、自製自幻滅，即降欲魔。
3. **降四魔於日常**〔行926–938〕：身病、身老皆自然現象，隨緣看醫、不執身（降身魔）；無生哪會死（降死魔）；不貪愛身、樂、命三者，天魔即奈何不了你。
4. **關掉貪瞋癡慢疑的開關**〔行876–884〕：習性是「用一次就有第二次」養成的；生氣時越生越氣會驅動身口造大錯。久不啟發五蓋，它本來就沒有；改為啟發佛性這一邊。
5. **以罪從心起、將心懺罪對治冤屈**〔行432–447〕：相上因果須受（該關要關），但心若無罪則清淨；「罪從心起將心懺，心若滅時罪亦亡」；把討債／還債／報恩／報仇四事以無所受心承擔，即入三昧、不再受輪迴干擾。
6. **作「不請之友」度化眷屬——先做普賢行**〔行900–909、1072–1076〕：從家中父母、配偶、子女開始；他們不聽，就「做給他看」（以前頂嘴今不頂、以前斤斤計較今放下、好睡不爭），久之他自會問你訣竅。三嫌而止、無諍隨緣，不糾纏。
7. **以本心（反聞聞自性）聽經、念咒**〔行834、952–964〕：聽經重在自性相應，非耳聽；念咒（六字大明咒、準提咒、穢跡金剛咒）縱不解義，一直念自自然然回歸本心——因總持句句直指本心。

## 12. 延伸・參

- **相關法脈連結**：本講兩大支柱《楞嚴》兩種根本、《華嚴》大種無差別，會在第03講「法界介紹」續講（法師預告下週講「離大種無異相可得」及地藏經堅牢地神）〔行635、613〕；下一講並將續誦序分「其名曰：等觀菩薩……」列名菩薩段〔行1084–1086〕。
- **教理釐清（misstatement 已於§6/校對標記）**：
  - 法師稱《法華義疏》為吉藏（嘉祥）「**翻譯**的」——實為隋·吉藏**撰**（T1721），非翻譯。
  - 《大日經》原文為「菩提心為因，悲為根本，方便為究竟」，法師引作「以菩提為因，大悲為根，方便為究竟」，義同而字略異。
- **一參問**：法師說序分三萬二千菩薩的功德「其實在講我們，本具而未認識」〔行872〕。若這一切功德本自具足、只被攀緣心「掩蓋」而非「失去」，那麼「修行」與「本具」之間，你如何安放「還要不要修、修什麼」這一問？（法師的答案是：修即是「悟」、「知幻即離」——你的答案呢？）〔行948–949、816〕
