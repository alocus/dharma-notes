## 1. 本講概要

本講進入《維摩詰經》第十二〈見阿閦佛品〉的主文——**佛與維摩詰居士首度、也是唯一一次的正面對話**〔行548-554〕。佛問維摩詰「汝欲見如來，為以何等觀如來乎？」維摩詰答以一長串「不…不…非…」的否定語，描寫**如來法身**的體性。這是全經正宗分的收束，五祖弘忍曾印證此品「若體悟則此生梵行已立、所作皆辦、不受後有」〔行13-19〕。

在正式解主文之前，體佛法師先用近三分之二的篇幅鋪陳三個大架構，作為讀懂「觀如來」的鑰匙：

1. **《涅槃經》四依法**〔行73-273〕，重點落在最難的第四依「依了義不依不了義」，並援引**趙宋·法護譯《大乘菩薩藏正法經》**列出「了義／不了義」的**五種判別**〔行273-418〕。
2. **五方五佛（金剛界曼荼羅）**——五蘊轉五智、識轉智的修行地圖〔行161-169、616-658〕。
3. **三轉法輪**——以「太陽先照山頂、次照山腰、後照平地」倒反佛「從平地講起」的次第，判攝苦集滅道／般若空性／空有不二三期〔行470-546〕。

貫串全講的核心譬喻是**冰與水**：冰＝煩惱／識／執著，水＝菩提／自性／上善若水；「你是冰，融了就是水，不必另覓水」〔行307-315、580-602〕。落到本品，就是維摩詰所說的**如來性＝如來藏＝空有不二**，法師以馬鳴《起信論》「真如門／生滅門」、黃金作器「器器皆金」為之疏解〔行921-940〕。全講最後以《楞嚴經》七處徵心後佛開示「若離前塵有分別性，即真汝心」作結〔行968-1091〕，並穿插兩則完整公案：**幻士仁賢**（《幻士仁賢經》）〔行810-873〕與**大梅法常「梅子熟」**〔行212-234〕。

本講另具特殊人情：法師自述「這一年多做了30遍化療，與《維摩詰經》同進退」〔行400-404、426〕，以「生死涅槃本無二，你現在就涅槃了」自況——正是本品了義的現身說法。

## 3. 核心概念

| 概念 | 體佛法師之解說〔行〕 | 經教連結（核驗） |
|---|---|---|
| **見阿閦佛品** | 正宗分最後一品；五祖印證體此品則「梵行已立、所作皆辦、不受後有」〔行13-19〕 | 《維摩詰經》第十二品 ✓ CBETA T0475 |
| **四依法** | 佛《涅槃經》遺教：依法不依人、依義不依語、依智不依識、依了義不依不了義〔行75-273〕 | 出《大般涅槃經》✓ CBETA T0374（四依詳見§6） |
| **了義／不了義** | 了義＝究竟圓滿＝實＝勝義諦；不了義＝方便＝權＝世俗諦。「不依」不是不要，而是不停留、不排斥，因它是過程〔行196-259〕 | 判別依《大乘菩薩藏正法經》✓ CBETA T0316（趙宋·法護譯） |
| **勝義諦／世俗諦** | 講世俗諦是為引入勝義諦；佛因根器不得不講世俗諦〔行198-204〕 | 龍樹《大智度論》二諦說 ✓ CBETA T1509（龍樹**造**·羅什譯，見§經證訂正） |
| **大圓鏡智／阿賴耶** | 二者不一不異；大圓鏡智是「主」（真心本性），阿賴耶是「客」（真妄和合），客變主則輪迴〔行43-51〕 | 《楞嚴》「認客為主」義；轉識成智詳見§5 |
| **如來法身（超三際）** | 如來超越過去現在未來，本心如虛空無時間，時間是入凡夫識才有〔行556-566〕 | 《金剛經》「過去心不可得，現在心不可得，未來心不可得」✓ CBETA T0235 |
| **如來性＝如來藏** | 不一相不異相之綜合＝空有不二；不變是「一」、隨緣出「異」；如叫善（不變）、來/逝叫變化〔行921-940〕 | 馬鳴《起信論》真如門／生滅門 ✓ CBETA T1666（法師用「空如來藏/不空如來藏」名相，起信論作「如實空/如實不空」，見下辨析） |
| **三明（天眼明/宿命明/漏盡明）** | 皆法界神通，非世界神通；不是修來，是了達真相後自性功德顯發〔行787-793〕 | 《維摩》「具足三明」✓ CBETA T0475 |
| **通達無我法者即菩薩** | 無我不是修來，是本來如此（天真佛本無我）；「通達」非「修得」〔行669-700〕 | 《金剛經》「若菩薩通達無我、法者，如來說名真是菩薩」✓ CBETA T0235 |
| **增上慢人** | 「上」＝有修行者，「慢」＝太慢（達涅槃太慢）；以生死涅槃為二際、欲斷煩惱者，即增上慢〔行890-898〕 | 《維摩詰經》語 ✓ CBETA T0475 |
| **法塵分別影事 vs 分別性** | 前者是第六意識執著之分別（妄心）；後者是大圓鏡智「漢來漢現、胡來胡現」之明明了了（真心/佛性）〔行1062-1067〕 | 《楞嚴經》✓ CBETA T0945 |
| **真心（若離前塵有分別性）** | 不受法塵干擾、卻明明白白的那顆心即真心；斷法塵＝斷心＝龜毛兔角〔行1030-1091〕 | 《楞嚴經》✓ CBETA T0945 |

**名相辨析——「空如來藏／不空如來藏」**：法師以「空如來藏＝自性清淨圓明體＝真如門（不變）」、「不空如來藏＝隨緣生滅門」相配〔行923-946〕。核驗《起信論》T1666：原文作「真如者依言說分別有二種義：一者如實空…二者如實不空」，並立「心真如門／心生滅門」。法師名相與《勝鬘經》「空如來藏／不空如來藏」相合，義理與《起信論》二門一致；此屬名相互用，特此標明其取自不同經論之語。

## 4. 故事・公案

### 4.1 密勒日巴事馬爾巴——依法不依人〔行89-95〕
藏傳白教（噶舉）祖師密勒日巴為求大手印拙火之法，事上師馬爾巴（Marpa）。馬爾巴極盡「侮辱」：叫他蓋房子，蓋完弄掉、再蓋再弄掉；密勒日巴傾其所有供養，只剩一隻跛腳的羊，因覺跛羊供師無禮而留著，馬爾巴仍責問。體佛法師以此說明：上師之嚴苛是在**消弟子心的障礙（真正的業障）**；心障平伏後，馬爾巴方傳其大手印第二次第拙火，密勒日巴遂成就〔行89-95〕。法師藉此印證「依法不依人」——法如明燈，管他拿燈者是誰，甚至仇敵亦當隨之出黑暗〔行79-85〕。（禪門/藏傳傳記公案，非CBETA根本經；※ 事蹟屬傳承史，不對根本經核驗。）

### 4.2 大梅法常「梅子熟了」——不了義入了義〔行212-234〕
大梅法常隨馬祖道一約八年。馬祖為他點出的最終勝義諦是「**即心是佛**」（自心是佛，心外無佛，法外無心）〔行218〕。大梅印可離開，久居一方。馬祖遣一侍者往試，故意說「馬祖近日又道『非心非佛』」。大梅答：「這老禿驢惑亂人未有了日，任汝非心非佛，我只管即心是佛。」侍者回報，馬祖曰：「**梅子熟也！**」〔行226-234〕。法師以此說明：從世俗諦（種種方法/道）進到勝義諦（即心是佛），一旦安住本心，「任憑須彌山可斷」，勝義諦絕不可變〔行234-236〕。（禪門公案，出《景德傳燈錄》《五燈會元》；法師明引《景德傳燈錄》〔行208、212〕。※ 語錄公案，不對T根本經核驗；「即心是佛/非心非佛」為禪門通傳。）

### 4.3 歌利王割截忍辱仙人／憍陳如先開悟〔行496-520〕
釋迦過去世作忍辱仙人時，被歌利王節節支解而不生瞋——**不是忍耐，是「無忍可忍」**，因他了知「你割的是虛幻的東西」，身體如影子，「你踏我的影子請便」〔行500-508〕。故無我相、無人相、無眾生相、無壽者相——這才是了義〔行504-506〕。此因緣極深，故佛初轉法輪度五比丘時，點頭最累、**第一個開悟的憍陳如尊者即當年的歌利王**〔行510-512〕。法師申論：歌利王「割對人了」，若割凡夫則互割百劫千劫、了無出期；放下（原諒）的那一天才不用再割〔行512-516〕。（本事出《金剛經》T0235「如我昔為歌利王割截身體…忍辱仙人」；忍辱仙人＝憍陳如過去因緣為禪講通說。）

### 4.4 幻士仁賢——《幻士仁賢經》全本〔行805-875〕
佛在王舍城靈鷲山說法，眾菩薩、阿羅漢、帝釋天、四天王皆集。摩羯陀國有大幻師名**仁賢**，具「世界神通」（幻術），能變神奇百怪令眾臣服，名聞王舍城。他聽說沙門瞿曇受各國尊重，遂欲挑戰，親往見佛、右繞三匝，邀佛至其住處受供養，暗中要「造一個局」戳穿佛、奪佛名聲〔行810-817〕。

目犍連（神通第一）問佛：仁賢不懷好意，何以應允？佛答：仁賢宿有深厚善根，我去正可「幻化成一部經典，令眾生了達世間皆幻相」，為度眾生故受邀〔行818-820〕。

仁賢以幻術變出莊嚴庭園、法座、如祇樹給孤獨園之樹林，欲請佛升座後當眾拆穿「這全是我的幻化，看佛知不知」〔行822-824〕。不料四大天王下來，讚其莊嚴但嫌「你畢竟是人，還不夠莊嚴」，遂變出更寬廣的法座、更莊嚴的庭園樹林；仁賢驚「天外有天、人外有人」〔行826-828〕。繼而帝釋天（法師稱玉皇上帝，印度稱毗濕奴/大梵天）又來，變出更殊勝者。仁賢自知「我連四天王、玉皇上帝都不及，而此二位為供佛竟變如此莊嚴，可見佛之偉大非凡夫所及」，天王與帝釋更告以「我等與佛之能力如滄海一粟」〔行830-834〕。

仁賢欲收回自己所幻，**竟收不回來**〔行836〕。次日佛來，四天王、帝釋跪迎，仁賢嚇壞、真實掉淚向佛懺悔：「我本要考驗祢…想不到天外有天、人外有人。」佛點頭：「我知仁賢宿有善根，今日應供是為以後講此經的廣大因緣。」〔行838-842〕

佛乃開示：「不但你們變的是幻術，**所有來聽經者全是幻化，包括菩薩、包括我到娑婆示現釋迦牟尼佛、包括我所講的般若智慧，皆是幻化**；三千大千世界無一不幻。仁賢若能悟此，當下成就。」〔行842-844〕仁賢跪泣，佛以偈開示——

> 譬如本此處，一切皆化造。仁賢所興幻，欺誑惑眾人。一切法如是，本悉皆平等。不覺了當來，愚癡行生死。〔行849〕

（此偈依逐字稿重組，※ 未逐句核驗至T0324原文行；經義與《幻士仁賢經》一致。）法師釋：「本此處＝今此相會皆因緣所生（皆化造＝一定有其因）；因緣所生法即是空，即幻影；仁賢所變是騙人的幻術；一切法本皆平等（皆幻故）；若不覺了，未來只有『愚癡行生死』一途。」〔行849-859〕仁賢由此開悟、求佛剃度。佛請彌勒（阿逸多）為之剃度，彌勒說出全經結論——

**「出家者非菩薩形象也，亦非沙門形象也；真出家者，是有佛的通慧，能在三界教化眾生，此為菩薩出家也。」**〔行863-867〕（法師轉述之義，※ 文句為法師依經義敘述，非逐字核驗。）法師申論：真出家是**通達佛智、發菩提心、不怕生死而於三界普傳佛法**，非僅現聲聞相〔行865-867〕。全經在此畫下句號，天人阿修羅皆得阿耨多羅三藐三菩提〔行863-865〕。此經西晉·竺法護譯，三國/西晉即入中國，五胡十六國、魏晉南北朝廣為流行，唐後因經典多而被忽略〔行869-871〕。

### 4.5 楞嚴七處徵心後開示真心（阿難）〔行968-1091〕
《楞嚴經》緣起於阿難與摩登伽女：摩登伽女不滿文殊破壞好事，其母（大魔術師）以幻術符咒放缽中，阿難托缽誤中，見女越看越美〔行968-976〕。文殊持咒帶回阿難。佛喝斥後「七處徵心」，阿難處處被否（在眼、在心、在外皆不對），最後泣求：「真心在哪裡？祢直接告訴我。」〔行980-988〕佛乃分**四段**開示（本講結論）——

1. **因聲而有分別**：你們藉我口出的音波，用耳聽卻用意識心解釋，故「我以一音而說法，眾生隨類得其解」〔行992-996〕。
2. **內守幽閑仍是法塵分別影事**：有人修行斷見聞覺知、守住內在幽寧（守空），佛說「此人猶為法塵分別影事，執為非心」，仍非真心〔行1018-1026〕。
3. **若離前塵有分別性即真汝心**：先肯定心「微細揣摩」（想什麼變什麼）；能不受法塵（心所現影像）干擾、卻明明白白的那顆分別性，即真心〔行1030-1042〕。法師舉虛雲老和尚「杯子撲落地作聲」而虛空粉碎、明明了了不受干擾為證〔行1044-1046〕。
4. **斷法塵即斷法身**：若欲斷除法塵分別影事，則「此心同龜毛兔角，法身同於斷滅，其誰修證無生法忍？」——法塵是心所變現，斷法塵＝斷心＝斷自性，反不能悟無生〔行1074-1091〕。

（全段《楞嚴經》T0945 卷一，核驗詳見§9。）法師以壇經**臥輪偈**（能斷百思想、對境心不起）為「斷妄」之病，以**惠能偈**（不斷百思想、對境心數起）為真見性——「應無所住而生其心」〔行1050-1055〕。

## 8. 本經解義（維摩詰所說經逐段）

> 本講主文＝〈見阿閦佛品〉佛問「汝欲見如來，為以何等觀如來乎？」維摩詰以「觀如來法身」長段答之（T0475）。以下依經文次第列「原句→體佛法師釋義→脈絡定位」。§9 為支撐性經證。

### 8.A 佛問・維摩詰觀如來（本品主段）

完整原句（T0475，✓ 核驗）：
> 爾時世尊問維摩詰：「汝欲見如來，為以何等觀如來乎？」維摩詰言：「如自觀身實相，觀佛亦然。我觀如來前際不來，後際不去，今則不住；不觀色，不觀色如，不觀色性，不觀受、想、行、識，不觀識如，不觀識性，非四大起，同於虛空；六入無積，眼、耳、鼻、舌、身、心已過；不在三界，三垢已離，順三脫門，具足三明，與無明等；不一相、不異相，不自相、不他相，非無相、非取相；不此岸，不彼岸，不中流而化眾生；觀於寂滅，亦不永滅；不此不彼，不以此，不以彼；不可以智知，不可以識識；無晦無明，無名無相，無強無弱，非淨非穢；不在方，不離方，非有為，非無為，無示無說；不施不慳，不戒不犯，不忍不恚，不進不怠，不定不亂，不智不愚，不誠不欺，不來不去，不出不入，一切言語道斷；非福田，非不福田，非應供養，非不應供養；非取非捨，非有相，非無相；同真際，等法性，不可稱，不可量，過諸稱量；非大非小，非見非聞，非覺非知，離眾結縛；等諸智，同眾生，於諸法無分別；一切無失，無濁無惱，無作無起，無生無滅；無畏無憂，無喜無厭無著；無已有，無當有，無今有；不可以一切言說分別顯示：世尊！如來身為若此，作如是觀，以斯觀者，名為正觀；若他觀者，名為邪觀。」

### 義理深入

**（一）觀如來即觀自身實相——法身是本具，非外求。** 法師扣住「如自觀身實相，觀佛亦然」〔行759〕，指出全段否定語（不觀色…不此岸…不可以智知）不是要否定一切，而是**遮遣凡夫對如來的相上執取**，逼顯法身「同於虛空」而又「化眾生」的雙重性。此段在本品的定位，是把前十一品維摩詰對十大弟子、諸菩薩的種種破斥，收攝為佛親問下維摩詰對「如來法身」的正面（以否定方式呈現的正面）界說——這是正宗分的封頂〔行548-556〕。

**（二）「不一相不異相」＝如來藏＝空有不二，是全段樞紐。** 法師以《起信論》真如門（不變/一）與生滅門（隨緣/異）、黃金作器（金一器多）疏解此句〔行921-940〕，並點出本品到此**首次由「不」轉為「非」**〔行916〕：「不」「非」皆非決然否定，而是「否定之中的肯定」（活句）。由此「不此岸不彼岸不中流而化眾生」「觀於寂滅亦不永滅」順勢而通——如來遍一切處、寂而常化，正是「不空如來藏」的大悲用〔行942-952〕。

**（三）「不可以智知，不可以識識」是本講落點。** 法師特別把此「智」訓為「世智辯聰/聰明」而非般若智〔行954-956〕，藉幻士仁賢（縱得無數諾貝爾獎仍不識如來）與《楞嚴》七處徵心（阿難多聞第一仍不知真心）雙線收束：**如來非聰明可測、非識心可識，唯離前塵之分別性（真心）方相應**〔行958-967、1030-1042〕。這使本品的「觀如來」不停在名相，而落到讀者當下可操作的「明明了了而不受法塵干擾」的一念真心。

## 11. 日常實踐

- **八風吹不動的正因**：不是忍耐，是了達「一切相皆虛幻」。碰到利衰毀譽稱譏苦樂，先認取它是幻影〔行15-17〕。（法師：你超越蘇東坡——他八風吹不動，人講「放屁」就一屁過江〔行434〕。）
- **往生淨土在當下一念**：過去所作不算，關鍵是臨終一念能否一心不亂；故現在要不斷薰陶，臨終方不被外境轉〔行31-41〕。「盡情縱欲卻想臨終一念清淨」如「平時不讀書卻想聯考兩天決勝」，必考不上〔行37-39〕。
- **依法不依人的實操**：聽法先看「是正法還是邪法」，不必先調查講者背景/學歷/交過幾個女友〔行85、263〕。但「沒有人（講者）也不行」——不了義（人/語/識/世俗）是過程，不可排斥〔行261-269〕。
- **煩惱在自心不在他人**：「我很討厭他所以煩惱」——若有一天不討厭他就不煩惱，可見煩惱在你心不在他〔行366-368〕。故懺悔、原諒是過第一關的功課；報復必被報復，除非對方是聖者不在意〔行514-518〕。
- **冰融成水的方法**：聽經、念佛，聽到「不執著」；「沒有那種（結冰的）溫度，自然成水，不用再找水——你就是佛」〔行311-315〕。放下就是了；「講那麼多，是因為不講你放不下」〔行315-317〕。
- **修行的真道場是娑婆**：香積佛國/阿閦佛國皆諸上善人，無逆增上緣；娑婆有人忤逆你，才是最好的歷練場，一世抵香積佛國數千劫〔行434-436、732-734〕。
- **對境心數起而不著相**：學惠能「不斷百思想，對境心數起」——紅綠燈要清清楚楚（不然罰單加送精神病院），佛性是明明了了不違世俗諦而不著相〔行1050-1055〕。真修行是「不斷妄想」，斷法塵即斷心〔行1089-1091〕。
- **法身重於色身**：色身終歸一死，眷屬財富名譽終歸沒有；問自己「用在法的心 vs 用在世間的心，比例多少？」便知會不會開悟〔行686-688〕。

## 12. 延伸・參

- **相關講次**：上一講（第57講）已講五方五佛，本講〔行161〕明言「上個禮拜我們講了五方五佛」，可對讀。本品〈見阿閦佛品〉的往生阿閦佛國妙喜國義，接續維摩答文殊之脈絡。
- **本經下一段**：主文尚有「無晦無明…一切言語道斷…同真際、等法性」等未及細講（T0475 原句已具，見§8.A 完整原文），法師預告「如來品我會放慢」〔行1093〕，待下講。**已展開者本講皆已收入**（無遺漏）。
- **跨宗教推演屬法師個人見解**：耶穌27歲前東學受大乘薰陶、上帝＝佛性、十字架＝悲智雙運等〔行125-179〕——法師明言為推演/會通，非佛經記載，讀者宜以「法師個人詮釋」視之，勿誤為經證。
- **一參問**：法師訓「不可以智知」之「智」為世智辯聰〔行954〕。試參：同一「智」字，於「依智不依識」之「智」（般若）與「不可以智知」之「智」（世智）判然不同——你當下讀經時，如何當機辨別一個字是了義語還是不了義語？
