## 1. 本講概要

本講承第八講「方便品」，完整講完維摩詰「以身疾廣為說法」一段（T0475 卷上〈方便品第二〉，CBETA 行114/116/118）。體佛法師的through-line是三段推進〔行108-345〕：

1. **呵身（十喻不可信）**：維摩詰示現七地（遠行地）菩薩，「以方便現身有疾」——法師強調此病是**真病**（站在三維物質空間是真的生病），非演戲；藉此真病，上至國王下至百姓、乃至佛遣弟子皆來問疾，維摩詰即以身說法，說身「無常、無強、無力、無堅、速朽」，並以聚沫、泡、炎、芭蕉、幻、夢、影、響、浮雲、電等十餘喻，破眾生對色身的貪執〔行108-294〕。
2. **讚法身**：呵身之後轉出正面——「此可患厭，當樂佛身；佛身者即法身也」。法身「非生因之所生，唯了因之所了」（引賢首國師《妄盡還源觀》自性清淨圓明體），是不生不滅、在聖不增在凡不減的第一因〔行302-337〕。
3. **發菩提心**：得法身之門，唯在「當發阿耨多羅三藐三菩提心」。菩提心即本心；忘失菩提心而修一切善法皆是魔業（《華嚴》）〔行341-352〕。

法師以大量祖師語印證「本心本具、頓覺即了」：《永嘉證道歌》摩尼珠、無價珍、三身四智體中圓〔行366-453〕；蓮花生大士伏藏《無染覺性直觀自行解脫之道》釋法化報三身皆自性本具〔行536-591〕；《六祖壇經》六祖言下大悟五何期自性、志誠問戒定慧「自性戒定慧」〔行594-753〕。並穿插密教法運史（那爛陀寺、四大士、東密台密、韋陀金剛杵）作方便度眾之例〔行488-535〕。

## 4. 故事・公案

### （1）神秀「時時勤拂拭」vs 惠能「本來無一物」——歡喜地的分水嶺〔行32-51〕
法師講歡喜地（初地）時說：初地菩薩「無所住煩惱」才叫沒煩惱；若還有一個煩惱要「讓它不煩惱」，那叫**壓抑煩惱**——這正是神秀的階段：「身是菩提樹，心是明鏡台，時時勤拂拭，勿使惹塵埃」——時時警覺讓煩惱不惹自己，這也在道的過程中，但五祖說神秀「不入門、未見性」。惠能則說「菩提本無樹，明鏡亦非臺，本來無一物，何處惹塵埃」——本來就沒有煩惱（煩惱是影像、不是實體，一講即破）。法師以「你把煩惱拿過來給我看」「醫生切肝腫瘤切得出，煩惱切不出」證明煩惱是主觀認定的虛幻。知幻即離，此人入歡喜地，無時不刻皆歡喜。
- 惠能偈 ✓ CBETA T2008；神秀偈為《壇經》記載，法師憑記憶述其大意。

### （2）衣索比亞垃圾堆孩童——代眾生苦是除「心苦」〔行137-143〕
法師講菩薩第三德「代眾生苦」時舉：一位記者到衣索比亞（或賴比瑞亞，法師自言記不清）採訪，看到小朋友成天在垃圾堆裡長大、沒書讀、還撿垃圾吃，便問「你們苦不苦？」孩童答「不會苦，好快樂喔！在垃圾堆裡自由自在、沒有束縛」——記者嚇了一跳。法師由此點出：原來世間的一切不是苦，苦是**心裡的苦**。有錢人、身體健康者可以天天苦不堪言，得癌症者反而天天快樂知足。故「代眾生苦」不是代受身苦，是把實相真智給眾生、除其心苦。

### （3）六祖言下大悟五「何期自性」與五祖夜傳衣缽〔行594-628,662〕
法師詳述六祖得法因緣：惠能（24歲、不識字）送木材時，在門外聽人誦《金剛經》至「應無所住而生其心」，言下大悟——「它是影像，我怎麼會住呢？」相契後問誦者何經、何處可請教，得知《金剛經》專家是湖北黃梅五祖（禪宗至五祖時由《楞伽》改用五千餘字的《金剛經》為印心經典），遂往黃梅。五祖見其一番話即知「法運來了、古佛再來人」，故遲遲不傳神秀（怕心法毀於神秀之手，寧等真人）。惠能書「菩提本無樹」偈，五祖故意擦掉（免人嫉妒），三更以袈裟遮圍為說《金剛經》，至「應無所住而生其心」，惠能啟曰五「何期自性」（本自清淨／本不生滅／本自具足／本無動搖／能生萬法），五祖知悟本性，即傳衣缽。渡江時六祖「迷時師度，悟了自度」自划船，請五祖速回。五祖假裝生病（法師特別對比：**五祖是假裝生病，維摩詰是真病**），讓大眾無機會問，並指點惠能躲入獵人隊歷練十五年，方出世為一方大祖師。
- 五「何期自性」、「應無所住言下大悟」、菩提偈 ✓ CBETA T2008。

### （4）法達禪師誦《法華》三千遍不解義〔行630-632〕
法達禪師已念《法華經》三千遍，拿錫杖見六祖不跪。六祖問他為何不跪，法達答「我念了三千遍」（帶驕慢）。六祖問「三千遍《法華》講什麼？」法達講不出。六祖（不識字）說「你念一段，我解釋給你聽」——法達聽後即向六祖頂禮。法師以此證：六祖不識字而能解，是**覺性本具的功德**（報身智慧），非學來的。

### （5）志誠問戒定慧——住心觀淨是病非禪〔行647-753〕
神秀弟子志誠隨神秀學道九年不得契悟。神秀（時為武則天國師，卻始終公開承認師弟惠能無師自通、得五祖衣缽才是真六祖）命志誠往曹溪聽法回報。六祖見有生人，戲稱「今有盜法之人」，志誠即出禮拜坦承。六祖問神秀如何教示，志誠答「住心觀淨、長坐不臥」。六祖曰「**住心觀淨，是病非禪；長坐拘身，於理何益**」，並偈「生來坐不臥，死去臥不坐，一具臭骨頭，何為立功課」（臭骨頭何來功德）。再問神秀戒定慧，志誠答「諸惡莫作名戒、眾善奉行名慧、自淨其意名定」（三者三分）。六祖曰此接大乘人、非最上乘、不了真實義，說自性戒定慧偈「心地無非自性戒、心地無癡自性慧、心地無亂自性定、不增不減自金剛、身去身來本三昧」（三則一、一則三，本心本無非無癡無亂）。志誠聞偈悔謝，呈偈「五蘊幻身，幻何究竟？迴趣真如，法還不淨」——法師特別點出「法還不淨」的雙關：一是不迴真如則法不淨；二是六祖讚歎「你心裡還有一個『要迴趣真如』的念，真如本自具足，你還有這念，此法哪有淨？」志誠遂願終身為六祖侍者，傳禪宗。
- 全段 ✓ CBETA T2008。法師述「何為立功課」處作「何來論功課」（變體，見§9）。

### （6）蓮花生大士伏藏與伏藏師的辨真〔行488-560〕
八世紀那爛陀寺真言宗（密宗）最盛，有四大士分傳：一至西藏（蓮花生大士），三至中國（善無畏、金剛智、不空）。蓮花生大士有一論，一千年後由**伏藏師**（把千年前大師密法找尋出來、可遇不可求者）掘出，中譯名《寧靜忿怒尊無上自性解脫最勝教敕》，又名《無染覺性直觀自行解脫之道》。如何辨伏藏師真偽？法師答：不看風水式的世間本領，**看掘出的法義是否即佛的法義**——若與經典道理相契、更上一層樓，即真。並引蓮池大師《竹窗隨筆》答「大乘非佛說」之問：「講的跟佛所講幾乎一樣，就是佛所說的，何須考證？」宗密大師答「《圓覺經》為何是佛說」亦同——內容與佛完全平等即是佛說；「考證是戲論，跟成佛無關」。

### （7）韋陀菩薩金剛杵破相・賢劫千佛〔行492-505〕
賢劫（我們這一劫）有千佛出生，釋迦牟尼佛為第四尊、彌勒為第五尊，韋陀菩薩是賢劫最後（第一千）佛——因祂發願護持賢劫千佛法運，故最後才成佛。韋陀手持金剛杵（vajra），金剛＝本心，金剛杵是法器非人間武器，用來「破相」（穢跡金剛、諸明王持杵皆為破眾生最大毛病——著相）。法師對比：韋陀是經典裡的法界護法（看不到、無史載），與伽藍代表關公（三國真實人物）不同。

### （8）密教法運東傳史〔行490-534〕
唐武宗毀佛後，正統唐密（不空→慧果傳空海）帶回日本成「東密」（高野山由來）；最澄以天台法要融入密宗成「台密」。中國僅留「雜密／別密」（胎藏界、金剛界正法未留，留幾個別法）。法師自陳其祖庭福慧寺師公慧山長老，把別密中的穢跡金剛帶回台灣，即此傳承。並解玄奘為何未帶《大日經》《金剛頂經》回中國——因當時那爛陀寺流行的是彌勒唯識宗（《瑜伽師地論》），玄奘主要目的是帶法相宗回中國。

## 8. 本經解義（維摩詰所說經逐段）

> §8 為本講之**脊梁**：依經文次第，逐句列出維摩詰原文（全句對 CBETA T0475 核驗）＋體佛法師之釋義＋在〈方便品〉脈絡中的定位。經文分三大段：呵身（十喻）→ 讚法身 → 發菩提心。

### 8-A 示疾緣起（序）

| 維摩原句〔行〕 | ✓CBETA T0475 | 體佛法師釋義（逐句） | 在本品脈絡之定位 |
|---|---|---|---|
| 「其以方便，現身有疾。以其疾故，國王、大臣、長者、居士、婆羅門等，及諸王子并餘官屬，無數千人，皆往問疾。」〔行201-208〕 | ✓ T0475 行114 | **「現身有疾」是真病，非演戲**（站在三維物質空間是真的生病、病得很嚴重、很痛苦，但心不痛苦）。因為病，喜事人未必來，喪事親友必到——故藉病引來上至國王下至百姓乃至佛遣弟子，都來問疾，才有說法的機緣〔行191-205〕 | 方便品度眾之「機」：以真病為方便，聚眾說法 |

### 8-B 呵身：十喻明色身不可信

**維摩原句（全文·CBETA T0475 行114）**：
> 「諸仁者！是身無常、無強、無力、無堅、速朽之法，不可信也！為苦、為惱，眾病所集。諸仁者！如此身，明智者所不怙；是身如聚沫，不可撮摩；是身如泡，不得久立；是身如炎，從渴愛生；是身如芭蕉，中無有堅；是身如幻，從顛倒起；是身如夢，為虛妄見；是身如影，從業緣現；是身如響，屬諸因緣；是身如浮雲，須臾變滅；是身如電，念念不住；是身無主，為如地；是身無我，為如火；是身無壽，為如風；是身無人，為如水；是身不實，四大為家；是身為空，離我、我所；是身無知，如草木瓦礫；是身無作，風力所轉；是身不淨，穢惡充滿；是身為虛偽，雖假以澡浴衣食，必歸磨滅；是身為災，百一病惱；是身如丘井，為老所逼；是身無定，為要當死；是身如毒蛇、如怨賊、如空聚，陰、界、諸入所共合成。」

| 維摩原句（節）〔行〕 | 體佛法師釋義（逐句） | 脈絡定位 |
|---|---|---|
| 是身無常、無強、無力、無堅、速朽之法，不可信也 | 上年紀或得病者最有感觸。無常其實是「常」（自然現象，看大學照片差很多）；老了「無強、無力」（走樓梯就喘）；「速朽」＝敗壞太快（癌症細胞分裂數月劇變）；身體「不可信」＝別太自信我的身體能怎樣，它都騙人〔行214-222〕 | 呵身總說：五個「無」皆站本心立場，本心則常 |
| 為苦、為惱，眾病所集；如此身，明智者所不怙 | 身體是苦惱的聚集地，眾病所集（只要有身一定有病）；真有智慧者（明智者）不依靠這靠不住的東西〔行222-224〕 | 引出下文「為何靠不住」的十喻 |
| 是身如聚沫，不可撮摩；如泡，不得久立；如炎，從渴愛生 | 身如泡沫，一撮摩就破（虎頭蜂一刺就死，何來強健）；如泡不能久立；「炎＝火」，由渴愛生——愛男女色時心如火、臉紅、心跳不已〔行228-237〕 | 隨文入觀：每喻皆令讀者親證身之虛脆 |
| 如芭蕉，中無有堅；如幻，從顛倒起；如夢，為虛妄見 | 芭蕉中空無堅；身是幻的、由顛倒（誤以為可靠）而起；如夢——夢見的人身是虛妄所見〔行237-239〕 | |
| 如影，從業緣現；如響，屬諸因緣；如浮雲，須臾變滅；如電，念念不住 | 身如影，由業緣（一生的註定劇本果報）而生；如響（蹦一聲，因緣而已）；如浮雲須臾變滅（細胞無一日停止分裂）；如電念念不住〔行239-246〕 | |
| 是身無主，為如地；無我，為如火；無壽，為如風；無人，為如水 | 身無主、無我、無壽、無人——其實是地水火風四大假合：地(站立骨骼)、火(溫度)、風(呼吸)、水(血液排泄)，缺一不可，皆因緣生的假象〔行246-250〕 | 四大破「我」：無一大可自主 |
| 是身不實，四大為家；為空，離我、我所 | 身不實，只是四大為家；身是空——父母未生前你在哪？死後你還存在什麼？故離「我」（我控制）與「我所」（我掌握）〔行250-252〕 | 由四大導出「空」與「無我我所」 |
| 是身無知，如草木瓦礫；無作，風力所轉 | 身本無知（會痛會癢是「覺知」來的，不是身體的感受），故如草木瓦礫；無作——身無自作用，是「風力（業力）所轉」〔行257〕 | |
| 是身不淨，穢惡充滿；為虛偽，雖假以澡浴衣食，必歸磨滅 | 身不淨——排汗、大小便，再美的人其穢物無人收藏；住院開刀便知。虛偽（假的），故不澡浴不行，但衣食終歸磨滅（還是要死）〔行257-261〕 | |
| 是身為災，百一病惱；如丘井，為老所逼；無定，為要當死 | 身即災（百一病惱）。老子亦言「吾有大患，為吾有身」（見§9）。「丘井」＝枯井，身如將無水之井，為老所逼——老僧自比「一口丘井、行將就木、為病所逼」；身無定，要當死（死路一條）〔行263-265〕 | 收束於「必死」：呵身之極 |
| 是身如毒蛇、如怨賊、如空聚，陰、界、諸入所共合成 | 身如毒蛇（時常侵擾，如煩惱毒蛇在心）、如怨賊、如空聚（假的東西）。「陰」＝五陰（色受想行識）；「界」＝十八界；「入」＝十二入——身是陰界諸入所合成〔行267-272〕 | 由喻歸結名相：五蘊/十二入/十八界所成 |

**義理深入（8-B）**：法師強調此段「全在講身體」，是**實相**、是自然現象，不是「修到」才如此——「這經文是讓你閱讀、隨文入觀」的。呵身的真正目的不在厭世，而在破「樂色身」的顛倒：眾生度不盡則成不了佛，而一切眾生正是「我們心產出的幻影」（「廣度如幻眾生」「降伏鏡裏魔軍」），故學佛是學內在、與外在截然無關（「所有成佛跟煩惱都是自心取自心」）〔行110-116〕。由身之十喻，直接導出五蘊/十二入/十八界皆幻——接《心經》「照見五蘊皆空」、《圓覺經》「知幻即離」：知一切幻、不被幻干擾的當下，六根六塵六識十八界乃至全法界清淨〔行270-289〕。此即〈佛國品〉「直心是淨土」的落腳處——淨土始於那顆不生不滅的本心〔行285〕。

### 8-C 讚法身：此可患厭，當樂佛身

**維摩原句（全文·CBETA T0475 行116）**：
> 「諸仁者！此可患厭，當樂佛身。所以者何？佛身者即法身也！從無量功德智慧生，從戒、定、慧、解脫、解脫知見生，從慈、悲、喜、捨生，從布施、持戒、忍辱、柔和、勤行精進、禪定、解脫、三昧、多聞、智慧諸波羅蜜生，從方便生，從六通生，從三明生，從三十七道品生，從止觀生，從十力、四無所畏、十八不共法生，從斷一切不善法、集一切善法生，從真實生，從不放逸生：從如是無量清淨法生如來身。諸仁者！欲得佛身、斷一切眾生病者，當發阿耨多羅三藐三菩提心。」

| 維摩原句（節）〔行〕 | 體佛法師釋義（逐句） | 脈絡定位 |
|---|---|---|
| 此可患厭，當樂佛身。所以者何？佛身者即法身也 | 身既可患厭（患、厭），故不要樂身體——它短暫、空聚、無定、無力。但不是不顧身體：它是因緣所生法，就用因緣法醫它（該醫就要醫，不能喪志自殺），因為你是願力菩薩，還要利用幻身度幻眾。轉出正面：當樂「佛身」，佛身即「法身」〔行294-307〕 | 全品轉折：由呵身（負面破執）轉入讚法身（正面立宗） |
| 從無量功德智慧生，從戒定慧解脫解脫知見生，從慈悲喜捨生，從布施…諸波羅蜜生，從方便生… | 這些功德「本來就存在」，不修也存在、修也存在，在聖不增、在凡不減——即《證道歌》「六度萬行體中圓、三身四智體中圓、八解六通心地印」，本自具足、一天沒消失〔行389,451,459-469〕 | 法身非新得，是本具功德的顯發 |
| 從斷一切不善法、集一切善法生 | 這裡的「善／不善」是**正與邪的善**（回本心才叫善），不是世間善惡——進入「善」＝回本心〔行476〕 | 呼應下文志誠段「相說的善」之辨 |
| 從真實生，從不放逸生 | 摩尼珠、無價珍即「真實」；「不放逸」＝時時警惕、安住摩尼寶珠（是「安住」非「執著」）〔行476-478〕 | |
| 欲得佛身、斷一切眾生病者，當發阿耨多羅三藐三菩提心 | 「眾生病」不是身病，是**著相（妄想執著）之病**——眾生最常患。得佛身、斷此病，唯在發阿耨多羅三藐三菩提心（無上正等正覺心，簡稱菩提心＝本心＝法身）〔行341-352,486〕 | 全品結穴：導向「發菩提心」的成佛要義 |
| 如是，長者維摩詰為諸問疾者，如應說法，令無數千人皆發阿耨多羅三藐三菩提心 | 維摩詰對這些問病者「如應說法」（包括有形無形眾生、國王），令無數千人皆發菩提心——把眾生的本心引出來〔行756-758〕 | 方便品度眾之「果」：說法圓滿，眾發菩提心 |

**義理深入（8-C）**：法師以「法身怎麼來」為此段核心，引賢首國師《妄盡還源觀》「自性清淨圓明體」——法身「**非生因之所生，唯了因之所了**」：凡因緣所生法皆幻（「因緣所生法，佛說即是空」），唯法身非因緣生，故沒有原因（如101大樓、器官皆有跡可循，唯自性無跡）；但萬法一切皆由它顯現、由它而了，是宇宙萬法的第一因〔行323-337,480〕。你能講話、走路、思惟，就是有那一個——佛已直指，再問即「非正問」，佛無諍不理你〔行331-339〕。此段把「當樂佛身」落實為「認取本具法身」，並以「發菩提心」為得法身之唯一門徑，直接開啟下講「阿耨多羅三藐三菩提心＋《金剛經》論」的續解〔行756-758〕。

## 11. 日常實踐

1. **病中修行法**：若正患重病，學維摩詰——不喪志、該醫就醫（用因緣法醫因緣身），但心不隨病苦轉；以自身之病為眾說法，即成願力菩薩〔行199,296-298〕。
2. **拿煩惱給我看**：煩惱起時，試「把煩惱拿出來給我看」——拿不出，即知它是主觀虛幻認定，一講即破；此即「知幻即離」的當下操作〔行44-48〕。
3. **代眾生苦＝給實相除心苦**：幫人時記住苦在心不在境，把「凡所有相皆虛幻」的真智給人，而非只解決外境〔行137-143〕。
4. **柔和質直·威儀有則**：內心質直、對外柔和（出家人頭要低），愛語利行、柔軟語令人歡喜——這是安眾生心的方便，非拍馬屁〔行124-134〕。
5. **為一切所應為而心恆處無為**：日常一切照做（吃飯、看病、工作），但當下心處無為，即入首楞嚴三昧；無為就在有為中〔行174,189,300〕。
6. **以經自印**：聽經時每一次點頭認同，即是本心與諸佛菩薩相契的一次印證——「經典所在之處則為有佛」，以經典印自己修證，如以古文觀止自印國文程度，不必求人印可〔行356-364,634-638〕。
7. **不忘菩提心**：修任何善法先發菩提心（本心），否則「忘失菩提心而修善法皆是魔業」（不能了生死）〔行347-352〕。
8. **不落相說**：為善、去惡、修淨若著相（有善要行、有惡不作、有淨要守），仍是「相說」；當知本心本無非無癡無亂、本自具足戒定慧〔行696-729〕。

## 12. 延伸・參

- **本經前後**：本講完整講完〈方便品第二〉的「維摩詰示疾說法」段（T0475 行114/116/118）。第八講已講「以如是等無量方便饒益眾生」（行112）為前段；下講將續解「阿耨多羅三藐三菩提心」並引《金剛經》論作對照〔行758〕。
- **相關教理探討**：法身「非生因之所生，唯了因之所了」與賢首國師《妄盡還源觀》「自性清淨圓明體」的關係（本系列前曾講《妄盡還源觀》）；《華嚴》十地/十波羅蜜的完整對應。
- **一參問**：維摩詰「呵身」呵到「是身無定，為要當死」極處，卻不許自殺、要「該醫就醫」——「厭身」與「用身度眾」如何在同一念中不相礙？（提示：§8-C「為一切所應為而心恆處無為」、「用因緣所生法的幻身度因緣所生法的幻眾」〔行296-300〕。）
