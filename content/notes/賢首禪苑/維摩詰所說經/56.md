## 1. 本講概要

本講是《維摩詰經》正宗分（主文）的最後一品〈見阿閦佛品〉的開講。世尊問維摩詰：「汝欲見如來，為以何等觀如來乎？」維摩詰以一長串「不…、非…、無…」的否定句來詮釋「如來」。體佛法師抓住這個結構，貫穿全講：

- **主軸一（如來義）**：「如來」言語道斷、心行處滅，凡人類語言文字所能形容者皆非如來，故維摩詰只能用「**不・非・無**」三字層層否定——否定時間、五蘊、四大、六入、六根、三界、三垢…否定到底，最後那個「不可以一切言說分別顯示」的，才叫如來。〔行384–412〕
- **主軸二（佛法架構＝先否定→再肯定→中道義）**：佛法先全盤否定相（凡所有相皆是虛妄），再肯定那放下相後本具的如來（若見諸相非相，則見如來），最後否定與肯定同時即中道義。維摩詰用否定式、《金剛經》用「即非—是名」三段式，法義一模一樣。〔行445–525〕
- **主軸三（一義＝空性＝如來）**：以《月燈三昧經》「一切諸法同一義」的偈為總綱——諸佛講經無量，只講「一義」，這一義就是空性、就是如來藏、就是自性；懂此一義，「於諸佛法不難得」。〔行254–312〕
- **前導長篇**：開講前近一小時，法師鋪陳修德→性德、發菩提心（350度）+六度萬行、人無我／法無我、真妄和合的阿賴耶、一心開二門（真如門／因緣生滅門）、不變隨緣，並引無垢光尊者「不通經義而遽然修法易入外道」、五祖《最上乘論》以《涅槃經·金剛身品》與《維摩·見阿閦佛品》二經印心等。〔行18–312〕
- **公案主打**：西晉竺法護譯《佛說如幻三昧經》**「文殊仗劍殺佛」**——度五百菩薩因宿命通見昔重罪而疑不成佛；藉「能殺所殺皆幻」令其當下悟無生。〔行637–694〕
- **末段延伸**：阿閦佛（不動如來）的來歷（無瞋念轉輪王第九子發願不瞋→妙色身如來→妙喜國）、五方五佛東方不動佛、金剛薩埵百字明、地藏菩薩種子字「訶」（微笑）、六祖「心地無非自性戒」偈、臥輪偈與六祖「惠能沒伎倆」、法師自述罹多發性骨髓瘤而「有覺覺痛，痛不干擾覺性」。〔行777–946〕

一句話總攝：**如來＝空性＝一義；欲見如來，先以「不・非・無」否定一切相，於相非相處即見如來，此即中道義。**

## 3. 核心概念（詞條＋經教連結）

| 概念 | 體佛法師釋義〔行〕 | 經教連結（已核驗） |
|---|---|---|
| **見如來／觀如來** | 「見」是「現」（現見即現也）；如來是眾生本具，一切眾生乃至螞蟻、蚊子、一闡提皆具如來性。「觀」即《心經》「觀自在」之觀，就是觀本心；觀即照也。〔行347–357〕 | 維摩「汝欲見如來，為以何等觀如來乎」T0475✓；心經「觀自在菩薩」T0251✓ |
| **不・非・無（三字表詮如來）** | 如來若能用人類語言文字形容，那就不是如來，是遍計所執、第六意識的分別。只能用「不、非、無」三字層層否定，否定到最後，那個不可言說者即如來。〔行396–414〕 | 維摩「不觀色…非四大起…無晦無明…」T0475✓ |
| **一義＝空性＝如來** | 諸佛講經無量，只講「一義」，故不復更宣說；這一義就是空性，「空就是如來，叫自性、叫如來藏」。懂此一義，「於諸佛法不難得」。〔行257–312,864〕 | 月燈三昧經「一切諸法同一義，以修空故如實知」T0639✓ |
| **先否定→再肯定→中道義** | 佛法先全盤否定相（凡所有相皆是虛妄），再肯定放下相後本具的如來（若見諸相非相即見如來），否定與肯定同時即中道義（既可也不可）。〔行445–464,825〕 | 金剛經「凡所有相皆是虛妄，若見諸相非相，則見如來」T0235✓ |
| **即非—是名（三段式）** | 《金剛經》語法：「三十二相＝即非三十二相＝是名三十二相」。即非＝否定，是名＝肯定，「即非即是名，是名即即非」＝中道。與維摩否定式法義一模一樣，表達方式不同。〔行512–527〕 | 金剛經「如來說三十二相，即是非相，是名三十二相」T0235✓ |
| **人無我／法無我** | 人無我＝四大假合是假的（善待身而不執著它）；法無我＝六塵緣影（心中現出的一切稱為「法」）不當真。通達無我法者即是菩薩。〔行28–36,698〕 | 金剛經「若菩薩通達無我法者，如來說名真是菩薩」T0235✓ |
| **一切法心想生** | 是「一切**法**心想生」非「一切**相**心想生」——法是心中現出的影像（不生不滅），相是外面的生滅法。心想鑽石不出現鑽石，正因外相非心所現之法。〔行50–55〕 | 觀無量壽經「諸佛如來是法界身…是心作佛，是心是佛」T0365✓ |
| **阿賴耶＝真妄和合／一心開二門** | 阿＝無量無邊，阿賴耶就是心。一心開二門：真如門（不變、空）＋因緣生滅門（隨緣起相＝妄）。真你不求（本存在，求則變妄），妄你不除（除妄即除真），只須「轉妄為真」。〔行145–166,185–189〕 | 大乘起信論（法師明引，見§6）；永嘉「不除妄想不求真」T2014✓ |
| **不變隨緣・隨緣不變** | 真如叫不變（它本空，怎麼變都不變）；不變的當下能隨緣而起生滅。緣起的當下即不變，一不是二。〔行161–166〕 | 心經「色即是空，空即是色」T0251✓ |
| **轉識成智／大圓鏡智** | 妄轉為真時，阿賴耶識轉為大圓鏡智，如鏡「緣來則應，胡來胡現、漢來漢現」，緣不干擾本心，即八風吹不動。〔行208–210,924〕 | 楞嚴「憶佛念佛…不假方便自得心開」T0945✓（不假方便自然轉） |
| **煩惱即菩提／貪瞋癡即戒定慧** | 戒定慧是覺性本能，因迷才變貪瞋癡；不是要斷波浪（斷則無海水／無覺性），而是「從波浪當下見海水」＝轉。有得有證、不悟煩惱即菩提者名增上慢。〔行635,880–924〕 | 諸法無行經（法師明引）；維摩菩薩行品「不盡有為，不住無為」〔行529〕 |
| **有覺覺痛** | 只要有佛性就會痛（打麻針才不痛）；但「無痛痛覺」——痛干擾不了覺性，身痛心不痛。法師以自身多發性骨髓瘤化療之骨痛為證。〔行902–908〕 | 楞嚴經卷五 畢陵伽婆蹉「有覺覺痛，覺清淨心，無痛痛覺」T0945（法師明引） |

## 4. 故事・公案（全敘述）

### 4.1 文殊仗劍殺佛——度五百菩薩悟無生〔行637–694〕
**出處**：《佛說如幻三昧經》（西晉·竺法護譯，T0342）；《大寶積經》亦有同記（法師：兩經同載可見其真實）。✓ CBETA T0342

**始**：佛在靈山會上入三昧，旁邊文殊菩薩亦入三昧。會中五百位聲聞（未完全成就的羅漢／菩薩）因已得四禪八定、宿命通，看見自己過去生所造的殺盜淫妄酒、乃至殺父、殺母、殺阿羅漢、破和合僧、出佛身血等五逆重罪——無有比這更嚴重者，他全做過。於是內心憂愁疑網：「我造這麼多惡，怎麼可能成佛？」甚至懷疑佛授記的話不真實，卻不敢說出口。

**承**：佛入三昧知道這五百人的心結，暗示文殊「出來演戲」。文殊即從座起，偏袒右肩，右手捉劍，走向佛所要殺佛。佛喝止：「止！」文殊問：「佛為何叫我等一下？」佛反問：「你到底是要殺我，還是要殺佛？」——「我就是佛」。

**轉**：佛替文殊說破：「若殺我，沒有意思，因為我本來無我，你要殺誰？若殺佛，佛本來不可得，你要殺什麼？」——因緣所成的我如幻師所化的幻人，我是幻、能殺我的是幻、你手中的劍更是幻，以幻取幻，哪有能殺、哪有所殺？

**合**：文殊聽完微笑，把劍放下。五百菩薩聞此法義，當下觀空——「我所認為的我、我幻想的，全部是空、都假的」——即證無所從生法忍（大阿羅漢）。佛更微笑，告訴五百人：「我一直教你們悟無生，你們不聽，用自己的罪惡處罰自己，已幾世不成佛；今日在靈山，還有此惡習，幸好與文殊演了一齣戲。」五百菩薩踊在虛空、去地四丈九尺，以偈讚佛。

**經末偈（canonical T0342，✓ 已核驗）**：
> 「文殊大智慧，　諸法度無極，　手自執利劍，　馳走向如來。佛亦如利劍，　二事同一相，　無生無所有，　亦無有害者。」

（法師口誦作「文殊大法王，於法深如底，手自握慧劍，馳奔如來身…如劍佛亦然，一相亦無二…無我無所生，云何而殺之」——屬變體／意引，見§9 ※。）

**法師引申（真懺悔）**：真懺悔不是儒家「不二過／不三過」的「不復作」，而是**「不復起」**——不再把假的罪惡撿起來折磨自己（宿命通見罪的五百人正是被自己撿起的舊罪所困，累劫不捨即累劫受苦）。故普賢偈「端坐念實相，重罪若霜露，慧日能消除」為真懺悔義。念佛亦然：「能念所念性空寂，感應道交不思議」。〔行682–694〕

### 4.2 佛度五比丘・割利王＝憍陳如〔行894–900〕
佛六年苦修，五比丘（憍陳如等）同修。佛知苦行非道，接受牧羊女乳糜，五比丘認為佛退大心，共議「悉達多以後不要理他」。後見佛現微妙相、不瞋、柔和語，知必有成就，遂於鹿野苑聽法。憍陳如尊者即《金剛經》中的**割利王**——昔日割截佛身體、千刀萬剮，佛無我相、人相、壽者相、眾生相，修忍辱波羅蜜。法師：「你割的那個是假的東西啊。」

### 4.3 阿閦佛（不動如來）的來歷〔行791–808〕
《悲華經》《阿閦佛國經》記載：無始劫以來有無瞋念轉輪聖王，第九子在大目（廣目）如來前發願「從此不瞋恨、不忿怒，了解一切都是影像」，修忍辱波羅蜜，因而感得**妙色身如來**之報（不瞋則臉色好看，生氣皆醜態）。此願力成佛，佛國名**妙喜國**，即阿閦佛（不動如來，「阿」＝不，「閦」＝動）國土。維摩詰有一世即在妙喜國當阿閦如來的脅侍菩薩（如觀世音為阿彌陀脅侍、本為正法明如來）——故《維摩詰經》正宗分最後必講〈見阿閦佛品〉。

### 4.4 臥輪禪師與六祖〔行745–768〕
六祖同時代的臥輪禪師入四禪八定（能坐兩三個月不食，凡夫最愛看），作偈「臥輪有伎倆，能斷百思想，對境心不起，菩提日日長」。有人講給六祖聽，六祖判「此偈未明心地，若依而行之，是加繫縛」，另示一偈「惠能沒伎倆，不斷百思想，對境心數起，菩提作麼長」。法師：斷心（想受滅無為，最多非想非非想天）是「假無為」；心就是讓你想的，「心隨萬境轉，轉處實能幽」——幽＝空性，怎麼想都干擾不了本心。✓ T2008

## 8. 本經解義（維摩詰所說經逐段）

### 義理深入（在維摩自身脈絡中）

**（一）「如自觀身實相，觀佛亦然」——觀如來即觀自身法身。** 本品緊接〈菩薩行品〉〈香積佛品〉之後，是正宗分收束於「如來義」的最高一問。維摩不從外相描述佛，而回到「自觀身實相」——你觀自己的法身實相是什麼樣，觀佛就是那樣。體佛法師點出：這一句已把「見如來」從向外求佛拉回向內見性，故全品的否定句不是否定佛的存在，而是**否定一切可被第六意識攀緣、分別、言說的相**，逼顯那「不可以一切言說分別顯示」的法身。這正呼應本講總綱：如來＝空性＝一義。〔行375–383,864〕

**（二）「不・非・無」是表詮如來的唯一句法。** 維摩通篇用「前際不來、不觀色、非四大起、無晦無明…」的否定串，體佛法師判為：如來若可用語言文字肯定地描述，那被描述的就落入遍計所執，即非如來。故只能層層否定——否定時間、五蘊、四大、六入、六根、三界、三垢，直到「一切言語道斷」。這與《金剛經》「即非—是名」三段式**法義全同、表達不同**：金剛經在否定（即非）後補一「是名」作假名安立，維摩則純用否定串到「順三脫門」處才以「隨順」輕輕一肯定。兩者都指向：**於相非相處即見如來**（先否定→再肯定→中道義）。〔行396–414,506–527,942–946〕

**（三）「順三脫門」是全段否定的收口，也是本講的落點。** 前七重否定（時間／五蘊／四大／六入／六根／三界／三垢）都在破「相」，到「順三脫門，具足三明，與無明等」才第一次出現肯定——但這肯定是「隨順」空、無相、無作三解脫門，即隨順本心，且「與無明等」（明暗不二）。體佛法師特意把講速放慢，強調重點不在文字快慢而在「思惟了義」：讀者須在每一「不」字上起觀照，否定到最後那個承載一切否定的空性，就是如來、就是自性、就是《月燈三昧經》所謂「一義」。本講止於此，餘「不一相不異相…」諸句留待下講。〔行829–833,864,942–946〕

### 9A 主經《維摩詰所說經》T0475（見阿閦佛品·觀如來全段）

> 爾時世尊問維摩詰：「汝欲見如來，為以何等觀如來乎？」

### 9C ※ 需標記的變體／未能對根本經逐字核驗者

1. **月燈三昧經「一義」四段偈**〔行257–312,292〕：法師在白板寫「諸如來廣說種種而說法，於此義中而得成於諸佛法不難得…世（甚）深信解，獲得一切福勝生，於諸世間出世間，所辦作事至成佛」。逐字稿此段 OCR 嚴重破碎（「世深诊我能信解，獲得一切福勝生…於諸世向出世向，所辦作事至成」）。經 grep T0639，**未找到與此四段完全逐字對應的連續 canonical 偈**；最接近的核心義理偈為 T0639「一切諸法同一義，以修空故如實知，彼無種種別異相，於此一義已修學」（✓ 已核驗）。故法師四段偈判為**意引／整理（reconstruction），非 T0639 逐字原文** ※。義理無誤（諸佛說一切法皆一義＝空性），僅偈文非逐字。

2. **如幻三昧經 文殊殺佛偈**〔行659–669〕：法師誦「文殊大法王，於法深如底，手自握慧劍，馳奔如來身…如劍佛亦然，一相亦無二…無我無所生，云何而殺之」。canonical T0342 作「文殊大智慧，諸法度無極，手自執利劍，馳走向如來。佛亦如利劍，二事同一相，無生無所有，亦無有害者」。屬**變體／記憶意引** ※（義理相符：能殺所殺皆幻、無我無所生）。

## 11. 日常實踐（可操作）

1. **臨終決於平日熏習**：一心不能二用，臨終真心／妄心哪個現起決定往生與六道，無把握，故唯一辦法是「不斷熏習經典，令妄意識再薄弱時仍是那一個」。〔行726–730,868〕
2. **不觀＝不執著的實修**：對時間、五蘊、四大、六塵緣影，「不觀」不是不去觀，是不受它干擾、不當真。日用中練習「用它而不執它」。〔行570–601〕
3. **真懺悔＝不復起**：不把過去的罪撿起來折磨自己（假的東西別再用假的折磨自己）；「端坐念實相，重罪若霜露，慧日能消除」。〔行682–694〕
4. **轉而非斷**：不斷貪瞋癡（斷則無覺性），而是「見波浪當下見海水」——起貪瞋癡時知其為迷、放下即戒定慧。轉識成智靠「知見轉／智慧轉」。〔行880–924〕
5. **不卑不亢**：承認「我是佛（本質）但還沒到（境界）」，說已到是自大，說不是則自卑；在過程中共同努力（法如筏喻）。〔行119–121,773–775〕
6. **微笑對眾**：修忍辱不瞋得妙色身；學地藏「訶」（微笑）度眾，不作苦瓜臉。〔行795–802〕
7. **有覺覺痛的安忍**：身痛心不痛——有佛性才會痛，但痛干擾不了覺性；以此面對病苦。〔行902–908〕
8. **金剛經六喻觀法**：以「如夢、幻、泡、影、露、電」六喻觀一切有為法，見相非相。〔行926–932〕

## 12. 延伸・參

- **本講止於**〈見阿閦佛品〉「順三脫門，具足三明，與無明等」；後段「不一相、不異相…名為正觀，若他觀者名為邪觀」及阿閦佛顯神通、維摩取妙喜國入此界等，**留待第57講**。〈見阿閦佛品〉為正宗分最後一品，其後尚有〈法供養品〉〈囑累品〉二品（流通分）。
- **相關前講**：本講多次回顧——菩薩行品「不盡有為，不住無為」（真菩薩空有不二）；諸法無行經「貪瞋癡即戒定慧、增上慢」；七佛滅罪真言諸佛偈（第三毗舍浮佛偈）；上一講引大乘起信論一心開二門。
- **一參問**：維摩以「不・非・無」層層否定至「一切言語道斷」來顯如來，六祖卻說「不斷百思想，對境心數起」——否定到底與心數起不斷，是否矛盾？（提示：否定的是「執相」，不是否定「心的作用」；轉處實能幽，正是心數起而不被相縛。試依§8「順三脫門」與§4.4臥輪公案自參。）
