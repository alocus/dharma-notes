## 1. 本講概要

本講正式進入《維摩詰經》第二品〈方便品〉上集，主角 **維摩詰居士** 登場。體佛法師先以「日照高山」譬喻，說明全經的編排次第：第一品〈佛國品〉（＝菩提／心之要義）先照上上根器，其後各品如太陽次第照下，令不同根器者漸次契入〔行11–17〕。接著以《大日經》「菩提為因、（大）悲為根本、方便為究竟」三句，為「方便品」定位——方便不可離菩提與慈悲，否則「方便」即淪為「隨便」〔行27–49〕。

法師點出全經三位主角（世尊·維摩詰·文殊師利）與兩條弘法路線之對比：世尊示現「教＋法」（出家、立僧團），維摩詰示現「以法為主、白衣護教」（在家、遊戲神通）〔行51–75〕。再引三論宗祖師 **吉藏**（嘉祥）於《思惟三昧經》之考證，及李白「金粟如來是後身」、王維字摩詰之自況，說明維摩詰即金粟如來倒駕慈航〔行79–95〕。

法師並以自身生命史（母親往生、擲筊九聖杯、2009 出家、走釋迦牟尼佛路線而非維摩詰路線）作真切見證，坦承「我做不到維摩詰」，以此襯托維摩詰在家而圓滿六度、空有不二之難能〔行99–170、569–571、828–841、872–876〕。

§8 是本講之脊——法師逐句解 T0475〈方便品〉的德行讚：遊戲神通（虛擬環境）→逮諸總持（陀羅尼＝sutra＋mantra）→善於智度（引《大乘密嚴經》密嚴國土「從智定得、以智慧火焚燒諸患因緣」）→大願成就·明了眾生心→六度皆能波羅蜜（引《頓悟入道要門》六度定義、五戒心法）→雖為白衣奉持沙門清淨律行（俱眼菩薩、身白衣心法界）→若在長者剎利婆羅門……護世，隨類度生→其以方便現身有疾。貫串全講的核心是《大乘起信論》**一心二門**（真如門／因緣生滅門）：維摩詰與虛雲老和尚皆「已入真如門，倒駕慈航示現因緣生滅門」以度如幻眾生〔行615–697、742–785〕。

## 4. 故事・公案

### 4.1 維摩詰＝金粟如來的三重考據〔行79–93〕

法師強調「講經要求真實」，遂追問：哪一部經寫過維摩詰是金粟如來？答曰出自《思惟三昧經》，然此經今大藏經、網路皆已佚失，無從查得。惟三論宗祖師 **吉藏**（嘉祥，唐朝八宗之一三論宗大師，血統帶外國，人稱「胡吉藏」）曾言，《思惟三昧經》中提到維摩詰是金粟如來。此考據又得旁證：唐朝大詩人 **李白** 於詩中寫「湖州司馬何須問，金粟如來是後身」——李白以金粟如來後身自況，實即自認維摩詰再世；另一大詩人 **王維**，字摩詰，亦以維摩詰自詡。可見《維摩詰經》於唐朝影響之大。法師由此反問：「你們是不是維摩詰？當你體悟到維摩詰的智慧，你就是維摩詰。」（考據源：吉藏《思惟三昧經》引文 ※ 該經佚；李白詩、王維字 ※ 非入藏，屬史料。）

### 4.2 法師母親往生・擲筊九聖杯〔行99–139〕

1999 年法師母親得癌症往生。往生前她自在不在乎身體，交代死後火化、骨灰撒入普陀山大海，要「跟觀音菩薩一起回歸觀自在」——法師提醒她從未去過大陸普陀山，她答「我只知道觀自在而已」。她未經任何治療、於八十餘高齡安詳往生。此遺言僅法師一人聽到。為安父親與弟弟的心，法師依台灣風俗火化、備玉罐瓷罐、選定台北北海福座牌位。安座前一天，母親由 **地藏菩薩** 帶著入夢，質問「我已交代撒普陀山大海，為何入塔？」法師徹夜難眠，隔晨在母親靈位前擲筊——並先向菩薩約定：若夢境為真，請示現。結果連續九個聖杯不停（多人作證）。法師遂親背母親骨灰赴普陀山（先寧波再搭船到普陀島），一路只持《大悲咒》完全入本心，祈觀音加持；香港關、寧波關檢查極嚴（骨灰粉恐被誤為毒品化驗），竟一關關通過、行李皆未開，最後於普陀普濟寺、稟毘盧觀音佛祖後，將母親骨灰撒入普陀毘盧遮那海。此即「方便為究竟」的親證：擲筊乃佛之方便，能安家人的心，心安則磁場圓滿。

### 4.3 虛雲老和尚：雲門事變與彌勒開示偈〔行195–270、742–746〕

法師以 **虛雲老和尚**（禪門大德，生於道光，歷清末民初，法名德清）為「虛擬人物示現方便」之近世典範。

- **西安大雪除瘟疫**：八國聯軍時慈禧太后自北京逃西安，虛雲一路追隨；西安因人馬集中爆發夏季瘟疫（瘟疫怕冷）。虛雲以方便神通遊戲三昧力，使七月西安下大雪、瘟疫頓除，慈禧欲賜最高榮耀，德清不受功名，越嶺入四川隱居；因見雲在虛空變化無窮，遂改號「虛雲」。
- **德清之名與憨山**：明朝四大高僧（依時序：蓮池·憨山·紫柏·蕅益）中憨山老和尚亦法名德清、示現肉身（如六祖）。虛雲至廣州發願弘揚衰微的六祖禪法，見憨山肉身剎那自語「德清（見）德清」，後人遂知虛雲前世即憨山。
- **反其道入內陸**：中國解放後眾多高僧政要爭相離開（赴美、赴台），虛雲卻自香港往深圳內陸而入，言「這一齣戲還沒有演完……中國的浩劫、佛教的浩劫還在後面，我不存在誰來善後」。
- **雲門事變（1952）**：廣州雲門寺被指藏反革命份子、電台、槍械，出家人遭拷打，虛雲被單獨關押、十餘日不許離開大小便，遭木棍鐵棍毆打吐血而不發一語；第一次昏迷甦醒後又遭續打，至頭破血流被丟溝渠。弟子中有數人燃指供佛、赴北京請願（燃指乃明清以來大發心之表法）。賴周恩來總理、廣東葉劍英元帥、李濟深等人奔走，方還虛雲公道。
- **彌勒開示偈**：虛雲甦醒後，急令弟子執筆記下他上兜率天所受 **彌勒菩薩** 的開示（記憶已不完整）。偈云（法師誦讀之殘偈，見 §8 義理深入）：「識智何分（水波一個）／凡夫夢宅（幻無所著）／知幻即離、離幻即覺／圓明大覺（能照森羅萬象）／一切皆空花、凡聖皆空花、善惡業與成就皆空花／悲願度生、夢境斯作／苦海慈航、毋生退卻／蓮開泥水、端坐佛陀。」彌勒告以「遊戲還沒結束，你再回去還有八年住世，至一百二十歲才回歸兜率」——虛雲回後果恢復肉身（眼張不開、傷處發膿久不癒），再住世八年於中國往生。法師指出虛雲往生那年正是他（貧僧）出生那年，兩者遙遙相對，皆「示現夢幻泡影平台以度眾生」。（此段亦引《圓覺經》「知幻即離、離幻即覺」意。）

### 4.4 埔里圓通寺演龍法師・回歸彌勒淨土〔行280–282、665–666〕

法師舉埔里圓通寺 **演龍法師**（著《聞經》三篇，將所聞經典寫出）為例：其告別式中一直表明願望是回歸 **彌勒淨土**（非往生阿彌陀佛），八十五歲坐化往生、後三年才聽到經，文章充滿對佛自性的體悟。法師以此印證「一回歸彌勒兜率淨土是有人在」（虛雲入兜率內院曾見阿難尊者為彌勒之維那、及同代高僧、紫柏老人法身不滅）〔行276–284〕。

### 4.5 法師三度求出家未果〔行828–841〕

法師自述曾想出家而被兩位師父拒絕：**廣欽老和尚** 不置可否；**宣化上人**（赴美唸書時求見）要他把《楞嚴經》全背起來，他背不了，知無此因緣。出家前又見 **淨空老和尚** 於台南極樂寺，從早餐、經行相談至中午，淨空勸他「在家也可以，在家用方便度眾可能更廣」——並點出「這件衣服一穿，非入釋門者就不聽你了」（如靈糧堂不會請出家法師去講道，但在家時可與之討論真理）。法師最終仍決意示現沙門相，「姓釋、成為佛陀弟子，明明白白以出家身份闡述佛陀要義」。

### 4.6 一眼猴喻（俱眼菩薩）〔行1015–1017〕

法師引「經典一段話」：某山上住著一群一隻眼的猴子，來了一隻兩隻眼的猴子，全部猴子都說牠「不正常、不是正常猴子」，把牠趕走。此喻俱眼菩薩：非真正俱眼者，看不出俱眼菩薩；維摩詰居家而成就、清淨行而空有不二，正是一般凡夫看不出的俱眼菩薩、金粟如來應世。（出處：法師稱「經典舉例」，具體經名待考，※。）

### 8.2 義理深入（依本品脈絡）

**（一）方便品在全經的位置——菩提·慈悲·方便三為一體。** 法師先以《大日經》「菩提為因·（大）悲為根本·方便為究竟」為方便品定調：〈佛國品〉講的是「菩提／心」（一切唯心造），方便品講的是「以方便度生」，二者不可割裂。真正的「方便」必含菩提與慈悲、且回歸究竟，離此即墮「隨便」。維摩詰之所以「善於智度、通達方便、大願成就」，正因他的方便從菩提出發、以慈悲為根、以究竟為歸〔行27–52、573〕。

**（二）遊戲神通·逮諸總持——維摩詰是「入陀羅尼的如來再來」。** 法師以「遊戲＝虛擬環境」點破：維摩詰示現的整場度生，是虛擬人物度虛擬眾生的一齣戲（此即「方便」的本質）。而他「逮諸總持」，說明他已入陀羅尼（總持本心）——陀羅尼含 sutra（聞經薰陶，一切大乘經論最終皆指本心）與 mantra（念佛·真言，念阿彌陀即念自性、入流亡所）二門。法師特別澄清：念佛·藥師灌頂真言·六字大明·往生咒，隨眾生願力習性相應不同，其實「同一平台（心）」；佛見的淨土全在心，「他力即自力」（靠自己的了解產生力量），自他不二、真妄不二、依正不二，方是淨土法門〔行284–538〕。

**（三）善於智度——密嚴國土「從智定得·以智慧火焚諸患因緣」。** 這是本講義理最深的一段。法師以《大乘密嚴經》（唐·地婆訶羅譯）指出：密嚴國土（較凡聖同居·方便有餘·實報莊嚴更高的淨土）之「去法」，一是「從智定得」（自心本智引出大定，即楞伽大定「無有不定時」，本自具足），二是「以智慧火（般若）入正覺見（本心），焚燒一切諸患因緣（緣起患習——誤認為實的塵相）」，三是「見相而不貪著，當下即是密嚴國土」（不叫你滅相，滅相是外道；相自然生起，只是知其虛幻不受干擾）。再以《菩提心論》「若修證則為一切導師，若歸本則是密嚴國土，不起於座而成一切佛事」收攝：菩提心具足諸佛一切功德，歸本當下即密嚴國土。故維摩詰「善於智度」＝已擅般若波羅蜜、已入密嚴國土，此是《維摩經》示現的第一要義〔行429–563〕。法師並藉此區分緣起的二義：外道·聲聞的緣起緣滅是外在四大假合之生滅（＝無常）；菩薩乘的緣起緣滅是外境入本心成影像之生滅（一切唯心，故站本心角度為常）——《中論》「因緣所生法我說即是空」，龍樹說的是幻相（空），並非外道的「無常」〔行479–496〕。

**（四）心不生虛妄＝供養恆沙佛——維摩詰即《金剛般若》之實踐者。** 法師以《圓覺經》清淨慧章「末世諸眾生，心不生虛妄，佛說如是人，現世即菩薩，供養恒沙佛，功德已圓滿」，回答「我沒供養無量諸佛，怎能學維摩詰」的自卑：功德不用求，自性功德本圓滿，只要心不對六塵誤認為實、不落二元，當下即現世菩薩、功德圓滿。再以《金剛經》一合相（富士山喻）與四句偈證成：貪著一合相（佔有心中之相）即凡夫；「一切有為法如夢幻泡影」、「凡所有相皆是虛妄」即「心不生虛妄」的操作。故一部《金剛般若》正是在詮釋維摩經的道理，維摩詰即具足金剛般若智慧者〔行330–367、548–567〕。

**（五）一心二門——維摩詰與虛雲皆「入真如門而示現生滅門」。** 這是貫串全講的骨架。法師以《大乘起信論》「一心開二門」立說：真如門（不變·本具無量功德·＝自性清淨圓明體·六祖「何期自性本自清淨」）與因緣生滅門（隨緣·緣起相·＝用）。心一產生即二門同時出現、一體不離；離緣起看不到真如。眾生一直在因緣生滅門造業受苦（＝業障），不見真如故無出期；維摩詰、虛雲則久已入真如門，倒駕慈航「以因緣生滅門的一齣戲，傳遞真如門的真諦」。彌勒對虛雲說「識智何分·水波一個」即此二門（識＝生滅門、智＝真如門，轉識成智在當下）。故維摩詰「久於佛道、決定大乘」的示現，本質是「入真如門者演生滅門以度如幻眾生」〔行615–697、742–785〕。

**（六）雖為白衣奉持沙門清淨律行——俱眼菩薩·六度五戒皆心法。** 德行讚後半（白衣行六度、涉俗五處度生、隨類度生）法師以「俱眼菩薩」（身白衣心法界、從出世間看世間）與「六度·五戒心法」貫通：布施＝捨、持戒＝無所起、忍辱＝無所念、精進＝離相、禪定＝無所住、般若＝離諸戲論（《頓悟入道要門》引《思益經》）；五戒亦是心戒——殺念頭即犯殺、掉口水貪求即犯盜、貪過久（酒久釀）亂性即犯酒。維摩詰六度皆能「波羅蜜」（回歸真心），故在家而圓滿、空有不二，是凡夫看不出的俱眼菩薩、金粟如來應世。最後「其以方便，現身有疾」開啟問疾——他示現生病即示現因緣生滅門，以病為緣廣說「是身無常」，度盡因緣生滅眾生回歸真如門（下講弟子品接續）〔行884–1109〕。

## 10. 法脈會通

### 10.1 兩條弘法路線（世尊 vs 維摩詰）

```
         宇宙真相＝法（不變的真如門）
                    │
      ┌─────────────┴──────────────┐
   世尊·釋迦牟尼                  維摩詰·金粟如來
   示現「教＋法」                示現「法為主·白衣護教」
   出家·立僧團·掌教與法          在家·遊戲神通·倒駕慈航
   （體佛法師走此路線）          （法師最敬仰、自承做不到）
   右手招文殊 ────────────────── 左手招維摩詰
              三主角共構《維摩詰經》
   文殊（從法界來）· 維摩詰（從妙喜國來）· 世尊（以之為主）
```
**連結要點**：教與法不可偏廢——空有教無用（教之目的在法），空有法無教則傳不了法。白衣只能護教（有家庭事業，不在教團內，護教有優婆夷·優婆塞之律儀），出家則須弘揚三寶、不夾私利（否則過更大，印光大師語）。

### 10.2 一心二門——本講的骨架（貫串維摩·虛雲·眾生）

```
                自性（常寂光·本來無一物·無消無息）
                          │ 心一產生（自性遇緣起心）
                    ┌─────┴─────┐  （同時·一體·不離）
               真如門            因緣生滅門
            （不變·性空）        （隨緣·緣起·用）
            自性清淨圓明體        鏡能現相→森羅萬象
            何期自性本自清淨       緣起（相生）·緣滅（相失）
                    │                    │
        ┌───────────┴────────┐   ┌───────┴────────┐
   維摩詰·虛雲               眾生
   已入真如門                只認因緣生滅門
   →示現生滅門（一齣戲）      →造業·被業所轉·業障·無出期
   以生滅門傳真如門真諦        碰善知識→懺悔·圓覺三法→識真如門
   ＝倒駕慈航·願              →再示現生滅門＝倒駕慈航（凡聖只此別）
```
**連結要點**：彌勒對虛雲「識智何分·水波一個」＝二門（識＝生滅、智＝真如，轉識成智在當下·水波一體）；凡聖之別「只在如此」——同是演因緣生滅門，維摩詰為願而演（真如門已通），凡夫為業所流轉（只在生滅門）。

### 10.3 淨土同一平台（西方·藥師·彌勒·密嚴皆在心）

```
       毘盧遮那佛（法界本體）───示現───► 一切法界諸佛·諸淨土
                                              │
   西方極樂（阿彌陀）  東方琉璃（藥師）  兜率（彌勒）  密嚴國土（實報莊嚴層次）
        │                 │              │              │
   都攝六根·一心不亂    八大菩薩接引     識智何分       從智定得·智慧火焚諸患因緣
   ·發菩提心一向專念    往生西方         龍華三會        ·見相不貪著
        └────────────────┴──────┬───────┴──────────────┘
                        同一平台＝心（他力即自力·自他不二）
```
**連結要點**：淨土差別「隨凡夫眾生·菩薩發願不同而產生萬千淨土」，其實同一平台在心；「阿彌陀帶你去」是自性彌陀顯現、與之合一（中鋒國師·三時繫念意），非外在四大假合之佛帶你去（那是外道念佛法）。念佛是「念進來」（入流亡所·自心取自心），非「念出去」傳訊給外在佛。

## 11. 日常實踐

1. **辨方便與隨便**：做任何法門前，先確認目標（究竟·菩提）正不正；目標正，則繞路·停頓·換工具皆是方便；目標不對，一切皆隨便〔行23–49〕。
2. **念佛要「念進來」**：念阿彌陀＝念自性（阿＝無·彌陀＝量·佛＝覺，無量光壽即本心）；入流亡所、自心取自心，勿口念心散〔行297–316、622–624〕。
3. **修總持（陀羅尼）二門**：sutra——每週聞經薰陶令見地鞏固；mantra——擇一相應真言／佛號（阿彌陀·六字大明·準提·藥師灌頂·穢跡金剛皆可），以幻取幻回歸本心〔行284–318、718–740〕。
4. **智慧火觀法（入密嚴國土）**：對心中生起的塵相，「知其為虛幻相，不受干擾、不貪著」；不滅相（滅相是外道），見相而不貪著，當下即密嚴國土〔行472–563〕。此即《金剛經》觀六喻（夢·幻·泡·影·露·電）、《大日經》十緣生句（如幻·陽焰·夢·影·乾闥婆城·響·水月·浮泡·虛空華·旋火輪）之日修〔行500–502〕。
5. **心不生虛妄的判準**：碰六塵時檢查自心有無「誤認為實·落二元」；能不誤認、不二元，即現世菩薩、功德本圓（不用外求）〔行337–367〕。
6. **五戒作心戒持**：不僅相上不殺盜淫妄酒，更於心上——不斷念頭（斷念亦違真心）、不掉口水貪求、不縱欲、不誤認影像為實、不貪過久（酒＝貪久亂性）〔行907–936〕。
7. **懺悔業障（大乘義）**：非追悔往事，而是「著相的心·對塵相的束縛」還在——時時警覺將起貪瞋、看不開時，以「凡所有相皆是虛妄」自照〔行701–716〕。
8. **看師之德，不看師之過**：修行人以師之德為所學，不以標準苛責師之過（高僧也會打呼）；法師自謂「只看我不辭辛勞把經講完、能契心就好」〔行689–695〕。
9. **記住本誓·毋生退卻**：娑婆五濁惡世，眾生更苦故不因苦而退；「蓮開泥水·端坐佛陀·苦海慈航·毋生退卻」——把經義傳給有緣眾生〔行250–268、326〕。
10. **知緣未盡則安住色身**：與有緣眾生的緣未盡時，任何醫療·方便可維持色身（身體看醫生）；心靈則需佛法薰陶——身心二分，不偏廢〔行373–375〕。

### 12.4 一參問

> 法師說維摩詰「入真如門而示現因緣生滅門」，虛雲「示現生滅門以度如夢眾生」，而你我「在因緣生滅門造業被業所轉」。同是一場因緣生滅門的戲——分判凡聖的，只在「你是為業而流轉，還是為願而示現」。那麼此刻你正在演的這齣戲，是業，還是願？（〔行262–264〕「凡聖之別，只在如此而已」）
