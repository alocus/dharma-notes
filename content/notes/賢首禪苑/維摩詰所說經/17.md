## 1. 本講概要

本講由第三品「弟子品」的總複習切入（十大弟子被維摩詰「重重否定、重重建立」），正式進入 **菩薩品第四** 的開頭——維摩詰與**彌勒菩薩**的第一次交手〔行11-79〕。

貫串全講的主軸線：**「授記」到底是哪一生受記？** 維摩詰以三個層層遞進的角度（有生／無生／真如）逼問已入等覺、補位下一尊佛的彌勒菩薩，使彌勒「從頭到尾一句話都不敢答、只能低頭聆聽」〔行75-77, 929〕。體佛法師指出這一品的性質：**因為對象是等覺菩薩，直接入本心、毫不囉嗦、沒有漸次、沒有方便**〔行388-390, 861〕。

三段辯破 + 一段結論 + 一段旁證，構成本講骨架〔行757-767〕：
1. **從「有」的角度**：受記是過去／現在／未來生？三時皆不可得。
2. **從「無」的角度**：無生即是正位（佛位），正位中亦無受記、亦無阿耨多羅三藐三菩提。
3. **從「真如」的角度**（本講主文所在）：真如不生不滅，故從真如之生、之滅皆無受記可言〔行295-323〕。
4. **結論**：一切眾生皆如、皆即菩提相、皆畢竟寂滅即涅槃相——故彌勒不應以「受記／得菩提」之見誘諸天子〔行325-416〕。
5. **菩提二十六句**：維摩詰以二十餘句反覆界說「什麼是菩提」，最終二百天子得無生法忍〔行419-851, 919〕。

法師大量援引旁證來鋪陳「不生不滅」與「一乘法」：**《圓覺經》**意識清淨即佛性、**《金剛經》**歌利王割截身無四相與燃燈受記、**《法華經》**方便品「諸佛兩足尊…是法住法位，世間相常住」、**《菩薩處胎經》**一彈指三十二億百千念、**《楞嚴經》**當處出生隨處滅盡、**僧肇《物不遷論》**、**《大智度論》**生忍法忍——並用「如」字三代譯法（本無→如如→真如）串起格義史〔行250-282〕。

## 4. 故事・公案（完整敘事）

### 4-1. 歌利王割截身體 — 釋迦何以先成佛（賢劫第四佛）〔行106-135〕
法師以《金剛經》一段公案解釋：**為何釋迦牟尼佛與彌勒本是同參，卻由釋迦先成佛、彌勒排第五**。

過去世，釋迦（尚未成正等正覺）為忍辱仙人，被**歌利王**節節支解身體。當時他「無我相、無人相、無眾生相、無壽者相」，心不生瞋恨——因為割他的人是四大假合、因緣和合而空，被割的我也是空，「以空來割空」，哪能起我相人相眾生相壽者相？這正是成佛的見地。法師強調：他不但不瞋，還**感激**歌利王讓他修忍辱行，並發願「我若成佛，第一個要度化的就是歌利王」〔行117-119〕。

因為這一段道行，釋迦的前身就超越了彌勒；賢劫千佛中，釋迦成為第四尊佛，彌勒為第五尊（龍華三會度眾）〔行113-115〕。

**果報的圓滿**：歌利王行此惡業，果報墮地獄；但受苦一段時間後，於佛成佛之時投胎娑婆——即佛度化五比丘的第一位尊者**憍陳如**〔行119-121〕。法師感慨：歌利王「割對人了」，割的是釋迦；若割錯人（凡夫或用凌遲對待），對方瞋恨心加重，來世千百倍相報，冤冤相報何時了，最後兩人同墮地獄〔行121-125〕。故要寬恕——「重罪若霜露，慧日能消除」，悟無生不復作，自然無業〔行127〕。

### 4-2. 耶穌十字架「以我血洗眾生罪」— 寬恕即最大能量〔行129-133〕
法師以基督教為旁例：耶穌被羅馬人釘十字架，兩旁兩個盜匪一直怨天尤人、希望上天懲罰加害者；唯耶穌只說一句「天父啊，我只能用我的血，洗刷眾生的罪惡」。單這一念，就足以成為累劫、千世萬世眾生共同救星的對象——因為他實行了寬恕之心〔行129-133〕。（法師以此類比等覺菩薩示現、寬恕的能量，非佛典公案，為教學旁引。）

### 4-3. 彌勒的歷史考證 — 真實人物・龍華三會・兜率天〔行135-147〕
法師區分《維摩詰經》所講的兜率天彌勒與地球上的彌勒：據歷史考證，佛陀時代真有一位彌勒，出生**南印度婆羅門家**，未出家、示現菩薩相，佛對他相當肯定〔行135-137〕。佛以「正法眼藏、涅槃妙心」付囑迦葉，並囑迦葉須等彌勒重來人世成第五尊佛時，把袈裟（信物）交給彌勒；因彌勒龍華三會將度化無量眾生〔行137-139〕。彌勒已受佛授記「當得作佛」〔行139-141〕。兜率分內外二院，彌勒在**兜率內院**準備下生；一切佛下生前必先居兜率內院。兜率意為**知足**，故成佛的必經條件就是知足——不知足則距成佛遠在天邊〔行141-145〕。本講場景：兜率外院天王來晉見在內院的彌勒菩薩〔行145-147〕。

### 4-4. 求那跋陀羅預言六祖與壇經〔行268-272〕
講「如」字翻譯史時，法師敘述大翻譯家**求那跋陀羅**曾在某地（六祖尚未出世）以拐杖指著一個土堆，預言「這裡以後會出現一位肉身菩薩、講一部驚天動人、可消除三界的經」。壇的意思就是土堆，這部經後來命名為《六祖壇經》，那個人就是惠能〔行268-272〕。（法師以此串接求那跋陀羅將「如」譯為「如如」。）

### 4-5. 僧肇《物不遷論》— 30歲入地菩薩「解空第一」〔行619-699〕
法師介紹鳩摩羅什弟子**僧肇**大師：年僅30歲卻是入地大菩薩再來，來人世間是為幫羅什翻譯。他寫《物不遷論》——「物」是森羅萬象（心產生的妙有），「不遷」是佛性（不動、不退轉）；一切物皆從不遷的自性衍生，故名「物不遷」〔行621-629〕。他舉三例——**河中水、大火聚、長風起**：河水湍流競奔逝，看似流動，其實「各各不相知」，如影片是一張張靜態底片速度太快變成動態；這一念不知後一念、彼此毫無相干〔行653-665〕。故「其法亦如是、其心亦如是」，全都是靜態流轉成動態的虛幻相〔行665-667〕。羅什讚僧肇「彷彿佛陀時代的須菩提，真正解空第一」〔行649〕；明朝**憨山大師**禪定中親證此理，跳起來要向僧肇頂禮〔行693〕。（《物不遷論》屬《肇論》T1858；法師三例「河中水/大火聚/長風起・各各不相知」為其闡釋語，非逐字經文——見§9。）

### 4-6. 胡適讚維摩詰邏輯不可破〔行375〕
法師提到**胡適之**看到《維摩詰經》「跳起來」，他不把它當佛法，而是說「這邏輯思想是不可破的」——太厲害，根本沒辦法讓你辯駁〔行375〕。（現代學人旁證，非佛典。）

### 義理深入

**一、三破的邏輯階梯——把「授記」逼到牆角。** 法師強調三破是層層遞進的哲學逼問，連胡適都嘆為「不可破」〔行375〕。第一層（有生）就世俗「時間」發問：受記若落在過去、現在、未來任一生，皆自相矛盾（已滅／未至／無住）。第二層（無生）翻到勝義：無生即正位、正位即佛位，此中「本來無一物」，連受記、連阿耨菩提都無立足處〔行207-211〕。第三層（真如）是本講主文所在：真如是對「生滅」現象的最終探討，結論不生不滅——所以無論從真如之「生」或「滅」立說，都無受記可得〔行295-323〕。三層一路把彌勒的「我已受記」推到無可安立，彌勒只能默然低頭〔行185, 203〕。

**二、「一切眾生皆如→即菩提相→畢竟寂滅」——平等心才是等覺的本色。** 法師指出，維摩詰真正要建立的（否定當下即建立）是**平等**：真如不二不異，眾生、聖賢、愚痴者、彌勒全都是如。你彌勒既得受記／得菩提，眾生為何沒得？若說眾生沒得，你就落入分別、就不配稱「等覺」（完全平平等等才叫等覺）〔行344-348〕。故「一切眾生即菩提相」「畢竟寂滅即涅槃相不復更滅」——眾生本來成佛，你去對天子講「受記、得菩提」，反而讓天子生分別心、從聖言道退回凡夫地〔行419-422〕。這就是維摩詰責彌勒「無以此法誘諸天子」的著力點。

**三、菩提二十六句是「本」字的二十六種側寫。** 法師點出「菩提不可以身得、不可以心得」對聲聞、對分別心一併掃除：非四大假合的身可得（可通聲聞苦修）、非分別心可得〔行423-425〕。其後二十餘句（寂滅、不觀、不行、斷、離、障、不入、順、住、至、不二、等、無為、知、不會、不合、無處、假名、如化、無亂、善寂、無取、無異、無比、微妙），法師逐一以「離相不受干擾／阻斷執著／不與塵相會合」串講，總結：《維摩詰經》善用文字，用了二十餘句舉例菩提，「其實你舉一百個也可以，無非在講空處、講心中本心的狀況」——言語道斷、心行處滅的那一個就是菩提〔行849-851〕。品末「二百天子得無生法忍」正是這番直入本心之法當場的證量；法師特別強調此「得」是**無得的得、本得**——本來就得到〔行931-933〕。

## 10. 法脈會通（連結圖）

### 10-1. 「授記」三破的軸線
```
彌勒對兜率天王講：不退轉地（第八不動地）
        │  不退轉 → 佛才授記（往前走必到，如按軌道走／蓋印章）
        ▼
維摩詰岔開議題，改問「授記」——三個角度層層逼問：
  ①有生 ── 過去生(已滅)/現在生(無住)/未來生(未至) ── 三時不可得 → 默然
  ②無生 ── 無生即正位＝佛位＝入法界＝本心 ── 正位中亦無受記、亦無阿耨菩提
  ③真如 ── 真如＝不生不滅 ── 從真如生(無生)/從真如滅(無滅) ── 皆無受記
        ▼
結論：一切眾生皆如 → 即菩提相 → 畢竟寂滅即涅槃相 → 不復更滅
        ▼
故：無以此法誘諸天子（本來成佛，無「發心」可發＝頭上安頭）
        ▼
菩提二十六句（非身得/非心得…微妙）→ 二百天子得無生法忍（無得的得）
```

### 10-4. 「如」字三代譯法（格義史）〔行250-282〕
```
魏晉南北朝  受道家「無」影響 ── 鳩摩羅什 譯「如」＝ 本無（→實空）
                                   └ 慮落斷滅空，越想越不對
劉宋       求那跋陀羅         ── 譯「如」＝ 如如（如如不動）
唐         菩提流支→玄奘     ── 正式定「真如」二字（沿用至今）
華嚴角度   賢首國師(法藏)    ── 真如＝自性清淨圓明體
連結要點：格義（用中國人懂的詞譯佛義，如「忍辱仙人」不譯「忍辱菩薩」）是傳法方便，
         但「本無/實空」易墮斷滅空，故最終定「真如」——真＝實際不變（佛性/菩提），如＝不生不滅。
```

### 10-5. 念念成形 → 各各不相知 → 不生不滅（三經一論的合流）
```
《菩薩處胎經》一彈指 32億百千念 → 念念成形，形形皆有識（×一秒4彈指≈1280兆次生滅）
        │  電影底片喻：一秒24張靜態→速度太快成動態
        ▼
《物不遷論》(僧肇) 河中水/大火聚/長風起：湍流競奔而「各各不相知」（每一念不知後一念）
        ▼
《楞嚴經》 當處出生，隨處滅盡（生的當下就滅，看不出生滅）
        ▼
結論：不生不滅不是理論，是實證 → 寂滅 ＝ 無生法忍 ＝ 菩提
```

## 11. 日常實踐

1. **知足是成佛的必經條件**——兜率意為「知足」。不知足則距成佛遠在天邊；能知足已入佛乘。知足是一種無生法忍〔行143-145〕。
2. **正思惟：可以想，但不受想牽制**。不敢起念是最大的斷滅空（不想你是死人、木石不能成佛）；佛教「善思惟」——意識清淨，能思惟而不受思惟影響〔行98-102〕。
3. **在相不離相，也不被相所著**——「聽天命、盡人事、沒煩惱」。不能離相（生活在相中），也不能被相黏住，取中道〔行62-64〕。
4. **寬恕即最大能量**：不寬恕則冤冤相報、千百倍相償、同墮地獄。心裡不留痕跡自然無業——「重罪若霜露，慧日能消除」〔行123-127〕。
5. **修行的目的是入本心，不是虐待自己**。幾天不吃不睡的苦行，若不入本心只是虐待、只是苦行，越修越執著就不是修行〔行556-558〕。
6. **不要以自造的影像折磨自己**：憂悲苦惱、喜悅悲傷都是自己製造、賦予生命的一齣影像（如電腦每天加零的自欺）。看破的唯一方法——凡所有相皆是虛妄，若見諸相非相〔行609-615, 871-875〕。
7. **我與佛本無異，但不可起慢心**：聽一乘法最怕起慢心；習性還在，故當精進而不自高〔行474-476〕。

## 12. 延伸・參

- **關聯前後講**：本講承第三品弟子品（十大弟子重重否定）之總複習〔行11-68〕，開菩薩品第四；下一講當續光嚴童子「直心是道場」等後續菩薩段（T0475 line 174起，本講未及）。
- **關聯概念解說**：真如／不生不滅／無生法忍／一乘法／格義／十地不退轉。
- **一參問**：維摩詰說「無生即是正位，於正位中亦無受記」，又說「二百天子得無生法忍」——若正位中無得，這「得無生法忍」的「得」，與凡夫「有得」的得，差別何在？（法師答：這是「無得的得」、本得——本來就得到〔行931-933〕。你能否於此不落兩邊？）
