## 1. 本講概要

體佛法師於本講先以近一半篇幅**重申「不二＝中道義＝佛的法身＝本心」的總綱**〔行20〕，把第38講的「空不空如來藏」再展開為一條可操作的見地鏈：真如**不變**（空如來藏）＋**隨緣**（不空如來藏）＝**真空妙有**〔行24-52〕。接著用三部經為「不二」築底——《入一切如來智不思議境界經》的**五要素（空／不生／不對治／不滅／不可記說）**〔行68-108〕、《楞伽經》佛答大慧的**無自性相**〔行92-100〕、《諸法無行經》喜根比丘的**貪欲即菩提**偈頌〔行196-256〕——並完整敘述了本講的中心公案：**勝意比丘毀謗喜根比丘、墮地獄、累劫受謗、終回本心而成文殊師利菩薩**〔行157-188〕。

打好見地後，才逐一開演四位菩薩的「不二」句〔行292-1077〕。其軸線是：**凡夫著相／聲聞著無相／菩薩不著相亦不著無相**〔行466-495〕。師子意菩薩的「有漏無漏」引出《永嘉證道歌》與大珠慧海《頓悟入道要門論》的**六度＝一「無所住」**〔行378-441〕；淨解菩薩的「有為無為」引《文殊師利所說不思議佛境界經》的**非思量境界＝六根對六塵不即不離**〔行575-702〕；那羅延菩薩的「世間出世間」引《六祖壇經》「佛法在世間不離世間覺」與《諸法無行經》「住空閑自貴賤人」〔行742-834〕；善意菩薩的「生死涅槃」則引《圓覺經》普眼章**「始知眾生本來成佛，生死涅槃猶如昨夢」**作結〔行947-1077〕。

**一句話貫穿全講**：一切妙有（貪欲、有漏、有為、世間、生死）都是真空本心所現的空華幻相，「不即不離」地看它，當下即是不二、即是佛的法身〔行716、775、1077〕。

## 3. 核心概念

| 概念 | 體佛法師釋義〔行〕 | 經教連結（已核驗） |
|---|---|---|
| **不二／中道義** | 入不二就是入中道義；佛的大乘經典全在講中道義，中道義即是本心，本心本來就中道義〔行20〕 | 《中論》「眾因緣生法，我說即是無，亦為是假名，亦是中道義」✓ CBETA T1564 |
| **空不空如來藏** | 本心具「空如來藏」（真如不變的真心）與「不空如來藏」（隨緣受薰而生變化）；了達空不空如來藏者即是法身、即是佛〔行24-44〕 | 法師繫於《涅槃經》《楞伽經》；「空不空如來藏」名相的根本經典為《勝鬘經》《楞伽經》（※ 見校對） |
| **不思議薰‧不思議變** | 真如本性堅實本淨，卻會「受無明所薰炙」而變，其清淨未變——如水性不變而遇緣成冰〔行28-30〕 | 法師繫於《楞伽經》（※ 逐字未核，見校對） |
| **真空妙有** | 空不空之「空」才叫真空；真空具隨緣妙有，故曰真空妙有；妙有從真空變現，二者同一件事〔行48-52〕 | 《心經》「色不異空，空不異色」✓ CBETA T0251 |
| **五要素** | 學佛最殊勝功德的總綱：空／不生／不對治（＝不二）／不滅／不可記說，其實是同一個——本心〔行68-80〕 | 法師引《入一切如來智不思議境界經》（※ 逐字未核，見校對） |
| **無自性相** | 一切都是緣起相、因緣所生法，我說即是空；空＝不生＝不對治＝不滅＝不可記說＝無自性相〔行102-108〕 | 法師引《楞伽經》佛答大慧；《中論》「未曾有一法，不從因緣生，是故一切法，無不是空者」✓ CBETA T1564 |
| **有漏／無漏** | 有漏＝有生滅現象，頂多得福報；無漏＝不生不滅，才稱功德（本心本具如恆河沙功德）〔行310-322〕 | 《金剛經》✓ T0235；《永嘉證道歌》✓ T2014 |
| **功德 vs 福報** | 福報是妄心所得（給人什麼回饋什麼）；功德是本心本具、非修來——梁武帝「無功德」即此〔行318-322〕 | 【公案】梁武帝問達磨〔行320〕 |
| **有為／無為** | 有為＝有生滅；無為＝不生不滅＝本心；「無為」的真義是「不執著心念」，非死寂〔行551、590-594〕 | 《文殊師利所說不思議佛境界經》✓ CBETA T0340；《金剛經》「一切賢聖皆以無為法而有差別」✓ T0235 |
| **非思量境界** | 六根對六塵起六識，影像清清楚楚而干擾不了我、不即不離——此即非思量境界，即是佛境界〔行660-702〕 | 《文殊師利所說不思議佛境界經》✓ CBETA T0340 |
| **世間／出世間** | 世間＝邪見＝只見「世界」生滅相；出世間＝正見＝見「法界」；於世間中見性空即是出世間，非離世間〔行762-782、868〕 | 《六祖壇經》無相頌 ✓ T2008；《華嚴經》「應觀法界性，一切唯心造」✓ T0279 |
| **生死／涅槃** | 凡夫住生死、聲聞住涅槃、菩薩不著生死不住涅槃；生死涅槃猶如昨夢，本無二〔行939-984〕 | 《圓覺經》✓ CBETA T0842 |
| **不即不離** | 對一切幻相：不需它離開，它也干擾不了我——這四個字是入不二的操作口訣〔行690-700、862〕 | 《圓覺經》普賢章「知幻即離」✓ T0842 |
| **末世眾生** | 非指死後；是「最後一次當眾生」的當下授記——你已聽到真實義〔行951-953〕 | 《圓覺經》普眼章 ✓ T0842 |

## 4. 故事・公案

### 4.1 喜根比丘與勝意比丘（本講中心公案，出《諸法無行經》）✓ CBETA T0650
〔行149-188、208-242、280-285〕

**體佛法師特別強調：這不是公案（公案有些不是事實），這是經典裡的事實。**〔行157〕

- **設定**：勝意比丘修行極為如法——**少欲知足、細行獨處、修十二頭陀（苦行）、已證四禪八定**〔行157〕。喜根菩薩卻**不稱讚**少欲知足、細行獨處，反而**講不二法門**〔行158-159〕。
- **衝突**：勝意比丘心生障礙，認定喜根是**邪見**——「哪有修行者不少欲知足、不獨處、不守戒、不入苦行、不入四禪八定的？」於是開始**誹謗**喜根〔行159-161〕。
- **辯論**：勝意到喜根弟子（居士子，已入無生法忍）家托缽，質問：「你師父教你不斷煩惱？煩惱是無明，是輪迴根本，哪有修行不斷無明的？」居士子反問：「煩惱從何而來？」——引出《維摩詰經》**「彼罪性不在內、不在外、不在中間……心垢故眾生垢，心淨故眾生淨」**〔行163-170〕。既然煩惱不在內外中間、無所從來，即是無生、是假、無能滅所滅；你還立能所，就是未入本心〔行172-174〕。勝意當下離開，並與弟子結黨譭謗喜根「邪見、誤導眾生」〔行174〕。
- **轉折**：喜根說「勝意比丘會以**障礙罪**而入地獄」——障礙是他障礙自己，非障礙喜根〔行176-180〕。（法師展開：罵人都是罵自己，你討厭一個人，最後討厭的是自己，對方不增不減〔行176-178〕。）勝意**墮地獄**，出來後**變愚癡、無智慧**，遇佛出家又還俗，累劫受眾生譭謗（誹謗佛法者反受眾生謗）〔行180-182〕。
- **結局**：勝意畢竟有四禪八定與長久善根，一日佛性顯現，**憶起當年喜根比丘的偈語**，依此偈參究，最後**悟本心**。他跪告佛陀：「我文殊師利，就是以前的勝意比丘」——**喜根比丘早已成佛**，勝意深自懺悔（懺悔自己「說人邪見、斷人慧命」），依偈悟入，成為今日的**文殊師利菩薩**〔行184-188、280-285〕。

> 法師點題：正因為勝意「凡夫聞怖畏，去佛道甚遠」而後回頭，這部《諸法無行經》才被說出——與《維摩詰經》《文殊師利所說不思議佛境界經》合稱**文殊菩薩三部圓頓法門**〔行151-153〕。

### 4.2 梁武帝問達磨「無功德」〔行320〕
梁武帝捐錢建佛寺、問達磨祖師有何功德，達磨答「並無功德」。法師借此辨：捐錢建寺是**福報**（有漏），功德是**本心本具如恆河沙**、非造作可得——「你捐一千萬億去布施，頂多是福報，跟本心的功德一點關係都沒有」〔行274、318-322〕。

### 4.3 蘇東坡「八風吹不動，一屁打過江」〔行416-418〕
蘇東坡自謂已入如來藏、寫偈「八風吹不動」，遣人過江送佛印。佛印批二字「放屁」。蘇東坡受不了，過江理論。佛印笑：「八風吹不動，一屁打過江」〔行418〕。法師借此驗：修行考驗很簡單，「兩三句話就知道你的功夫」，不必談你閉關幾年、受戒多久〔行416-420〕。（後文再提蘇東坡歷經烏台詩案、寫〈前赤壁賦〉，經佛印、等慧堂法師指導回歸本心〔行908-909〕。）

### 4.4 篡人者人恆篡之：曹丕篡漢→司馬炎篡曹〔行314-316〕
引孟子「愛人者人恆愛之，敬人者人恆敬之」，法師再加「篡人者人恆篡之」：曹操之子**曹丕篡東漢**，其後代終被**司馬炎所篡**。此為因果、屬有漏法〔行316-318〕。

### 4.5 鳩摩羅什的老師向他頂禮〔行561-564〕
鳩摩羅什幼隨母出家，先於印度學阿含、聲聞乘法；長成通達大乘後回喀什米爾見老師，**老師反跪地向他頂禮**，說：「聞大乘者即菩薩也，小乘者聲聞也；聲聞向菩薩頂禮，理所應該。」法師以此說明：這是證悟的關係、非輩分——鳩摩羅什是「七佛以來的譯師」〔行561-564〕。

### 4.6 佛陀頭痛三日與琉璃王（因果不爽）〔行638-642〕
佛過去世為小孩時，見村人捕大魚將盡殺，他**拍大魚的頭三下**；那條大魚即後世**屠殺釋迦族的琉璃王**，故佛此生示現**頭痛三天**〔行640-642〕。法師借此立「佛受因果時**身受心不受**」——真正評判賢聖不看外相，看**心是否落因果**〔行642-658〕。

### 4.7 六祖惠能聞《金剛經》言下大悟〔行555-559〕
惠能24歲不識字，聞《金剛經》「應無所住而生其心」而大徹大悟，見五祖時是「講給五祖聽、請五祖評論」，非去學。除「菩提本無樹」偈外，最要緊的是「**何期自性，本自清淨；本不生滅；本無動搖；本自具足；能生萬法**」——已入空與不空如來藏〔行555-559〕。（法師按：六祖是有人類以來唯一非佛親說而稱「經」者〔行553〕。）

### 4.8 虛雲老和尚杯落開悟〔行664-666〕
虛雲老和尚聞杯子墮地「噗」一響——有聽到聲音，但「干擾不了我」，虛空粉碎——即此非思量境界〔行664-666〕。

### 4.9 弘一大師（李叔同）虎跑寺斷食回本心〔行648-650〕
弘一大師出家後腸胃極差、長年病，夏丏尊給他日本斷食法，他去**虎跑寺斷食**，適逢**大勢至菩薩聖誕**，聞梵唱、看佛經而動出家之念。本是風流倜儻的李叔同，回本心極快——法師按：修行看的是「心的安樂」，不是外相〔行648-650〕。

### 4.10 常不輕菩薩頂禮眾生（＝釋迦前身）〔行1020-1024〕
常不輕菩薩見一切眾生皆是「本來成佛」的純金，故一律頂禮，即使被侮辱仍頂禮；此菩薩即後世的**本師釋迦牟尼佛**。與《法華經》人人授記、連提婆達多也授記成佛相呼應〔行1012、1020-1024〕。

### 4.11 大珠慧海答「六度萬行」（頓悟入道要門論）〔行392-437〕
有長者問大珠和尚（慧海禪師）何謂六度萬行。他先引《思益梵天所問經》網明菩薩「布施即俱捨也」，再逐一詮釋：持戒＝無所起、忍辱＝無所念、精進＝離相、禪定＝無所住、般若＝離諸戲論——六度歸為一個「無所住」〔行392-437〕。

### 4.12 思益梵天問網明菩薩（六度以布施為首）〔行380-388〕
思益梵天問網明菩薩：六度以何為首度？答：以布施（悉檀）為首。何謂布施？答：**俱捨煩惱即是布施**。思益梵天由此得阿耨多羅三藐三菩提。法師詮：真布施是**三輪體空**（無能施、無所施、無施之行），該捨即捨、心不存留〔行380-390〕。

## 8. 本經解義（維摩詰所說經逐段）

> 本講在入不二品逐位開演，§8 依**經文出現次序**排列（師子意→淨解→那羅延→善意），完整四位菩薩本句皆錄。師子菩薩（罪福）於第38講已講，本講僅作橋接複習〔行304〕。

| 維摩原句〔行〕 | ✓CBETA T0475 | 體佛法師釋義（逐句） | 在本品脈絡之定位 |
|---|---|---|---|
| **師子意菩薩曰：「有漏、無漏為二。若得諸法等，則不起漏、不漏想，不著於相，亦不住無相，是為入不二法門。」**〔行294-308、530〕 | ✓ T0475 | 有漏＝有生滅（頂多福報）；無漏＝不生滅（功德）。「得諸法等」即證諸法平等，就不起「漏／不漏」之想；「不著於相」破凡夫著相，「亦不住無相」破聲聞著無相——回歸本心即無有漏無漏〔行310-322、454-468〕 | 第十位菩薩；緊接第38講師子菩薩「罪福」之後 |
| **淨解菩薩曰：「有為、無為為二。若離一切數，則心如虛空，以清淨慧無所礙者，是為入不二法門。」**〔行295-302、539、724〕 | ✓ T0475 | 有為＝有生滅；無為＝不生滅＝本心。「數」＝心念（心數）；「離一切數」非離開，是**不受心念干擾、不即不離**；如此則「心如虛空」；「清淨慧」＝金剛智慧，六根對六塵起六識照樣現，卻干擾不了我，故「無所礙」〔行551-716〕 | 第十一位菩薩；引《文殊佛境界經》定義「無為」 |

> 【橋接】師子菩薩（第九位，罪福）於本講僅作複習：「若達罪性，則與福無異，以金剛慧決了此相，無縛無解者，是為入不二法門。」✓ T0475〔行293、304〕——第38講已開演，本講以之引出師子意菩薩。

### 義理深入

**① 師子意菩薩（有漏‧無漏）── 「不著於相，亦不住無相」是三乘的分水嶺。**
法師把這一句讀成一張三乘地圖：**凡夫全在著相修行**（做什麼都有所求、有回報想）；**聲聞乘知道不能著相，卻著了無相**（入偏空涅槃、只修自己）；**菩薩不著相也不著無相**〔行466-495〕。為什麼？因為實相是「無相‧無不相」——無相才是本心相，卻能現無不相。所以《金剛經》一面教你「生心」（六度萬行是相，不能否定）、一面前提是「應無所住」〔行474-495〕。這一句把「有漏無漏」從名相之爭，翻成「你的心有沒有所住」的實地考驗，與大珠慧海六度＝一無所住完全接榫〔行438-441〕。

**② 淨解菩薩（有為‧無為）── 「無為」不是死寂，是不執著心念。**
法師特別防一個誤解：以為「無為＝不能想事情＝一潭死水」〔行590-592〕。他借《文殊佛境界經》定住：無為的真義是「六根對六塵起六識，影像清清楚楚，我卻不即不離、干擾不了我」〔行660-672〕。念（數）是心的妙用，是假象、讓你方便用的，用完不執著即可——走錯路再走就好，何必停在懊惱裡〔行604-610〕。所以「離一切數」不是斷念，是**在念中不被念縛**，心如虛空而清淨慧無所礙。這把「無為法」從一個哲學名相，落成日常「過去心不可得、庸人自擾之」的當下工夫〔行268-270、606-610〕。

**③ 那羅延菩薩（世間‧出世間）── 出世間＝於世間中見性空，非另尋淨土。**
法師用《壇經》無相頌「佛法在世間，不離世間覺；離世覓菩提，恰如求兔角」定住那羅延的本句〔行742-782〕，再作一組關鍵對位：**世間＝邪見＝只見「世界」（生滅相）；出世間＝正見＝見「法界」**〔行762-765〕。凡夫在世間只做世間相的事、執著生滅；賢聖在世間見「真相（覺）」，即《華嚴》「應觀法界性，一切唯心造」〔行771〕。再引《諸法無行經》「住空閑自貴賤人，尚不得生天」反破：你搬到阿里山、月球、空閑處，只要還立一個「世間／出世間」、還「自貴賤人」，那也是世間、更是邪見〔行788-834〕。故「於其中不入不出、不溢不散」＝一切隨緣、不即不離。**出世間就是蓮花——不離淤泥而不染**〔行862-868〕。

**④ 善意菩薩（生死‧涅槃）── 「本來成佛」，故無生死可了。**
法師以《圓覺經》普眼章作全講結穴：恆沙世界「猶如空花亂起亂滅，不即不離，無縛無脫；**始知眾生本來成佛，生死涅槃猶如昨夢**」〔行977-982〕。他用金礦／純金辨破一個常見的辯難——「我們是含雜質的金礦，佛是純金」：不對，眾生是**百分之百純金、只被污垢蒙蔽**，洗不洗價值都一樣（心佛眾生三無差別）〔行998-1010〕。既然生死是空華、是本心所現的妙有，那「了生死」不是修到沒有生死，而是**了知生死是幻、干擾不了我**——「無生死可了」〔行1046-1058〕。凡夫落生死、聲聞落偏空涅槃，皆是把空華當真；菩薩不著生死不住涅槃，生死即涅槃、涅槃即生死，當下入不二〔行1024-1032〕。

## 10. 法脈會通

### 10.1 見地骨幹：空不空如來藏 → 真空妙有（本講的地基）

```
        本心（如來藏＝空不空如來藏）
        ├── 空如來藏 ── 真如「不變」──「真空」──不生不滅
        │                                    │
        └── 不空如來藏 ─ 真如「隨緣」──「妙有」──生滅（六道輪迴亦不離真如）
                                             │
        真空 ⇄ 妙有（同一件事，非二）→ 進入「不二」＝得佛法身
連結要點：不變隨緣、隨緣不變；妙有從真空變現，故凡所有相皆虛妄，而妙有不離真空。〔行24-52〕
```

### 10.2 五要素 ≈ 無自性相（兩經一義的等式鏈）

```
《入一切如來智不思議境界經》(文殊)   《楞伽經》(佛答大慧)
     空  ─────────────────────────  無自性相
     不生 ────────────────────────  無自性相
     不對治(＝不二) ─────────────  無自性相
     不滅 ────────────────────────  無自性相
     不可記說 ───────────────────  無自性相
連結要點：空＝不生＝不對治＝不滅＝不可記說＝無自性相，皆同指本心；
一切唯緣起相，「因緣所生法，我說即是空」（中論）。〔行92-135〕
```

### 10.3 六度萬行 ＝ 一個「無所住」（大珠慧海《頓悟入道要門論》）

| 六度 | 大珠慧海詮釋 | 三經同一口訣 |
|---|---|---|
| 布施 | 俱捨（俱捨煩惱即是布施；三輪體空） | 《金剛經》無所住 |
| 持戒 | 無所起（本心尸羅四義） | 《頓悟入道要門論》無所起 |
| 忍辱 | 無所念（無辱可辱、無忍可忍） | 《六祖壇經》無念 |
| 精進 | 離相 | 《六祖壇經》無相 |
| 禪定 | 無所住 | 《金剛經》應無所住 |
| 般若 | 離諸戲論（一切有漏皆戲論） | ── |

```
連結要點：布施/持戒/忍辱/精進/禪定/般若 → 全是「應無所住而生其心」一個心。
生心（六度是相，不可廢）＋ 無所住（不著相亦不著無相）＝ 菩薩行。〔行378-441、491-521〕
```

### 10.4 三乘對相（貫穿四位菩薩的判準）

| 乘 | 對「相」的態度 | 果位定位 | 本講對應 |
|---|---|---|---|
| 凡夫 | 著相（有所求、有回報想） | 生滅、有漏 | 全部都要做、都著相 |
| 聲聞 | 著無相（入偏空涅槃、只修自己） | 賢‧無為法（一半本心） | 乾脆都不做 |
| 菩薩 | 不著相亦不著無相 | 聖‧圓滿無為法（空不空） | 應無所住而生其心地做 |

連結要點：《金剛經》「一切賢聖皆以無為法而有差別」——差別在入本心的深度；賢＝聲聞阿羅漢，聖＝佛菩薩。〔行466-568〕

### 10.5 那羅延「世間／出世間」的對位鏈

```
世間  ＝ 邪見 ＝ 只見「世界」（生滅相、執著）
出世間 ＝ 正見 ＝ 見「法界」（於世間中見性空）
   │
「應觀法界性，一切唯心造」＝ 以本心看森羅萬象 → 全是幻影 → 入法界
連結要點：不離世間覓菩提；蓮花不離淤泥而不染 ＝ 出世間。〔行762-868〕
```

## 11. 日常實踐

1. **口訣「不即不離」隨身用**：遇順逆境（讚歎的彩虹、烏雲的煩惱），對虛空而言不增不減——不需它離開，它也干擾不了你〔行220、690-700〕。
2. **走錯了就再走，不停在懊惱**：念是心的妙用、是假象，過去心不可得；「早知道昨天賣掉」式的悔惱是庸人自擾〔行606-610、268〕。
3. **以境驗心，不以年資自估**：修行考驗「兩三句話就知道」——別人一句「放屁」你動不動？（蘇東坡‧佛印）〔行416-420〕。
4. **布施即「俱捨」**：真布施是三輪體空、心不存留、該捨即捨；捨的是那顆有所求、想討回的心〔行386-390〕。
5. **持戒是手段不是究竟**：戒（尸羅）是指月的手指，目的是回歸本心「清涼／安穩／寂靜／寂滅」；別拿戒去衡量他人〔行402-414〕。
6. **罵人＝罵自己，討厭人＝討厭自己**：對方不增不減，你卻一直被自己現的幻相折磨；放下即是文殊〔行176-178、898-902〕。
7. **不必逃到「空閑」才修**：搬到深山、閉關若「自貴賤人」，尚不得生天；破初關前的閉關只是短暫逃避〔行798-808〕。
8. **當「末世眾生」是當下的授記**：最後一次當眾生就在此刻——你已聽到真實義，就走在覺有情的菩薩道上〔行951-953、1062-1064〕。
9. **娑婆一日勝極樂百年**：於此五濁惡世妙有假有中，體悟一天勝西方修一百年；不急去、隨因緣〔行56-66〕。
