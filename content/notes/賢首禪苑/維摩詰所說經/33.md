## 1. 本講概要

本講是《維摩詰經》第33講，橫跨兩品：先把〈觀眾生品第七〉圓滿，再切入〈佛道品第八〉開頭。through-line（貫串主軸）是**「無生」**——一切生滅、輪迴、得證、男女、生死，本來都是空花，是「六塵妄想緣氣」所現的虛幻相，並非真心本體。

- **上半場（收〈觀眾生品〉）**：體佛法師以元末明初**無垢子（松溪道人）**禪師的兩首偈語破題，導出「法身常在／逐妄迷真／輪迴假相」的總綱，再以《圓覺經》金剛藏章、文殊章印證「有作思惟從有心起，皆是六塵妄想緣氣，非實心體」〔行86-155〕。接著逐句講天女與**舍利弗**最後四番問答：生死去處（佛化所生）、幾時成佛（還為凡夫我乃成佛）、三世諸佛（世俗文字數）、得阿羅漢否（無所得故而得），末由**維摩詰**點破天女身分——已供養九十二億佛、得無生忍、住不退轉，實為**觀世音菩薩**倒駕慈航之示現〔行161-525〕。中段插入《心經》「三層破執」（我執→法執→權教之智得）的完整結構圖〔行301-372〕。
- **下半場（開〈佛道品〉）**：**文殊師利**問「菩薩云何通達佛道」，**維摩詰**答「**若菩薩行於非道，是為通達佛道**」〔行571-694〕。體佛法師以《思益梵天所問經》「得道」定義、龍樹《中論》「不生偈」與「二諦偈」、《壇經》邪正、稻稈經「見緣起即見法」層層鋪陳「非道＝因緣所生法之道，佛道＝從非道見第一義諦」〔行607-723〕。末段逐條解「行五無間而無惱恚……至於畜生無無明憍慢」，並以**地藏王菩薩**入五無間、小乘五逆／大乘五逆（《大薩遮尼乾子所說經》）、《大乘義章》五逆輕重、《悲華經》釋迦不取淨土之願、《圓覺經》普眼章「幻滅→非幻不滅→無方清淨」作結〔行807-1078〕。

一句話總持：**輪迴生死是誤會的空花，得道不在相上修成，而在「行於非道」——於因緣所生法中不受干擾、回歸本心、度化眾生。**

## 3. 核心概念（附經教連結）

| 概念 | 體佛法師釋義〔行〕 | 經教連結（已核驗） |
|---|---|---|
| **六塵妄想緣氣（非心體）** | 心不自起，因思惟而起；心起則六根對六塵，所生皆因緣所生之「氣」（假），是真心本性所現之虛幻妙用，非真心本體〔行88-100,546-548〕 | 《圓覺經》T0842 金剛藏章「有作思惟從有心起，皆是六塵，妄想緣氣，非實心體，已如空花」✓ |
| **空花・空果** | 空中本無花（如彩虹因緣所生）；以空花思辨佛境，如空花復結空果，展轉妄想；輪迴即是空花結空果之虛幻相〔行105-122〕 | 《圓覺經》T0842「用此思惟辨於佛境，猶如空花復結空果」✓ |
| **無生・無輪轉** | 眾生於無生中妄見生滅，故名輪轉生死；如來因地知是空花即無輪轉，非修成無輪迴，是本來無輪迴〔行139-153〕 | 《圓覺經》T0842 文殊章「一切眾生於無生中，妄見生滅」✓ |
| **煩惱性即菩提性** | 同一真心，逐妄則現煩惱性，轉回則現菩提性；如大海起波浪，波浪不離大海（不思議熏、不思議變）〔行53-59〕 | 《諸法無行經》T0650「貪欲是涅槃，恚癡亦如是，如是三事中，有無量佛道」✓ |
| **無我（人無我＋法無我）** | 四大假合非我（無自身相）；六塵緣影非真心；通達此二即菩薩〔行208-214〕 | 《金剛經》T0235「通達無我法者，如來說名真是菩薩」✓ |
| **無所得故而得** | 眾生本得阿羅漢、本得佛；有得有證是增上慢；本得本證，故「無所得」才是「真得」〔行356-471〕 | 《維摩詰經》T0475「無所得故而得」✓；《心經》T0251「無智亦無得，以無所得故」✓ |
| **菩提無住處** | 菩提是無形之真心本性，盡虛空遍法界，一切眾生共用一體（雲彩共用虛空喻），故無有得者〔行376-386〕 | 《維摩詰經》T0475「菩提無住處，是故無有得者」✓ |
| **二諦（世俗諦・第一義諦）** | 第一義諦不可說，為轉法輪度眾生不得不用世俗諦（語言文字）；一講出來即世俗諦；執著世俗諦則不識勝義〔行390-414〕 | 《中論》T1564「諸佛依二諦，為眾生說法，一以世俗諦，二第一義諦」✓ |
| **非道／佛道** | 非道＝凡因緣所生法之道（非黑道邪惡義）；佛＝覺；於非道中見因緣法所生之第一義諦即佛道〔行701-719〕 | 《維摩詰經》T0475「若菩薩行於非道，是為通達佛道」✓ |
| **得道（無生法忍）** | 一切法不自生・不他生・不眾緣生（＝眾緣生而不受眾緣干擾），從本已來常無有生；證此即得道〔行607-683〕 | 《思益梵天所問經》T0586「若法不自生、不他生、亦不眾緣生，從本已來常無有生，得是法故說名得道」✓ |
| **虛幻生・虛幻滅** | 因緣所生之生是虛幻生，因緣所滅之滅是虛幻滅（雲之生滅喻）；不受虛幻生滅影響即入無生法忍〔行643-667〕 | 《楞嚴經》T0945（第32講引「因緣所生生是虛幻生」義）；《心經》「是諸法空相，不生不滅」✓ |

## 4. 故事・公案

### 4.1 無垢子（松溪道人）的兩首對照偈〔行11-83〕
體佛法師破題請大眾參究元末明初開悟大禪師**無垢子**（號松溪道人，淨土宗禪師，時代近於元代**中峰國師**明本，中峰造《三時繫念》）的兩首偈。
- **第一偈（迷）**：「法身體若太虛空，性道元來總一同，只因逐妄迷真性，所以輪迴六道中。」——法身常在、本與太虛空同體，只因逐妄（追逐假的煩惱）而迷真性，遂帶著真心本性輪迴六道。
- **第二偈（悟，作對照）**：「原來那一個無毫纖……只怕時人錯認識……何處不是武陵春。」——真心本性本無絲毫污染（何期自性本自清淨），所謂污染只是「幻染」（認知錯誤）；只怕修行人「錯認識」（不識本心、盲修瞎練），忙一輩子白費功夫；只要放下（＝承擔＝不執著），了然本來無一物，處處都是「武陵春」（本地風光、最美的回歸本心）。
體佛法師以此二偈立全講骨幹：**輪迴是逐妄的假相，回頭即本地風光。**（❖ 二偈為禪師語，非大藏經 T 系，見§9 標註）

### 4.2 天女與舍利弗的四番問答（本經・觀眾生品收束）〔行196-475〕
承前品天女散花：花著舍利弗身而不著菩薩，因菩薩已無身心可執著。舍利弗連番設問考驗天女，天女一一破其著相：
1. **生死去處**——舍利弗問「汝於此沒，當生何所？」天女答「佛化所生，吾如彼生」（如佛之因緣化生，我亦如是），並推廣「眾生猶然，無沒生也」（不只我與佛，一切眾生本無生死，心佛眾生三無差別）。
2. **幾時成佛**——舍利弗問「汝久如當得阿耨多羅三藐三菩提？」天女答「如舍利弗還為凡夫，我乃當成」；舍利弗答「我作凡夫無有是處」，天女順勢「我得菩提亦無是處」——菩提無住處，本無得者。
3. **三世諸佛**——舍利弗問已得、當得如恒河沙諸佛云何解？天女答「皆以世俗文字數故，說有三世，非謂菩提有去來今」。
4. **得阿羅漢否**——天女反問舍利弗「汝得阿羅漢道耶？」舍利弗答「無所得故而得」，天女總持「諸佛菩薩亦復如是，無所得故而得」。
末由維摩詰出面制止（怕沒完沒了），揭露天女實已供養九十二億佛、得無生忍、住不退轉，以本願隨意能現——即**觀世音菩薩**倒駕慈航之示現。體佛法師特別讚歎舍利弗「示現智慧稍弱」以顯天女智慧，是表法之慈悲，非真無智〔行482-490〕。

### 4.3 波斯匿王法會・最大功德主是乞丐〔行599-601〕
佛在**波斯匿王**設的法會中，波斯匿王是出資最多的最大功德主，佛卻不讚歎他，而讚歎一位「制心一處、專注聽法、心已全放下」的乞丐為「今日法會最大功德主」。體佛法師以此說明「俱舍（捨盡煩惱）才是真布施」，佛眼中的最大功德不是出錢最多者。

### 4.4 地藏王菩薩入五無間〔行811-844〕
非道中最嚴重者為五無間地獄。**地藏王菩薩**是「佛的老師」，發願自己不成佛而令學生成佛，故佛講《地藏菩薩本願經》時（於忉利天為母說法），出現兩件稀有事：**十方諸佛齊聚**、**法界一切地藏齊聚**（可見「地藏」是發此願者的通名，非一人）。地藏之偉大在於「示現在非道而通達佛道」——不現神通讓眾生羨慕崇拜，而是與五無間眾生示現同樣的苦，再告訴他們「你本來也是佛」。地藏之母因保有善根、聆聽地藏與如來教誨，得回人道、升忉利天。「地即心（虛空）也，藏即如來藏也。」

### 4.5 昨日之我・今日之我（無常公案）〔行382-384〕
有人來見佛說「感謝您昨天幫我做的事」，佛說「我什麼時候幫你做事？」——「昨天的我」與「今天的我」不是同一個我。體佛法師以此喻眾生剎那生滅、細胞剎那變化，如雲彩快速變化，只是自己不知。

### 4.6 狗眼看人低・祖先投胎為狗〔行973-983〕
畜生道憍慢——狗只認一個主人、有強烈地域觀念，是被人類需求馴服。俗謂夢見狗是夢見祖先，因祖先是人群中最顧家、最有地域觀念者，福報不足時往往投胎為狗，與你最有緣，故你看牠順眼、牠見你搖尾。體佛法師以此說明因緣結合又生新因緣、人變狗狗變人於輪迴中流轉——皆假，若不從中觀假即隨之輪迴。

### 4.7 悲華經・不取淨土之願者即釋迦〔行1001-1007〕
《悲華經》中，一如來座下眾菩薩聞說西方極樂淨土後，皆至心信樂發願往生（易行道、阿鞞跋致、無五濁）。唯有一菩薩發願不往生淨土，願入欲界人道、於五濁惡世度化眾生、講「難信之法」。如來起立讚嘆，告諸方如來與菩薩：此不入西方者，即當今之**釋迦牟尼佛**，能於五濁惡世說此難信之法，最為珍貴。體佛法師以此印證「行於非道」之殊勝。

### 8-B 〈佛道品第八〉開題

| 爾時文殊師利問維摩詰言：「菩薩云何通達佛道？」維摩詰言：「若菩薩行於非道，是為通達佛道。」〔行571-694〕 | ✓ | 文殊問：菩薩如何「通達」（無障礙、直接回本心）成佛道？維摩答：**行於非道即通達佛道**。「非道」＝凡因緣所生法之道（非世俗黑道邪惡義）；「佛道」＝覺（佛即心・性・道・禪，覺正淨）。於因緣所生法（非道）中，見其本質皆覺性所現虛幻相、見所生之第一義諦，即佛道〔行578-719〕 | 立品眼：全品綱領。與《金剛經》「不度眾生不能得菩提」同旨——佛道須於非道（世間因緣）中成 |

### 義理深入

**（一）「無沒生」——本經如何把生死變成一場誤會。** 在維摩自己的脈絡裡，天女四番答問是一條「破相」的下行線：前品已破身心相、男女相，此處續破**生死相→時間相→三世相→得證相**，層層剝到「無所得故而得」。體佛法師點出經文的關鍵句法：天女不說「我不會死」，而說「眾生猶然，無沒生也」——把個案（我如佛）普遍化為通則（一切眾生本無生死）。這正是本經「不二」精神在生死問題上的落點：生死不是要「修到沒有」，而是「本來沒有」，眾生只因「一直認為有死」而自造空花、按自己邏輯真去了那個本不存在的「哪裡」〔行259-263〕。此與§8-A末「菩提無住處」互為表裡：既無去處可生，亦無菩提可得。

**（二）「無所得故而得」——本經對「得」的釜底抽薪。** 這是天女問答的總結穴，也是本經與《心經》「無智亦無得，以無所得故」在維摩脈絡中的合流〔行356-471〕。體佛法師強調：舍利弗答「無所得故而得」時，經文立刻由天女推到「諸佛菩薩亦復如是」——把阿羅漢、菩薩、諸佛的「得」一律歸零。在維摩本品，這一步是為下品〈佛道品〉張本：正因「本得」，故不必去淨土「幾時得」，反而要回頭「行於非道」度眾生，才是本願的真妙用。

**（三）「行於非道，是為通達佛道」——本經最險也最高的一句。** 體佛法師指出很多人不敢看《維摩詰經》正因此句。在本經脈絡，這句緊接天女「隨意能現、教化眾生」而來——天女能入世俗諦遊戲神通度眾，正是「行於非道」的活榜樣。維摩對文殊的答，把「通達佛道」從「離世修成」翻轉為「即世度生」：非道（因緣所生法、六道二界）不是障礙，而是唯一的道場；菩薩「示現同類而心不受染」（示行貪欲離諸染著、示入地獄無諸罪垢），才是佛道之「通達」。這與本經一貫的「不二」「入不二法門」一脈相承——煩惱與菩提不二、生死與涅槃不二，於是非道與佛道亦不二。

**（四）本願＝發菩提心＝度眾生——本經與淨土的會通點。** 維摩揭天女「以本願故隨意能現」，體佛法師由此把「本願」定義為「度化無量無邊眾生而無眾生可度」，並接通《金剛經》發心、《華嚴》「無眾生不成佛」、乃至阿彌陀第十八願〔行499-521,753-763〕。在維摩脈絡，這一句是全品「行於非道」的動力來源：不是為自己成佛，而是本願要度眾生，才「隨意能現」入一切非道。體佛法師的收攝是：你若與阿彌陀「度眾生」的本願同心，十方世界任你遨游，西方只是本心示現之一。

### 10-C 《心經》三層破執結構（講者獨立展開）

```
《心經》一路「無」到「得阿耨多羅三藐三菩提」——四次「無」的層次：
  ①破我執 → 我空   ：無色/無受想行識/無眼耳鼻舌身意/無色聲香味觸法（身心世界假）〔行301-317〕
  ②破法執 → 法空   ：無無明…無老死/無苦集滅道（破聲聞十二緣覺之法執）〔行319-327〕
  ③破權教之智得→空空：無智亦無得（本得般若、本來成佛，連得證亦放下）〔行332-341〕

  以無所得故 → 菩提薩埵 → 心無罣礙 → 無恐怖 → 究竟涅槃 → 三世諸佛得阿耨菩提〔行343-372〕
```
連結要點：**三層破執對應「我空・法空・空亦空」，破盡即畢竟空，畢竟空即「無所得故而得」——與維摩天女答「無所得故而得」同一結穴。**

## 11. 日常實踐（可操作的takeaway）

1. **煩惱現前時，先認它是空花。**〔行51-59〕當下問自己「我現在煩惱的那一個，是不是自己製造的空花？」——煩惱性即菩提性，看破即轉。
2. **思惟後即放下。**〔行212〕碰到事情可以思惟（正思惟），但要知道思惟本身是「六塵妄想緣氣」、是空花結空果；思惟完就放下，別讓空花再結空果。
3. **放下＝承擔＝不執著，不是放棄。**〔行74-80〕手握緊是執著（痛苦），手全放開什麼都不要是放棄，手撐開承擔住才是放下。
4. **臨終那一刻，把握本心（太虛空）。**〔行45-47,773-787〕分段生死的關鍵一刻，只要安住覺性、觀「凡所有相皆是虛妄」，當下即西方極樂淨土。平日就要訓練，別等那天才練。
5. **都攝六根＝六根接六塵不受塵相干擾。**〔行744〕這就是一心不亂、就是往生的門檻，不是「唸到阿彌陀佛來才走」。
6. **修行修見地、修這顆心，不修相上功夫。**〔行206-208,455〕不是「走過櫻花不沾身」那種外道修法；別自製一個標準懲罰自己（久沒拜懺、看電視就愧疚）。
7. **真懺悔＝端坐念實相＋不再做。**〔行453,949-951〕懺悔不是一直把罪放在心裡折磨自己，而是知一切罪是當時因緣所生的幻影、悔改不再犯即無罪。
8. **從法界看世界。**〔行795-797〕把世界看成法界所現的「影像」，知幻即離、知離即覺，不須漸次方便，當下即是。
9. **本願＝發菩提心＝度眾生，別嫌麻煩。**〔行511-518〕眾生與你一體，如左手癢右手自然抓；發此心則十方世界任你遨游。
10. **逆增上緣是最好的緣。**〔行787-793〕最障礙你的（眷屬、財富、名利）正是最好的訓練場；於非道中不受干擾，即維摩所說的大菩薩。

- **一則參問**：天女答「眾生猶然，無沒生也」——若眾生本無生死去處，何以還要「發願往生西方」？（提示：本講行746「生則實際生，去則實不去」；願同心同則本心自現西方，非別有一淨土可去。）
