## 1. 本講概要

第五講的骨幹是《最上乘論》十四問中的**第七、八、九問**——五祖依序回答「何知守本真心是涅槃之根本」「何知守本真心是入道之要門」「何知守本真心是十二部經之宗」〔行604-802、1060-1160〕。法師花了全講三分之二的篇幅先鋪墊「什麼是涅槃」，然後才正式回到論文逐句誦讀。

課程分四大段：

1. **母子相見的最後叮嚀**〔行95-266〕：以《佛臨涅槃母子相見經》（摩耶經）全篇故事開場——佛陀入滅前，天眼第一的阿那律尊者引導摩耶夫人自忉利天下來見佛最後一面，佛以「諸行無常，是生滅法；生滅滅已，寂滅為樂」作最後告白，引出「因緣和合虛妄有生，因緣別離虛妄而滅」的總綱。
2. **何謂涅槃：字源與楞伽四門**〔行266-497〕：先講「涅槃」（泥洹、Nirvana）的字源與「火」的隱喻，再重講一遍楞伽四門——八識、五法，並在第四講未及講完的基礎上**新補三性三無性**（相無性・生無性・勝義無性），最後帶到二無我，作為「涅槃」的義理骨架。
3. **三經一論釋涅槃**〔行497-604〕：依序引《解深密經》（斷遍計所執依他起則成圓成實）、《勝鬘經》（法身即大涅槃之體）、《法華經》（究竟圓滿智慧即涅槃）、龍樹《中論》（不受因緣即名涅槃，涅槃與世間無有少分別），四路匯通「涅槃」一詞。
4. **論文正誦與收尾**〔行604-1164〕：正式誦讀並詳解第七問（涅槃之根本）、第八問（入道之要門，以佛遺教經「制心一處」作結）、第九問開端（十二部經之宗，以《法華經》譬喻品、《六祖壇經》智常公案、罪福如幻、佛藏經舍利弗問答層層鋪展），最後回到第九問結論句收束全講。

**通貫全講的核心命題**：涅槃不是死亡，而是我們本自具足、不生不滅的真心；「守本真心」既是涅槃的根本，也是入道的要門、十二部經的宗旨、三世諸佛的祖師——四個問題其實是同一件事的四個角度。

## 3. 核心概念

| 術語 | 體佛法師的解釋 | 經教連結 |
|---|---|---|
| 涅槃（泥洹、Nirvana） | 音譯詞，與「泥土」無關；梵文字根「Nir」義為「火」——印度文化用火代表解脫（能焚燒污穢），佛教沿用此隱喻，但佛所講的涅槃不只是「火」，而是更圓滿的法義〔行267-274〕 | 《楞嚴經》咒首 om anale anale（見§9） |
| 世界觀／法界觀 | 迷者只從世界角度看生滅現象，永遠困在無常裡；悟者入法界，見一切生滅皆是本心影像，不生不滅——這是「識心故悟，失性故迷」的具體展開〔行240-244、600-601〕 | 《楞嚴經》因緣和合虛妄有生，因緣別離虛妄名滅（見§9） |
| 三性（遍計所執・依他起性・圓成實性） | 楞伽四門第三門：對相貼標籤、產生我執＝遍計所執；能生出相的緣起本身也是虛幻＝依他起性；本具、不假外求的本來面目＝圓成實性〔行415-462〕 | 《解深密經》三自性架構（見§9） |
| 三無性（相無性・生無性・勝義無性） | 本講新補的解藥：遍計所執的相是虛幻，故「相無性」；能生相的依他起性也是虛幻，故「生無性」；連圓成實性、勝義諦本身也不可執著，猶如虛空現幻相，故「勝義無性」〔行423-462、479-486、511-517〕 | 《解深密經》三性三無性架構 |
| 二無我（人無我・法無我） | 四大假合的色身沒有一個真實的我＝人無我；六塵緣影（心中產生的一切影像）也是虛妄不實＝法無我〔行486-497〕 | 楞伽四門之四 |
| 涅槃三經一論總攝 | 《解深密經》：斷遍計所執依他起，則成圓成實，即涅槃性；《勝鬘經》：法身即如來大涅槃之體，具三大特性（法界心・諸佛甚深禪定・常樂我淨）；《法華經》：究竟圓滿的智慧即涅槃；龍樹《中論》：不受因緣即名涅槃，涅槃與世間無有少分別〔行497-602〕 | 四部經論交叉印證「涅槃即真心」 |
| 真心與妄心 | 兩顆心其實是同一顆心的體與用：對虛妄相產生執著，稱為妄心；體悟相是虛妄而不執著，當下即是真心——「其實兩顆心是同一顆心，是你誤會以後才成為妄心」〔行608-624〕 | ✓《金剛經》若見諸相非相，即見如來（見§9） |
| 寂照智生・通達法性 | 正念具足後，心的本能「寂」（如鏡體）與「照」（能現萬相）同時生起，稱寂照智生；寂照不二即是心的本心，通達此即通達法性，通達法性當下即是涅槃〔行636-640〕 | 第七問正文逐句（見§8） |
| 真空妙有／性空緣起 | 心如鏡子，鏡子必須是「真空」（不執著任何一物）才能顯出萬相（妙有）；妙有之所以能顯，是因為它依緣而起（依他起性），而依他起性之所以可能，是因為心「本性是空」——真空妙有與性空緣起是同一件事的兩種說法〔行838-856〕 | 《法華經》佛種從緣起（見§9） |
| 見聞轉誦・悟法解義・依法修行・萬法盡通 | 《六祖壇經》智常公案中六祖對「四乘」的定義：見聞轉誦（只念經迴向）是小乘；悟法解義（理解經義）是中乘；依法修行（解義後實踐）是大乘；萬法盡通、萬法俱備、一切不染、離諸法相、一無所得，是最上乘〔行895-914〕 | ✓《六祖壇經》機緣品智常章（見§9） |
| 制心一處，無事不辦 | 《佛遺教經》原句作「制之一處」，《最上乘論》本文「故經云」處已引作「制心一處」（T2011自身的引句異文，法師忠實誦讀T2011原文）；意思是：不是求世間法的圓滿，而是守住本心、入法界，則一切法無不圓滿——「無事不辦」不是你希求的世間法都會成就，而是進入法界後沒有一樣不圓滿〔行738-756〕 | ✓《最上乘論》T2011本文；對照《佛垂般涅槃略說教誡經》T0389（見§9，字句有異，見附註） |

## 4. 故事・公案

### 佛臨涅槃母子相見經（摩耶經）——佛陀對母親最後的告白

法師以這部「很多人沒有聽過」的經開場〔行97-99〕。佛陀即將涅槃時，母親摩耶夫人在忉利天發現自己所戴的花冠凋萎、頭上天光熄滅、腋下流汗、眼睛閃爍、坐立不安——現出天人五衰相，內心生起不祥的預感〔行101-106〕。已證天眼第一的阿那律尊者（佛陀堂弟，與摩耶夫人有很深的親戚關係）此時來到忉利天，告知佛陀將涅槃的消息，並帶領摩耶夫人來到娑羅雙樹林〔行107-111〕。佛陀從色身中示現法身與母親對話。摩耶夫人抱住佛陀，感嘆佛身為天人師、世壽雖僅八十，理應留在人間為三界眾生多說經典，為何此刻就要涅槃〔行111-113〕。

佛陀告訴母親：面臨涅槃是生滅法，是生死法，凡是人必有生滅；佛的法身不滅，只是示現生滅。佛說：「我梵行已立，所作皆辦，隨著因緣而已，不受後有，沒有任何業力可以干擾到我。」〔行113-116〕法師特別指出，這句話後來成為阿含部常用的定型句，是佛陀對眾生「該做的都做了」的交代〔行115-121〕。佛陀接著開示：「諸行無常，是生滅法；生滅滅已，寂滅為樂」——世界一切皆是無常的生滅現象，體悟到「生滅滅已」（我對生滅完全理解，它已經干擾不了我），當下即是「寂滅現前」，即涅槃、解脫〔行123-145〕。摩耶夫人聽完由悲轉喜，開顏頂禮，感恩自己生了悉達多太子而成佛，如今已從忉利天的生滅之樂，進入不生不滅的法界〔行145-149〕。

法師的引申：這句話「諸行無常，生滅滅已，寂滅現前」是佛陀對眾生最後、也是最重要的交代——世間一切都是因緣和合而虛妄有生、因緣別離而虛妄而滅，我們活在生滅現象的世界，若體悟到這一切都是虛幻相，干擾不了不生不滅的本心，這就是解脫；若不體悟，就會不斷在生滅現象裡製造生命現象，這就是輪迴——「輪迴是你每一個念頭，都在輪迴」〔行150-241〕。

### 雪山童子捨身聞偈公案——《涅槃經》半偈因緣

法師引《涅槃經》記載：有一位童子一心想聽聞佛法，用盡方法而不得，最後遇到一位大魔王，魔王說可以告訴他佛法，條件是要奉獻自己的身體給魔王吃掉。童子認為生命不是最重要的，重要的是如何進入永恆的寂滅，因此願意付出一切〔行222-224〕。魔王便說出前半偈：「諸行無常，是生滅法」，童子點頭稱知，但要求聽完後半偈才肯捨身。魔王擔心他聽完就反悔，童子便保證：把自己吊在樹上，魔王講完後半偈就剪斷繩子，讓他墜地被吃〔行224-228〕。魔王於是說出後半偈：「生滅滅已，寂滅為樂」。說完，這魔王現出佛身——原來這位童子就是後來的釋迦牟尼佛。法師強調：佛陀最後告訴母親的這番話，正是祂自己過去生捨身求半偈所得的同一句法義〔行228-232〕。

### 目犍連神通與出家因緣——一句驚惶中的真心

法師舉例：曾有人求佛陀出家，目犍連以神通觀察，告訴佛陀此人沒有出家的因緣。佛說：「你阿羅漢只能看到幾世而已，我佛眼可看到幾劫。」原來在過去某一劫，這個人爬樹躲避老虎追咬時，在驚惶之中喊出一句話——法師強調，那句話不是隨便唸的，是驚惶之中迸發的真心，種下了今生出家成道的因〔行865-869，《法華經》所載〕。佛陀因此為他剃度。法師以此說明：一念真心種下的佛種，即使發生在驚惶顛倒之中，也必然成佛之因。

### 六祖壇經機緣品智常公案——大通和尚的「猶有知見」與六祖的「最上乘」

《六祖壇經》機緣品，僧智常參禮六祖，六祖問他：來之前曾參訪過誰？智常答：曾參訪大通和尚，問「如何是我本心本性」，大通和尚答：「汝之本性，猶如虛空，了無一物可見，是名正見；無一物可知，是名真知」〔行887-892，本文見§9〕。六祖聽完評論：大通和尚說得雖好，但「猶有知見」——因為他仍認為「心是虛空」，心中還有一個「虛空」的相，並未大徹大悟；六祖自己的法是「本來無一物」，連虛空這個物也不立〔行889-891〕。

智常又問六祖：佛說三乘法，又說最上乘，弟子不解，願聞開示。六祖答：法本無四乘之別，是人心自有等差——「見聞轉誦是小乘；悟法解義是中乘；依法修行是大乘；萬法盡通，萬法俱備，一切不染，離諸法相，一無所得，名最上乘」〔行895-919，本文見§9〕。法師特別指出，很多人以為佛教徒只需出錢做功德（見聞轉誦、迴向），這正是「小乘」的層次；懂得經義是中乘；依教修行、實踐六度萬行是大乘；而六祖直接為智常開示最上乘——即身成佛，不需三大阿僧祇劫〔行907-920〕。智常聞法後在六祖座前痛哭流涕，成為《壇經》裡一位大成就者〔行984-987〕。

### 密勒日巴與瑪爾巴——得來不易才知珍惜

法師以藏傳佛教密勒日巴尊者的故事，說明「守心第一」這番話雖然可以五分鐘講完（如大圓滿灌頂），但瑪爾巴尊者刻意讓密勒日巴經歷三年苦修的試煉，用意不是刁難，而是要讓他知道法義得來不易、才會真正珍惜守護〔行1013-1017〕。法師以此反問聽眾：你們沒有經歷那樣的苦修，卻能直接聽到這番最上乘法，福報有多大，是否真的臣服、點頭承擔？〔行1017-1019〕

### 鳩摩羅什與僧肇——師徒之間對「言說是邪」的叮嚀

法師引《佛藏經》，鳩摩羅什大師告訴弟子僧肇：「若講法者不入法界，若聽法者不入法界」——不能只在語言文字上打轉；但若兩人皆已入法界，則「語語相應，字字相通」，當下共同成佛，共入《法界觀》〔行1148-1150〕。法師稱這是一種師生之間情深的叮嚀——不得不講（因為眾生需要語言文字的橋樑），但講的人與聽的人都不能執著在語言文字本身〔行1148-1153〕。

**義理深入**：這一段把「守本真心」拆解為一條可操作的鏈路：真心（本具）→妄想斷（不受相干擾）→正念具足→寂照智生（心的本能同時現起）→通達法性→即得涅槃。法師強調「邏輯很簡單」——這不是抽象口號，而是每一步都可以在行住坐臥中觀照、驗證的過程；也正因如此，法師在正式誦讀第七問之前，先花大篇幅用楞伽四門、三經一論鋪陳「涅槃是什麼」，讓論文中看似簡短的四句話，在讀者心中有了紮實的義理骨架。

| 「問曰。何知守本真心是入道之要門。」〔行687-697，OCR零散〕 | ✓ CBETA T2011 | 前一問講「涅槃根本」，本問接著問：為什麼守本真心也是「入道的要門」——法師強調這是第八問，緊接第七問的結論〔行695-698〕 | 四問的第二問 |

**義理深入**：法師特別提醒讀者「制心一處，無事不辦」這句被廣泛引用、甚至被世間法借用來講「專注就會成功」的名言，必須連同前面「縱此心者，喪人善事」一起理解——「縱容你的心」放蕩而著相，才會「喪人善事」（妨害眾生圓滿的心性）；反過來，「制心一處」不是世間法的專注技巧（法師舉例：他自己世間法也很專心，事業卻仍會破產），而是佛法的「守住本心」，其果是「無事不辦」——沒有一樣不圓滿，而不是你所希求的世間成就都會實現。這是法師糾正世俗誤讀最有力的一段。

### 10.2 涅槃三經一論對照表

| 出處 | 涅槃的定義 | 對應本經（最上乘論）概念 | 行號 |
|---|---|---|---|

### 10.3 楞伽四門（三）三性三無性：本講新補的解藥

```
   三性（凡夫執著的病相）           三無性（佛陀開出的解藥）
   ┌───────────────┐            ┌───────────────┐
   │ 遍計所執性       │  ────→     │ 相無性          │
   │（對相貼標籤執著） │            │（執著的相是虛幻） │
   ├───────────────┤            ├───────────────┤
   │ 依他起性         │  ────→     │ 生無性          │
   │（緣起而生的相）   │            │（能生相的緣起也是虛幻）│
   ├───────────────┤            ├───────────────┤
   │ 圓成實性         │  ────→     │ 勝義無性         │
   │（本具的如如本性） │            │（連圓成實也不可執著，猶如虛空現幻相）│
   └───────────────┘            └───────────────┘
```
〔行415-490，法師依《解深密經》三性架構，補講第四講未及講完的三無性〕

**連結要點**：法師強調三無性不是否定三性，而是對三性各自「補上不執著」的提醒——這帖藥吃下去，凡夫的「著相」病根就被一層層拆解：先知道執著的相是假的（相無性），再知道連能生相的緣起本身也是假的（生無性），最後連修行人最珍視的「本心／勝義諦」也不可執著（勝義無性），才是真正究竟的解脫，呼應第九問「我及涅槃二皆空故，更無二無一，故無所學」。

## 11. 日常實踐

- **面對生老病死，不求「常」，只求體悟「生滅滅已」**：法師強調，生病、面臨無常不必恐慌，「不如意是你的覺受，不是這一件事讓你不如意」——覺受本身也是無常、生滅法，體悟這一點就是修行的下手處〔行234-241〕。
- **罪福皆是心中覺受，放下即消**：「重罪若霜露，慧日可消除」——不是靠身體的勞苦（拜懺、苦行）消業障，而是體悟罪福如幻，不再作、不復起，當下即是大懺悔〔行384-391〕。
- **喝咖啡的例子：有也行，沒有也行**：分辨「喜歡」與「執著」的判準不在行為本身，而在「非它不可」的心理——有咖啡就喝，沒有也無妨，才是不執著〔行467-471〕。
- **念佛、持咒的重點在回歸本心，不是求佛加持世間法**：持咒、觀想曼荼羅若當作求佛菩薩保佑健康、事業，法師直言「不但是外道，你走入迷信了，你終身不悟道」——真正的重點是「願解如來真實義」〔行308-313〕。
- **助念臨終者，提醒的是「正智」而非儀式本身**：臨終前執著於子女、財產，會障礙見到阿彌陀佛的接引；助念的核心不是次數，而是幫助亡者放下心中的相，讓「正智」現前，當下即是如如、即是涅槃〔行548-560〕。
- **修行不是求世間法圓滿，而是守心後一切自然圓滿**：法師糾正「制心一處，無事不辦」的世俗化解讀——不是專心就能考好試、做好事業，而是守住本心、入法界後，世間看似不圓滿的事，對你而言也是圓滿〔行751-756〕。
- **佛像、造功德不是修行的終點，是給無智慧眾生的方便**：有能力布施、造像固然好（種下未來見佛之因），但若因此忽略「守本真心」，仍是本末倒置——兩者不可偏廢，也不可拿其中一項去否定另一項〔行714-724〕。
