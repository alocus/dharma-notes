## 1. 本講概要

本講是《與佛有曰》訪談第二集，時值新春〔行11〕。宗月居士先回顧上一集法師講出家因緣、以自身多發性骨髓瘤示範承擔眾生之苦〔行13〕，再轉述頻道收到的來信：有人聽經後眼睛漸能看見光明、有人憂鬱症痊癒、有人聽經後自在往生並燒出舍利花與舍利子〔行15〕〔行17〕〔行23〕。全講由九個問題串成，而貫穿的只有一句話——**一切法門最後都回歸本心（自性功德），佛菩薩的加持是把這個本心告訴我們**〔行29〕〔行153〕〔行226〕〔行416〕。

1. **力量從何而來？**（〔行25〕–〔行89〕）：兩種力——佛菩薩的加持力與自性功德的自在力，法師只是助緣〔行29〕；佛法即覺法，覺性具體相用（《起信論》）〔行31〕–〔行37〕；聽經要「諦聽」，放下主觀、無分別，音波引發自性功德〔行45〕〔行47〕；憂鬱症、自殺都是遍計所執，入法界心則有療效〔行49〕〔行51〕〔行61〕；人生是夢，修行者「知夢」，臨終是轉換夢境最重要的一刻〔行63〕–〔行75〕；都攝六根、淨念相續則不入中陰，身心一體故燒出舍利〔行79〕–〔行89〕。
2. **淨土在哪裡、如何往生？**（〔行95〕–〔行194〕）：十萬億佛土在你的心〔行99〕；信分理上、事上，理事無礙才是真信〔行113〕–〔行119〕；願往生、願見阿彌陀佛、證大菩提〔行121〕；念佛是制心一處〔行123〕；四土、五濁、諸上善人〔行133〕–〔行139〕；不一定念阿彌陀佛，關鍵在願〔行147〕；「不可以少善根福德因緣」是體相用〔行157〕；世親《往生論》五念門是往生最完整的具體法門〔行170〕–〔行194〕。
3. **自力還是他力？**（〔行197〕–〔行228〕）：究竟義中自他不二〔行203〕；法藏比丘的本願就是自性功德〔行205〕〔行207〕；第十八願「至心信樂」的當下即往生〔行212〕〔行214〕；自力、他力、外力是同一力〔行226〕；「不識本心，學法無益」〔行228〕。
4. **如何一心不亂？**（〔行230〕–〔行258〕）：一心是本心、不亂是都攝六根〔行232〕；六根接六塵皆是幻影〔行240〕；擒賊先擒王〔行242〕；平日以五念門訓練〔行250〕–〔行256〕。
5. **中陰與《西藏度亡經》**（〔行258〕–〔行306〕）：中陰即中蘊，也是幻相〔行264〕〔行266〕；臨終藍光先現，安住則融入毘盧遮那性海〔行280〕–〔行301〕。
6. **失智者能否往生？**（〔行309〕–〔行325〕）：失智是器官，不是佛性〔行313〕。
7. **臨終助念**（〔行325〕–〔行362〕）：助念是外力、助緣，重在提醒〔行329〕；法師的做法〔行341〕–〔行360〕。
8. **演龍法師**（〔行362〕–〔行374〕）：聽講經後坐化往生的案例。
9. **華嚴與淨土、諸宗會通**（〔行377〕–〔行416〕）；**真言宗何以灌頂**（〔行419〕–〔行462〕）。

## 4. 故事・公案（全敘事）

### 4.1 觀眾來信：聽經而目明、而憂鬱症癒、而自在往生〔行15〕–〔行27〕

宗月居士說，自賢首禪苑頻道播出以來，收到非常多居士的 E-mail 與來信〔行13〕：有人眼睛看不見，聽了法師講經後慢慢能看到「彩燦爛的光明」；有人憂鬱症竟然痊癒，而且開始發心走上修行之路〔行15〕〔行17〕；也有許多人因為聽經，往生時當下往生淨土，燒出許多舍利花、舍利子〔行17〕。有人的朋友、家人「聽完師父講經自在往生」〔行23〕。法師證實這五年來確實收到很多這類訊息，來信者還附照片作證明〔行27〕。法師的回答不居功：「貧僧、小僧，我只是一個助緣」〔行29〕；這些人自我療癒，「任何人只要能聆聽、能諦聽佛的法要，都有這種效果」〔行53〕〔行55〕。

### 4.2 法藏比丘發四十八願〔行205〕〔行207〕

法師依《無量壽經》講：法藏比丘參考了一切淨土，要創造一個最理想的淨土，讓所有眾生在其中成佛，於是發了四十八願〔行205〕。法師的重點在「本願」二字：一切佛發的願都叫本願，是佛與眾生自性本有的功德所產生的願，「完全不是外求」；法藏比丘之所以偉大，是因為他發現自性功德可以在四十八願裡呈現出來，並告訴了我們〔行207〕。而今阿彌陀佛已經成佛，祂的願「完全相符」，因為佛是不異語者、不誑語者〔行216〕——祂看眾生本來都是佛，當下就是淨土〔行219〕〔行221〕。

### 4.3 法師瀕死經驗所見：第八識演電影〔行329〕–〔行335〕

法師說「因為我有瀕死的經驗，我會知道」〔行329〕：人要往生時，第八意識會把這一生像演電影一般呈現出來；在哪個時間點你最在意的人、最在意的事——也就是最執著的人事物——那一剎那，你就會投胎、輪迴到你當時認為最重要、最執著的那個時空點，「再去做一個訓練」，就像被留級一樣重新演一次〔行331〕〔行333〕。所以臨終的八小時內，如果有因緣，要提醒他佛的要義和他平常修行要警惕的地方，「藉著一個第三者來告訴他而已，重點還是他個人」〔行335〕。

### 4.4 法師如何為人助念〔行341〕–〔行362〕

法師說自己也幫人助念過〔行341〕。他的做法分五步：

1. **先安冤親債主**：用真言宗的穢跡金剛法，顯現金剛明王，先跟往生者的冤親債主溝通好——這個人已經發菩提心要往生淨土，「當願所有的眾生往生淨土」〔行341〕〔行343〕。法師點明：冤親債主其實是自心顯現的業力；很多人臨死時認為冤親債主都要來，「是你的心裡面已經有設定冤親債主要來，當然他就來」〔行343〕〔行346〕。告訴冤親債主：此人往生後也會幫助你們往生淨土、成佛〔行348〕〔行350〕。
2. **讓臨終者心安**：真正的重點是讓往生者心安——他一旦認為冤親債主已被安撫、已祝福他往生，「其實他往生已經一半了」〔行350〕〔行352〕。
3. **念他平常念的佛菩薩**：阿彌陀佛、地藏王菩薩、觀音菩薩都無所謂，「所有的佛都歸於一佛」〔行352〕〔行354〕。
4. **每隔二十分鐘開示**：告訴他一切皆是虛幻，凡情干擾不到你，不需要愧疚、不需要負責〔行354〕〔行356〕。
5. **令五門齊備**：讚歎如來即讚歎他自己的自性功德，禮拜如來，觀想阿彌陀佛的依正二報，願往生，最後發菩提心——「在那一剎那五門齊備，他必定往生淨土」〔行358〕〔行360〕。

案例中至少都見到面帶微笑，也有人燒出五彩舍利子、舍利花〔行360〕〔行362〕。

### 4.5 演龍法師坐化往生〔行362〕–〔行374〕

宗月居士提到一個案例：演龍法師只聽了法師講經短短一段時間，坐著往生〔行362〕〔行364〕。法師補述：演龍法師出家很久、僧臘很高，在台灣中部埔里的圓通寺——一個戒律道場——修行得很好〔行366〕；偶然聽到法師講《妄盡還源觀》，也聽了《六祖壇經》，做成筆記，覺得對契入本心非常有用，發願印行普及，先後出版三版與大家結緣〔行366〕〔行368〕。法師說他「真的是一個菩薩的示現」，並以《楞嚴經》（※ 實出《遺教經》，見 §9 #26）「制心一處，無事不辦」解說：入本心時一切事情全部解決〔行368〕〔行370〕〔行372〕。他把名字從「演龍」改為「緣影」——可見他已了解本心顯現的都是緣影；他示現坐化往生，大家都看到了〔行372〕。他本修彌勒法門，發願回歸彌勒內院、彌勒淨土，將來隨彌勒菩薩倒駕慈航來娑婆，在龍華三會中取證〔行374〕。

### 4.6 龍樹菩薩開南天鐵塔〔行419〕〔行421〕

法師說：真言宗在佛陀三轉法輪的第三轉才出現，由龍樹菩薩從南印度的鐵塔裡，受金剛薩埵的灌頂，再把密教傳出來〔行419〕〔行421〕。（傳說性質，CBETA 未逐字核驗，見 §12。）

### 4.7 玄奘大師西行取瑜伽〔行401〕〔行403〕

法師說玄奘大師到印度，最主要是要取瑜伽回來，因為瑜伽很複雜，所以翻譯了《瑜伽師地論》〔行401〕〔行403〕。（✓ T1579 題記：彌勒菩薩說、唐玄奘譯。）

## 8. 本經解義（《與佛有曰》訪談第二集逐段）

### 8.1 聽經的力量：兩力・覺性・諦聽

```
            佛菩薩加持力〔行29〕
     （經典的語言文字・般若智慧〔行53〕）
                 │
                 ▼  法師＝助緣（音波）〔行29〕〔行45〕
   聽者「諦聽」：放下主觀・無思考性＝無分別〔行45〕〔行47〕
                 │
                 ▼
       引發自性功德（覺性：體・相・用）〔行31〕–〔行37〕
                 │
     ┌───────────┴───────────┐
     ▼                       ▼
 心病可反轉〔行59〕        身病隨自然・醫療・無常〔行57〕
 （憂鬱症・自殺＝遍計所執〔行49〕〔行61〕）
```

| 原句〔行〕 | 法師釋義 | 脈絡定位 |

| 「第一個是佛菩薩的加持力，另外一個是他自性功德的自在力，就產生了圓滿的功德力」〔行29〕 | 兩力合成；法師自己只是助緣 | 全講總綱 |
| 「佛法是覺法，覺在哪裡？覺在自性的功德」〔行31〕 | 眾生本來具備完全沒有缺失的覺性 | 定義佛法 |

| 「佛雖然講無法可說」〔行41〕 | 佛藉語言文字闡述自證的自性功德；因人人本具，故無法可說〔行43〕 | 引《金剛經》（§9 #3） |

| 「所謂的無思考性就是沒有分別性」〔行47〕 | 諦聽＝排除一切、放下主觀意識；當下音波引發自性功德 | 聽經方法 |

**義理深入。** 法師把「聽經而病癒」這件看似神奇的事，拆成兩條可理解的線：一條是佛菩薩留下的般若文字〔行51〕〔行53〕，一條是聽者本具的覺性〔行31〕。兩者相遇的條件只有一個——「諦聽」：不是用頭腦分析，而是放下主觀、無分別地聆聽，音波便直接觸動自性〔行45〕〔行47〕。他特別劃清界限：這不是說身體馬上變好；四大假合的病照樣隨無常演變，連佛陀都示現生老病死〔行55〕〔行57〕。能反轉的是「心」的病，因為憂鬱、自殺都是遍計所執——執著某一件事——而般若正是破執的〔行49〕〔行59〕〔行61〕。這樣一來，法師把功德從自己身上卸下：「小僧只是一個助緣」〔行29〕。

### 8.2 人生如夢與臨終一刻：瑞相從何而來

```
不知夢 ──▶ 夢完再做夢 ──▶ 過去・現在・未來 ＝ 輪迴〔行69〕
   │            （每人因緣不同，夢不同〔行71〕）
   ▼
知夢（修行者）〔行65〕 ──▶ 點醒夢中人（倒駕慈航）〔行67〕
   │
   ▼  臨終＝轉換夢境最重要的一刻〔行73〕
若見諸相非相→見本具如來〔行75〕
   ├─ 身受心不受・以無所受受諸受（三昧）〔行77〕
   ├─ 都攝六根 → 淨念相續（何期自性本自清淨）〔行79〕〔行81〕
   └─ 回歸自性 → 不入中陰 → 願生淨土即生〔行83〕
          ▼
   身心一體 → 舍利子・舍利花・面帶微笑〔行85〕–〔行91〕
```

| 原句〔行〕 | 法師釋義 | 脈絡定位 |
|---|---|---|
| 「一切都是幻相，所以如夢幻泡影」〔行63〕 | 我們現在就是在做一場夢 | 引《金剛經》偈（§9 #4） |
| 「真正有深入法界修行者，他是知夢」〔行65〕 | 修行者與非修行者只差在知不知夢；入菩提心則要點醒夢中人〔行65〕〔行67〕 | 修行定義 |
| 「這就是輪迴」〔行69〕 | 不了解是夢，就不斷做夢 | 輪迴＝夢續 |
| 「臨終的那一刻是所有最重要的那一刻」〔行73〕 | 負責轉換；若知是夢而不執著 | 全講第一次點出臨終 |
| 「若見諸相非相即見如來」〔行75〕 | 如來是眾生本具，不是去找一個如來；心性處在「制心一處」的如來藏當下 | 引《金剛經》（§9 #5，※「即見」） |
| 「這個叫做身受心不受」〔行77〕 | 臨終不受苦不是四大不分離，是心不受苦；已入三昧，「以無所受，受諸受」 | 引《維摩詰經》（§9 #6） |
| 「都攝六根是第一句話」〔行79〕〔行81〕 | 六根干擾不了他，淨念相續；淨念是本來清淨心，「何期自性，本自清淨」；相續是不斷 | 引《楞嚴》大勢至章、《壇經》（§9 #7、#8） |
| 「不用進入中陰身」〔行83〕 | 了解淨土是我心顯現的境界，只要願往生，當下一定往生 | 不入中陰（問五再申） |
| 「舍利子就是自性功德產生了一種表相」〔行89〕 | 身心靈一體，如生氣則血壓上升〔行85〕〔行87〕；八小時內打開看，他一定面帶微笑〔行89〕〔行91〕 | 解釋瑞相 |

**義理深入。** 法師以「夢」統攝了生死：輪迴不是被外力推著走，而是不知是夢的人一場接一場地做下去，因緣不同所以夢不同〔行69〕〔行71〕。由此，臨終的意義被凸顯——那是「轉換夢境」的一刻〔行73〕。這一刻若能知夢不執，就是《金剛經》的「若見諸相非相」，而所見的如來不在外，是自己本具〔行75〕。法師把三組經文串成臨終的內在過程：心不受苦（身受心不受、以無所受受諸受）〔行77〕→ 六根收攝（都攝六根）〔行79〕→ 本來清淨的念頭不斷（淨念相續＝何期自性本自清淨）〔行81〕。到這裡已回歸自性，所以不必經中陰〔行83〕。舍利與微笑不是目的，只是「身心靈一體」下自性功德的外在表相〔行85〕〔行89〕。

**義理深入。** 法師對「為何密法須灌頂、顯教不必」的回答，建立在自受用與他受用的分別上：本心的道理（自受用、法身）任何人都可以講，所以顯教人人可傳〔行421〕〔行425〕〔行430〕；但諸佛菩薩回歸本心的具體方法——手印、種子字、咒音的三密陀羅尼——是他受用、是「方法」〔行430〕〔行432〕。方法要有效，前提是信；不信則不只無效，還會生起誹謗〔行440〕〔行444〕。所以要上師觀察資質與信心才傳，傳後再以三昧耶戒立約〔行442〕〔行458〕〔行460〕。老師傅「江湖一點訣」的比喻讓這個道理落地〔行446〕〔行452〕。最後法師又把密與淨會通：一句阿彌陀佛也是即身成佛的法門，可顯可密〔行454〕——回到本講主軸。

## 11. 日常實踐

1. **聽經時「諦聽」**：放下主觀、不分析、不分別，讓音波直接觸動自性〔行45〕〔行47〕〔行55〕。
2. **把煩惱看成遍計所執**：憂鬱或想不開時，先認出「我在執著某一件事」〔行49〕〔行61〕。
3. **練習「知夢」**：日常遇境時提醒自己這是夢、是影像，不執著〔行65〕〔行256〕。
4. **建立「理事兩信」**：理上信淨土是我心所現，事上信確有淨土、確有阿彌陀佛〔行113〕〔行119〕。
5. **每日修五念門**（法師說「不離你的日常生活」〔行250〕〔行252〕）：
   - 禮拜阿彌陀佛＝禮拜自心〔行252〕；
   - 讚歎阿彌陀佛＝禮敬諸佛、稱讚如來〔行252〕；
   - 觀察淨土依正二報是我自心顯發〔行252〕；
   - 發願往生淨土〔行254〕；
   - 迴向發菩提心：當願眾生都回歸極樂、回歸本心〔行254〕。
6. **念佛時制心一處**，並了解阿彌陀＝無量光、無量壽〔行123〕。
7. **不必擔心將來失智**：現在這一念心最重要；平日薰習五門〔行319〕〔行325〕。
8. **先訓練自己能自在往生**，不依賴助念；若要請人助念，請自己信賴的人〔行337〕〔行339〕。
9. **為人助念時**：令其心安；念他平常念的佛菩薩；每隔約二十分鐘開示「一切皆虛幻，不需愧疚」；引導他禮拜、讚歎、觀察、發願、迴向〔行352〕–〔行360〕。
10. **密法不可自學自傳**：須有合格上師灌頂，受三昧耶戒〔行458〕〔行460〕〔行462〕。
