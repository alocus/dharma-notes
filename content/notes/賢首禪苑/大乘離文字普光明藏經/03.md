## 1. 本講概要

第三講分三段。

**前段**（承前）：經題「離文字」不是不要文字——莊子「得魚忘筌」〔行97-99〕，語言文字是工具，「得魚就忘筌」，但沒有它也不行〔行99-101〕；法化報三身用鏡子與 200 吋電視螢幕重新申論一次：鏡子（體＝法身）本自具有能顯像的功能（報身），顯出的像（化身）不離鏡體，「三則一，一則三」〔行104-118〕，由此帶出「唯心淨土，自性彌陀」〔行118-122〕與「法外無心，因為心外無法」〔行120-124〕。法師引《華嚴經》「三世一切佛，應觀法界性，一切唯心造」，說法界之性即是心，是我們的心變現出十法界〔行124-132〕。普光明藏＝法性——法性是體，法性起法相（電視螢幕能顯像的功能），凡夫與佛「一模一樣」，差別只在凡夫「迷於法相」而佛「知道法相是讓我用的」——「凡所有相皆是虛幻，我不取著，不是要放棄它」〔行139-151〕。

**中段**：進入序分第二波當機眾。觀自在菩薩以「西方三聖」的相用身分登場——阿彌陀佛（體／法身）、大勢至與觀音（報化身），「一則三，三則一」〔行180-186〕；觀音屬蓮花部，帶出「嗡嘛呢唄咪吽」六字大明咒逐字釋義：嗡＝宇宙第一音・法身無聲而顯聲；嘛呢＝摩尼寶珠・自性功德；唄咪＝蓮花・出淤泥不染；吽＝圓滿〔行188-200〕。觀音出，即帶出《心經》全咒——法師逐句解「五蘊皆空」：蘊者，影像隱藏，色受想行識五種皆自性功德所顯之隱藏物，本無自體，故曰空〔行209-234〕；並辨正「佛法沒有『放下』兩個字，只有『不執著』三個字——有放下就有不放下，我沒有執取，哪來放下」〔行236-250〕。觀自在為般若・蓮花二部之首，其後諸菩薩依序登場：大勢至（梵天／色界）〔行301-306〕、遍吉祥＝妙吉祥＝文殊師利〔行307-311〕、普賢〔行311〕、不空見（申論中國四大譯師：鳩摩羅什・真諦・玄奘・不空，及不空→惠果→空海之密法傳承）〔行312-322〕、星宿王・息諸蓋（除蓋障）〔行328-333〕、藥王藥上（＝日光月光菩薩，藥師佛脅侍，屬密部）〔行339-358〕、聲聞三尊者（舍利弗智慧第一・目乾連神通第一・大迦葉）〔行361-366〕、那羅延（大梵天）〔行367〕、諸天威光「猶如聚墨對閻浮金」之喻〔行369-376〕、八大龍王・乾闥婆・迦樓羅（金翅鳥；泰國國徽、印尼航空圖騰）〔行389-403〕。序分至此結束，十方菩薩「來入此會⋯即於會中坐蓮華座」〔行403-407〕。

**後段**：勝思惟菩薩起座，請問「二字之義」（如來）〔行409-421，479〕；法師以「勝思惟梵天所問經・獵人捕鳥」本生重申「不動即本心」〔行461-476〕（詳見第二講故事，本講另從「正思惟＝依止不動」角度重講），並串起法化報三身＝毗盧遮那（法身）・普賢（化身）・文殊（報身，護持文殊智），配唵阿吽三字真言（法化報）與蓮花身大士咒〔行496-539〕，警示「只有 mantra 沒有 sutra 會走偏」，舉不良上師以持咒謀世間利誘眾生為戒〔行540-547〕，並以不空大師譯《大方廣佛花嚴經入法界品頓證毘盧遮那法身字輪瑜伽儀軌》串起「顯（普賢十大願王）→密（唵阿吽三密）→文殊智慧海→頓毗盧遮那法身」之顯密圓通次第〔行556-565〕，附空海・最澄「入唐求法・四船遇颱風」史事，說明唐密（東密／台密）東傳日本之因緣〔行566-590〕。

轉入正宗分本文：勝思惟三問——何者一法諸菩薩所應永離、何者一法諸菩薩應常護持、何者一法諸如來現所覺了〔行479-489，594〕。本講只答第一問：**九離**——貪・瞋・愚癡・我取・疑惑・憍慢・懈怠・惛眠・愛著〔行601-609〕。法師以《大智度論》《俱舍論》《雜阿含》共通之「五蓋」（貪欲蓋・瞋恚蓋・掉舉蓋・惛眠蓋・疑蓋）貫通九離，逐一釋義，其中特重「掉舉」＝心躁動＋悔已做之事，才是真懺悔之對治〔行613-670〕。以儒家「不問天意、不猜人心」（斧頭公案）釋「疑蓋」〔行653-666〕。

最後以十二因緣（本講稱十因緣）「齊識而還，不能越彼」總收：生滅門——識→名色→六入→觸→受→愛→取→有→生→老死；還滅門逆推回「識」，此識本是入胎識・如來藏・阿賴耶，但還滅門推回之識已挾帶第六（分別）・第七（我執）二識之法執與我執，破此二執即《金剛經》「通達無我法者，如來說名真是菩薩」〔行679-805〕。法師嚴駁「人死斷滅」之邪見與自殺（犯根本重戒）〔行733-741〕，並以淨土宗「臨終一心不亂」之理收攝——「你執取什麼，就生在什麼」〔行753-775〕。末引《圓覺經》金剛藏菩薩三問（「眾生本起無明」為不正問）與普眼章摩尼寶珠喻，說明「法執・我執如何來」〔行810-840〕，以準提咒與《心經》咒語為例申論「持咒持經＝頻率相應」，全講在《金剛經》「一切有為法，如夢幻泡影」之觀法作結，預告第四講續答第二・三問。

貫串全講的命題：**離文字不是不要文字，是不執著於文字〔行101〕；凡夫與佛的差別只在迷不迷於法相，而非本體有異〔行145-147〕；佛法只有「不執著」三個字，沒有「放下」兩個字〔行238-239〕；十二因緣真正的關鍵在「識」，識裡的我執・法執才是輪迴的根本〔行791-801〕。**

## 4. 故事・公案・因緣

**（1）鏡子與電視螢幕：法化報三身的雙重譬喻**〔行104-118〕
法師以鏡子重申三身一體：鏡子本身是「體」，是法身；鏡子具備「顯像」的功能，這功能叫「報身」——石頭沒有這個功能，拿石頭來顯像顯不出來，因為石頭不具此功能，所以不是鏡子；鏡子顯出的像叫「化身」。三者是同一件事：鏡子若沒有能顯像的功能，就不是鏡子了。法師再舉電視螢幕為喻：螢幕本身是法身，螢幕具有能顯像的功能是報身，螢幕顯出來的文字（例如此刻讀者眼前的「大乘離文字普光明藏經」幾個字）是化身——文字會變，但不管顯出多少化身、多少文字，「有沒有離開這個螢幕？沒有」，所以法化報三則一、一則三。

**（2）將軍與斧頭的疑心公案**〔行658-665〕
公案里有一家人斧頭丟了，一直懷疑是隔壁鄰居的人拿的——鄰居的一舉一動、走路的姿態、眼神，全被解讀成「偷斧頭的證據」。後來斧頭在自己家某處找到，再看那個鄰居，怎麼看都不像偷斧頭的人；那天他匆忙走過自家門前躲躲藏藏，原來只是想大便忍著跑而已。法師以此說明「疑蓋」——懷疑自性、猜人心，「你一猜就會讓你妨礙你的自性」，並引儒家「不問天意，不猜人心」二語，坦言自己也曾如此，忐忑不安皆源於猜疑〔行653-666〕。

**（3）空海・最澄入唐求法・四船遇颱風**〔行576-590〕
不空大師往生那一年，日本同時誕生一位人物——空海大師（法師稱其為不空轉世）。空海入唐時，日本天皇挑選遣唐使共四艘船，載著當時日本最重要的一時之選：第一批是建築家（欲取中國建築之法，今日京都街道格局即當時長安翻版，故京都舊稱「小長安」）；第二批是文學家；第三批是工樂家（學唐朝音樂，因唐玄宗最精音律）；第四批是政治家（學中國三省六部官制）；另有一批專學佛法精髓。四船同時渡海，結果遇上颱風，兩艘船全數罹難，日本痛失英才；剩下兩艘，一艘被吹到南方浙江登陸，一艘依原計畫從北方登陸。從北方登陸、「註定不會死」的這一位就是空海大師；被吹到浙江的一位叫最澄大師，他就近到天臺山向智者大師一系學天台法要。空海帶回的是東密（真言宗），最澄帶回的是台密（天台加密），兩大系統支撐了日本佛教一千多年直到明治維新。法師以「這不是天運，還是什麼」感嘆其中因緣之巧（不空往生年即空海誕生年）〔行576-590〕。（背景：唐武宗滅佛，密部在中國先滅，中國自此難再有高僧從日本取回原汁原味的東密〔行573-576〕。）

**（4）獵人捕鳥本生（勝思惟菩薩前身）——「不動」角度重講**〔行461-476〕
（詳細情節見第二講學習筆記〔賢首禪苑/大乘離文字普光明藏經/02〕第4節第2則：獵人以會移動的偽裝樹林誘鳥棲息，一網打盡；唯一隻鳥因觀察「樹枝雖動，樹幹本不動」而不輕易棲息，最終未落網，即勝思惟菩薩前生，設陷阱的獵人即波旬魔王。）本講法師特別點出這則本生要教的是「正思惟」二字：「思惟不動的這個——我是要依止不動，不是要依止動的，動的是幻相，不動的就是我們的本心，就是如來」。法師稱：如果懂這一層，「大乘經典出現任何一部都是有非常縝密的邏輯跟安排」，勝思惟之名代表祂所問的正是「不動的如來是什麼」〔行472-476〕。祂所依止的「不動」，法師稱之為「阿閦（不動）如來」，亦稱「準提自性」（主隸折隸準提娑婆訶）〔行589-593〕。

### 連結視覺一：法化報三身＝鏡子／電視螢幕（結構教學）

```
                      體（法身）── 鏡體 ／ 電視螢幕本身
                            │
        報身（相）── 能顯像的功能（本自具足；石頭沒有＝非鏡）
                            │
        化身（用）── 顯出的像／顯出的文字（不離鏡體、不離螢幕）
                            │
              法化報三則一，一則三，本不離斷滅
```
**連結要點**：鏡子與電視螢幕是同一個結構教兩次——體是「什麼東西」，相是「它具備什麼功能」，用是「它顯出什麼」；三者永遠一起出現，缺一即非其物（石頭沒有顯像功能就不是鏡子）〔行106-118〕。

### 連結視覺二：五蓋 → 蓋住戒定慧三無漏學

```
貪欲蓋 ─┐
瞋恚蓋 ─┴─→ 蓋 戒
掉舉蓋 ───→ 蓋 定
惛眠蓋 ─┬─→ 蓋 慧
疑  蓋 ─┘
```
| 蓋 | 定義（體佛法師釋） | 對治 | 行 |
|---|---|---|---|
| 貪欲蓋 | 所求過分、過度 | 知足、不執取 | 〔行620-622〕 |
| 瞋恚蓋 | 對違情之物產生不滿（愛之欲其生，惡之欲其死） | 觀違情之物亦是幻相 | 〔行622-624〕 |
| 掉舉蓋 | 掉＝心躁動；舉＝悔已做之事 | 真懺悔＝不復作、不復起 | 〔行624-638〕 |
| 惛眠蓋 | 存有煩惱之睡眠；本義即「煩惱蓋」 | 睡前不掉舉不貪瞋，身心自然調和 | 〔行638-651〕 |
| 疑蓋 | 懷疑宇宙真相・懷疑自性 | 不問天意，不猜人心 | 〔行651-666〕 |

**連結要點**：九離的「貪瞋癡慢疑・我取・愛著・惛眠・懈怠」全部收攝在五蓋之中；法師強調「掉舉」是最常被忽略卻天天發生的一蓋——懊悔已做之事，比貪瞋更隱微地蓋住修行人的自性〔行627-638〕。

### 連結視覺三：十二因緣（十因緣）——生滅門・還滅門，「齊識而還，不能越彼」

```
生滅門（順觀，流轉）
無明 → 行 → 【識】 → 名色 → 六入 → 觸 → 受 → 愛 → 取 → 有 → 生 → 老死
                ▲
                │  齊識而還，不能越彼（不再往前推無明）
                │
還滅門（逆觀，還滅）
老死 ← 生 ← 有 ← 取 ← 愛 ← 受 ← 觸 ← 六入 ← 名色 ← 【識】
                                                    │
                        還滅門推回之識 ＝ 挾帶第六（分別）・第七（我執）識
                                                    │
                              破我執（粗，錯認四大假合為我身）→ 出三界
                              破法執（細，執著如來藏所現影像）→ 成大菩薩
                                                    │
                          《金剛經》：通達無我法者，如來說名真是菩薩
```
**連結要點**：生滅門的「識」是清淨的入胎識・阿賴耶・如來藏；但還滅門逆推回同一個「識」時，已挾帶第六・七識的分別與我執——凡夫與佛差別只在此識乾不乾淨（有無我執法執），不在識本身有別〔行779-801，843-845〕。

## 10. 法脈會通

**（一）序分雲集的三重讀法**：法師把本經序分的雙波當機眾（第二講：勝思惟等十五菩薩摩訶薩＋第三講：觀自在以下之天龍八部）與《阿彌陀經》三圍當機眾（內圍歷史人物聲聞乘、外圍菩薩、最外圍諸天）、《圓覺經》十二菩薩為上首之體例並置比較——重點在於本經當機眾「全部不是四大假合的人類」，而是「佛陀入法界心中的菩薩」，這與一般經典之當機眾（如《金剛經》須菩提）形成對比〔第二講已述，本講延續此結構〕。

**（二）觀自在＝蓮花部＝般若部的雙重身分**：本經序分中觀自在菩薩以「西方三聖」（阿彌陀佛體，觀音勢至報化）身分登場，隨即帶出六字大明咒（蓮花部）與《心經》全文（般若部），法師以此指出觀自在菩薩在唐密體系裡同時是「蓮花部」與「般若部」之首——這是本經「顯密圓融」（同一位菩薩同時具備顯教般若智慧與密教蓮花部真言）的第一個實例〔行186，271-279〕。此結構在第二講「五方五佛／四智」圖已鋪陳（西方阿彌陀如來＝妙觀察智＝第六識），本講的觀音・大勢至正是西方蓮花部之左右脅侍。

**（三）九離→五蓋→戒定慧→十二因緣，一以貫之**：本講的核心會通鏈是——菩薩九離（本經正宗分第一答）＝五蓋（雜阿含・俱舍論・大智度論・摩訶止觀共說）＝蓋住戒定慧三無漏學＝十二因緣「齊識而還」還滅門所要破的我執・法執。法師把這條線收束在《金剛經》「通達無我法者，如來說名真是菩薩」——顯示本經看似簡單的「九離」清單，其實與最深的十二因緣・唯識學義理是同一件事，只是從不同角度切入而已〔行601-805〕。

**（四）顯密圓通次第——三段結構貫串全講**：（1）第二講「五方五佛／四智」圖（結構）→（2）本講「唵阿吽三密」配「法化報三身」（配對）→（3）不空大師《字輪瑜伽儀軌》「普賢十大願王（顯）→唵阿吽三密（密）→文殊智慧海→毗盧遮那法身」（次第）。三者同一條軸線一路加深，是本講「顯密融合」教學的骨幹〔行496-565〕。

## 11. 日常實踐

- **文字是工具，不執著也不捨棄**：讀經、聽經、持咒都要「得魚忘筌」——藉文字契心，契心後不執著文字本身，但沒有文字（沒有經教）也悟不了〔行97-101〕。
- **練「不執著」，不練「放下」**：面對日常煩惱，不是強迫自己「放下」，而是觀照「這是不是我在執取」；佛法只有「不執著」三個字〔行236-239〕。
- **懺悔＝不復作、不復起**：做錯事，發願以後不再做（不復作），也不再拿這件事一再懲罰自己（不復起）；反覆自責是「掉舉」，仍蓋住自性，不是真懺悔〔行632-637〕。
- **不問天意，不猜人心**：遇到不確定的事，不去卜算天意，也不去揣測別人的心思（斧頭公案）——這樣做人會比較自在，也是對治「疑蓋」的具體方法〔行653-666〕。
- **平時要訓練，不要指望臨終那一念**：「一心不亂」不是臨終喊口號就能達成，是平日對治貪瞋、練習不執取的積累；現在小事就會生氣的人，不要騙自己說臨終那一刻就能不生氣〔行761-775〕。
- **持咒持經先明其義**：無論持準提咒、持「阿彌陀佛」聖號、或誦《心經》，都要先了解其義（如蕅益大師《彌陀要解》之於「阿彌陀佛」），否則「口唸彌陀心散亂，喊破喉嚨也枉然」，反而容易走偏〔行548-553〕。
- **不要因誘惑而依止「會動」的東西**：獵人捕鳥本生教我們分辨——凡是會生滅、變動的境界（名聞利養、世間讚譽）都不是真正的依止處，只有不動的本心才是〔行461-476〕。

- **下承**：第四講將續答勝思惟三問之第二問（何者一法是諸菩薩應常護持——本經 T0829 原文已見於本講校對：「謂諸菩薩非己所安不加於物」）與第三問（何者一法是諸如來現所覺了——本經原文「一切法性普光明藏是如來覺⋯」，第二講已先行部分引用）。
- **參問**：本講九離與十二因緣「齊識而還」都指向同一個「識」——生滅門的識清淨（如來藏），還滅門推回卻挾帶我執法執而顯得不淨。這是否代表「識」本身從未改變，改變的只是我們是否「認出」它挾帶的執著？下一次讀經時，可以留意勝思惟三問的第二問（護持）與第三問（如來現所覺了）如何回答這個「識」如何真正清淨的問題。
