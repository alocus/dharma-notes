## 1. 本講概要

第四講分三段。

**前段**：法師先複習前三講當機眾之盛（八大菩薩、佛佛道同、龍天八部皆來請法），指出全經其實只圍繞兩個字——「如來」——而《金剛經》5100 多字中，鳩摩羅什大師所譯「如來」一詞大致出現 88 次，可見「如來真實義」是學佛的核心，若不懂此義，經典只能當文學、哲學、史學來欣賞〔行91-115〕。法師拆字解「如來」：如講理（性），來講事（相）；有來有去是事，事的體性是理；理事一如、性相不二，即是「如來」（梵文 tathāgata）〔行117-129〕。法師引《金剛經》彌勒菩薩偈頌「如來者，無所從來，亦無所去」申論：化身報身有來有去，法身無來無去，兩者要圓融看，不可偏執一邊〔行127-131〕。

法師以華嚴五祖傳承申論理事圓融：杜順（初祖，相傳文殊化身，《法界觀》作者）、智儼（二祖）、賢首法藏（三祖，即法師常講的《妄盡還源觀》作者）、清涼澄觀（四祖）、宗密（五祖，法師講《圓覺經》所據之疏主）——五位皆入地大菩薩，法師稱皆為文殊菩薩應化〔行131-165〕。中間穿插：今日恰逢觀音菩薩聖誕，故以此講經向觀音祝壽〔行133-135〕；阿彌陀佛聖誕定於農曆十一月十七日，因永明延壽禪師（《宗鏡錄》作者，淨土宗六祖）生日即此日，法師稱其為「阿彌陀佛再來人」（人為共識所立的紀念，非血肉之軀等同於佛）〔行135-148〕；杜順生日農曆四月初四，即文殊菩薩聖誕〔行156-158〕。

由宗密疏解華嚴《法界觀門》引出本講第一個核心法義：「色不即空，以即空故」〔行170-253〕。法師逐句拆解：色（色蘊）＝如來藏心所顯之影像，本無自體，故「空中無色」；但這虛幻之色能顯，故「以即空故」而非斷空；空有不二，性相一如〔行180-253〕。以此引出《心經》「照見五蘊皆空」全段〔行253-264〕，並引《楞嚴經》佛告阿難「見見之時見非是見」段，申論「無得疲怠妙菩提路」——真修行是行住坐臥不離本心，非強求形式功課〔行266-296〕。以《金剛經》「凡所有相皆是虛妄，若見諸相非相，則見如來」收束「從相見性」一節〔行296-317〕，並引《華嚴經》「三世一切佛，應觀法界性，一切唯心造」申明心有不變（真如）與隨緣（生滅）二種功德〔行316-322〕。

**中段**：法師簡短複習勝思惟菩薩前身（有智慧的鳥，不為會動之物所誘）之公案，帶出勝思惟三問結構——菩薩應離（過程）、菩薩應護持（過程）、如來現所覺了（性德本身）〔行326-360〕。正式誦讀本經原文：複習第一問「九離」（貪・瞋・愚癡・我取・疑惑・憍慢・懈怠・惛眠・愛著）〔行361-370〕，正答第二問——「非己所安不加於物」，即諸佛如來一切禁戒之總綱，舉例不殺生、不偷盜、不侵人妻室，並說明眾生皆求安樂、無有愛苦者，故菩薩求無上正等正覺亦是為令自他皆得樂〔行369-375〕。

法師以此展開全講篇幅最長的一節：藉《永嘉證道歌》「無價珍用無盡」「君不見絕學無為閒道人」申論眾生自性本具五智（法界體性智・大圓鏡智・平等性智・妙觀察智・成所作智）、五方佛（毘盧遮那・阿閦如來・寶生佛・阿彌陀如來・不空成就如來），以十字五股金剛杵為表法圖示；因自性有隨緣功德，眾生執著五蘊（色受想行識）為實有，五佛遂變五毒（癡・慢・貪・疑・瞋），五智變五識〔行398-666〕。法師以此申論淨土念佛之理——念「阿彌陀佛」是呼喚自己本具之性德能量，非向外求；準提咒「唵折隸主隸準提娑婆訶」亦同理，持咒持經皆是「頻率相應」〔行517-627〕；並舉「柔軟語利於做生意」等日常事例說明佛法不離世間法〔行630-641〕。

法師重讀「非己所安不加於物」，以儒家「己所不欲，勿施於人」（消極義）與「己所欲，施於人」（積極義，如聖經金律）合釋此句，帶出《華嚴經》「悲智雙運」——普賢代表悲，文殊代表智〔行672-722〕。

**後段**：法師引大乘《起信論》申論心性由來——本覺本有，一念不覺（極微細之波動）生三細相：業相（心之生起）、轉相／見相（能見之功能顯現）、境界相（所見之相顯現）；此三細本是自然現象，凡夫與菩薩尚且一致，差別在於「境界遇緣長六粗」——因執著境界相為實而生智相（分別愛與不愛），不斷分別成相續相（苦與樂），執取所欲成執取相，貼上標籤成計名字相，依標籤造身口業成業起相，終受生死輪迴之報成業繫苦相〔行725-902〕。法師以《維摩詰經》文殊問疾一節作為「計名字相」的活生生案例：維摩詰稱「我沒有病，是你們說我有病所以我才病」——眾生為健康／疾病貼上標籤，是六粗運作的實例；末以文殊問維摩詰死後靈魂何去，維摩詰答「回到我心的深處」收束，法師點明此即是「心淨則國土淨」〔行815-865〕。法師再以生相・住相・異相・滅相四種無明對應三細六粗，並對應《華嚴經》五十二位——破執取相・計名字相（異相）即入十信位、出三界了生死；破業起相・業繫苦相之根本（我執・法執）需入三賢位（十住・十行・十回向）；生相無明則留待成佛，並以「留惑潤生」解釋等覺菩薩（如觀音）為何仍故意示現一念不覺以倒駕慈航度眾〔行886-926〕。全講在「妄盡還源」的呼籲中作結，預告第五講講如來所覺（第三問）〔行926-930〕。

貫串全講的命題：**如來即理事不二、性相一如〔行117-129〕；自性本具五智五佛，眾生執取五蘊為實而五佛變五毒，五智變五識〔行546-570〕；菩薩所護持的禁戒，是「己所不欲勿施於人」與「己所欲施於人」合稱的一法〔行692-722〕；一念不覺生三細、境界遇緣長六粗，是眾生流轉生死最具體的地圖，而我執・法執正是六粗後半段（業起相・業繫苦相）的根源〔行886-910〕。**

## 3. 核心概念

| 名相 | 體佛法師釋義〔行〕 | 經教連結（已核） |
|---|---|---|
| **如來＝理事不二** | 如講理（自性、性），來講事（相、來去）；理事一如，性相不二，即是如來，梵文 tathāgata〔行117-129〕 | 本經 T0829 全篇以「如來」二字為主軸；《金剛經》T0235 彌勒偈頌「如來者，無所從來，亦無所去」（法師述義，本講未逐字誦，見校對） |
| **色不即空，以即空故** | 色（色蘊）＝如來藏心所顯之影像，本無自體，故「空中無色」；但此虛幻之色能顯，故非斷空，「以即空故」〔行180-236〕 | 《華嚴法界觀門》T1883「三、色不即空。以即空故。何以故。以空中無色故不即空，會色無體故是即空」✓（見 §9） |
| **會色歸空空中無色，色是假色** | 空中出來顯示的色是虛幻色、假色，此虛幻不實之影像即是「蘊」（隱藏之意）〔行215-236〕 | 承上，宗密《注華嚴法界觀門》T1884 疏解義 |
| **法字皆講內在** | 「經典裡面只要出現了法，全部都講內在」——現在講的「色」是色蘊，不是外面的東西，但外面的東西也是你的色蘊；有沒有開悟就看有沒有這個觀點〔行182-196〕 | 法師教學用語，非逐字引經 |
| **心外求法謂之外道** | 即便出家、受戒（三皈五戒甚至菩薩戒），若心外求法（如籍宗教之名求身體健康），全都是外道；世間法有沒有道理是另一回事，但先要入本心才能做〔行186-192〕 | 六祖「學法無益，不入本心」義（法師引申，見校對）；「心外求法，謂之外道」為法師常用口訣 |
| **無得疲怠妙菩提路** | 行住坐臥四威儀之中，「觀」的對象永遠與你同在，此法門不會疲怠——日常生活即是修行，修行即是日常生活，不必等待特定形式的功課〔行284-296〕 | 《楞嚴經》T0945「汝等聲聞狹劣無識，不能通達清淨實相。吾今誨汝，當善思惟，無得疲怠妙菩提路」✓（見 §9） |
| **真空妙有** | 如來本不動故名真空；相上顯現來去故名妙有；真空是體，妙有是從相裡看見的性，二者不離〔行296-317〕 | 《金剛經》T0235「凡所有相，皆是虛妄；若見諸相非相，則見如來」✓（見 §9） |
| **阿閦如來＝真不動；阿彌陀如來＝隨緣入不變** | 真心不變的那一面即是阿閦（不動）如來；隨緣的功德使眾生從隨緣裡回歸不變的本心，此歷程即是阿彌陀佛〔行310-314〕 | 承第三講之五方五佛圖，本講首度將阿閦／阿彌陀二佛之「不動」與「隨緣入不變」對比講解 |
| **十字五股金剛杵＝五智五佛表法** | 十字代表身口意（法師比對基督教十字架、唐密傳承）；五股代表五智：中央法界體性智（第九識）、東方大圓鏡智（第八識，阿閦如來）、南方平等性智（第七識，寶生佛）、西方妙觀察智（第六識，阿彌陀如來）、北方成所作智（前五識，不空成就如來）〔行480-516〕 | 承第二・三講「五方五佛／四智」圖之延伸，本講加入第九識法界體性智與五股金剛杵之具體表法 |
| **五蘊即五毒／五智即五佛** | 自性本具五智五佛、圓滿無瑕；因隨緣功德，眾生不知蘊是虛幻影像而執以為實：色蘊→愚癡，受蘊→憍慢，想蘊→貪，行蘊→疑，識蘊→瞋；五佛因此變成五毒〔行544-664〕 | 《永嘉證道歌》T2014「無明實性即佛性，幻化空身即法身」「五陰浮雲空去來，三毒水泡虛出沒」✓（見 §9） |

| **十法界唯心頻率** | 念頭本身即是波動：念貪即與貪相應之境界（餓鬼道）相應，六趣是自己「取」去的，非佛不慈悲不救〔行530-537〕 | 法師教學用語，非逐字引經；通於《華嚴經》「一切唯心造」義（見 §9） |
| **非己所安不加於物（雙義）** | 消極義：己所不欲，勿施於人（自己不要的，不加在別人身上）；積極義：己所欲，施於人（自己要的最好的東西，如入本心了生死之法，也要給眾生）；兩者合稱才是菩薩所護持的禁戒〔行685-706〕 | 本經 T0829「謂諸菩薩非己所安不加於物」✓（見 §8）；儒家《論語》「己所不欲，勿施於人」為法師比對用語 |
| **悲智雙運（普賢悲・文殊智）** | 華嚴思想：悲者普賢也，度人不疲；智者文殊也，智慧不疲；毘盧遮那（本心）即是文殊與普賢共同成就〔行695-701〕 | 《華嚴經》義，法師綜述（本講未逐引原文，見校對） |
| **一念不覺生三細** | 本覺本有、本自清淨，但有一極微細之波動（法爾如是，不可問為何有），此不覺（非「沒有覺悟」，是「沒有感覺」的意思）產生三個同時出現的細相：業相（心之生起）、轉相／見相（能見功能顯現）、境界相（所見之相顯現）〔行725-768〕 | 大乘《起信論》T1666 義，法師綜述申論（本講以口述詳解，未逐字引原文，見校對） |
| **境界遇緣長六粗** | 執著境界相為實而生智相（分別愛不愛）→相續相（苦樂）→執取相（我執萌芽）→計名字相（貼標籤）→業起相（依標籤造業）→業繫苦相（承受輪迴果報），六階段一個比一個粗、一個比一個嚴重〔行768-886〕 | 大乘《起信論》義，法師綜述（本講以口述詳解，未逐字引原文，見校對） |
| **法執・我執在六粗中的位置** | 智相・相續相＝住相無明，尚屬對「法」（境界相）之執，稱為法執；執取相・計名字相＝異相無明，已進入對「我」之執，稱為我執；業起相・業繫苦相＝滅相無明，是造業受報的結果〔行886-910〕 | 《金剛經》T0235「一切法無我，得成於忍」✓（見 §9）；唯識學義（法師綜述） |
| **留惑潤生** | 生相無明（一念不覺生三細）本身，成佛之前不必急於除去，因菩薩度眾生正需要「一念不覺」示現生滅相；佛成道後雖已清楚照見業相・轉相・境界相，但示現菩薩身時故意再現一念不覺以倒駕慈航〔行914-921〕 | 法師教學用語，通於《觀世音菩薩普門品》倒駕慈航義（本講未逐引原文） |
| **計名字相的活案例——「我沒有病」** | 疾病與健康只是眾生依「活得快活、活得長」貼的標籤（計名字相）；維摩詰稱病是因為「你們都說我有病」，非他自己執以為病〔行841-864〕 | 《維摩詰經》義，法師述義（見 §4） |

## 4. 故事・公案・因緣

**（1）《維摩詰經》文殊問疾——「我沒有病，是你們說我有病」**〔行815-865〕

法師舉佛陀時代同時有兩尊佛：一位在家（維摩詰居士），一位出家（釋迦牟尼佛）。維摩詰是中印度人，他生病了——法師特別強調「真的有這個人」——病得很嚴重。佛陀派遣弟子前往慰問，但佛陀的十大弟子與諸大菩薩竟無人敢去，因為過去都曾被維摩詰批判過，自認沒有資格慰問這位長者。最後只有一位有資格——文殊師利菩薩，祂是諸佛的老師。文殊前去時，十大弟子與諸菩薩都跟隨在後，像看戲一般。

維摩詰將侍者全數支開，自己獨坐（或躺臥）於一張床榻。法師提到唐朝詩人畫家王維，字「摩詰」，即取自維摩詰之名，曾畫維摩詰躺臥床榻的畫像，相傳原畫仍存於故宮。維摩詰所處的床榻之地，大小約三坪，稱為「方丈」——法師指出，自《維摩詰經》以後，「方丈」便成為出家住持所居之處的專稱，其巧妙處在於：三坪大的方丈，卻能容納無量無邊菩薩，這正是本經要教的道理。

文殊一到便問：「長者啊，維摩詰居士，你到底生什麼病？」維摩詰回答：「我沒有病。」眾人譁然——佛陀叫我們來問你的病，你卻說沒有病？維摩詰於是說明：眾生投胎為人，是由百萬種不同因緣（如同 DNA 組合）而成，因此才有男女、高矮、胖瘦、美醜之別；眾生把活得快活、無病無惱、長壽的稱為「健康」，把較早死亡、身體疼痛的稱為「疾病」——這都是眾生自己貼的標籤，是二元對立的分別。法師特別引自身經歷為例：「大家都說我得癌症所以我就說我得癌症，癌症是你們發明的，我叫做多發性骨髓瘤，也是醫生發明的；你們都說體佛很可憐，得到這種病也是你們認為的；得就得啊，對我而言，這是我的因緣所生法。」文殊聽完便已退三步向維摩詰頂禮，讚歎：「難怪，你是維摩詰，你是佛。」

文殊接著問：「你會不會痛？」維摩詰答：「當然會痛，可是我沒有病啊。」文殊再問：「你會不會死掉？」維摩詰答：「當然會，可是我沒有病啊——人不是都會死嗎？」文殊於是問（法師點出文殊其實是金粟如來）：「你死後，你的靈魂要去哪裡？」文殊先答自己的看法：「你的靈魂會飛到無量無邊遠處的宇宙的那一方。」維摩詰糾正：「文殊啊，你錯了。蜜蜂飛過，你看不到它的痕跡；鳥兒飛過，你看不到它的痕跡；花兒的香，你看不到香味去哪裡；糖含在嘴裡溶化後，你不知道糖去哪裡。我死後，我的靈魂不是飛到遠去的宇宙那一方，我的靈魂是回到我心的深處。」法師點明：這就是「心淨則國土淨」——我們死後要去的，是本心原有的五方五佛、本具的五智，那個心的深處。

**（2）勝思惟菩薩前身——有智慧的鳥（複習，詳見第二講）**〔行326-336〕

法師簡要複習：勝思惟菩薩無量劫前是一隻有智慧的鳥，知道能動的東西（波旬所設偽裝成樹叢移動誘捕的陷阱）都不是牠要的，只有不動的東西才是安心之處；今日眾生正如那些被引誘、落入生死輪迴之網的鳥。祂依止不動，那不動的東西便是如來，也就是我們這顆心。（完整情節見〔賢首禪苑/大乘離文字普光明藏經/02〕）

## 10. 法脈會通

**（一）「如來」二字貫穿本經與《金剛經》**：法師以《金剛經》「如來」一詞出現約 88 次為引子，指出本經（T0829）全篇也不過圍繞「如來」二字——勝思惟三問中，前二問問「相／事」（菩薩應離・應護持），第三問才問「理／如」（如來現所覺了）。本講止步於第二問，正是全經「先事後理」結構的一半〔行113-129，336-360〕。

**（二）華嚴五祖傳承與《法界觀門》一脈相承**：本講引入杜順《法界觀》「色不即空，以即空故」及宗密《注華嚴法界觀門》之疏，與法師慣常援引的《妄盡還源觀》（三祖賢首）、《圓覺經》（五祖宗密疏本）同出一脈——五祖皆被法師視為文殊菩薩應化身，構成一條「華嚴智慧的傳承鏈」，貫串第一至第四講對「法性」「法界」「如來藏」的反覆申論〔行131-165，166-253〕。

**（三）五方五佛圖的第三次深化**：第二講首建「五方五佛／四智」圖，第三講延伸至觀音（蓮花部＋般若部），本講第三度深化——加入第九識法界體性智、十字五股金剛杵之具體表法，並首度講解「五佛因隨緣執著而變五毒」的完整對應鏈（色蘊→愚癡，受蘊→憍慢，想蘊→貪，行蘊→疑，識蘊→瞋）。三講疊加構成一條完整的「五方五佛」修學地圖〔行480-666〕。

**（四）大乘《起信論》「一念不覺生三細，境界遇緣長六粗」與十二因緣「齊識而還」相通**：第三講「齊識而還，不能越彼」講十二因緣還滅門止於「識」，本講進一步展開這個「識」如何從清淨一路墮入生死——一念不覺生三細，正是「識」最初的微細波動；境界遇緣長六粗，正是「識」如何一路挾帶我執法執、造業受報的完整機制。兩講合看，正是同一件事的兩種講法：十二因緣是「果報鏈」，起信論三細六粗是「心理機制」〔行725-902；承第三講〕。

```
一念不覺（極微細波動，法爾如是）
      │
      ├─ 業相（心生起）
      ├─ 轉相／見相（能見功能）
      └─ 境界相（所見之相）   ── 三細，本是自然現象，菩薩凡夫一致
              │
       境界遇緣（碰到條件）
              │
              ▼
      智相（分別愛與不愛）── 住相無明・法執
              │
      相續相（苦與樂）── 住相無明・法執
              │
      執取相（我執萌芽）── 異相無明・我執
              │
      計名字相（貼標籤）── 異相無明・我執
              │
      業起相（依標籤造業）── 滅相無明
              │
      業繫苦相（承受輪迴果報）── 滅相無明
```
**連結要點**：破執取相・計名字相（異相無明・我執）＝入十信位，出三界了生死；破智相・相續相（住相無明・法執）＝入三賢位（十住・十行・十回向）；生相無明（一念不覺生三細本身）則留待成佛，或菩薩「留惑潤生」以倒駕慈航度眾〔行886-926〕。

**（五）《維摩詰經》作為「計名字相」的活教材**：本講後段抽象講完「境界遇緣長六粗」理論後，立刻以《維摩詰經》文殊問疾的具體故事作印證——「我沒有病，是你們說我有病所以我才病」正是「計名字相」（把健康／疾病貼上標籤）的示範案例。理論與故事在同一講內互相印證，是本講結構上的特色〔行768-810，815-865〕。

## 11. 日常實踐

- **修行不必等待特定形式**：行住坐臥四威儀之中，觀照的對象（本心）永遠與你同在，不必因工作忙碌而覺得自己沒有用功——「無得疲怠妙菩提路」〔行284-296〕。
- **不因宗教之名心外求法**：持咒、念佛、誦經若只為了求身體健康、求財、求壽，即便受了三皈五戒甚至菩薩戒，仍是「心外求法，謂之外道」；要先入本心，才能真正利益眾生〔行186-192〕。
- **貼標籤前先停一下**：健康／疾病、美／醜、好／壞常只是眾生依習慣貼的標籤（計名字相）；覺察自己正在貼標籤，是阻斷「執取相→計名字相→業起相→業繫苦相」這條輪迴鏈的第一步〔行799-810，841-864〕。
- **己所不欲勿施於人，己所欲施於人**：面對日常人際，消極義是不把自己不要的加諸別人；積極義是把自己認為最好、最珍貴的東西（不只是物質，更是使人安心的道理）分享給別人〔行685-706〕。
- **念佛持咒先明其義，且知是呼喚自己**：念「阿彌陀佛」聖號或持準提咒，是在呼喚自己本具的性德能量，不是向外求救；平時心穩定、不易貪瞋癡，身體自然健康，待人接物自然柔軟，這些都是自然效應，不是刻意求來的〔行517-536，627-639〕。
- **檢驗修行是否有效的簡單標準**：聽經聞法之後，問自己脾氣有沒有減緩、執著有沒有變少、煩惱有沒有變少；若沒有，法師建議坦然換一個適合自己的法門，因為佛度眾生本來就示現種種不同的法〔行641-643〕。

## 12. 延伸・參

- **上承**：〔賢首禪苑/大乘離文字普光明藏經/01〕〔賢首禪苑/大乘離文字普光明藏經/02〕〔賢首禪苑/大乘離文字普光明藏經/03〕——經題「大乘離文字普光明藏」之體相用骨架、五方五佛／四智圖之首建與觀音延伸、序分兩波當機眾、正宗分第一問「九離」之完整解答。
- **下承**：第五講將答勝思惟三問之第三問——「何者一法，是諸如來現所覺了」。本經 T0829 原文已見於本講校對（CBETA 第 49 行）：「善男子！如汝所問：『何者一法，是諸如來現所覺了？』善男子！無有少法是如來覺⋯一切法性普光明藏是如來覺⋯」——此段第二講已先行部分引用（普光明藏＝法性），第五講當有更完整之逐句解義。
- **參問**：本講揭示「非己所安不加於物」有消極（不害）與積極（給予）雙義，而全講後半段又用大篇幅講「境界遇緣長六粗」如何使人墮入生死輪迴。這兩件事是否其實是同一件事的一體兩面——菩薩之所以能「己所欲施於人」，正是因為看透了眾生皆困於同一套「智相→相續相→執取相→計名字相→業起相→業繫苦相」的機制、而生起同體大悲？下次讀經時，可留意第五講「如來現所覺了」的答案，是否正是解開這整條六粗鏈的鑰匙。
