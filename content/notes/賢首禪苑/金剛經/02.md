## 1. 本講概要

本講是《金剛經》第二講。前半承第一講，把「金剛般若波羅蜜」六種譯本的經題再做一次總結，並引六祖惠能「佛性雖堅，煩惱可亂；煩惱雖堅，般若智可破」一語，點出全經宗旨〔行73／77〕。後半正式進入經文「法會因由分第一」：從「如是我聞」到「敷座而坐」，再到須菩提從座而起、啟問「應云何住？云何降伏其心？」〔行88-106〕。

體佛法師的講法有一條清楚的**through-line（貫串線）**：**《金剛經》的最高義只有一個——「回歸本心」**〔行225〕。他用三條主軸把整堂課串起來：

1. **經題義理**——般若如金剛能斷「如金剛般堅固之煩惱」，得以波羅蜜（到彼岸）〔行60-64〕。
2. **經首四問**——以《阿含》記載佛涅槃前阿難所問四事（四念處為住／以戒為師／默擯惡比丘／經首安「如是我聞」）貫穿全講，並一一會通到《金剛經》〔行108-126〕。
3. **日常即修行**——佛在《金剛經》開頭示現的「著衣持鉢、次第乞食、飯食訖、洗足、敷座」正是六度波羅蜜的日用；須菩提正是從這日常生活中看出佛在行菩薩道而啟問〔行519-521〕。最後以《華嚴經·淨行品》的日用觀照作結〔行543-573〕。

貫穿全講的核心口訣：**「佛性雖堅，煩惱可亂；煩惱雖堅，般若智可破。」**〔行73-77〕

## 4. 故事・公案

### 4-1 阿難問四事——「如是我聞」的由來〔行108-126〕
佛陀將示現涅槃時，堂弟阿難尊者痛哭流涕、失去依怙、不知所措。此時阿那律尊者（體佛法師稱「無貧尊者」，「貧窮的貧」，即阿[少/兔]樓馱，義譯無貧／如意）勸他：「阿難，現在不是你傷心的時候。你是佛陀的侍者，跟佛陀最親近，趕快回去問佛陀以後如何交代。」阿難隨即回去問佛：「聖者你即將入涅槃，我們孤苦無依的眾生盼你拯救，你入涅槃後的後事要怎麼交代？」佛陀由此開金口，交代**四事**：
1. **依四念處住**——後世眾生以四念處為住〔行114〕；
2. **以戒為師**——頓失老師後，以戒為師〔行116〕；
3. **默擯惡比丘**——對時常與佛作對、危害僧團規矩的惡比丘，「擯而棄之」〔行118-120〕；
4. **經首安「如是我聞」**——經典結集時，經首一定要冠「如是我聞」，並記明一時（時）、何地、與何人集會〔行120-126〕。
> 體佛法師將此故事定為全講骨架，四事一一會通《金剛經》。他繫此故事於「雜阿含」〔行108〕——按：阿難問四事之記載通見於《長阿含·遊行經》與《大般涅槃經（後分）》，非專屬《雜阿含》，此為繫屬之寬泛（詳§校對）。

### 4-2 波斯匿王恆河觀性——身死佛性不滅〔行371-387〕
憍薩羅國波斯匿王與佛陀同年，是佛的好友，常有疑即問佛。一次召開內閣大會議國事時，忽覺自己已六十歲（印度當時算高壽），對「死」生大畏懼。他去問佛：「我六十歲了，對死有點畏懼，請佛開示。」佛問他：「印度的恆河看過沒有？」「三歲、二十歲、如今都看過。」佛點出：不論幾歲來看，恆河還是恆河，能看的「見性」不因年歲而變；你看到的、記憶中的恆河，其實都是心所現的幻影（「法是塵，心是根，兩者猶如鏡上痕」）。所以身體會生滅、會死，但你的佛性不滅、是無量壽的。波斯匿王有善根，回去便告訴群臣：「佛陀為我開示，我不會死，佛性不死、永恆。」〔行371-387〕
> 體佛法師指此段最精彩者在《楞嚴經》波斯匿王與佛的對話 ✓ CBETA T0945。

### 4-3 給孤獨長者黃金鋪地買祇陀園〔行390-400〕
給孤獨長者名須達，極富有。正為女兒辦婚事、備了許多嫁妝時，聽人說有一位世尊在講宇宙真相，便去聽法，**當下證得須陀洹果**（未曾修行，聞見地即證果）〔行390-392〕。須達深感佛恩，決意為佛覓一宣法之地。他看中一塊最適合的地，卻是祇陀太子所有。太子奇怪：「我身為太子，還有誰敢向我買地？」須達說明是要供養佛陀，好讓佛講無數文字般若、令眾生觀照回歸實相般若。太子存心考驗：「若你有誠意，就用黃金鋪地，鋪到的地方我才賣。」須達真的照做——為法竟能如此。地鋪完，太子感動願賣，卻說：「你只鋪了地，沒鋪到樹，樹是我種的。」於是**土地是給孤獨長者供養、樹是祇陀太子供養**，此地遂名「祇樹給孤獨園」；《阿彌陀經》《金剛經》皆在此講〔行396-400〕。

### 4-4 琉璃王篡位·祇陀太子神識歸天〔行402-415〕
波斯匿王有二子：長子祇陀太子、次子琉璃王。琉璃王趁波斯匿王去拜訪佛陀時，受人煽動起篡位之心，派兵追殺波斯匿王。波斯匿王雖已到佛的場所，琉璃王不理，波斯匿王只好流亡，最後（多說）飢餓而死。琉璃王回城對兄長說「你沒資格繼承王位」，一劍將祇陀太子刺死；太子被殺那一剎那**穩如自若、毫不抵抗**〔行407〕。此事傳到僧團，有比丘問佛：「波斯匿王深信您法卻這樣死去，祇陀太子供樹讓我們得以講經，竟被弟弟一劍刺死，怎麼會這樣？」佛答：世間一切是因緣所生法，生命長短只是因緣週期所現的幻相；而祇陀太子死那天梵天、帝釋天震動，其靈性已回歸天界享梵福，並現黃金異相於空中讚歎佛陀〔行409-415〕。
> 體佛法師藉此警示：學佛不可因見人供養而得負面果報便起退心、乃至毀謗；兩千多年後我們仍懷念祇陀太子，可見其功德之大〔行413-415〕。

### 4-5 羅睺羅受辱——「不接受則還其人」〔行505-509〕
佛陀時代外道充斥，僧團時常被人侮辱、屈打。佛子羅睺羅出去托缽，有人用石頭丟他、辱罵他，回來便問佛：「有人罵我們、打我們，怎麼辦？」佛答：「羅睺羅，若有人送你東西而你不接受，那東西會怎樣？」羅睺羅：「就還給對方。」佛：「同樣，人家辱你、侮辱你，當你心如如不動、不接受、不理會，他的因果由他自負。」羅睺羅依此亦得開悟〔行505-509〕。

### 4-6 《楞伽經》羅婆那大王——神變多楞伽山〔行341-351〕
《楞伽經》開頭，佛以神通力示現一座楞伽山為無量楞伽山，每一楞伽山各有一佛、一首座（當機）菩薩受化，各成佛國、珠寶莊嚴。楞伽處的羅婆那大王（實為菩薩示現）問佛：「本來只有一座山、只有您與大慧菩薩是當機者，現在怎麼變出這麼多山、這麼多佛與大慧？難道是幻化嗎？」佛微笑：「善哉善哉，這是我以神通力所現的幻化。」語畢，所有楞伽山盡皆消失；羅婆那大王頂禮後，佛在說「如是」的當下，眾楞伽山與佛、菩薩之景象又一一重現〔行341-347〕。
> 體佛法師點出深意：一楞伽山變多楞伽山、一大慧變多大慧，佛是在暗示——**願來聽聞經典的當下，每一個人都是當機者**〔行349-351〕。

### 4-7 《壇經》楞伽變相圖公案——五祖改宗《金剛經》〔行327-332〕
《六祖壇經》載：五祖弘忍本要請一位學佛的畫家盧珍在牆壁上畫「楞伽變相圖」。後五祖說「現在不用畫了」，改令門人各寫偈語傳法，偈語寫得最好者即為傳人。結果只寫了兩偈，以惠能「**本來無一物，何處惹塵埃**」（此即《金剛經》之法要）勝出，成為六祖〔行327-331〕。
> 體佛法師解此安排之義：本欲畫楞伽，卻換成惠能所依的《金剛經》——經典的含義不必盡是史實，其更深遠的含義才是重點；由此可見《楞伽經》與《金剛經》義理大重疊，同為禪宗要典〔行331-333〕。

### 8-B 義理深入

**（一）「還至本處」＝回歸本心，是整段日用的樞紐。** 體佛法師強調：佛在《金剛經》開頭示現的並非神通放光的場面，而是「著衣持鉢、次第乞食、飯食訖、洗足、敷座」這樣**完全人性化的日常生活**〔行435-437〕。這一天的比丘生活幾乎佔盡大半時間，剩下才是敷座與說法〔行443-447〕；而佛日中一食，是因古印度潮濕炎熱、無冰箱，食物易變質，且交通全靠步行、往返城中需兩三小時，一天兩托缽會累死——是重視個人衛生與健康的人性化安排〔行450-464〕。深意在於：這一切日用，逐句正對六波羅蜜；而其樞紐是「還至本處」——**「本處」即本心**〔行511〕。佛雖隨緣過生活、且帶頭在做，但內心微笑、不受所做干擾，因已回歸本心，此即般若波羅蜜、此即金剛〔行539-541〕。

**（二）須菩提何以獨能啟問？** 佛講法四十九年、《金剛經》約在第三十幾年講〔行519〕，隨行弟子多以聲聞乘為主；唯獨須菩提以聲聞身份看出佛在**行六度波羅蜜（菩薩大乘法）**於日常生活中，因而慧眼識機、代眾啟問〔行519-541〕。故「應云何住？云何降伏其心？」不是抽象問題，而是從「佛怎麼過日子」生出的活問題。

**（三）般若為眼，五度為盲。** 布施、持戒、忍辱、精進、禪定五度若無般若導引，即如盲者；般若一帶，五度即放光〔行531〕。而「般若」的定義就是**無所住**——「無所住叫做般若，無住」〔行533〕。全經主文即「應無所住而生其心」；有住則不名般若，縱背千經萬典亦然；無所住、無對象可住的當下，就是本心〔行533-535〕。

**（四）隨緣須有「不變」在支撐。** 本心如鏡，衣鉢、乞食、次第、洗足、敷座種種，皆是本心所現幻影，天天存在、無所不在，面對當下叫「隨緣」；但隨緣須知有一「不變」在支撐，若不識那「不變」，隨緣就淪為「隨便」，製造因果、再入輪迴〔行535-539〕。這正呼應「如是我聞」之「如＝不變」（§7）。

## 10. 法脈會通

### 10-1 一語貫全經：六祖口訣的結構

```
              佛性  ──雖堅（永恆·不可破）──  唯「可亂」
                │                              │ 被亂 → 輪迴
              煩惱  ──雖堅（如金剛）────────  唯般若智「可破」
                                               │ 破亂 → 波羅蜜
   金剛般若波羅蜜  =  以「般若（金剛）」斷「如金剛之煩惱」，到彼岸（回歸本心）
```
- **連結要點**：六祖此語同時對應《金剛經》六譯的兩種取譬——前三譯以金剛喻「般若之體相」，後三譯以金剛喻「煩惱之堅固」；六祖一句話兼容二義：般若堅、煩惱亦堅，唯般若能破煩惱〔行60-77〕。

### 10-2 佛日用 × 六度 × 華嚴淨行品（三重對照）

體佛法師用《金剛經》開頭的佛日用，配上六度，再引《華嚴經·淨行品》的「當願眾生」觀照法，三者對讀：

| 金剛經佛日用〔行〕 | 六度 | 淨行品「當願眾生」偈（✓CBETA T0279 全偈） | 師述變異 |
|---|---|---|---|
| 著衣持鉢 | 持戒 | 「著袈裟衣，當願眾生：心無所染，具大仙道。」 | 師作「具大仙道，心無所染」（次序互換）；釋「大仙」＝佛道〔行551〕 |
| 入舍衛大城乞食 | 布施 | 「入里乞食，當願眾生：入深法界，心無障礙。」 | 相符〔行555-557〕 |
| 次第乞·見不捨人 | 忍辱 | 「見不捨人，當願眾生：常不捨離，勝功德法。」 | 相符〔行561-563〕 |
| 次第乞·見能捨人 | 忍辱 | 「見能捨人，當願眾生：永得捨離，三惡道苦。」 | 師作「常當捨離三惡道苦」〔行563-567〕 |
| 托空鉢 | — | 「若見空鉢，當願眾生：其心清淨，空無煩惱。」 | 相符〔行567〕 |
| 鉢滿 | — | 「若見滿鉢，當願眾生：具足成滿，一切善法。」 | 師作「具足充滿一切善法」〔行567-569〕 |
| 洗足已 | 精進 | 「若洗足時，當願眾生：具神足力，所行無礙。」 | 師作「得神足力，所行無礙」〔行571〕 |
| 敷座而坐 | 禪定 | 「正身端坐，當願眾生：坐菩提座，心無所著。」 | 相符；釋「菩提座」＝本心〔行573〕 |
| 還至本處（回家） | 般若 | （師述「回歸本心，究竟圓滿」——**淨行品無此偈**，為師之總結歸納） | 師述〔行569〕 |

- **連結要點**：佛在《金剛經》所現的日用，是「無時無刻在觀照本心、觀照般若智慧」；《華嚴·淨行品》則把同一觀照法門，落實為在家日用中「碰到什麼狀況就做這樣的觀照」〔行573-575〕。

### 10-3 「法」的義理鏈——一條等式

```
心（根）起用 → 六根 → 接觸 → 六塵 = 法（法塵）= 鏡中影像
   │
   └─ 影像：有 / 但捉摸不住、主宰不了  →  觀「法無我」（我＝主宰）
                                          →  「無所」（無對象可住）
                                          →  應無所住而生其心（六祖大悟句）
```
- **連結要點**：永嘉《證道歌》「心是根，法是塵，兩者猶如鏡上痕」＋《壇經》「自性能含萬法，名含藏識」＝說明「法」皆自心所現影像；由此直通《金剛經》「應無所住而生其心」〔行164-197〕。

### 10-4 《楞伽經》五法·三自性·八識·二無我 → 皆從本心

| 楞伽四門 | 內容 | 體佛法師之會通〔行〕 |
|---|---|---|
| 五法 | 相·名·妄想·正智·如如 | 皆從本心／自性而現〔行308-319〕 |
| 三自性 | 圓成實·依他起·遍計所執 | 皆從性（心）出，故「性相一如」〔行311-319〕 |
| 八識 | 眼耳鼻舌身意＋末那（我執）＋阿賴耶 | 本只四智（大圓鏡·平等性·妙觀察·成所作），凡夫迷故轉成八識〔行314-321〕 |
| 二無我 | 人無我·法無我 | 本來無我，是性之功能〔行321-323〕 |

- **連結要點**：《楞伽經》是「講真心本性的經」，故達摩以之傳宗（傳慧可→僧璨→道信）；至五祖弘忍改以《金剛經》教化，六祖依《金剛經》大悟——可見《楞伽》《金剛》義理重疊，同為禪門要典〔行323-333〕。

## 11. 日常實踐

1. **以四念處為「觀」而非「修」**：時時體悟身本不淨、受本是苦（樂亦是苦，因會干擾你要保持它）、心本無常（如瀑流）、法本無我（掌握不了的影像），不去執著、不去主宰〔行130-157〕。
2. **般若為眼，帶著五度過日子**：上班穿制服＝著衣持戒，工作攬客／做業務＝乞食布施，天天不間斷＝精進，受氣（父母被小孩氣、夫妻相氣）＝修忍辱，休息睡覺＝禪定；關鍵在「有沒有回歸本處（本心）、有沒有波羅蜜（無所住）」〔行523-533〕。
3. **受辱時「不接受」**：如羅睺羅公案——人辱你、罵你，心如如不動、不接受、不理會，辱歸其人、因果自負；懷報仇心則因果不斷〔行489／507-509〕。
4. **乞食悉檀（布施雙向）**：受供時令施主種福、受罵時替己消業障，善惡兩面都對你有好處——關鍵在你的心，莫懷報仇〔行483-489〕。
5. **妄動即懺悔回歸**：本心一被妄心攪動即是「犯戒」，趕快懺悔——懺「自心本不動」，懺悔回歸本心的當下，亂心即破〔行215-225〕。
6. **忍到「無生法忍」**：忍無可忍不是忍不住，而是「沒有忍可忍」；把世間一切當作沒有（因它是影像）是最好的解決法，但事上仍須具體去處理，心則無生〔行581-585〕。
7. **諦聽即反聞**：聽經時放下「我」的批判分別、回歸無我，文字般若一入即可回歸自性——此即「反聞聞自性」，人人當下皆當機眾〔行357-361〕。

## 12. 延伸・參

- **與第一講之銜接**：本講開頭把第一講的六譯經題再作總結；建議與第一講對讀（經題「金剛般若波羅蜜」vs「能斷金剛般若波羅蜜」）。
- **相關經教**：欲深究「法皆自心所現」，可讀《楞伽經》T0670 五法三自性；欲深究「日用觀照」，讀《華嚴·淨行品》T0279；欲深究「離三相」，讀《大乘起信論》T1666 心真如門。
- **一參問**：佛在《金剛經》開頭所現的，只是「著衣持鉢、乞食、洗足、敷座」這樣的日常——若這日常本身即是六度、即是般若，那麼「應云何住？云何降伏其心？」的答案，是否早已寫在佛「還至本處」的那一步裡？
