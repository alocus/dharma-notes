## 1. 本講概要

本講是《金剛經》第20講，全講落在**世親菩薩科判的第十分「斷疑分」**之中。斷疑分共分十六段，破的是修行人進入聖流後、微細見地上仍殘存的十六種疑。〔行62〕體佛法師先總說：《金剛經》**前半破相（破四相）、後半破見（破四見）**；破四相已入聖流，但要圓滿佛性必須連四見也去除。〔行64〕

本講內容主軸有二：

1. **複習第七～第十疑**（第19講已講，為求「綿密不斷、全經通徹」再串一次）〔行66〕〔行273〕：
   - 第七疑「無法可說是名說法」（寂照不二）〔行66-83〕
   - 第八疑「眾生／即非眾生」（不變隨緣、心佛眾生三無差別）〔行85-162〕
   - 第九疑「無有一法，法無高下」（自性平等）〔行162-221〕
   - 第十疑「較量功德」（引出唯識學**三量**）〔行227-271〕
2. **正講第十一、十二疑**（今日新內容）：
   - 第十一疑「度眾生／凡夫」疑——「實無有眾生如來度者」「如來說有我者，則非有我」「凡夫者，如來說則非凡夫」〔行276-443〕
   - 第十二疑「以三十二相**觀**如來」——關鍵在「見」與「觀」之別，收於「若以色見我」偈，並補入鳩摩羅什未譯、由真諦／玄奘所續的「應觀佛法性」偈，斷疑分至此圓滿收束。〔行445-890〕

貫串全講的骨架是唯識學**三量（現量→比量→無量）**：佛從無量（本住法／自身內證法）隨緣現出文字般若（現量），修行人透過觀照（比量）回歸自性本來圓滿的無量。〔行229-265〕本講並大幅切入淨土法門，以「自性彌陀、唯心淨土」貫通《金剛經》與淨土三經。〔行148-162〕〔行717-815〕

## 2. 大綱

- **一、開場與總綱**〔行62-65〕：第20講；世親十六疑；前破相後破見，破四相入聖流、破四見圓佛性。
- **二、第七疑複習：無法可說是名說法**〔行66-84〕
  - 佛說49年卻「說而無說」；聞者「聞而未聞」〔行71-73〕
  - 天帝散花讚須菩提「善說般若」，須菩提「無說」、天帝「未聞」＝真般若〔行73-75〕
  - 寂照不二＝本心；鏡子譬喻（本無相、遇緣顯像）〔行77-83〕
  - 馬鳴「離文字相、離言說相、離心緣相」〔行83-85〕
- **三、第八疑：眾生／即非眾生**〔行85-162〕
  - 眾生＝眾緣和合而生（H₂O／H₂O₂ 皆眾生）〔行87-91〕
  - 覺性本具；**不變（空）＋隨緣**兩功德；心佛眾生三無差別〔行93-111〕
  - 二乘悟不變不悟隨緣，故不度眾生〔行113-115〕
  - 慧命須菩提章經文；成佛在剎那，習性使然〔行124-134〕
  - 《圓覺經》成佛三條件＋三法（奢摩他／三摩缽提／禪那）〔行136-143〕
  - 自性彌陀、唯心淨土；淨土五經；阿彌陀佛從相見性；心淨則國土淨〔行148-162〕
- **四、第九疑：無有一法，法無高下**〔行162-221〕
  - 無所得、法無高下、自性平等（相不平等，性平等）〔行164-215〕
  - 三字經「人之初，性本善」＝見性語；六祖「何其自性」〔行168-170〕
  - 法＝心所現幻影；「心是根，法是塵，兩者猶如鏡上痕」〔行174-176〕
  - 水中捉月、鏡中取影＝凡夫；知幻即離、不即不離〔行180-186〕
  - 幻相所苦；正法vs迷幻藥（希特勒例）；理先知、事才行〔行188-200〕
  - 器器皆金、以金作器＝真平等〔行217-219〕
- **五、第十疑：較量功德，引三量**〔行221-271〕
  - 斷疑分破微細比量之見；現量／比量〔行221-225〕
  - 唯識三量：現量（文字）／比量（觀照）／無量（空性自性）〔行229-265〕
  - 《楞伽經》大慧108問、本住法；佛珠108〔行239-240〕
  - 真空妙有；穢跡金剛一腳踏地（不變）一腳騰空（隨緣）〔行243-245〕
  - 本住法＋自身內證法→文字般若（現量）→觀照（比量）→無量功德〔行247-265〕
  - 無量功德能生西方極樂淨土，非七寶可較量〔行267-271〕
- **六、第十一疑：度眾生疑、凡夫疑**〔行276-444〕
  - 經文「汝等勿謂如來作是念：我當度眾生」〔行279-294〕
  - 眾生是自心大圓鏡智所現影像（杯子、琵琶湖、富士山例）〔行336-366〕
  - 「實無有眾生如來度者」；如來＝自性；有能度所度即落四相〔行369-382〕
  - 佛諄諄教誨如慈母；誹謗佛、斷人慧命墮地獄〔行384-398〕
  - 「如來說有我者，則非有我」；《涅槃經》常樂我淨四德〔行399-405〕
  - 常＝不常不斷（八不）；《中論》龍樹八不中道；《心經》不生不滅不垢不淨〔行406-431〕
  - 凡夫者即非凡夫；設名破名〔行433-444〕
- **七、第十二疑：以三十二相「觀」如來（見vs觀）**〔行445-890〕
  - 經文「可以三十二相觀如來不」；與前文「具足色身見」對照〔行447-495〕
  - 前講「見」＝現量，今講「觀」＝比量；如來＝無量〔行495-511〕
  - 前半破現量（歌利王無我相），後半破比量（無我見）〔行511-517〕
  - 煩惱即菩提（《維摩經》《六祖壇經》）為比量思惟示範〔行518-529〕
  - 觀照＝比量；入海算沙徒自困（永嘉）〔行532-538〕
  - 須菩提本事：青龍佛因緣、空生善現、內祕菩薩行外現聲聞相〔行542-576〕
  - 須菩提「如是，如是」是活話：入本心則一切皆是，不入則一切皆非；諸法如義〔行581-640〕
  - 證道歌「是則龍女頓成佛，非則善星生陷墜」〔行611-619〕
  - 轉輪聖王亦具三十二相；三十二相＝非相之相＝自性功德（造像儀軌、劉備手過膝例）〔行648-685〕
  - 《觀無量壽佛經》諸佛如來是法界身、是心作佛是心是佛、十六觀〔行686-705〕
  - 淨土開示：一心繫念、印光念佛、楞嚴毫無疲怠、無量壽18願、六信、圓覺本起因地、五逆誹謗正法、準提三密相應〔行702-815〕
  - 「不應以三十二相觀如來」是活語；「若以色見我」偈〔行820-852〕
  - 補譯「應觀佛法性，即導師法身，法性非所識，故彼不能了」；導師＝佛；如來vs佛之別；華嚴「應觀法界性，一切唯心造」收束〔行854-890〕

## 3. 核心概念

| 概念 | 體佛法師釋義〔行〕 | 經教連結（核驗） |
|---|---|---|
| **斷疑分（第十分）** | 世親菩薩科判；分16段，破入聖流者微細之見（比量之疑），故留在最後〔行62〕〔行221-225〕 | 世親《金剛般若波羅蜜經論》科判（論疏，非根本經；本講屬師承科判） |
| **前破相・後破見** | 前半破四相已入聖流，後半破四見方圓佛性；「金剛」＝不動、本來清淨本心〔行64-65〕 | 呼應全經結構 |
| **寂照不二** | 佛說法是「照」（有法可說），照的當下本心不動是「寂」；如鏡本不動而遇緣顯像〔行77-83〕 | 鏡喻（師述譬喻） |
| **眾生／即非眾生** | 眾生＝眾緣和合而生；因具佛性隨緣而成眾生（「非不眾生」），從佛性看則「彼非眾生」〔行87-117〕 | ✓《金剛經》T0235「彼非眾生，非不眾生」〔行125〕 |
| **不變・隨緣（真空妙有）** | 覺性二功德：不變＝空＝本自清淨（不動）；隨緣＝空有不二、示現萬象；不變必隨緣，否則落斷滅相〔行99-111〕〔行243〕 | 呼應《起信論》體大/相大/用大之隨緣義（師承說法） |
| **心佛眾生三無差別** | 一切眾生皆具不變＋隨緣之覺性，故與佛無異，有成佛之機〔行105-107〕 | ✓語出《華嚴經》「心佛及眾生，是三無差別」（T0279 夜摩宮偈；師引） |
| **三量（現量／比量／無量）** | 唯識（法相宗）所立：現量＝感官可見（語言文字）；比量＝透過思惟觀照；無量＝空性、本自清淨圓覺自性。佛從無量現出現量，行人以比量回歸無量〔行229-265〕〔行500-508〕 | 唯識學名相（師承） |
| **本住法・自身內證法** | 佛49年所說皆從「本住法」（本來就有的空性，眾生皆具）與「自身內證法」流出，故聞法能感動、能開悟〔行247-261〕 | ✓概念出《楞伽經》T0670（師引大慧菩薩章） |
| **見・觀之別** | 「見」＝現量（明顯可見之相）；「觀」＝比量（透過思惟觀照）；本講第十二疑由「見」深入到「觀」，破更微細之比量見〔行495-511〕 | ✓《金剛經》前文用「見」（具足色身見），後文用「觀」（三十二相觀）〔行469-495〕 |
| **常樂我淨（涅槃四德）** | 自性圓滿之四功德；「常」非常斷之常，是不常不斷之「本常」；「我」非人我之我，是清淨法身之「本我」；「淨」非淨垢之淨，是不垢不淨之「本淨」〔行402-429〕 | ✓「常樂我淨」為涅槃四德，見《大般涅槃經》T0374（師引《涅槃經》，屬實） |
| **八不中道** | 常之為義乃「不常不斷」；推之不生不滅、不來不去、不一不異——龍樹於《中論》立八不，名中道論；「中」不得已而說，即「不是這個、也不是這個」〔行414-419〕 | ✓《中論》T1564「不生亦不滅，不常亦不斷，不一亦不異，不來亦不出」 |
| **三十二相＝非相之相** | 如來本無相而能現功德相；三十二相是自性功德所現，「三十二」是舉例（實為恆河沙功德），非真三十二；轉輪聖王亦具三十二相，故不可以相取如來〔行655-685〕 | ✓《金剛經》「若以三十二相觀如來者，轉輪聖王則是如來」〔行451〕 |
| **三身（法身／報身／應化身）** | 三十二相＝應化身，具足諸相＝報身，具足色身合稱身相；如來＝法身（無形相）；不可以報身、應化身見法身〔行488-495〕 | 三身義（師承說法，呼應《金剛經》具足色身／諸相段） |
| **自性彌陀・唯心淨土** | 阿彌陀＝無量光無量壽＝不變而能隨緣創造淨土；以自性彌陀之功德成就唯心淨土；淨土在心，離心無淨土〔行148-162〕〔行772〕 | ✓「心淨則國土淨」出《維摩詰經》（師引）；淨土五經（師述） |
| **六信** | 蕅益大師《彌陀要解》：信自、信他、信因、信果、信事、信理；重點在信自性彌陀〔行762-771〕 | 蕅益《彌陀要解》（師承；「往生與否在信願之有無」為要解語） |
| **如來 vs 佛** | 如來＝自性功德，眾生本具；佛＝已徹悟此本具功德者；故普賢言「禮敬諸佛、稱讚如來」〔行873-875〕 | ✓「應觀佛法性，即導師法身」——導師即佛（師依補譯偈釋） |

## 4. 故事・公案

### 4.1 天帝散花讚須菩提（第七疑複習）〔行73-75〕

上一講講到玉皇上帝（天帝）於須菩提善說般若時**天女散花**讚嘆。須菩提反問：「你為何讚嘆我？」天帝答：「因為你善說般若。」須菩提說：「我不說一法，未曾說任何一個字。」天帝說：「你未說，我亦未聞。」——**未說、未聞，是真般若也**。體佛法師以此點出「說而無說、聞而未聞」的般若正見。（屬佛典散花讚須菩提之公案，師轉述；細節依師講。）

### 4.2 須菩提的前世因緣——青龍佛與空生善現〔行551-576〕

體佛法師介紹「解空第一」的須菩提本事：須菩提本是古佛，號**青龍佛**（「一佛出世，千佛擁護」，問答者多是古佛再來）。〔行551〕在賢劫、釋迦（第四尊佛）之前，他曾為一名比丘，在山中修行時因**辱罵其他比丘**，因果不爽，墮為一條龍受苦。〔行554-557〕一日金翅鳥飛來，抓走並吞食一條大龍；當時的小龍（須菩提前身）內心畏懼，回想起昔日佛對他的教誨，**深自懺悔**、想回歸佛性。世相因果不能了，金翅鳥再來仍將牠叼走吞掉，牠也死去；但因靈識含著「回歸正法、懺悔瞋怒」的心願，來世投生於**婆羅門**（印度最高階級）富有之家。〔行558-567〕

出生後家忽然破產，故有法號**空生**；不久又恢復富有，故又號**善現**。〔行563-565〕因宿世深自懺悔之心種在第八意識，他跑到山中欲現聲聞相修行，遇一大善知識勸他下山：「有一位釋迦牟尼佛現世說法，可助你成佛。」須菩提下山求佛剃度，佛毫無拒絕（因知其來歷），並記其「必當成就」，後成**解空第一**。〔行567-570〕佛常於大眾中讚須菩提「內祕菩薩行，外現聲聞相」。〔行571-574〕

> 附：此「青龍佛／金翅鳥」前世故事屬傳統敘述，未見於《金剛經》根本經文；本筆記如實保留師之講述，並於校對標注「未見CBETA根本出處」。

### 4.3 地藏王菩薩「內祕菩薩行，外現聲聞相」〔行574-575〕

法師以地藏王菩薩為對照：地藏「誓不成佛，地獄不空」，示現聲聞相（光頭如比丘）而實為祕密之菩薩如來行——與須菩提同屬「內祕菩薩行、外現聲聞相」之大菩薩示現。

> ※ 師言「內秘菩薩行外現聲聞相」；根本經《妙法蓮華經》T0262（富樓那品）作「**內祕菩薩行，外現是聲聞**」。義同，字有出入。

### 4.4 提婆達多出佛身血〔行789-791〕

講「五逆」中的「出佛身血」時，法師舉提婆達多推石欲壓死佛；韋馱菩薩示現金剛杵，石頭蹦開時碎片傷及佛陀腳趾出血，提婆達多因此墮地獄。以此說明「出佛身血」實難為，但確有其事。（傳統佛傳事蹟，師轉述。）

### 4.5 一兆富豪與「幻相所苦」〔行188-192〕

法師以時事作喻：某位（台南府城出生、到台北造成旋風的）身價破一兆的名人，穿一件標誌性皮衣造成轟動；眾人欣賞，是因為「得不到」。法師反問：得到又如何？那件皮衣四千塊，你買二萬、十萬穿著又如何？人死後一兆也帶不走。**一切都是幻相**——錢財、名利、親屬、身體皆是幻相所苦；知其為幻，還苦什麼？（師以此導入「知幻即離」。）

### 4.6 是則龍女頓成佛，非則善星生陷墜〔行611-619〕

法師引永嘉《證道歌》：「是不是、非不非，差之毫釐失千里，**是則龍女頓成佛，非則善星生陷墜**。」
- **龍女**：龍屬旁生類（非人），因識得本心而頓成佛（《妙法蓮華經》提婆達多品）。〔行611-613〕
- **善星**：佛之長子，隨佛多年、三藏十二部極熟、語言文字極擅，卻偏信外道、不信佛說自性功德，臨終仍不信，故生身陷墜地獄。〔行614-616〕

一「是」一「非」之差，全在「識不識得本心」。

### 義理深入

**（一）第八疑——「彼非眾生，非不眾生」是全講的樞紐。** 體佛法師把這句拆成「不變／隨緣」兩軸：從**不變**（佛性）看，眾生「非眾生」（本是佛）；從**隨緣**看，眾生「非不眾生」（確因眾緣和合而現）。二乘人只悟不變（入空性、超三界）卻不悟隨緣，故不度眾生；凡夫只在隨緣中著相（「隨緣」墮成「隨便」）而不知有不變，故六道輪迴。唯有同時了達不變＋隨緣，才「有成佛的機會」。這一疑一旦通，後面第九～十二疑（法無高下、度眾生、觀如來）都只是同一義理的展開。〔行99-144〕

**（二）第九、十疑——法無高下即是引出「三量」的階梯。** 「法無高下」不是相上的齊頭平等（相是千差萬別、男女上下皆不平等），而是「法皆心所現影像，影像即平等」的**性平等**。〔行208-221〕由此法師把《金剛經》反覆出現的「較量品」重新定位：四句偈之所以勝過三千大千世界七寶，因為七寶是**有漏（有為）功德**，四句偈是**文字般若（現量）**，能引人透過**觀照（比量）**回歸**無量**的自性功德。三量（現量→比量→無量）是本講理解後半部一切經文的鑰匙。〔行229-265〕

**（三）第十一疑——「度眾生」與「我」，收在自心影像上。** 法師以琵琶湖／富士山「帶不回台灣、帶回的只是影像」層層逼出：眼前一切（杯子、大德、山湖）無一不是眾緣和合而生，而「眾緣」本身又是自性佛性所現的影像。既然眾生是自心大圓鏡智所現影像，「度眾生」即是度自心影像，了不可得——若仍存「我度眾生」之念，我相／人相／眾生相／壽者相四相俱起。接著「如來說有我者，則非有我」把「我」導向**常樂我淨的清淨法身**（非凡夫身心之我），並以「設名即破名」的手法破「凡夫」相。〔行336-443〕

**（四）第十二疑——由「見」入「觀」，是全經最微細的一刀。** 前半《金剛經》講「無我相」（現量，如歌利王割截身體無我相），後半講「無我見」（比量，微細）。法師指出：《金剛經》前文問「可以具足色身**見**」，此處改問「可以三十二相**觀**」——一字之差，正是從現量深入比量。須菩提「如是，如是」是**活話**：程度（入本心與否）不同，答案就在「一切皆是／一切皆非」之間擺盪，全繫於「諸法如義」的「如＝心＝一如」。最後「若以色見我」偈把著相求佛者判為「行邪道」，而羅什未譯、真諦／玄奘所補的「應觀佛法性，即導師法身」偈補足了正面指示：要**觀法性（法界）、回歸唯心**，斷疑分至此圓滿。〔行495-890〕

## 10. 法脈會通

本講的核心「連結網」是**唯識三量**貫穿《金剛經》後半，並把淨土法門「掛」在同一根軸上。以下用等式鏈與對照表呈現。

### 10.1 三量等式鏈（本講總骨架）

```
        佛（法身）
         │
    無量 ─┤ 本住法 + 自身內證法（空性 / 本自清淨圓覺自性 = 空）〔行247-261〕
         │
         ▼ 隨眾生緣而現
    現量 ─┤ 文字般若 / 語言文字 / 三十二相 / 見 / 稱名念佛〔行255-265〕〔行778〕
         │
         ▼ 透過思惟・觀照（善思惟 = 思惟修 = 禪 = 觀照般若）
    比量 ─┤ 觀 / 觀照 / 觀阿彌陀是自心〔行259-265〕〔行500-508〕〔行778〕
         │
         ▼ 回歸
    無量 ─┤ 平等真性之理 / 自性圓滿的佛性 / 無量光無量壽 = 阿彌陀〔行265-267〕〔行780〕
```

**連結要點**：見＝現量、觀＝比量、如來＝無量；《金剛經》前文問「具足色身**見**」（現量）、後文問「三十二相**觀**」（比量），一字之差正是三量的深入。〔行495-511〕念佛亦三量齊發：稱「阿彌陀佛」（現量）→觀阿彌陀是自心（比量）→回歸無量光無量壽自性（無量）。〔行778-780〕

### 10.2 三身 × 見／觀 對照

```
          身相（有形象，可"見"）              法身（無形象）
   ┌──────────────┬──────────────┐         │
 三十二相=應化身   具足諸相=報身   具足色身    如來 = 法身
   └──────────────┴──────────────┘         │
        不可以報身/應化身"見"法身 ────────────┘（前文「具足色身見」）
        更不可以三十二相"觀"如來（無量）────────（本講「三十二相觀」）
```
〔行488-511〕連結要點：報身、應化身都有形象，唯法身無形象；故「見」「觀」都取不到如來——如來是無量。

### 10.4 淨土「自性彌陀・唯心淨土」等式

```
自性彌陀（性，體）── 無量光無量壽 = 不變 ──┐
                                          ├─ 不變隨緣 = 真空妙有
唯心淨土（心之妙用）── 隨緣所現淨土 ───────┘
   六信：信自(核心) → 信他 → 信因 → 信果 → 信事 → 信理〔行762-771〕
   本願（第18願）：至心信樂(信) + 乃至十念(願) → 必生〔行757-759〕
```
連結要點：自性彌陀是「性」，唯心淨土是「性所現的妙用」；「往生與否在信願之有無」（蕅益要解），非在外相求佛來接。〔行772-801〕

## 11. 日常實踐

1. **聽經＝思惟修，不是聽過就算。** 聽經要「諦聽」——把主觀意識放下，從文字（現量）進入思惟觀照（比量），再回歸自性（無量）；只看資料、入海算沙徒自困。〔行532-536〕
2. **知幻即離、不即不離。** 面對錢財名利身體等幻相，如經過湖邊看水中月：欣賞可，不去佔有；知其為幻即離，煩惱自消。〔行184-192〕
3. **念佛三量齊發，不必執24小時不斷。** 稱名（現量）→觀阿彌陀是自心（比量）→回歸無量光無量壽自性（無量）；「一心繫念」是「不離」（因它本與你不斷），非機械式數萬遍。〔行778-785〕〔行702-715〕
4. **重信願：信自性彌陀。** 六信之核心是「信自」——信自性本來就是彌陀、信自己有佛性；「往生與否在信願之有無」。〔行762-801〕
5. **切忌誹謗正法。** 誹謗正法＝不信「彌陀與我本無異、我有佛性」；比五逆更重，斷人慧命墮地獄。莫在文字上挑佛語病（佛講有你說空、講空你說有）。〔行392-398〕〔行795-799〕
6. **成佛三條件（《圓覺經》）：善知識、懺悔業障、修三法。** 承認「雖是佛而習性我執太重」，勤加懺悔放下我執；依奢摩他（以淨為行）／三摩缽提（以幻取幻）／禪那，皆須先以淨覺心（入本心）為前提。〔行136-143〕〔行803-805〕
