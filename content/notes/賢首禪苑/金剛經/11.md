## 1. 本講概要

本講是《金剛經》講席的第11講，體佛法師以世親菩薩的分法，帶學人走過「功德具足較量分」的收尾，正式進入須菩提聞經涕淚悲泣、佛答「如是如是」、以及「不驚、不怖、不畏」與「歌利王割截身體」這一段〈離相寂滅分〉的核心經文〔行53、行104〕。

貫穿全講的「主軸」有三：

1. **三空次第**——我空 → 法空 → 空空（空亦空），對應禪宗「見山是山 / 見山不是山 / 見山又是山」三階段，及天台「六即佛」的修證階梯〔行124、行205、行210〕。
2. **不驚不怖不畏的三種對機**——凡夫聞「四大假合是空」則「驚」；二乘聞「空即實相」則「怖」；權教菩薩執著法空則「畏」；唯超越三者、入中道義者能「不驚不怖不畏」〔行273、行310、行316〕。
3. **空有不二·實相不壞假名**——「即非/是名」不是否定相，而是「空有不二」；故蕅益大師作《破空論》破人「落空」之病，佛更以「歌利王割截身體」自證：真無為是「有為裡見無為」，是「為一切所應為，心恆處無為」〔行67、行122、行498、行615〕。

法師並以自身罹癌的經歷，現身說法「痛是痛，我心不痛」，把「安受之心」的忍辱波羅蜜落到日常〔行668、行674〕。

## 2. 大綱

- **一、開講與複習定位**〔行53–65〕
  - 本講為第11講；《金剛經》譯史複習：無著入定〔兜率天〕請**彌勒菩薩**造偈頌 → 世親造疏 → 北魏**菩提流支**譯《金剛般若波羅蜜經論》〔行55–59〕
  - 諸宗與外道皆重此經；羅什譯本歷久盛行，對比《圓覺經》唐末至宋為主流後漸衰〔行61–65〕
- **二、學經二誡：勿高推聖境、勿起增上慢**〔行69–99〕
  - 「若無信」則高推聖境「謂己無分」；「若無慧」則起增上慢「與佛均同」（出《圓覺經》）〔行69–80〕
  - 摩尼寶珠喻：本具而未證，須經文字般若→觀照般若→實相般若〔行80–82〕
  - 天台「六即佛」：理即→名字即→觀行即→相似即→分證即→究竟即〔行90–94〕
- **三、複習第10講經文（實相者即是非相）**〔行106–121〕
  - 須菩提「信心清淨則生實相」段；「離一切諸相，則名諸佛」為結論〔行111、行120〕
- **四、三空與禪宗三階段·空花喻**〔行122–213〕
  - 蕅益大師《破空論》破「落空」〔行122、行184〕
  - 禪宗三階段（青原惟信）＝三空次第〔行124–132〕
  - 蓮花出淤泥而不染＝中道義實相〔行128–132〕
  - 「翳眼看空花，花處即是空處，不須滅花而別取空，翳淨而花自無」〔行188–203〕
  - 我空／法空／空空（空亦空）〔行205–210〕
- **五、須菩提心得與佛印可「如是如是」**〔行223–243〕
  - 須菩提為當機者，即眾生代問；心心相印＝印心〔行231、行259、行266〕
- **六、不驚不怖不畏——三種對機**〔行268–319〕
  - 凡夫（人天執四大假合）聞則驚〔行281–294〕
  - 二乘（守我空）聞則怖〔行295–299〕
  - 權教菩薩（執法空）聞則畏〔行302–307〕
  - 三空俱空、入中道者不驚不怖不畏〔行310–318〕
- **七、第一波羅蜜＝如來＝眾生本具·般若為眼帶五度**〔行335–364〕
  - 如來為第一因；此岸彼岸同一岸；引中峰「我心即彌陀」〔行340–346〕
  - 六度以般若為眼，餘五度為盲〔行348–350〕
- **八、彌勒菩薩偈頌「捨船筏」與《壇經》無住為本**〔行394–450〕
  - 彌勒偈：於法中證智者可捨船筏，未證者仍須法（船）〔行402–443〕
  - 《六祖壇經》無相為體、無念為宗、無住為本；鏡喻〔行407–424〕
  - 二十二祖「隨流認得性」〔行426–428〕
- **九、財施內施皆有為·永嘉證道歌**〔行472–491〕
  - 三千大千世界七寶施、恆河沙身命施皆有為法；不如受持四句偈之無為〔行475–481〕
- **十、忍辱波羅蜜的義理與三障**〔行514–569〕
  - 忍＝心，辱＝陵夷（逆）之境；凡夫二種業障（報復／心忍如刀）〔行517–541〕
  - 三障：業障→報障→苦障（煩惱障）；迴向偈「願消三障諸煩惱」〔行548–569〕
- **十一、歌利王割截身體公案（本講高潮）**〔行577–660〕
  - 佛因地初地菩薩，被歌利王節節支解而無四相〔行491–611〕
  - 對比僧肇臨刑偈、袁崇煥凌遲〔行633–641〕
  - 五百世作忍辱仙人；娑婆修行速於淨土〔行649–655〕

## 3. 核心概念

| 概念 | 體佛法師釋義〔行〕 | 經教連結（核驗） |
|---|---|---|
| **三空** | 我空（離四相）→ 法空（知四相虛幻相亦是實相，不須滅）→ 空空／空亦空（連法空亦放下，離一切相到無可離即佛）〔行205–210、行312〕 | 天台三觀‧般若三空義；師述次第，非單一經文 |
| **即非·是名** | 「即非」指回歸真心本性（性、本具、無形無相）；「是名」指從相上假名安立，引導未證者；性相一如、空有不二才是「是名」〔行210–213、行360–364〕 | 《金剛經》T0235 貫串句式 ✓ |
| **不驚不怖不畏** | 三種眾生的三種恐懼：凡夫聞我空而驚、二乘聞法空破我空而怖、權教菩薩執法空而畏；超越者不驚不怖不畏〔行310–318〕 | 《金剛經》「不驚、不怖、不畏，當知是人甚為希有」✓ CBETA T0235 |
| **第一波羅蜜** | 如來為第一因，眾生本具如來智慧德相，萬相皆從如來所生，故稱第一；彼岸此岸不離當下〔行340–344〕 | 《金剛經》「如來說第一波羅蜜，非第一波羅蜜，是名第一波羅蜜」✓ T0235 |
| **般若為眼·五度為盲** | 布施、持戒、忍辱、禪定、精進五度須般若（＝如來、眼）帶領；有般若帶則任一度皆第一波羅蜜〔行348–350〕 | 六度萬行；師述（般若攝五度） |
| **忍辱（忍＋辱）** | 忍是「安受之心」（心），辱是「陵夷之境／拂逆之境」（境）；心境二者合為忍辱；真忍辱是境來而心不起拂逆〔行517–522、行573〕 | 《金剛經》忍辱波羅蜜段 ✓ T0235 |
| **三障** | 業障（拂逆之心起報復或心忍如刀）→ 報障（因果不空必報）→ 苦障（＝煩惱障）〔行548、行541〕 | 迴向偈「願消三障諸煩惱」（通行迴向文，※ 見下） |
| **無為法** | 「為一切所應為，心恆處無為」；有為法（財施、命施、住相布施）生天福如仰箭射空，勢盡還墜；無為法是「有為裡見無為」〔行481、行498、行489〕 | 《金剛經》「一切賢聖皆以無為法而有差別」✓ T0235（本講引其義〔行148〕）|
| **實相不壞假名** | 影像（相）是真如自性所現幻影，見幻影即見實相；何必破相才見性——「花處即是空處」〔行182、行186、行201〕 | 般若空花喻（師引般若經典，※ 見§7）|

## 4. 故事・公案

### 4.1 歌利王割截身體（本講高潮，法師依《涅槃經》述）〔行593–611〕

法師指出此段記於《涅槃經》，佛在因地、已入初地菩薩、然仍具四大假合之身時的實證〔行593、行491〕。

**緣起**：歌利王（梵意為「極惡的國王」〔行593〕）率宮女到花園遊玩，園外有一修行者（佛之前身）正在入定。宮女出遊時見這位相貌莊嚴的年輕人，圍繞而問法〔行595〕。

**發展**：歌利王驕慢，不容親信崇拜他人，見宮女圍繞修行者而生瞋〔行597〕。王問：「我全國第一的美色宮女，你見了如何？」修行者答：「我修不淨觀，觀身不淨，故不覺其有美與不美。」〔行599–601〕王不消氣，再問：「你證果了嗎？」答：「未證果。」王更怒：「未證果何敢言不見美色？」又問持戒否，答持「忍辱戒」〔行603〕。

**高潮**：王曰「那我看看你忍辱到幾分」，遂剁其手指、斬其手腳、削其鼻，節節凌辱，每凌辱一次即問「你忍辱嗎？」修行者答:「本無辱可忍。」〔行605〕當下四天王感動，降下沙雨；歌利王驚怖，心生懺悔〔行605–607〕。

**旨趣**：佛因無我相、人相、眾生相、壽者相，「無忍可忍」，反因此逆境道業增長〔行607〕。佛發願：成佛時第一個要度的就是歌利王。歌利王後懺悔投胎為人，即成佛後五比丘之首**憍陳如**尊者〔行609–611〕。法師並依經典傳說指出：本應**彌勒菩薩**先成佛，因此事件佛道業增長而先成佛，彌勒遂為候補佛（一生補處）〔行609〕。

> 核驗：《金剛經》經文「如我昔為歌利王割截身體…應生瞋恨」「又念過去於五百世作忍辱仙人」✓ CBETA T0235。詳細情節（宮女、不淨觀、四天王降沙、憍陳如）出《大般涅槃經》，法師口述，※ 未逐字對 T0374 核驗（本講未讀誦，屬敘事）。

### 4.2 僧肇臨刑偈（對比公案）〔行639〕

法師舉**鳩摩羅什**大師大弟子、後自成一格（其思想稱「肇論」）的**僧肇**大師：三十幾歲被皇帝處死，臨刑說偈「四大本無我，五蘊本來空，將頭臨白刃，猶如斬春風」，以證其已破四相〔行597、行639〕。

> 核驗：僧肇臨刑偈載《景德傳燈錄》T2076作「四大**元無主**，五**陰**本來空，將頭臨白刃，猶**似**斬春風」。法師誦作「四大本無我，五蘊本來空…猶如斬春風」，※ 用字小異（元無主／本無我、五陰／五蘊、猶似／猶如）。史實上僧肇卒於414年、年31，傳統《傳燈錄》記「遭秦主（姚興）難臨刑」，與法師所述一致（現代學界對是否被處死有異說）。

### 4.3 袁崇煥凌遲（反例對比）〔行631–635〕

法師以明思宗（崇禎）時代抗滿名將**袁崇煥**為反例：因被疑通滿清（愛新覺羅）而遭凌遲處死。袁崇煥凌遲時邊受刑邊罵明思宗，心中充滿「我效忠之心天上可鑒，為何這樣對我」的不滿——境界與佛陀「安受之心」相反，仍是凡夫〔行633–635〕。法師讚其忠義可嘉，但指出「這還不是佛法」〔行635〕。

### 4.4 法師罹癌現身說法（自證公案）〔行660–676〕

法師講經第十五年，在家時曾有幾位聽經菩薩罹癌往生。其中一位（每次都在其身旁誦經的教授菩薩）臨終對他說:「老師你叫我們放下沒錯，可是我們得癌症，你又沒有得。」〔行662–666〕法師坦言當下即發願「我自己來得癌症看看」——果然不久真的罹患罕見癌症，骨頭劇痛、覺如節節支解〔行668–670〕。故他說對癌症病人講此段「有公信力」，非同理心（文字般若）而是「感同身受」：「痛是痛，我心不痛」——有覺受（當然痛），但心不受〔行670–676〕。

## 8. 本經解義（金剛般若波羅蜜經逐段）

本講所走的是羅什本〈離相寂滅分〉（第十四）核心。以下依經文次第，逐句列出法師的釋義。完整經文（自須菩提聞經至「應生無所住心」）如下，一律取自 CBETA T0235：

> 白佛言：「希有世尊！佛說如是甚深經典，我從昔來所得慧眼，未曾得聞如是之經。世尊！若復有人得聞是經，信心清淨，則生實相，當知是人，成就第一希有功德。世尊！是實相者，則是非相，是故如來說名實相。世尊！我今得聞如是經典，信解、受持不足為難，若當來世後五百歲，其有眾生得聞是經，信解、受持，是人則為第一希有。何以故？此人無我相、人相、眾生相、壽者相。所以者何？我相即是非相，人相、眾生相、壽者相即是非相。何以故？離一切諸相，則名諸佛。」佛告須菩提：「如是，如是！若復有人得聞是經，不驚、不怖、不畏，當知是人甚為希有。何以故？須菩提！如來說第一波羅蜜，非第一波羅蜜，是名第一波羅蜜。須菩提！忍辱波羅蜜，如來說非忍辱波羅蜜。何以故？須菩提！如我昔為歌利王割截身體，我於爾時，無我相、無人相、無眾生相、無壽者相。何以故？我於往昔節節支解時，若有我相、人相、眾生相、壽者相，應生瞋恨。須菩提！又念過去於五百世作忍辱仙人，於爾所世，無我相、無人相、無眾生相、無壽者相。是故，須菩提！菩薩應離一切相，發阿耨多羅三藐三菩提心，不應住色生心，不應住聲、香、味、觸、法生心，應生無所住心。」

### 義理深入

**一、三段話成一實相義。** 法師反覆強調須菩提報告的三句——「無四相（我空）」「四相即非相（法空）」「離一切相則名諸佛（空空）」——不是三件事，而是同一實相義的三層深入，須「三段才是真正入實相義」〔行162、行229〕。這正對應禪宗「見山是山→見山不是山→見山又是山」與天台六即佛的階梯。他特別點破學人最易停住的第二關：知道相是假（第一階段我空）之後，容易「落空」而停在法空；佛之所以再講「我相即是非相」，是要人回頭看見「所看到的影像它就是真相」——因為影像正是真如自性所現，「你不是看到了相當下就進入性嗎，何必破相才能看性」〔行180–186〕。這是蕅益大師作《破空論》的着眼點。

**二、「如是如是」是印心。** 法師把佛答「如是如是」讀成金剛法會的印心事件：須菩提是「當機者」，代眾生問，而學人今日聽經「不是站在第三者，你是站在祇樹給孤獨園的當機者，只是沒有發問而已」〔行231–233〕。佛心與須菩提心「同一個心，兩個心」，故說兩個「如」〔行266〕。這把一段經文對答，轉成可操作的「你有沒有契心」的當下體驗。

**三、第一波羅蜜＝如來＝般若為眼。** 法師解「第一」為「第一因」：如來是眾生本具、萬相所從出，故稱第一〔行340〕。落到修行，即六度以般若為眼、餘五度為盲——「只要有般若來帶，不管哪一度都是第一波羅蜜」〔行348–350〕。而「即非/是名」在此再現：第一波羅蜜本具（即非），未證前仍須它引導（是名）——如同「摩尼寶珠放在你家」而你未取用，仍是貧窮〔行362–364〕。

**四、忍辱段是全經「空有不二」的自證。** 法師指出佛不講別人、講自己被歌利王節節支解，是要證明《金剛經》「不是我們想的空的道理，它是空有不二的道理」〔行615〕。真無為是「為一切所應為，心恆處無為」〔行498〕——不是什麼都不做（消極、厭世），而是「有為裡見無為」：人有難、有為法的因緣可及，就去做而不求回報，這才是金剛要義、成佛的最大根本〔行500–504〕。他並強調此段「所有六大翻譯者沒有人敢刪掉」，因其防人把空義「聽聽就好」而落於空談〔行615〕。

## 10. 法脈會通

本講的骨幹，是體佛法師以「三空次第」把《金剛經》這一段串起來，再以禪宗、天台、般若空花喻互相印證。可視為一條等式鏈與一張對照網：

### 三空次第 · 三家印證（等式鏈）

```
   我空          →        法空           →        空空(空亦空)
   離四相                 四相即實相              離一切相到無可離
   ────────           ────────           ────────
禪宗:見山是山(凡夫)    見山不是水(修行人)        見山又是山(不離相而不染)   〔行124-132〕
天台:名字/觀行即       相似即                    分證→究竟即               〔行90-94〕
對機:凡夫聞則「驚」    二乘聞則「怖」            權教菩薩執法空則「畏」      〔行310-318〕
病:  不敢聽/高推聖境   落空(蕅益破空論所破)      執法空不入實乘             〔行75,184,438〕
   ↓超越三者
        不驚·不怖·不畏 → 甚為希有 → 中道義實相    〔行312,322〕
```

**連結要點**：三空不是三段割裂，而是同一實相的漸深；唯有走完三空、能「不驚不怖不畏」者，才真入《金剛經》中道義。凡夫在第一關即驚（連我空都入不了），二乘守我空聞法空而怖，權教菩薩執法空而畏——恐懼的位置，正暴露修證的位置。

## 11. 日常實踐

1. **學經先立心態**：勿高推聖境「謂己無分」（自棄），亦勿起增上慢「與佛均同」（自欺）；取其中道，謙卑細心而學〔行75–88〕。
2. **拂逆現前時的觀法**：辱（陵夷之境）來時，先「諦聽、仔細聽，不要主觀思考」，覺察「心因境而有」（境不自境因心故境）；不隨境起拂逆之心，代以「安受之心」〔行517–526、行573〕。
3. **止息三障的迴向**：以「願消三障諸煩惱，願得智慧真明了」自省——三障非菩薩赦罪，而是「自障自消」，須以智慧真明了照破內心不滿〔行567–569〕。
4. **忍不是壓抑**：辨別「心上插一把刀」的忍耐（仍成業障、死後帶不滿投胎）與「安受之心」的真忍辱（無忍可忍）〔行536–541〕。
5. **有為裡見無為**：眾生有難、因緣可及就去幫助且不求回報，勿以「我心加持他就好」的空談無為為藉口——空談般若無功德反而造業〔行487–491〕。
6. **病苦當道場**：如法師罹癌自證「痛是痛，我心不痛」——有覺受而心不受，把陵夷之境當回歸本性最好的老師〔行619、行674〕。
7. **珍視娑婆**：五濁惡世處處陵夷之境，正是考驗安受之心、進道最速之處；人身難得，勿厭世〔行651–653〕。

## 12. 延伸・參

- **相關講次**：第10講（須菩提「信心清淨則生實相」段之前文、二十二祖參究）；下一講將展開「菩薩應離一切相，發阿耨多羅三藐三菩提心，不應住色生心…應生無所住心」〔行684、行689〕。
- **相關經論**：世親《金剛般若波羅蜜經論》T1511（彌勒偈全帙）；《圓覺經》T0842（成佛二要素：善知識、懺悔；「知是空華即無輪轉」）；蕅益《金剛般若波羅蜜經破空論》。
- **一參問**：法師說「你何必滅花？花處即是空處」——若「相即是實相、不須破相」，那麼「觀照」到底觀什麼？（提示：觀的不是「把相變沒有」，而是「翳淨」——妄執除則花自無，非花變無〔行239、行201〕。）
