## 1. 本講概要

本講進入《妄盡還源觀》六門中的**第二門「起二用」的第一用——「海印森羅常住用」**，並在前半段用大量篇幅先把「入法界」的正知見架好，才切入原文。體佛法師的貫串主軸是一句：**「悟即是修，修是在悟」**〔行67〕——華嚴的要旨要去「悟」，悟的目標就是**明心見性、了生死**〔行67-69〕。

全講的骨幹是一組對比與一個等式：

- **世界 ⇄ 法界**：世界＝四大假合的器世間（世間），從人的身體是生老病死、從器世間是成住壞空、生住異滅——這是「常」（恆常的定律），凡夫誤以為是「無常」而被境所苦；法界＝出世間＝站在「心」的角度看世界〔行95-103、143〕。
- **一體 → 二用**：前門的「一體」是**清淨自性圓明體**（在凡不減、在聖不增，煩惱覆則隱、智慧了則顯）〔行107-111〕；本門的「起二用」講此淨體起用，第一用即**海印森羅常住用**——「海印」就是我們的**心**，能現森羅萬象；心所現的一切影像都是「緣影」、都是「假」，故名為「空」〔行179、193、278-284〕。
- **貫穿的等式**：**海印＝心＝法界＝如來藏之用**；性起作用叫心、心起作用叫念、念起作用叫六根〔行151-153、282-286、483-485〕。

後半段以三個歷史層次（**正法無相 → 像法有相 → 末法**）解釋佛教何以「著相」，並點出**馬鳴菩薩造《大乘起信論》力挽狂瀾、真諦大師渡海入華弘無相法**的因緣〔行336-416〕；最後以**《菩薩處胎經》「一彈指三十二億百千念，念念成形，形皆有識」**與量子科學互證，把「一念不覺生三細／海印森羅」推到「一切法心想生」的結論〔行635-721〕。文殊、普賢兩位華嚴主角預告下週登場〔行432-434〕。

## 2. 大綱

1. **開題**：修華嚴奧旨；悟即是修；明心見性；了生死＝本無生死可了〔行65-75〕
2. **入法界的正知見**：法界（出世間）vs 世界（世間＝邪見）；世界是「常」不是無常〔行85-105〕
3. **一體**：清淨自性圓明體（在凡不減在聖不增、隱顯）；月亮／千江月譬喻〔行107-115〕

6. **世界角度的放下＝忍耐、了無出期**；福報享盡；賢首禪苑是了生死法門〔行131-143〕

9. **依經而講、述而不作**；蓮花表法〔行201-215〕
10. **《心經》**：照見五蘊皆空（本來空）、度一切苦厄、無所得、究竟涅槃；顏回「不貳過＝不二＝入法界」〔行217-261〕
11. **本經原文（起二用·海印森羅常住用）逐段**：若風止息海水澄清無象不現；起信論無量功德藏；一法之所印＝一心；一法界大總相法門體；唯依妄念而有差別〔行263-292〕
12. **無相法的歷史**：佛陀不造像→大英博物館佛足印（正法）→犍陀羅造像（像法）→末法；能所出現＝外道盛行〔行296-374〕

14. **一法即一心**：攝＝攝影；心可隨時改；妄念＝誤認（非「有想法」）；臥輪偈公案、一碗沙一碗米公案〔行434-536〕
15. **三昧＝正受＝無所住＝無生法忍**：猴子掛印、心猿意馬、西遊記；六祖24歲大徹大悟公案〔行536-608〕
16. **海印森羅的妙用**：你即觀世音；貪瞋痴即現三惡道；一切法心想生〔行610-630〕
17. **量子科學互證**：愛因斯坦；《菩薩處胎經》佛問彌勒；1280兆生滅；電影24格；金剛經一合相、僧肇《物不遷論》；觀想治病、杜順〔行631-695〕
18. **難陀公案**（忉利天天女、先以欲勾牽、地獄掛號）；蜉蝣譬喻；無量光無量壽〔行696-712〕
19. **結**：菩薩清涼月遊於畢竟空；代眾生苦＝大悲心＝海印示現；方東美尊崇華嚴；預告華嚴三昧與文殊普賢〔行715-729〕

## 4. 故事・公案（全程敘事）

### 4.1 葉曼居士的道場遺願（美國洛杉磯）〔行77-84〕
昨天有一位美國師兄來找體佛法師。洛杉磯有一個道場，原是**葉曼居士**的道場。葉曼居士得病、臨終有三個願望，其中一個是：她的道場要供養出來，請「真正有德者」來演講心性、令大眾能了生死。這位師兄答應了她第一個願望，於是把道場買下、供養出來，讓許多人去講經，並希望體佛法師去美國弘法。這一批葉曼居士的弟子，早在體佛法師還在家時，就把他講的《金剛經》《六祖壇經》定為每日定課、互相討論；如今《妄盡還源觀》他們也在看——本以為極難（《華嚴經》本是對法身大士而講，賢首國師又濃縮成幾千字更難），聽後卻「心開意解」。高雄醫學院的教授一班六人也曾從早談到下午，盼此法義能同登佛道、同蒙法義。（法師以此帶出：**講心法的經，能令人心開意解**。）

### 4.2 宣化上人與背《楞嚴經》的考驗〔行163-177〕
法師24歲在美國時，〔廣欽老和尚〕還在世。楊正和告訴他去找〔宣化〕老和尚。他到金山寺按門鈴，開門的正是〔宣化上人〕本人——當時很多出家人到美國都見不到宣化上人，法師卻一按鈴就見到。宣化上人問「你來做什麼」，先請他禮佛，禮畢才表明身分。法師第一句話說「我想要出家」，這是「過去生中的習性」現在才實現。宣化上人點頭答應，並拿了一本《楞嚴經》（八萬個字）給他，說「你把它背起來」。法師在美國功課壓力極大，怎麼背？又去問：「我是背楞嚴咒還是《楞嚴經》？」老和尚回答「是《楞嚴經》」。他的柏克萊學長**恆實**（與恆觀行三步一拜之修法）也告訴他，自己是用英文拼音背**楞嚴咒**。法師由此對《楞嚴經》極有感觸，發願「《楞嚴經》如果沒有講完，我不會輕易往生」。閉關看《楞嚴經》二十五圓通時，他用的不是觀音耳根圓通，而是**眼根圓通**，由此體悟「我眼睛看過去的一切，就是我心裡鏡子的影像而已」，從此看《楞嚴經》再無障礙。（法師自述：「我不敢說我開悟，這是讓我體悟《楞嚴經》的精神」〔行177〕。）

### 4.3 一樓大殿「猴子掛印」〔行538-548、600-606〕
賢首禪苑一樓大殿靠近佛菩薩處有兩面牆：一面是**大勢至菩薩念佛圓通章**，一面是**《心經》**。電梯旁坐了一尊**猴子**，牠的眼睛剛好看著《心經》，脖子上掛著一個「印」。法師說：這個印叫「心印／海印」；猴子的眼睛看到《心經》，就把《心經》的要義（四個字：**五蘊皆空**）印進牠的心裡，牠就能「定」——這就是「入三昧」。猴子代表「心猿意馬」的凡夫心，看了五蘊皆空、永遠掛在心上就能定。法師交代大眾下樓要向牠頂禮、稱牠「大聖」，因為牠已入三昧。孫悟空之名意在「悟空」，其修行處「靈台方寸山」即是「心中」（靈台、方寸都指心）——《西遊記》的要義正是講這顆心；金箍是為了讓心猿定下來、入三昧。（法師補：這尊猴子本擺在前院，「牠跟我說牠要在那裡」〔行546〕——此為法師自述之緣起。）

### 4.4 真諦大師渡海入華弘無相法〔行402-416〕
《大乘起信論》約在西元後二世紀出現，後由**真諦大師**帶到中國（中國四大翻譯家依年代為：鳩摩羅什、真諦、玄奘、不空，唯玄奘是漢人）。真諦來時正值**梁武帝**時代，全中國幾乎95%都在「像法」——拜懺、法會都在有相中求法，梁武帝即典型。真諦大感失望，欲搭船回印度，海中狂風大作、天昏地暗、漂流一兩個月，以為回到印度，上岸卻見人人講中文——原來漂到了**廣州**。他知這是佛菩薩示現：要無相法、要《大乘起信論》在中國流傳。於是他跪在佛菩薩前發願「一生把生命投注在無相法」，翻譯《大乘起信論》，最後在講台上講無相法的當下昏厥往生。（同時代另一位是**菩提達摩**，與梁武帝不對盤，只好北上尋有緣人，傳二祖三祖四祖乃至六祖。）

### 4.5 六祖惠能二十四歲大徹大悟〔行574-600〕
六祖24歲以前孤苦伶仃、不識字：父親本當官，八歲時父亡，與母親相依為命、砍柴為生（人稱「獦獠」，即未受文化洗禮者）。他聽人誦《金剛經》至「應無所住而生其心」，言下大悟——「這不是在說我嗎？砍柴一定要生心啊：樹要往哪裡倒、柴從哪邊砍，不生心怎麼砍？」他找五祖，不是去學什麼，而是去**印證**自己這顆「阿耨多羅三藐三菩提的心」。五祖初見即問「獦獠人你來做什麼」，他答「我是要來做佛的」，氣魄震驚眾人。五祖暗喜找到傳人，卻故意叫他去舂米（「法將不能曝光，人家會嫉妒」）。後令門人作偈：神秀寫「身是菩提樹，心如明鏡臺……」（有東西讓你住、要時時擦拭）；惠能請人代書「菩提本無樹，明鏡亦非臺，本來無一物，何處惹塵埃」（本來無所住、沒有一樣東西讓你住）。法師評：神秀一百分之外、惠能是一百分；若兩人只差5分，以五祖之智會傳神秀（一表人才、實至名歸、免後患），但惠能真的無所住、證無生法忍，故得法脈。

### 4.6 臥輪偈與六祖的駁斥〔行493-509〕
有僧舉臥輪禪師偈：「臥輪有伎倆，能斷百思想，對境心不起，菩提日日長。」六祖聞之，說「此偈未明心地，若依而行之，是加繫縛」，另示一偈：「惠能沒伎倆，不斷百思想，對境心數起，菩提作麼長。」法師解：哪裡須要伎倆？斷百思想是修行最大的障礙，就像瀑布從上流下，你強迫不讓它流是錯誤的。對境一定要起心（看紅燈知停、看綠燈知走），這叫「對境常起心」。

### 4.7 一碗沙一碗米／真鈔假鈔〔行507-521〕
有人拿一碗沙、一碗米給你吃，你選米——這是「法爾如是」，有分別（能分別）卻不起分別想、不執著。若被質問「你不是沒有分別嗎，為什麼不拿沙？」——愚痴妄念者才拿沙。真鈔假鈔亦然：學佛是念實相，誰要拿假鈔？要分別真假，但「無分別想」。此即六祖精神：**能分別一切法而不起分別想**。

### 4.8 難陀為忉利天天女而出家〔行696-717〕
阿難是佛的堂弟（同父異母）；難陀也是佛同父異母的弟弟。佛出家後回宮，阿難見三十二相即隨佛出家，難陀卻不動心——「我剛娶了那麼漂亮的老婆，怎麼可以出家」。佛帶他上**忉利天**看天女，問他感受，難陀說：與天女相比，我老婆就像猴子一般；「我也要去忉利天！」佛說「那你來出家」——**先以欲勾牽**。忉利天壽命又長（忉利天一天＝人間一百年）。後佛又帶他去**地獄**，見一牢籠掛著「難陀」的名字，他嚇壞了，問佛何故；佛答：**因為你心有貪瞋痴，當下地獄就掛號**。法師以此點出：貪瞋痴的當下，「量子科學」就出現了，你在餓鬼、地獄、畜生道就有你身形的化身出現。

### 義理深入

**（一）「海印＝心＝法界」是本門的樞紐。** 體佛法師指出賢首國師的行文是「對仗法」：起二用的第一用講「海印森羅」，第二用講「法界圓明」——「海印森羅、法界圓明」兩者是同一個東西（我們的心）用不同名詞說〔行284〕。因此「海印就是我們的心、所以法界也是我們的心」〔行286〕。這把《妄盡還源觀》最難的地方點破：若只看字面（海、印、森羅、法界），無從索解；一旦認定其所指皆是「心」，全文豁然〔行284-286〕。這正呼應原文「言海印者，真如本覺也」——海印非外境之海，而是真如本覺之心。

**（二）「唯依妄念而有差別，若離妄念，唯一真如」是全門的修行落點。** 法師特別澄清「妄念」二字：不是「我現在有想法」就叫妄念（那是「差之千里」的錯解）〔行468〕；「妄」是「誤認」——把「念」誤認為真實才叫妄念〔行524〕。故原文說「若離妄念」而不說「若離念」：念不可斷（真如能起念），要離的是對念的執著與誤認〔行530〕。這與《壇經》「不斷百思想」、黃檗「無念不是沒有念」完全一貫〔行503、532〕。因此「海印三昧」的成就不在滅念，而在**知念是心之緣影、不執著**，當下即「唯一真如」〔行526-534〕。

**（三）「一法界大總相法門體」把凡聖打成一片。** 原文說此一心「即是一法界大總相法門體」，法師釋為「諸佛如來跟凡夫眾生都是這樣子」的顯現〔行456-458〕。故海印森羅是「常住用」——不論凡聖，心能現象這件事恆常不斷；差別只在諸佛「知是影像、讓它出現就好、不執著」，凡夫則「留下永恆的記憶」而被縛〔行450〕。這使本門的教理不停在描述，而直接落成「入法界」的操作：站在「心」的角度看世界，即出世間、即法界。

## 10. 法脈會通

### 10.1 貫穿等式：海印＝心＝法界＝如來藏之用

```
        清淨自性圓明體（一體·如來藏法性之體）
                 │ 一念不覺＝起作用（性→心）
                 ▼
        ┌──────────────┐
        │   海 印  ＝  心 │  真如本覺；妄盡心澄，萬象齊現
        └──────────────┘
          │森羅（心所現）      │對仗（賢首行文）
          ▼                    ▼
     森羅萬象＝一心所印    法界圓明（第二用·同指此心）
          │                    │
          ▼                    ▼
    唯依妄念→有差別（凡）   若離妄念→唯一真如（聖）
```
**連結要點**：「海印森羅」與「法界圓明」是同一顆心的兩個對仗名詞〔行284-286〕；差別只在「妄念（誤認）」之有無〔行269、524〕。

### 10.2 心 → 念 → 六根 → 覺受 的生起鏈

```
性  ──起作用──▶  心  ──起作用──▶  念  ──▶  六根(眼耳鼻舌身意)
(真如/本無)     (顯物/海印)      (當下)        │
                                             ▼
                          六根 × 六塵 ─▶ 六識 ＝ 覺受（因有覺性/佛性）
                                             │
                          所現之像 ＝ 緣影 ＝ 空（有而不有）
```
**連結要點**：知有念即知有心，不必外覓〔行485〕；身之痛觸亦是覺受、緣影〔行189〕。此鏈與《華嚴》「心如工畫師」、《起信論》三細同一義〔行179、378〕。

### 10.3 一念不覺生三細 × 《菩薩處胎經》× 電影 × 一合相（跨典互證）

| 維度 | 內容〔行〕 | 核驗 |
|---|---|---|
| 本門原文 | 海印森羅常住用；妄盡心澄萬象齊現 | ✓ T1876〔行267〕 |
| 論 | 一念不覺生三細（業相＝能量＝鏡子）｜離言說相離心緣相 | ※師述／✓ T1666〔行378、652〕 |
| 經 | 一彈指三十二億百千念，念念成形，形形皆有識，不可執持 | ✓ T0384〔行645-650〕 |
| 譬喻 | 電影一秒24格靜止照片→疊成活動；心一秒1280兆生滅→疊成「真實」相 | 〔行654-662〕 |
| 經 | 一合相即非一合相：相是一張張堆疊、不可說 | ✓ T0235〔行667-675〕 |
| 論書 | 僧肇《物不遷論》先說此理 | 〔行677-679〕 |

**連結要點**：「念念成形」把「一念不覺（起用）→海印現象」量化——1280兆/秒的生滅堆疊出我們誤以為真實的「一合相」；電影是同一原理的世間類比〔行662-675〕。

### 10.4 三時判教：無相 → 有相 → 末法（結構圖）

```
正法(無相)          像法(有相)              末法
├ 佛不造像          ├ 犍陀羅造像(希腊式)      ├ 講經多在相裡
├ 佛足印/法輪/虛擬座  ├ 佛法「變有相」           ├ 無相法稀少
├ 追隨佛陀腳步        ├ 能所出現→了無正覺        └ 力挽者：馬鳴造《起信論》
└ 無為法·無能所       └ 外求法→外道盛行             真諦渡海弘無相法
```
**連結要點**：有相＝能所（我＝能、佛像＝所）出現＝有為法〔行368-372〕；正法＝無相＝無為法＝無能所，故《金剛經》「一切賢聖皆以無為法而有差別」〔行348-352〕。

### 10.5 三昧 = 正受 = 無所住 = 無生法忍（等義鏈）

```
三昧(Samādhi)  ＝ 正受(三＝正/Sam) ＝ 無受 ＝ 無所住 ＝ 無生法忍(八地)

  猴子掛印·心印五蘊皆空                      六祖聞「應無所住而生其心」言下大悟
```
**連結要點**：咒（陀羅尼）之目的唯一——定心、歸「五蘊皆空」〔行550-556〕；大勢至「都攝六根，淨念相繼，得三摩地」即此〔行560〕。

## 11. 日常實踐

1. **站在「心」的角度看世界**：出世間不是離開世間，是「我站在心的角度看世界」〔行143〕。遇事先問：這是我心裡的境界，還是外面的環境？——同一件事五人五種感受，苦不苦是心理境界〔行224〕。
2. **看破為因、放下為果**：先以經教開法眼（觀／看破），才放得下（止）；沒有經、修行都是盲修瞎練〔行197-199〕。因地要真，否則「果招迂曲」〔行199-201〕。
3. **念不必斷，但不執著**：想哭就哭、想笑就笑，秉性而為；抑制真如之念反成「斷滅相」，是修行最大障礙〔行452-456〕。知念是緣影、不執著即正念〔行526〕。
4. **能分別而不起分別想**：該拿米就拿米、該拿真鈔就拿真鈔——分別一切法而不執著分別〔行513-520〕。
5. **聽天命、盡人事、沒煩惱**：本分扮演好（盡人事），成敗交給天（聽天命），因照見五蘊皆空故沒煩惱；箭來仍要盡量閃（盡人事），閃不掉也不煩惱（聽天命）〔行240-247〕。
6. **知足即住兜率天**：眾生最苦是「有所求」，最樂是「知足」；知足即彌勒真弟子、當下住兜率（知足）天之心境〔行332〕。
7. **唯心淨土·自性彌陀**：西方在自性之中，往生的關鍵在那一刻「不執著（不煩惱）」，清淨自性圓明體即顯〔行308-310〕。
8. **依經而講、不依己意**：述而不作，不夾雜個人思想；離經一字即同魔說，依文解字則三世佛冤——故須善知識、常隨佛學〔行89-91、201-203〕。
