## 1. 本講概要

本講是《妄盡還源觀》由「四德」跨入「五止」的關鍵一堂。體佛法師先以將近半程作前導：借藏傳/唐密的**三密相應（身口意）**、**嗡阿吽=自性本元**、**嗡嘛呢唄咩吽**與**蓮花（摩尼）**之喻，說明一切咒語都是「諸佛成佛最後的結論（陀羅尼總持）」——但若只念不悟其理，便如「口唸彌陀心散亂，喊破喉嚨也枉然」〔行99〕。由此帶出**自性彌陀、唯心淨土**：西方極樂不出一念心之外，見性即「萬修萬人去」，心外求佛則機率極低〔行146〜154〕。

接著回收全論綱骨——**自性清淨圓明體**碰緣才起用（緣起論），性即心之轉化；心具**普周法界、出生無盡、含容空有**三功能〔行181〜216〕；四德為**隨緣妙用、威儀有則（柔和質直）、代眾生苦**，並點出眾生的根本苦是兩重錯認：「錯認四大假合為我身、錯認攀緣心為我心」，故曰「身心幻垢」〔行261〜268〕。

後半正入本論。法藏在「入五止門」段先精解**「入」＝無入而入、不入而入、本入本住**：一切眾生本來不離如來境界，更無可入；迷則謂東為西、謂妄可捨，悟則妄即是真、更無別真可入——引《華嚴經》、《入佛境界經》、《起信論》為證〔行325〜417〕。法師以**六祖「無念」三義（無念/無相/無住）**、**臥輪偈 vs 惠能偈**公案詳釋「能觀無念者是名入真如門」，並補講**馬鳴造《起信論》緣起、韋陀破相菩薩、龍樹入龍宮取華嚴、易經乾卦潛龍→亢龍**等一連串法脈公案。最後開講**第一止「照法清虛離緣止」**：以「照」字為佛法總要義（《心經》照見五蘊皆空即此止），辨**真諦/俗諦**、**世界/法界**、**五蘊（陰）/事物類**，歸結為「似有即空、能所皆空、性相一如」，證得「正證之時，因緣俱離」即開悟見地〔行732〜1027〕。

**through-line：入者本入——妄盡即還源，還源即照法清虛離緣；不斷念而不執念，是名入真如門。**

## 3. 核心概念

| 概念 | 體佛法師釋義〔行〕 | 經教連結（已核） |
|---|---|---|
| **入（本入/無入而入）** | 入五止之「入」非二元化的入，是「不出不入」「本來就入、本來就住（本住）」；一切眾生本不離如來境界，更無可入〔行288〜312、330〕 | T1876〔行92〕；《華嚴經》T0279「一切眾生入，而實無所入」；《入佛境界經》 |
| **妄盡還源** | 「妄盡就是知道本來沒有妄，不需要還源，當下就還源，因為本來就還源」〔行345〕 | T1876 論題 |
| **自性清淨圓明體** | 清淨圓滿明亮、毫無缺失的一體；不起作用，碰到緣才起用（緣起論），起用即轉化為「心」〔行181〜185〕 | T1876 一體 |
| **性↔心** | 「性跟心是一，是它的轉化而已」；自性不是精神也不是物質，碰緣起用就變心（外境現鏡中影）〔行185〜187〕 | 對應易經「潛龍勿用/見龍在田」〔行530〜536〕 |
| **心之三功能** | ①**普周法界**（大到無量無邊，含一切淨土六道地獄）②**出生無盡**（如電視轉台，一切唯心）③**含容空有**（色不異空空不異色）〔行189〜216〕 | 《心經》T0251；T1876 二用 |
| **無量壽 / 百年壽** | 百年壽是假、必生滅（花開花謝）；自性清淨即無量壽，與我同在＝阿彌陀佛；「但得本，莫愁末」〔行168〜174〕 | 開經偈；自性彌陀 |
| **無念（六祖三義）** | 無念＝於念而無念（不斷念、不執念）；無相＝於相離相（相是虛相）；無住＝人之本性（眾生本無住）〔行579〜594、725〕 | 《六祖壇經》T2008「無念為宗、無相為體、無住為本」 |
| **無者無二相** | 「無」＝無「二相」（能相/所相），無諸塵勞之心；「念」＝念真如本性〔行606〜609、648〕 | T2008「無者無二相，無諸塵勞之心；念者念真如本性」 |
| **真如＝本無** | 鳩摩羅什時代公認之譯：真如是梵音，中譯最佳義為「本無」——本來就沒有那樣東西，可又有那樣東西〔行709〜712〕 | 《起信論》T1666 真如門（師述，屬翻譯史說明） |
| **真諦 / 俗諦** | 真諦＝鏡子本身、本性空寂；俗諦＝鏡中顯出的事物類影像、似有即空〔行937〜951〕 | T1876 第一止 |
| **蘊（陰）/ 事物類（陽）** | 事物類（陽）=摸得到、世界生滅之物；入我心即成蘊（陰）=摸不著；五蘊=色受想行識=物質+精神〔行808〜814〕 | 《心經》五蘊皆空 T0251 |
| **世界 / 法界** | 世界＝事物類、生滅（戲論）；法界＝心、不生不滅；「不講世界，全部講法界」，世界最後仍歸法界〔行815〜820〕 | 「應觀法界性，一切唯心造」 |
| **照** | 五止第一止之首字、佛法總要義；即《心經》「照見五蘊皆空」——照見即止住苦〔行764〜776〕 | 《心經》T0251 |
| **正證之時·因緣俱離** | 你證佛（悟）的時候，能所不二、全部是假，這樣的見地即「正證之時」＝真正開悟那一剎那〔行1003〜1005〕 | T1876 第一止 |

### 名相辨析：入的四種說法（皆同一義）

```
無入而入 ── 入而不入 ── 不入而入 ── 本入(本住)
   └────────── 皆＝「本來就入，本來不用入」〔行294〜312〕
```
- 諸佛菩薩「入寂靜」：因祂知有一寂靜，讓我也無所入（本來就入）〔行339〜341〕
- 凡夫「不入寂靜」：不知有一寂靜，用妄心攀緣外境〔行342〕
- 結論：迷／悟皆本住此，「不入而入，故云入也」〔行330〕

## 4. 故事・公案

### 4.1 臥輪偈 vs 惠能偈（六祖三度駁斥「長坐不臥」之一）〔行665〜701〕
臥輪禪師在當時是一位大禪者，作偈曰「臥輪有伎倆，能斷百思想，對境心不起，菩提日日長」。六祖慧能一聽「快昏倒了——這是不對啊！」六祖說此偈**未明心地，若依而行之是加繫縛**，因示一偈「惠能沒伎倆，不斷百思想，對境心數起，菩提作麼長」。體佛法師點破：真如本性就是鏡子，鏡子一定會顯相；臥輪要「斷百思想、令鏡不顯相」，第一句就錯——「鏡子能顯相，我讓鏡子不顯相，這不是更加的妄心嗎？」六祖主張「對境常起心，緣來則應，什麼東西照就起什麼」〔行679〜684〕。法師並將此公案與**神秀「時時勤拂拭」/惠能「本來無一物」**對照，指出這是《六祖壇經》兩個最重要的對照公案：一個要漸修拂拭，一個本自圓滿〔行691〜693〕。

### 4.2 馬鳴造《大乘起信論》的緣起〔行419〜461〕
南傳（阿含）是佛陀一生的紀錄（如是我聞、講世間現象），因此南傳不承認北傳大乘、說「大乘非佛說」。體佛法師敘史：**阿育王**認為成就者不應只自身成就，要把成就狀況講出來與眾生分享，於是大乘經典開始集結，同時**開始為佛陀造像**（大乘經典時代佛陀才有造像）。造像有功德（見像方知佛要教什麼），但負面是眾生會**著相**，著相修行非佛法。於是**馬鳴菩薩**造《大乘起信論》以破相；法師稱馬鳴是「龍樹的老師」〔行458〕、大乘佛法自此燦爛（「佛菩薩有應，因為眾生有感」）〔行487〕。

### 4.3 韋陀——破相菩薩（金剛杵＝真心）〔行461〜488〕
與造像同時，一尊法界菩薩的法相誕生：身穿盔甲（武將）、手握武器（金剛杵）。體佛法師解：這尊菩薩「最後一個成佛，因為祂要負責破相」；金剛杵所代表的**真心才能破相**——「凡是有造像的佛寺、家中供釋迦三十二相，一定要再供這尊菩薩」，讓人「一方面拜像、一方面破相」，是「金剛般若」。故有相就要有韋陀，沒相不需韋陀〔行463〜480〕。並辨：**韋陀是法界的菩薩**（印度亦有）、**關公是中國歷史人物**（伽藍護法）；「關公護教，韋陀護法」，站在兩旁〔行485〕。

### 4.4 梁啟超・歐陽竟無「非佛說」與割錯腎的因果〔行437〜447〕
民國初年〔梁啟超〕（屬楊仁山→內學院、取自日本學風一派）、〔歐陽竟無〕竟說《圓覺經》《楞嚴經》「非佛說」，影響大量知識份子以為是偽經。體佛法師力斥：中國大乘文字最美的兩部「絕對見性之經」正是《圓覺經》《楞嚴經》；華嚴五祖**宗密**研究《圓覺》「嚇了一跳，原來圓覺就是華嚴境界」〔行439〕。法師續述：梁啟超後因腎病開刀，協和醫院一位留美名醫「把好腎割錯」，梁不久死——「護法處罰，因為斷人慧命之罪無量無邊」。法師申明此為其個人因果之說，並警醒：**偽經豈能讓人開悟？斷人慧命是阿鼻地獄之罪**〔行443〜447〕。（按：此屬近代學術史/因果之論，非CBETA可證，。）

### 4.5 龍樹入龍宮取《華嚴經》・大龍菩薩〔行503〜557〕
《華嚴經》是龍樹菩薩入龍宮取回的；龍樹的老師叫**大龍菩薩**——是佛陀二七日（二十一天）對四十一位法身大士開示時全部成佛的龍王之一。體佛法師以「龍」貫串：龍非世間動物，是心所變化的影相；印度以「龍」名心，中國儒家《易經》乾卦亦以龍喻心——**潛龍勿用**（自性未起用）、**見龍在田**（碰緣變心，田＝心田）、**飛龍在天**（著相至極）、**亢龍有悔**（物極必反、煩惱綁住難脫六道）。故「大龍」＝摩訶（無量無邊）之大心，「龍樹」＝見心後樹立妙有、開枝散葉成八宗共主、建立中國各宗〔行518〜555〕。

### 4.6 外道絕慾割生殖器・提婆達多苦行〔行715〜723〕
外道修行「絕慾」，有人竟把生殖器割掉，隔天來對佛陀說「我絕慾了」。佛陀答「你絕錯了、割錯地方了」——**絕慾是絕心中影像的那種慾，不是斷絕身體某個器官**。又**提婆達多**與佛陀辯論、帶走一批人，主張比佛更「清淨」：日中一食且全素、只住室外樹下一宿、不受四事供養、只穿死人堆的糞掃衣。佛陀說「你的做法是苦行，苦行跟成佛無關」；但適度苦行是戒律，令慾望不叢生〔行720〜723〕。法師以此證：斷念、虐待身體皆非正法。

### 4.7 昨日佛陀非今日佛陀・250歲老人〔行370〜372、742〜761〕
有人來感謝佛陀「你昨天幫我很多」，佛陀說「昨天的佛陀跟今天的佛陀是不同的佛陀」——站在色相角度，一秒前的你已非一秒後的你（身體細胞在變、心態在變）〔行370〜372〕。又法師述近見網路一則：大陸有人自稱活250歲（從康熙到今），歷經三藩、乾隆十大戰役、鴉片戰爭、英法聯軍、八國聯軍、抗戰、內戰、文革……「一切歷史全部是滄桑」；「若有神仙叫我活250歲——我才不要」，因為學佛求的是自性之心，「朝聞道，夕死可矣（道就是佛、就是心）」〔行742〜761〕。

## 8. 本經解義（妄盡還源觀 T1876 逐段）

> §8 依論文段落順序前進；§3/§9 可按主題排列。本講法師朗讀並詳釋 T1876 兩大段：**入五止門序**（第15頁）與**第一止 照法清虛離緣止**（第16頁）。

### 8-A 入五止門序

| T1876 原句〔行〕 | ✓CBETA T1876 | 體佛法師釋義（逐句） | 在本論脈絡之定位 |
|---|---|---|---|
| 自下攝用歸體入五止門。五止門者，謂依前能行四德之行，當相即空，相盡心澄而修止也〔行325〕 | ✓ | 五止由前四德之行而來，「當相即空、相盡心澄」即是止 | 由二用四德「攝用」歸「一體」，開五止之總標 |
| 所言入者，性相俱泯，體周法界，入無入相，名為入也〔行325〕 | ✓ | 「入」是無入而入、不出不入、本入本住；本來就入、本來不用入〔行294〜312〕 | 先破「入」字二元義，全段樞紐 |

| 《起信論》云：「若有眾生能觀無念者，」是名入真如門也〔行332、417〕 | ✓ T1666 | 眾生能觀「無念」即入真如門；此為五止全部基礎〔行417〜418〕 | 轉入「無念」專題 |

**義理深入（8-A）**：法師強調法藏在正講五止之前，先花大力氣精解一個「入」字，是全論最值得尊敬處〔行387〕——因為若把「入止」理解成二元化的「進入」，整套止觀就成了向外攀求。法藏的立場是「妄盡還源」：**妄盡就是知道本來沒有妄，故不需要還源、當下即還源，因為本來就還源**〔行345〕。所以「入五止」不是去獲得五種本無的境界，而是認得「本來就住在此」。法師把「入諸無相定」的無相接到「平等即彌陀」〔行358〕，又把「敬禮無所觀」直接連到**普賢十大願前二（禮敬諸佛、稱讚如來）**——諸佛即自性，故「敬禮無所觀」就是禮敬自性〔行362〜364〕；並以文殊（智/嚴/無能所）莊嚴普賢（十大願）共成毘盧遮那來釋「華嚴」二字〔行360〜362〕。最後落到《起信論》「能觀無念」，正是要接六祖對「無念」的定義，作為進入第一止的鑰匙。

### 8-B 第一止 照法清虛離緣止

**義理深入（8-B）**：法師把第一止的鑰匙全押在「照」字上，並宣稱《心經》即此止的總綱領——「照見五蘊皆空」的「照」正是「照法清虛離緣」，照見即止住苦，故「你就能度一切苦厄，就是止」〔行776〕。他用一組層層辨析把「法」拆開：**世界（事物類/陽，摸得到、生滅、戲論）→ 入心成蘊（陰，摸不著）→ 五蘊即色受想行識（物質+精神）→ 法界（心，不生不滅）**〔行808〜820〕，指出佛陀不探討「事物類」（那是印度教、四大文明、乃至孔子五倫所討論的世界事），佛陀只探討「蘊」，並把世界最後歸於法界（應觀法界性，一切唯心造）〔行784〜817〕。再以「真諦=鏡體空寂／俗諦=鏡影似有即空」證成能所皆空、性相一如，最後標舉：**開悟是見地不是修來的**——神通（目犍連神通第一仍不敵業力）、會飛會跳都是雕蟲小技，不離生死〔行1005〜1008〕；真正開悟是這顆心「不再疑惑」，並分**解悟→證悟**（順逆兩境皆一如當下即證悟成佛）〔行1021〜1023〕。以《維摩經》「法不屬因，不在緣故」作壓軸，點明心能顯物「不在因也不在緣，法爾如是」〔行1025〕。

## 9. 經證（全部直引，逐句對 CBETA 核驗）

**《修華嚴奧旨妄盡還源觀》T1876（入五止門序，第15頁）** — ✓ CBETA T1876〔行325〜332〕
> 自下攝用歸體入五止門。五止門者，謂依前能行四德之行，當相即空，相盡心澄而修止也。所言入者，性相俱泯，體周法界，入無入相，名為入也。《華嚴經》云：「如來深境界，其量等虛空，一切眾生入，而實無所入。」又準《入佛境界經》云：「入諸無相定，見諸法寂靜。常入平等故，敬禮無所觀。」此乃一切眾生本來無不在如來境界之中，更無可入也。如人迷故，謂東為西，乃至悟己西即是東，更無別東而可入也。眾生迷故，謂妄可捨，謂真可入；乃至悟已，妄即是真，更無別真而可入也。此義亦爾，不入而入，故云入也。何以故？入與不入本來平等，同一法界也。《起信論》云：「若有眾生，能觀無念者，」是名入真如門也。

**《妄盡還源觀》T1876（第一止，第16頁）** — ✓ CBETA T1876〔行732〜734〕
> 一者、照法清虛離緣止。謂真諦之法本性空寂，俗諦之法似有即空。真俗清虛，蕭然無寄，能緣智寂，所緣境空，心境不拘，體融虛廓，正證之時，因緣俱離。《維摩經》云：「法不屬因，不在緣故。」依此義理，故云照法清虛離緣止也。

**《大方廣佛華嚴經》T0279（如來境界品，文殊師利菩薩以頌答）** — ✓ CBETA T0279〔行325、354〕
> 「如來深境界，　其量等虛空，
> 一切眾生入，　而實無所入。」

> ※師讀作「其量等虛空，如來深境界」（前後句倒），義同，經文以「如來深境界」在前為正〔行325〕。

**《入佛境界經》（智炬如來三昧經／T1876 引）** — 依 T1876 引文 ✓〔行327〕
> 入諸無相定，見諸法寂靜。常入平等故，敬禮無所觀。

**《大乘起信論》T1666（心生滅門·究竟覺）** — ✓ CBETA T1666〔行417〕

## 10. 法脈會通

### 10.1 一體→二用→四德→五止 的下貫（本講在全論的位置）

```
自性清淨圓明體（一體）
   │ 碰緣起用＝緣起論／性→心
   ▼
二用：海印森羅常住用 ＋ 法界圓明自在用
   │ 心之三功能
   ▼
普周法界 ── 出生無盡 ── 含容空有（色不異空）
   │
   ▼
四德：隨緣妙用(大悲大智) ─ 威儀有則(屍羅四義) ─ 柔和質直 ─ 代眾生苦
   │「攝用歸體，相盡心澄而修止」
   ▼
五止（本講入其一）：① 照法清虛離緣止 …②③④⑤（待後講）
```
**連結要點**：五止不是新境界，而是把前面「二用四德」之行「攝用歸體」——故「入」即「本入」，第一止之「照」即《心經》「照見五蘊皆空」〔行325、764〕。

### 10.2 三密／咒語 → 自性 的會通（前導段）

```
身 ── 嗡（口念真言起處）        法界共同語言（咒＝陀羅尼＝成佛最後結論）
口 ── 阿（母音／自性本元）  ┐
意 ── 吽（心·保任）        ┴─ 嗡阿吽＝普賢王如來自性三字
                         嗡嘛呢唄咩吽：嗡(身)─呢(摩尼寶珠＝蓮花)─吽(心保任如蓮清淨)
```
**連結要點**：一切咒語（大悲咒「南無喝囉怛那哆囉夜耶」、蓮師心咒「班雜咕嚕貝瑪悉地吽」）都是總持；但「只念不觀＝口唸彌陀心散亂」，重點在觀照其理〔行108〜144〕。此段屬師之教說，非CBETA可證，見§12。

### 10.3 無念的等式鏈

```
能觀無念(起信論) ＝ 於念而無念(壇經) ＝ 不斷念而不執念 ＝ 真如自性起念·真性常自在
        ↑對治：斷念(臥輪「能斷百思想」)＝加繫縛＝修行最大障礙〔行655、677〕
```

## 11. 日常實踐（可操作）

1. **念咒/念佛先觀理再持誦**：念「嗡嘛呢唄咩吽」「阿彌陀佛」前，先觀「身心如蓮花清淨、保任這一體」，一路保任下去，才是三密相應；否則「喊破喉嚨也枉然」〔行99、144〕。
2. **不斷念、只不執念**：念起時「只要不執著」即回歸真如本性，切莫學臥輪「能斷百思想」去壓念——斷念是修行最大障礙〔行657〜663、677〕。
3. **盡人事、聽天命、沒煩惱**：隨緣要認真（盡責、不馬虎）但不當真（他不謝你、毀謗你也沒關係）；不盡人事會落消極，非佛法〔行222、239〜241〕。
4. **忿怒向內**：把「忿怒」轉為對治自己貪瞋癡的力量——「我們一直原諒自己、卻不原諒別人」，要對自己的貪瞋癡現忿怒〔行257〜259〕。
5. **以「照」治苦**：遇境時作觀——外境入心即成「蘊（影像）」，影像是假、能煩惱的攀緣心也是假，「照見五蘊皆空」則事物類干擾不了你，這輩子平安如意〔行621〜623、874〜880〕。
6. **認無量壽，放百年壽**：認得自性即無量壽，則百年壽「緣來則應、能過就好」，飢來吃飯睏來眠、天冷多穿一點〔行172〜174〕。
7. **見地重於苦行**：拜佛、朝山、懺法、佈施皆可依習性隨緣而做，但成就全在「見地」；別把韻律操當功德——「知道所有一切是假，在假中隨緣妙用，這當下才叫功德」〔行895〜907、983〜988〕。
