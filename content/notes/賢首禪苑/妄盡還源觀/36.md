## 1. 本講概要

本講是《妄盡還源觀》36講的**圓滿結業**，講的正是 T1876 本文的**最後總結段**（〔行202〕起讀第24頁：「舉一為主，餘五為伴……智者當勤學」）。體佛法師以兩條主軸收束整部：

- **經文主軸（§8 的脊梁）**：賢首國師把全觀的 **一體→二用→三遍→四德→五止→六觀** 六重觀門，最後統攝為「**舉一為主、餘五為伴，隨入一門即全收法界**」，並以圓珠六孔為喻；再標明六門「**名目無定**」，各得一「**三昧門**」之名（海印炳現／華嚴妙行／塵含十方／四攝攝生／寂用無礙／佛果無礙）；末以「余雖不敏，素翫茲經」自謙，頌曰「備尋諸教本，集茲華嚴觀，文約義無缺，智者當勤學」〔行202-220、354-357、518-520、935-948〕。

- **法脈主軸（§4／§5）**：因是圓滿，法師從**華嚴五祖／七祖**（杜順─智儼─法藏─澄觀─宗密＋印度馬鳴、龍樹）講起，說明「賢首禪苑」為何以妄盡還源觀為第一部經、以及**華嚴與禪合流**的道理，接著預告下一部要講菩提達摩的《四行觀》《血脈論》〔行63-102〕。

貫串全講的**一個核心判準**：一切唯心所現，**入法界即佛、入世界即凡夫**；「正」就是入法界，「邪」就是落世界，悟則剎那，迷則千百劫〔行403-422、441-446〕。法師並以自身求道六十年、得癌讀《壇經》而豁然的親證作結〔行949-961〕。

## 4. 故事・公案

**（一）馬鳴菩薩以「入法界」判大乘真偽・造《大乘起信論》破有相**〔行102-147〕
大乘佛法從萌芽走向全盛時，雖經題冠「如是我聞」，仍有人懷疑《華嚴》《法華》《楞伽》《楞嚴》《大寶積》範圍太廣、結集時未收，是否佛陀親口所說。馬鳴菩薩指出：佛陀的化報身雖是四大假合之肉身，但**法身無差別**，藉報化身講出的究竟法都是佛說——判準只有一個：**「有沒有入法界」**。入法界才是佛所講，不入法界縱有再多考據也是外道、偽經（二千五百年前無從考證誰講）。大乘廣立諸佛菩薩名相以應眾生根器，是大悲的實踐，但眾生易生偶像崇拜、著相；馬鳴憂此，遂造《大乘起信論》，強調「**無相才是大乘，有相非大乘**」，凡所有相皆虛幻，無相即自性清淨圓明體、即佛性。（法師以此故事作圓滿「開頭呼應結尾」的引子。）

**（二）龍樹從龍宮取出《華嚴》**〔行147-149〕
馬鳴之後是龍樹菩薩，從龍宮取出《華嚴經》。印度此二祖（馬鳴、龍樹）加中國五祖，合稱華嚴七祖；此二祖又是禪宗印度28祖中之二祖——由此可證**華嚴與禪合流、同源**。

**（三）歌利王割截身體・佛無四相**〔行305-323〕
法師講「證實相，剎那除去阿鼻業」時，舉佛陀往昔為忍辱仙人被歌利王節節支解的公案：世人以為沒有比割裂身體更侮辱者，但佛陀「侮辱我的人是被侮辱的、我也是無生，那只是身體」，沒有一個我被侮辱、也沒有一個人來侮辱我。憑此無四相，忍辱功德使釋迦超越本應先成佛的彌勒，彌勒反成其學生，待龍華三會方成佛。（《金剛經》記載，見 §8/§9。）

**（四）龍女八歲頓成佛・善星比丘墮地獄**〔行432-461、573-576〕
永嘉《證道歌》「是則龍女頓成佛，非則善星生陷墜」。**龍女**是旁生道（龍非人類），八歲頓成佛，因她本來就是佛、知入法界事，「十信道圓，一念該於佛地」——不必考據她生於何年、幾歲成佛，那是「愚痴的佛學家」所為。**善星比丘**能背誦三藏十二部、是佛陀的兒子（法師另說善星往生後才轉世為阿難，屬法師之說），卻因入邪見終墮地獄。臨終還與佛辯論、罵父「你不能救我」，佛言：「我不是不能救你，因為你的心沒辦法救你自己」——**往生去處是自己走的**（六趣＝六走、六種取向），佛只是勸告。（表法：不重考據，重是否入正知見。）

**（五）六祖與陳惠明・不思善不思惡**〔行414-419〕
《六祖壇經》開悟第一大公案：四品將軍陳惠明追至大庾嶺求法，六祖曰「不思善、不思惡，正與麼時，那箇是明上座本來面目？」法師點出其要旨即**「去邪見、入正見」**——不落世界的善惡二邊而入法界。

**（六）梁武帝問達摩「有無功德」**〔行408-411〕
法師舉梁武帝與菩提達摩對話：梁武帝造寺度僧卻「無功德」，因為他**沒有入法界**；入世界才有善惡（善事叫善德、惡事叫惡行），入法界才是真功德。

**（七）佛陀誕生・天上天下唯我獨尊・浴佛表法**〔行530-549〕
史學家考據佛陀在藍毘尼園誕生是否會走路、兩派相爭，法師斥為「人類妄念無聊到這個程度」，與成佛無關。佛一手指天一手指地、云「天上天下唯我獨尊」，並非色身之尊，而是指**內心那個創造天上天下、毀壞不了的心（即上帝、即自性清淨圓明體）**。浴佛所浴是「**小孩子佛**」——剛知道佛性故如新生；用「花」是因古文花＝法（花跟法同字），以**法水**洗習性，令佛性顯現；踏七步、蓮花＝清淨圓明、七＝圓滿。每次聽經即是一次浴佛。

**（八）關公伽藍・韋馱菩薩表法**〔行466-476〕
佛寺進門有伽藍、韋馱。**關公（伽藍菩薩）**是世界真實人物（《三國志》可考生平），拿關刀（人類武器），表「護教」；**韋馱菩薩**無生平、是虛擬人物、表法，拿金剛杵（法界武器），杵表「**凡所有相皆可壞**」——因相皆是心變、皆假，故皆可壞；無相者才不可壞。

**（九）淨空老和尚三師兄弟同年之厄**〔行760-769〕
近代大德淨空老和尚，早年三位同年齡的師兄弟，李炳南老居士曾預言三人同一年（45歲）死。其一因害怕，去大溪學密得神通（能見冥界眾生傍晚三四點出、卯時回去，與人作息顛倒），仍45歲死，修密救不了命；另一自搭公車去榮總掛號候診，即在候診處往生。淨空老和尚那年也得一場大病，但他**堅持講經、代眾生苦**（把經義與眾生分享），今96歲（民國16年生，與法師老菩薩同年）。

**（十）趙州和尚・得來全不費工夫**〔行393、695-696〕
趙州和尚煩惱一輩子求成佛，終有一天知道**本來是佛**，故講「得來全不費工夫」——開悟者會跳起來（原來本有的那個就是），完全篤定毫不猶疑，即是入地。

**（十一）貫馗法師出家後作偈供養師父**〔行798-800〕
義工菩薩複習五止六觀前，貫馗法師先向師父請罪（出家後睡眠不足、記憶大退），恭念自作一偈：「出生無盡釋體佛，妄盡還源觀空有，一體二用變化億，弗來只是水月宴，佛恩師慈無以報，五止六觀為哪般，百千萬劫今已遇，我終曉解如來佛。」（藏頭表對師恩與法義的領受。）

**（十二）體佛法師自述六十年求道與得癌讀《壇經》而悟**〔行499-503、949-961〕
法師自言63歲，自小即想成佛，凡高僧大德做過的苦行都想做：斷食七天（是折磨、走不動）、頭上六個戒疤、全身是疤，做完「又怎麼樣呢？見地也沒提高」。曾隨師父〔廣欽老和尚〕學念佛不解其義、到美國隨〔宣化上人〕學密（蓮師專修法，手印咒語觀想皆熟），皆不能成就。**直到有一天觀念返轉、剎那入法界**；最後得癌症時重讀《六祖壇經》，於「若不識本心，學法無益」一句恍然大悟——原來六祖是這樣成佛的，此後「法界一通，千經萬典」再難不倒他，諸經好像諸佛為他而宣說。

**連結要點**：六門名目無定，但一線貫穿——**全部是「三昧門」，三昧門＝本心＝「以無所受而受諸受」**（鏡受萬物而不抉擇不取捨）。故入哪一門都全收法界、都入佛地〔行659、675、921〕。（校勘：T1876 line 47 作「多身入一**境**像觀」，法師依鏡喻讀作「鏡像觀」，二形canon皆見於 line 47/133。）

### 義理深入

**其一・「舉一為主餘五為伴」是全觀的收攝法。** 賢首把辛苦鋪陳的六重觀門，最後不立高下、不排先後，而以「主伴互現」統之：任一觀為主、餘五為伴，隨入一門即全收法界（圓珠六孔喻）。法師點出此即**帝網觀**的落實——依報可作正報、正報可作依報，光光相映；其所以能如此，是因六門「全部都是心」，心涵蓋全部，攝境歸心是心、從心現境也是心，乃至智身影現、多身入一無非是心〔行237-243〕。這一步把「觀門」從次第修法翻轉成「**當下全收**」的頓門，是全觀落在「圓」字上的關鍵。

**其二・「一際絕其始終」與「攝多生於剎那」印證頓悟。** 法師以《楞嚴》「當處出生、隨處滅盡」釋心相同時：相不是慢慢產生、也非照到才形成，緣現即當下出生，故無前後、無始終〔行231-235〕。由此「初心正覺攝多生於剎那、十信道圓一念該於佛地」——**入信位那一剎那道即圓滿**，因為本來就圓，這正是佛法「立地成佛、回頭是岸」的教理根據〔行424-429〕。是則龍女八歲頓成（本來是佛）、非則善星背三藏而墮（入邪見），差別只在「入正見／入邪見」一線〔行432-446〕。

**其三・「名目無定→皆三昧門」把六門收歸本心。** 賢首明言六門「名目無定，隨德立名」，一體得名海印炳現、二用得名華嚴妙行、三遍塵含十方、四德四攝攝生、五止寂用無礙、六觀佛果無礙〔行137〕。法師反覆強調：**這六個名字後面都是「三昧門」，都沒有離開本心**；三昧的中文最好解釋是「以無所受而受諸受」——心如鏡，受諸受（照萬物）而心體毫不抉擇、毫不取捨、本自清淨〔行593-595、659、701〕。凡夫則「有所受、受諸受」——把幻相當真而愛憎取捨，遂成無明輪迴〔行597、923〕。此一句把全觀的修證落到一個可操作的觀心口訣上。

**其四・結頌「文約義無缺，智者當勤學」與親證。** 賢首自謙「余雖不敏，素翫茲經，聊伸偶木之文，式集彌天之義」，頌曰遍尋三藏皆集於華嚴之法界觀，而法界觀即「應觀法界性、一切唯心造」的那顆心〔行943-948〕。法師以自身六十年苦行無果、得癌讀《壇經》「若不識本心，學法無益」而剎那入法界作結——**「文約義無缺」的驗證，正在於一旦入本心，千經萬典如諸佛為己而說**〔行959-961〕。

## 10. 法脈會通

**（一）華嚴七祖 ＝ 禪宗印度祖師：合流一體**

```
  釋迦（教主·說華嚴）
        │
  ┌── 馬鳴（起信論·破有相）──┐   ← 禪宗印度28祖之一
  │                          │
  └── 龍樹（龍宮取華嚴）──────┘   ← 禪宗印度28祖之一
        │  （印度二祖）
  杜順→智儼→法藏(賢首·本經)→澄觀(清涼)→宗密(圭峰)  ← 中國五祖
        │                                    │
   法界觀                            與禪宗正式結合（禪不離華嚴）
        │
   達摩東來為初祖→…→六祖（下一部要講：四行觀·血脈論）
```
連結要點：馬鳴、龍樹既是華嚴七祖之首二，又是禪宗印度28祖之二——**華嚴與禪本是一體、合流**；故「賢首禪苑」以《妄盡還源觀》為第一部經，講完接講達摩之禪〔行86-102〕。

**（二）圓覺三法・淨土一心不亂・禪明心見性・華嚴大開圓覺 ── 同一句話**

| 宗／經 | 法門名相 | 對應六門/本心 | 〔行〕 |
|---|---|---|---|
| 《圓覺經》 | 奢摩他(止)／三摩缽提(觀)／禪那(寂滅無生) | 隨意一門修即成佛，如六門隨入一門 | 〔行248-351〕 |
| 淨土宗 | 一心不亂（念阿彌陀＝念本心＝三昧） | 深信「我就是阿彌陀＝三昧」，境來只是幻影 | 〔行599-603〕 |
| 禪宗 | 明心見性 | 見自性清淨圓明體 | 〔行603〕 |
| 華嚴 | 大開圓覺 | 一體二用三遍四德五止六觀皆三昧門 | 〔行603〕 |

連結要點：法師明言「都是同樣一句話」，賢首把它稱為「三昧門」＝本心〔行603-604〕。

**（三）三昧口訣：以無所受而受諸受**

```
   性（自性清淨圓明體·無形）
        │ 遇境
        ▼
   心（本心＝鏡＝三昧門）── 受諸受（照萬物） ── 但「無所受」（不抉擇取捨、本自清淨）＝入佛地
        │ 若著相（只看影像不見鏡）
        ▼
   妄心 ── 愛憎取捨 ── 無明 ── 輪迴
```
連結要點：正常的心（佛地）＝「以無所受而受諸受」；扭曲的心（凡夫地）＝有所受而受諸受。凡夫本是佛地，只因「妄認自己是凡夫」〔行593-597、681-683、921-923〕。

**（四）表法判準：佛法（法界·無相）vs 佛教（世界·有相）**

| 屬性 | 佛法／法界 | 佛教／世界 |
|---|---|---|
| 人物 | 文殊·龍女·善財·韋馱（表法·虛擬） | 舍利弗·須菩提（真人）·關公伽藍（可考） |
| 相 | 無相·心法 | 有相·護教 |
| 武器（表法） | 韋馱金剛杵＝凡所有相皆可壞 | 關公關刀＝人類武器 |
| 判準 | 入法界 | 入世界 |

連結要點：不可對表法人物作歷史考據（考龍女幾歲、善財父為誰皆愚痴）；佛教是為傳佛法而立，二者不可偏廢〔行459-476〕。

## 11. 日常實踐

1. **保任「以無所受而受諸受」**：境界現前時，練習如鏡照物——照它、用它，但不抉擇、不取捨、不著相；相來即用、用了就丟〔行593-595、722-726〕。
2. **把生活當大富翁**：盡人事（很努力玩/工作）＝隨緣，聽天命（知都是假、不動得失心）＝妙用；坐牢破產皆不害怕，當下現大悲（陪玩）與大智（無所受）〔行726-746〕。
3. **五止即放下，放下靠見地不靠苦修**：不是修到影像變3D電影才放，而是知一切假故當下能放；若放不下，是「不知它是假」，補的是見地〔行812-820〕。
4. **念佛＝念本心（三昧）**：往生時任何境界出來，只深信「我就是阿彌陀＝我的三昧、永恆存在」，不期望佛來接引，即當下見彌陀、一心不亂〔行599-603〕。
5. **勤學而非只讀誦**：把《妄盡還源觀》勤學、瞭解法義，然後**保任住一體的自性清淨圓明體**（智者當勤學）〔行947-949〕。
6. **修行是修習性、非修佛性**：佛性本自具足，用法水（經典、聽經）洗去邪見著相的習性，令佛性顯現（即「浴佛」的真義）〔行538-550〕。
7. **知幻即離**：《圓覺》要「知幻」（知它是假）即離，不是要去「離幻／滅幻」——離幻仍是凡夫〔行933-935〕。

- **一參問**：賢首說「名目無定」六門皆是「三昧門（本心）」，法師以「以無所受而受諸受」為三昧的中文最佳解釋——那麼當你此刻讀這行字，是「有所受而受諸受」，還是「無所受而受諸受」？這一念之差，即是入世界與入法界之分〔行593-595、921-923〕。
