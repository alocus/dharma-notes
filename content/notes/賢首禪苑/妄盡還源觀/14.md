## 1. 本講概要

本講是「一體二用三遍」框架的收束之講——體佛法師把「三遍」最後一遍「**一塵含容空有遍**」講完，並以《寶性論》「三疑」為道前菩薩／道後菩薩的分水嶺作結。開宗即定調：**佛法是「內在」不是「外在」**，凡聽到「法」字全講內心；「心外求法為之外道」，我們學佛卻都在找外在〔行65-73〕。《妄盡還源觀》雖是賢首國師「論述」，卻是把整部《華嚴經》八十萬字濃縮成四五千字、大徹大悟的「佛知見」，看《妄盡還源觀》即等於在［靈山］會上聆聽佛陀法要〔行76-78〕。

法師以近半小時鋪陳其**法脈地位**：永嘉禪與賢首國師同代（佛佛道同），六祖頓禪由南方廣州往北發展；武則天以帝王之尊印可六祖為正統、尊崇賢首國師，「華嚴宗其實是如來禪」在北方生根；此心法四十二代傳到賢首禪苑〔行80-194〕。

主體是三段本經消文：

1. **一塵出生無盡遍——十對問答**：就「一塵」開演染／淨、真／俗、生死／涅槃、煩惱／菩提、小乘／大乘〔行196-208〕。
2. **一塵含容空有遍**：塵無自性即空、幻相宛然即有；「觀色即空成大智而不住生死，觀空即色成大悲而不住涅槃」，色空無二、悲智不殊〔行545-547,760-988〕。
3. **《寶性論》三疑**：道前菩薩對真空妙有的三種誤解——疑空滅色（斷滅空）、疑空異色（色外空）、疑空是物（取空為有）；除三疑即是道後菩薩、法界菩薩〔行547,989-1061〕。

貫串全講的核心譬喻是**鏡子**：心如明鏡，鏡能顯相、相即是鏡（染淨、空有、生死涅槃只是「見地不同」）；法師並以自身罹骨癌血癌、道證法師畫自性彌陀、廣欽老和尚「無來無去」等當代見證，證「唯心所現、本無生死」〔行266-295,640-666,880-916〕。

## 4. 故事・公案

### 4.1 大梅法常——「梅子熟了」〔行121-137〕
上根器的大梅禪師不斷參禪，最後見**馬祖道一**，馬祖只告訴他一句「**即心即佛**」——「心就是佛」。大梅當下如**趙州**和尚般生起「踏破鐵鞋無覓處，得來全不費工夫」的感慨，從此大徹大悟。三年後，馬祖要考驗他，派弟子去傳話：「師父現在改講『**即心非佛（非心非佛）**』。」大梅聽完立刻回：「這老禿驢腦筋退化了，隨他去講『心不是佛』，我只管『即心即佛』！你回去告訴他。」使者回報，馬祖聽完只說一句：「**梅子熟了**」——意即大梅已徹悟、再不會被言句轉動，成熟了、定了。法師以此證頓悟成佛、「回頭是岸」真實不虛〔行121-137〕。（大梅法常、馬祖道一皆唐代禪師，公案見《景德傳燈錄》等禪錄；此處為師述。）

### 4.2 武則天召六祖、神秀——印可頓禪為正統〔行156-172〕
賢首國師《妄盡還源觀》深深影響最有權力的**武則天**；她寫下開經偈後，晚年驀然回首，覺得南方六祖所傳與賢首國師「不是一模一樣嗎」。武則天真是有見地的皇帝，把賢首國師請來坦白問：「禪宗自**五祖**以後分南北兩宗，一頓悟一漸修，哪一個最契如來真實義？」賢首國師毫不思考答：「**六祖慧能是正統**。」武則天再召**神秀**（比慧能大三十歲、活到百餘歲），問他師父真正的衣缽傳給誰；神秀大氣度地答：「陛下，真正的衣缽傳到南方的慧能。」兩大訊息之下，武則天派使者兩度到南方（光孝寺／已移［國恩寺］，屬［廣州］［新州］鄉下），賜琉璃（玻璃／水晶）缽及珍貴祖衣，請慧能北上受供。慧能兩度拒絕，只回一句：「請陛下不要勞心，慧能年紀已大、四大已衰，不堪勞累；**可是陛下當你想到貧僧慧能的剎那，慧能就出現在你的面前了。**」武則天聽完掉淚：「我不虛此行。」不久武則天往生〔行156-170〕。法師點題：「不用色身到，只要想到我就到」——這是截然的心法、心的作用；一切唯心造，物質能束縛身體卻束縛不了心，心能普周法界〔行171-172〕。

### 4.3 西遊記——無字真經與敲木魚的由來〔行445-483〕
有人告訴法師，台灣密宗〔華藏上師〕（法脈：**諾那上師**→〔華藏上師〕→〔智敏慧華上師〕）曾說《西遊記》是他前世**吳承恩**所作（法師言明「這不是重點」）。重點是《西遊記》其實是一部「見性的經」：孫悟空、唐三藏歷經九九八十一難到達［靈山］大雷音寺見如來——「靈山」就是我們的心（空），「大雷音」就是妙有（要透過妙有、語言文字才能傳真空之法，故「空有不二」）。佛陀說他們只經過八十難、還差一難，先給了一部**無字真經**；唐三藏嫌無字又折返，佛陀說「**無字的經才是真經**」，因東土（唐朝）眾生福薄，「大乘無文字、小乘有文字」。三藏堅持要有字真經，佛陀便給；回程過**通天河**，載他們的「神龜（烏龜）」也擋不住狂風，經卷全落海底、被魚吞食。孫悟空到海底捉魚、以棍敲魚頭，魚一直吐出經卷——「出家人敲木魚扣扣扣就是由此而來」。法師點題：敲木魚是提醒我們「語言文字只是表達、重在涵義」，不可執著經典文字（佛涅槃時交代「不能執著經典上的語言，但要懂經典的涵義」）〔行445-483〕。（此為坊間演義與師述，非史實考證。）

### 4.4 目犍連救釋迦族——碗中血水〔行898-907〕
神通第一的**目犍連**（尊者），能遨遊任何地方。當**琉璃王**要屠滅釋迦族時，目犍連不聽佛陀勸阻，以神通把要被殺的釋迦族靈魂蓋在一個碗裡、送上［忉利天］，對佛陀說「你的後代都沒有死」。佛陀說「你打開碗看看」——碗一打開，全是血水〔行898-901〕。法師點題：會死的是肉體，我們要的是靈性不是身體；求身體最後仍是死路一條，佛陀不是保佑家族不死，而是要告訴我們覺性〔行893-907〕。（釋迦族滅於琉璃王事見律藏／阿含；碗中血水為此一系公案的傳講，師述。）

### 4.5 廣欽老和尚——「無來無去，無代誌」〔行880-916〕
〔廣欽老和尚〕也死了、也留下舍利子。法師藉此破斥：舍利子的目的不是要人膜拜、求靈波保佑（那是走入鬼神相法），而是「告訴我們真有其人」；就像六祖留金身、佛陀示現舍利，是為證明真有其人講過這些話，重點在「祂的經典講的話讓你明白」，不是死人的骨頭〔行880-893〕。廣欽老和尚偉大，不在「六十年不吃不睡」（印度瑜伽外道也這樣，木頭石頭幾千年更久，何足崇拜）；偉大在他臨終說「**無來無去，無代誌**」——沒說「阿彌陀佛來接我」（那還有來去、境界還低），這正是我們的空性、是「這面鏡子」〔行912-916〕。

### 8B 義理深入

**（一）十對問答＝一心的十種見地。** 本經最精要處，是賢首國師把染淨、真俗、生死涅槃、煩惱菩提、小乘大乘「十對」全繫於同一「一塵」而分判。體佛法師的釋義軸心是：這十對「不是十樣東西、也不是兩邊」，而是**對同一心（同一鏡）的十種見地**。同一鏡相，執它為獨立實有、被它牽動煩惱，就是染／俗／生死／煩惱／小乘；照見「相即是鏡、相盡空無有實」，就是淨／真／涅槃／菩提／大乘。所以法師反覆說「淨跟染只是見地不同而已，與修行毫無相關」〔行282-290〕，並把全觀收成一句對舉：一邊「全部都是**本**」（眾生本真、本淨、本涅槃、本菩提、本大乘），一邊「全部都是**幻**」（幻染、幻俗、幻生死、幻煩惱、幻小乘）；「把幻當真＝迷，知真相＝悟」〔行528-534〕。這正是賢首國師「就一塵字而為解釋」的用意——一切法門無盡海，只在一心上轉染成淨。

**（二）含容空有＝大智大悲的根據。** 「觀色即空成大智而不住生死，觀空即色成大悲而不住涅槃」是本遍的心臟。法師把它講成菩薩的存在方式：入生死而見空（知生死是幻相）→不被生死折磨＝**大智**（般若）；證涅槃而不住涅槃（願淪落生死度眾生）＝**大悲**。二乘人「住涅槃」是「偏空」（只有一半，不是一真法界）；凡夫「住生死」；唯大乘「不住生死、不住涅槃」，故「色空不二、悲智不殊」，當下即普賢行、文殊智、觀音慈悲從心顯發〔行923-988〕。法師特別強調此句「真正講出佛陀的大悲心」——空不礙有，故證空者仍入五濁惡世度眾。

**（三）《寶性論》三疑＝道前／道後的分水嶺。** 法師用「鏡子」把三疑講到人人可懂：斷滅空＝只認鏡子、不認鏡能顯相；色外空＝認鏡也認相、卻說相與鏡無關；空是物＝把空當成一個實物。三者都是「愚痴（誤解）」，連小學生都知道「鏡中相跟鏡子有關」，大人卻跨不過（「雖智不能解，經典無人說」）。本經「今此釋」給出正解：色是幻色不礙空、空是真空不礙色——空有本自不二。除此三疑，「即是道後菩薩、即見性、即是法界菩薩」〔行1056-1061〕。法師以此恭喜聽眾「今天你們都成為法界菩薩了」，把一部華嚴奧旨落到當下一念的見地轉換上。

## 10. 法脈會通

### 10.1 一句本經如何被多部經論交織詮釋

本講的樞紐句是本經「觀色即空成大智而不住生死，觀空即色成大悲而不住涅槃；以色空無二，悲智不殊」。法師以下列經論為輻條詮釋這一句：

```
                     本經 T1876：觀色即空／觀空即色，色空無二，悲智不殊
                                        │
        ┌───────────────┬──────────────┼───────────────┬───────────────┐
   《心經》T0251     《金剛經》T0235   《寶性論》T1611  《華嚴經》T0279   《證道歌》T2014
   色不異空          歌利王割截        道前菩薩三疑     一切唯心造        頓覺了如來禪
   空不異色          無四相            (揀斷滅空／       (色空皆心所現)    六度萬行體中圓
   (色空互即之        (相的折磨＝忍辱     色外空／取空為有)                 (證空即具萬德，
    根本經證)         仙人＝我們的心)   →除疑即法界菩薩                    悲智本圓)
```

| 本經本句 | 法師援引 | 該引文如何詮釋本句 | 核驗 |
|---|---|---|---|
| 色空無二 | 《心經》色不異空、空不異色〔行929-972〕 | 直證「色從空變現、色空互即」，是「觀色即空」的般若根據 | ✓ T0251 |
| 觀色即空成大智而不住生死 | 《金剛經》歌利王／無四相〔行612-755〕 | 相一直來（歌利王）＝生死之逼；無我相→無人相→無眾生相→無壽者相＝不住生死之大智 | ✓ T0235 |
| 三疑除盡方為真實 | 《寶性論》三疑〔行999-1061〕 | 揀去斷滅空／色外空／取空為有，才是「色空無二」的真實見地 | ✓ T1611（本經引） |
| 一切皆心所現 | 《華嚴經》一切唯心造〔行1034〕 | 色與空俱是「應觀法界性」的心之所現，故不落內外 | ✓ T0279 |
| 悲智不殊、體中圓 | 《證道歌》六度萬行體中圓〔行943〕 | 證真空即具萬德（六度），故大智大悲本自一體、不假次第 | ✓ T2014 |

```
[華嚴/賢首宗傳承]

   └→ 永明延壽(宗鏡錄) ─→ 明·高原明昱(萬曆,法相+華嚴合流)
        └→ …清…民國 ─→ 40代 慧三老和尚(賢首宗=華嚴宗+法相宗/慈恩宗,福慧寺)
```

連結要點：法師以此鏈說明「賢首禪苑」命名由來（華嚴＝賢首宗），並解釋為何開講即講《妄盡還源觀》——它是賢首國師「最精華」、把如來真實義「佛家的富貴」顯示出來的一部濃縮綱要〔行182-194〕。

### 10.3 三組等式（本講反覆會通）

```
① 頓禪的心髓：   即心即佛 ＝ 涅槃妙心 ＝ 正法眼藏 ＝ 不立文字直指人心 ＝ 佛性(在凡不減在聖不增)
② 自性彌陀：     阿彌陀佛 ＝ 我心(彌陀即我心/我心即彌陀) ＝ 無量光(空間無礙)＝無量壽(時間無礙)＝此方淨土
③ 空有不二：     真空 ⇄ 妙有 ；靈山(空) ⇄ 大雷音(有) ；鏡(空,不生不滅) ⇄ 鏡中相(有,生滅)
```

## 11. 日常實踐

1. **以「見地」轉染成淨，不向相上修。** 遇煩惱時問自己：我是把「鏡中相」當成獨立實有（染），還是照見「相即是鏡、相盡空無有實」（淨）？差別只在一念見地，不在拜山、布施、做懺的多寡〔行282-290,334-336〕。
2. **「本無業障可消」。** 心安不安是自己的選擇；賺賠、季節、遭遇與「業障」無關，那只是相上的因緣果報。真諦是「應無所住」，不再把心想的障礙當成外在的業障去消〔行334-354〕。
3. **修「三時繫念」＝時時繫念佛（覺性從未離你）。** 不是去參加三場法會就回家；「佛＝覺性」，能吃能睡、六根有覺受皆是覺性在用，佛沒有一天離開你——這是「永無疲倦之法」，因它本自具足〔行397-429〕。
4. **恨誰＝恨自己的影子。** 你所恨的對象是六根接觸六塵時「自心的顯現」；恨他等於恨自己的影子。看破這點，「你自己綁自己，放下就是」〔行684-693,1120-1123〕。
5. **面對病苦生死：身痛與心無關。** 法師以親歷骨癌血癌作證——痛的是四大假合、六根神經；佛性不生不滅。修到「不畏生死，亦不需涅槃」，才是究竟〔行643-666〕。
6. **持誦經典重涵義、不執文字（敲木魚的提醒）。** 「大乘無文字」——唸經敲木魚是提醒語言文字只是表達，重在體會涵義，不可執著文句〔行481-483〕。
7. **辨「萬法唯心」非「萬物唯心」。** 心想鑽石會現「鑽石之相」，但心不會變出真鑽石；痛苦與否在心不在外。混淆「法（心內顯相）」與「物（外在）」會讓學佛暈頭轉向〔行1027-1042〕。

## 12. 延伸・參

- **前後銜接**：本講承第十三講「二用」與「一塵普周法界／出生無盡（十對問答之問）」，本講把十對問答的「答」與「含容空有遍」「三疑」講完，是「三遍」的收束。四德、五止、六觀（本經後四門）留待後續。
- **一參問**：法師說「除三疑即是道後菩薩」。試以「鏡子」自問——此刻我對眼前的人事，是把它當「鏡外別有實物」（色外空／空是物），還是照見「相即是鏡、鏡不礙相」？若後者，我這一念是否已「不住生死、不住涅槃」？
