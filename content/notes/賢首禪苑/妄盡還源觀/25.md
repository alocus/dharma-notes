## 1. 本講概要

本講是《妄盡還源觀》「六門」中第五門「**五入五止**」的收束堂，並開啟第五門到第六門（六觀）之間的「**依止起觀**」樞紐。體佛法師以華嚴宗（賢首宗）「見性＝見本心＝自性清淨圓明體」為總綱〔行58〕，先用**法相宗（唯識學）**把「一念不覺 → 三細 → 心（本心／真心）→ 海印·法界 → 三心二意（第八·第七·第六意識）」的妄心生起過程完整複習一遍〔行157–382〕，再落到賢首國師所立的**五止**逐止解義：

1. 照法清虛離緣止（法）〔行608–635、679〕
2. 觀人寂怕絕欲止（人／身）〔行635–660、679〕
3. 性起繁興法爾止（理事·性相一體）〔行663–679〕
4. 定光顯現無念止（如來藏顯相）〔行675–680〕
5. 理事玄通非相止（大智獨存·體周法界·萬行紛然·悲智雙融）〔行681–856〕

末段以《大乘起信論》「若修止者對治凡夫、若修觀者對治二乘」證成**止觀不相捨離**〔行868–1031〕，並以《華嚴經》「金翅鳥鼓揚海水、搏取命盡之龍」譬喻如來以「大止妙觀」兩翅度脫根熟眾生作結〔行1033–1080〕。through-line：**看破（觀）＋放下（止）＝理事圓融、悲智雙融**——淨空老和尚得章嘉活佛「看得破、放得下」六字之公案正是此意〔行875–881〕。

穿插的重要材料：菩薩四德收尾（尤其「代眾生苦」）〔行448–586〕、荷澤**神會**傳頓法過江北的公案〔行504–531〕、梁武帝與達摩「並無功德」〔行405〕、老子「吾有大患為吾有身」〔行643〕、維摩詰示疾與弟子托缽的公案〔行997–1008〕。

## 3. 核心概念

| 概念 | 體佛法師釋義〔行〕 | 經教連結（核驗） |
|---|---|---|
| 自性清淨圓明體 | 華嚴宗立的本體專名，即本心／真我／空性；光明無黑暗，在凡不減、在聖不增，一切眾生共用一體，故能「同體大悲」〔行58、106–140〕 | T1876 顯一體：「謂自性清淨圓明體…處凡身而不減」✓（家本原文） |
| 一念不覺 | 自性清淨圓明體本來空寂，最原始的「緣」即一念不覺——一個極微細（法相宗說1280兆分之一秒）的波動，由此起無始無明、由性轉心〔行157–166〕 | 攝《起信論》「依不覺故心動」義；「一念不覺生三細」為傳統攝頌，非起信論原句（見§9） |
| 三心二意 | 中國成語本是佛語：三個心＝第八（阿賴耶）·第七（末那）·第六（意識）；二意＝意根（末那）·意識（第六）。三心二意是法相宗唯識學要義〔行359–376〕 | 唯識學名相；體佛法師之攝義 |
| 海印／法界 | 心（一念不覺後）有兩個專名：一稱海印（森羅常住用，能照現宇宙萬象）、一稱法界（圓明自在用）〔行168、434〕 | T1876 二用：「海印森羅常住用」「法界圓明自在用」✓（家本） |
| 末那識（意根） | 從第八識一顆種子輾轉緣出、涵「虛幻之我」概念的識，中文譯「意根」；是投胎與六道輪迴、眾生苦的最強種子（我執）〔行215–227、275〕 | 唯識學；體佛法師釋義 |
| 空花／緣影 | 第七識我執＝空花（本來無此物、自己設定有）；第六識分別緣自第七識＝緣影。修行不除空花也不除緣影，而是「知是空花、知是緣影」〔行82–97、332、455〕 | 攝《圓覺經》「知是空花即無輪轉」義；體佛法師以此貫串全講 |
| 尸羅四義（威儀有則） | 進入真心本性的持戒；只要不體悟空花緣影而生任何煩惱，一律叫破戒——非做了何事才叫破戒〔行494–496〕 | T1876 四德「威儀住持有則德」引《起信論》尸波羅蜜、「尸羅不清淨三昧不現前」✓（家本引文，見§9） |
| 五止 | 賢首國師所立、由「攝用歸體」而入的五個「止（放下）」門，本俱、入而不入，任入一門即全收五門〔行592–598、858–862〕 | T1876「五入五止」✓（家本，見§8） |
| 理事玄通（第五止） | 幻相之事與無性之理互隱互顯即玄通；理由事顯、事徹於理，互存互奪；到此則「大智獨存·體周法界·萬行紛然·悲智雙融·性相俱泯」〔行681–683、774–856〕 | T1876 第五止✓（家本） |

### 名相辨析：性 ↔ 心（一念不覺的轉換點）

```
自性清淨圓明體（性）── 空寂·無精神無物質·什麼都沒有
        │  一念不覺（1280兆分之一秒的波動）＝最原始的「緣」
        ▼
       心 ── 起作用·什麼都有（萬德莊嚴·無量種子）
        │  「心產生的那剎那」＝本心／真心（與性幾乎無二無別，只是起作用）
        ▼
   一念不覺生三細 ── 三細相一出，宇宙萬物即此產生
        ├─ 海印（森羅常住用）：能照現宇宙萬象
        └─ 法界（圓明自在用）：圓明含攝一切
```
連結要點：性「什麼都沒有」→ 一念不覺 →心「什麼都有」；本心＝真心（大根器者變心當下即真心、即佛菩薩生活〔行188–191〕），妄心則是六七二識支配宇宙運行的軌跡〔行191–194〕。

### 名相辨析：三心二意（唯識妄心結構）

```
第八識 阿賴耶（藏識·無量種子·翻「無量無邊」）── 真心轉換即「大圓鏡智」〔行370〕
   │ 拉出一顆種子，輾轉緣出
   ▼
第七識 末那（意根）── 「我」的概念·我執·煩惱根源〔行275–278〕
   │ 第六識緣第七識而來
   ▼
第六識 意識 ── 分別（是非善惡好壞）·緣影〔行326–332〕
   │ 六·七二識（兩個妄心）回頭又存入第八識儲藏〔行370–382〕
   ▼
儲藏的全是虛妄相 → 故第八識所藏皆假 → 稱「妄心」〔行393〕
```
連結要點：**三個心**＝八·七·六識；**二意**＝意根（七）·意識（六）；「沒有第七（我）就沒有第六（分別）——沒有我，怎麼知道有他」〔行302、455〕。打禪七＝放下第七意識（回歸阿賴耶，已是要成佛的階段）〔行309〕。

## 4. 故事・公案

### 4.1 荷澤神會過江北傳頓法（代眾生苦的示例）〔行504–531〕
體佛法師以「代眾生苦」引出神會。神會是六祖五大弟子之一（荷澤神會），已悟空性。六祖門下五大禪師——慧忠國師、永嘉大師、懷讓禪師、青原（行思）禪師等，全在長江以南（江西有石頭希遷、行思禪師；湖南有南嶽懷讓禪師；懷讓弟子即馬祖道一、行思弟子即石頭希遷——此即「跑江湖」之由來，學圓頓禪不是江西就是湖南）〔行506–511〕。當時北方（皇室）奉神秀為國師、行漸法，南方六祖行頓法。唯有神會有勇氣、冒生命危險，越長江到洛陽、長安傳六祖頓法〔行512–517〕。因傳正法最易得罪當道（二祖即因思想問題被害），神會最後退到河南南陽〔行513–520〕。不久安史之亂爆發、天下蒼生受難，神會於皇家所設之**開元寺**（唐玄宗年號開元、天寶，故天下州郡佛寺多名開元寺）大開法筵，以懺法安撫戰死英靈、募款捐國賑災，取得皇帝信賴，南方禪法自此才真正傳入北方〔行520–529〕。神會唯一把六祖之法傳過江北；其（後代）弟子即華嚴五祖**宗密**（雖未親見神會，卻承荷澤宗，故華嚴與禪得以結合）〔行531〕。
> 核驗：荷澤神會於安史之亂中助朝廷（度僧、香水錢助軍餉）為史所載；體佛法師以「懺法超渡」為其講述版本，核心（神會亂中助國、南宗因此北傳）與史相符。宗密為華嚴宗五祖、屬荷澤法系，屬實。

### 4.2 梁武帝與達摩「並無功德」〔行405–407〕
以「聖人不在你今天修什麼」帶出梁武帝與菩提達摩的對話：梁武帝一再強調自己造寺供養無數、了不起，達摩答「並無功德」——因為功德是自性才有，外在只是善德（善有善報、惡有惡報，全是有為法）。體佛法師接永嘉「一切有為法…猶如仰箭射虛空，勢力盡、箭還墜，招得來生不如意」〔行407〕。

### 4.3 強盜持燈引路（不清淨的師父也要尊敬）〔行422–429〕
經典所寫的譬喻：黑暗中有一人雖是有前科的強盜，但他手持一把燈能引你走出黑暗——你要跟的是「燈」不是「人」；如同你快溺水，有手拉你上岸，難道還先問他有沒有說謊、犯戒？當然趕快抓住。故《菩提道次第廣論》佛之警告：不管高僧犯多大罪惡，毀謗他即等同毀謗三世諸佛、罪惡無量——因為他現的是三寶之相、代表佛陀的解脫道〔行422–429〕。

### 4.4 淨空老和尚得章嘉活佛「看得破、放得下」〔行875–881〕
淨空老和尚一生幾位重要老師：先親近方東美教授（體佛法師入台大那年方東美剛往生，體佛從方東美最得意弟子楊政和教授學華嚴）〔行875–877〕；第二位遇章嘉活佛——淨空問「佛法到底要怎麼修行、怎樣見性」，章嘉活佛一直看著他，待其心沉靜下來，只講六個字：**看得破、放得下**〔行879–880〕。體佛法師點明：**看破＝觀、放下＝止**，止觀即放下與看破而已〔行881〕。

### 4.5 維摩詰示疾與弟子托缽〔行997–1008〕
維摩居士是在家人（有兒女），卻能呵責一切出家弟子——因對維摩之圓滿法界心而言，眾人皆不圓滿。維摩示疾（生病是示現，非真病）；佛遣弟子問疾，阿難、迦葉、目犍連、舍利弗皆說「不敢」〔行1001〕。托缽公案：阿難（此處體佛的講法）主張只向富人托缽被呵——「富人本已富貴，你再向他托，窮人怎麼辦」；舍利弗只向窮人托缽也被呵——「富人好不容易當富人，下輩子若變窮怎麼辦」；怎麼說都有理，故無人敢去，最後須智慧圓通者去問疾，即文殊師利菩薩——這正是《維摩詰經》的緣起〔行1003–1008〕。體佛以此說「現出家相而做在家事（執著世間）、未入法界心，則著袈裟何義」〔行1008〕。
> 核驗：見《維摩詰所說經·弟子品／文殊師利問疾品》T0475。體佛之托缽細節為其講述簡化版（原經 迦葉捨富從貧、須菩提受呵等），核心（維摩示疾、諸大弟子辭不堪任、文殊問疾）與經相符。

### 義理深入

**其一，五止是「由體起用」的逆收——攝用歸體。** 家本 line 95 明言「攝用歸體入五止門…當相即空，相盡心澄而修止」，又說「入者，性相俱泯、體周法界、入無入相」。體佛法師扣此點反覆強調：五止是「本俱的止」、「入而不入」，開為五門而任入一門即全收法界〔行856–862〕。這與《圓覺經》「一城開五門，隨門皆可入」的比喻同義〔行858〕。故五止不是五種次第功夫，而是同一自性清淨圓明體從「法／人／性相／定光／理事」五個切面的當處放下。

**其二，第五止「理事玄通」是全觀的樞軸。** 體佛法師花了本講最大篇幅（行683–858）在此止上，關鍵在破二乘偏空：二乘「見空、見理、見性」卻不敢踏入事相有，佛斥之為「偏空、焦芽敗種」〔行709–712〕；凡夫則全世界99.9%只在事相有裡打轉、煩惱無邊〔行712–715〕。唯「理事玄通」——蓮花開在污泥與清水之際、不著有不著空——才有果位坐蓮花（眾生·天道·阿羅漢皆不坐蓮花，唯菩薩坐蓮花）〔行729–739〕。此止之德「大智獨存」＝於理性空又不離事相有（別於只精通事相的「聰明」與只住理性空的「小智」）〔行786–800〕；「萬行紛然·悲智雙融」＝隨緣現文殊智·普賢行·觀音悲〔行835–854〕。

**其三，「依止起觀」把五止導向止觀不二。** 家本自問「依五止修行已足圓滿，何須止觀兩門」，答以《起信論》對治義：止治凡夫著世間、觀治二乘不起大悲〔行111–113〕。體佛法師點出這正對應蓮花喻的兩種病——一種在五濁事有下功夫出不來（凡夫）、一種躲進清水不沾染（二乘）〔行895–898〕，故必修止觀。並以淨空—章嘉「看得破（觀）、放得下（止）」六字為最精要的口訣〔行881〕，再以金翅鳥喻收全講：止觀即如來度眾之兩翅。

## 11. 日常實踐

1. **思惟修（正思惟＝禪）**：煩躁無法忍受時，思惟「此煩惱來自第七意識我執」，並以「若此事發生在別人身上我不會煩惱」自我勘驗——同情與煩惱是兩回事〔行460–465〕。
2. **知是空花、知是緣影**：修行不是除空花緣影，而是「知」它是空花緣影——我執、分別本是假，煩惱的對象也是假，兩面（從我執看·從事相看）反覆正反思惟，久之保任〔行332、754–756〕。
3. **持圓滿戒（尸羅四義）**：檢查心是否起煩惱——心一起煩惱即破戒；不見空性無法持圓滿戒〔行494–496〕。
4. **隨緣妙用而不捨緣**：逆境勿求早死（違背因緣即犯大戒，緣是你的責任還沒了）、順境勿貪久活；一切按生老病死·成住壞空·生住異滅之軌則，該保養仍保養、但不執著〔行831–833、966–968〕。
5. **看破·放下並修**：只放下（止）易落偏空無大悲，只看破事理（觀）而著世間則善根不起——兩者共修，不避世也不著世〔行959–1020〕。
6. **薰陶保任**：每週聽經薰陶佛知見至圓滿剎那即「踏破鐵鞋無覓處、得來全不費功夫」；利根如懷讓、青原隨六祖尚需二十年，累劫阿賴耶第七識堅固，故須一直聽、保任住〔行353–356、627–629〕。
7. **臨終觀照**：訓練到往生那刻，不管肉體多痛也是空花緣影（肉體痛是我執覺受、神經在痛，佛性不痛）〔行478–484〕。

## 12. 延伸・參

- **「五百羅漢退席」**〔行543、986〕：《妙法蓮華經》序品原文為「比丘、比丘尼、優婆塞、優婆夷**五千人**等，即從座起，禮佛而退」——是**五千**四眾增上慢者、非「五百羅漢」。✓T0262。（此misstatement不影響其「此法非一般人能聞」之義理。）
- **證道歌變體**（義同、字異，非誤義）：法師「剎那除去阿鼻業」＝原「剎那滅却阿鼻業」；「了則業障本是空」＝原「了即業障本來空」；「二乘精進無道心」＝原「二乘精進勿道心」；「我以此誑眾生願招拔舌塵沙劫」＝原「若將妄語誑眾生，自招拔舌塵沙劫」。✓T2014。
- **「若無見性，學法無益」**〔行58〕：義同《六祖壇經》五祖語「不識本心，學法無益」，非壇經逐字原文。✓T2008。
- **「一念不覺生三細」**〔行166〕：為後人攝《起信論》之義偈，非論文原句（原：「以依不覺故心動，說名為業」✓T1666）。

- 神會於安史之亂「開元寺設懺法超渡戰死英靈」為法師講述版；史載其核心為亂中助朝廷（度僧、香水錢助軍餉），細節可續考。
- 「1280兆分之一秒＝一念」〔行159〕為法師引法相宗說法之數值，未逐一對藏經核。

**相關講次：** 妄盡還源觀 24（菩薩四德前段）；本講後「過年後第一堂」預告講止觀實修法（靜坐如何觀）〔行1040〕；六觀（攝境歸心真空觀…主伴互現帝網觀）為下一階段，見 T1876 lines 121–137。

**延伸連結：** T1876 第五止與六觀（家本 lines 107–139）；《起信論》止門修法（家本 line 119 引 T1666）。

**參問：** 若「五止本俱、入而不入、任入一門即全收」，那麼「還要不要修」與「本來現成」如何不矛盾？——家本以「理由事顯（事修＝因緣）而理當下即是、理不用修」作答〔行764–768〕，可與淨空—章嘉「看得破、放得下」對讀自參。
