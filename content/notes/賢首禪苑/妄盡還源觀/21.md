## 1. 本講概要

本講是《妄盡還源觀》修證架構的一個大轉折點。前二十講已把**一體（自性清淨圓明體）→二用（海印森羅常住用／法界圓明自在用）→三遍（普周法界／出生無盡／含容空有）→四德（隨緣妙用／威儀有則／柔和質直／代眾生苦）**這套「理論見地」講圓滿〔行54〕；本講從第四德「代眾生苦」的結頌《雜集論》句收束理論，正式跨入**修行方法——五止六觀**〔行54、421〕。

體佛法師反覆強調一條主軸：**《妄盡還源觀》是《華嚴經》八十卷八十萬字的濃縮**，賢首國師（法藏）以幾千字把整部華嚴的理與行分判得如此清楚，功德不可思議〔行200、208〕。而五止六觀的修法，**不是打坐、不是苦行，全在「見地」**——「所有的佛法都講這個，沒有一部佛經是例外，全部都是見地，正知見就是大修行」〔行520〕。

本講的核心操作概念有二：一是**「世界 vs 法界」的抉擇**——身活在生滅的「不堅」世界，心本在不生滅的「堅覺」法界；眾生「深住於顛倒」只看世界，故輪迴不已〔行432、437、464〕。二是**「入五止門」的「入」是「入無所入」**——法性本自普周法界，本來無出入，所謂「入」只是「了了見」自己本具的性德〔行787、806〕。修法的樞紐句是本經「**當相即空，相盡心澄而修止**」與「**攝用歸體**」〔行528、604、660〕。

本講援引極廣：以《六祖壇經》證「何期自性本自具足／心生種種法生」、以《心經》證空有不二、以《般若經》「畢竟空無所有不可得」與《楞嚴經》析微塵歸空證「一切法畢竟空」、以《永嘉證道歌》「不除妄想不求真／了知二法空無相」證真妄雙泯、以《入佛境界經》《起信論》釋本經之「入」。並穿插南宋氣節、淨空求學李炳南、玄奘遇萬年行者、蓮花色比丘尼遇目犍連、六祖惠明奪衣諸多公案。

## 3. 核心概念（glossary）

| 概念 | 體佛法師釋義〔行〕 | 經教連結（核驗） |
|---|---|---|
| **五止六觀** | 《妄盡還源觀》的「修行方法」；前四德是理論見地，第五「止」第六「觀」才是實修法要；先講止、再講觀，兩者可互先，觀當下即止、止當下即觀〔行54、522、573、576〕 | 本經T1876「言五止者…」段（本講止於入門總說）✓ |
| **止（奢摩他）** | 總歸一句「教我們放下」；一切相皆虛幻，教你放下＝不住＝無所住；究竟奢摩他是「無所住——沒有東西讓你放下」〔行562、564、588、590〕 | 梵 śamatha；《圓覺經》T0842 用「奢摩他」〔行552〕 |
| **觀（毗婆舍那）** | 教你「看破」——看破宇宙的實相〔行564、567〕 | 梵 vipaśyanā |
| **止觀雙運（優畢叉）** | 放下幫助看破、看破再助放下，一體不離，止觀雙運〔行557、560、570〕 | 梵 upekṣā／均等 |
| **攝用歸體** | 攝用＝廣泛運用、應用在日常生活；歸體＝回歸自性。佛菩薩攝用歸體（身受心不受），凡夫攝用「違體」（全用在世界故常在生滅）〔行604、606、616、622〕 | 本經T1876「自下攝用歸體入五止門」✓〔行604〕 |
| **當相即空 / 相盡心澄** | 從法界心看，世界一切相沒有一樣真實，故當相即空；知相是空，相自「盡」（非除相、非修到相盡），相盡則心自澄——即「妄盡還源」〔行660、757、759、762〕 | 本經T1876「當相即空，相盡心澄而修止也」✓〔行528〕 |
| **入（入無所入）** | 「入」只是語言文字；法性本自普周法界、本無出入。所謂入五止＝「了了見」自本具性德；性相俱泯、入無入相方名入〔行787、791、806、819〕 | 本經T1876「入無入相，名為入也」✓〔行528〕 |
| **不堅 / 堅覺** | 不堅＝世界（國土危脆、無常生滅）；堅＝覺＝覺醒，即完全不變、無生滅之自性（法界）。人身處世界與法界之間，須抉擇〔行432、434、437〕 | 本經T1876引《雜集論》「於不堅堅覺」✓〔行427〕 |
| **深住於顛倒** | 眾生以身為基礎點，強調在「不堅」的世界一邊，故深住顛倒、不斷輪迴；顛倒＝世界（顛倒見）〔行464、466、483〕 | 本經T1876《雜集論》句✓ |
| **離煩惱所惱（能所雙放）** | 加一字更明：「離煩惱所煩惱」——有能煩惱之心、有所煩惱之境；本無能所，能所雙放即入法界〔行469、475、477〕 | 本經T1876《雜集論》句✓ |
| **得最上菩提** | 非真有所得，是「得而無得」；一切要放下者本是幻影，本無可得可放，當下即得〔行479、592、595〕 | 本經T1876《雜集論》句✓ |
| **世界 vs 法界** | 世界是實有、生滅、顛倒見；法界不生不滅即自性。不懂法界只知世界者，世界為實有；入法界則世界只是鏡中花·水中月〔行483、485、487〕 | 華嚴義；《心經》空相〔行169〕 |
| **無相** | 「無相」不是「沒有相」；相是影像，稱為無相——是心裡產生的幻相〔行861、869〕 | 《壇經》「凡所有相皆是虛妄」T2008 ✓〔行864〕 |
| **本師（本覺本性）** | 「南無本師釋迦牟尼佛」之本師是我們的本覺本性、本心，非指化身釋迦；一切佛法都要加一個「本」〔行916、925〕 | 師述（見§4·§8） |

## 4. 故事・公案（全敘事）

### 4.1 善財童子五十三參中的貪瞋癡大菩薩〔行58–64〕
體佛法師說：華嚴的「實踐」在八十華嚴〈入法界品〉的普賢行願與善財童子五十三參。所參者皆是「當時已開悟、卻示現在各行各業」的大菩薩——有出家、有在家，有男有女、有老有少，有止觀法門、有念佛法門，**甚至有代表人類貪瞋癡三毒的大菩薩**：如勝熱婆羅門、甘露火王（表瞋）、婆須蜜多女（表貪、示現男歡女愛的妓女），「可是它是入本性的菩薩」。師的用意：善財五十三參其實就是我們從小到大周遭的一切人事——學《華嚴》要用在日常生活，才能「入華嚴」。（按：此為法師依經義說，五十三善知識名相見〈入法界品〉。）

### 4.2 南宋氣節與日本武士道（附帶史話）〔行270–320〕
法師附帶講一段歷史以襯「世間法之正邪（氣節）」不同於佛法之正邪。南宋偏安，忽必烈率元軍南下，南宋都城臨安（**今杭州**〔行300〕）被攻陷；文天祥作《正氣歌》寧死不屈，陸秀夫背負幼主（衛王）自山崖投海，皇宮兩千多后妃宮女武裝抵抗、城破集體殉節。此種「城破則女子集體自殺、寧死不降」的精神，後來影響日本武士道；日本歷史劇即演此景。法師說：這是「世間法的氣節」，可敬，但**佛法所講的「正邪」不是這個**〔行294、312、323〕。（史料校勘見§5。）

### 4.3 淨空老和尚求學李炳南「你要信佛啊」〔行453–462〕
法師以此辨「世界的佛教」與「法界的佛法」。淨空老和尚出家、受大戒之後，仍以在家人李炳南老居士為一輩子的老師（法師說「這不容易，出家人能這樣」）。淨空要進門求學時，李炳南在門口就喊：「淨空啊——你要信佛啊！」淨空心裡起疑：我都出家了，還叫我信佛？法師解：李炳南是怕淨空所信的佛是「世界的佛教」（一進世界，不久便求名聞利養、大陣仗山頭、揚名全球），而要他信的是「法界的佛法」那顆入法界的心。（法師註：網路上有此事記載〔行458〕。）

### 4.4 菩薩入法界殺三盜匪的菩薩戒公案〔行337–381〕
法師先立「入法界者做什麼都對」，隨即自問「難道菩薩不會做錯嗎」，並舉著名公案：一艘船上載眾商人，夜有三個盜匪欲於三更半夜殺盡商人奪財；一位（入法界的）菩薩先下手把三盜匪殺掉。**請問這位菩薩有沒有犯戒？** 法師答：在法界上不犯罪（是真正的菩薩戒，非相戒）——因他是為救眾生、替眾生犧牲（自願承擔殺業因果、身受心不受）；但在世法上「要不要受處罰，看當地隨俗的法律」。此公案配合「正人行邪法，邪人行正法」與「皆以無為法而有差別」而說〔行334、337、349、382〕。（按：此即菩薩戒中「大悲殺」開緣之傳統喻，法師據以說菩薩戒。）

### 4.5 玄奘遇入定萬年的行者——窺基的前生〔行767–781〕
法師以此破「盲修瞎練」——「五天不睡覺任你打坐、一百年不睡覺你還是凡夫」〔行765〕。玄奘大師往印度取經途中，遇一能入定一萬年的行者，不吃不喝，一心等待釋迦牟尼佛出世；見玄奘過來，非常歡喜、拉住他的手，以為他就是釋迦牟尼佛。吳承恩《西遊記》即取此一段化為「壓在山下的孫悟空伸手抓住唐三藏、求救求解脫」的情節（本於《大唐西域記》）。法師點出關鍵：這位仙人**能入定卻無見地**，故「出無門」；一切最後的解脫都是**慧解脫**，沒有戒解脫、定解脫（然戒定慧三則一、一則三）。玄奘教他：先出定、捨此不壞之身去投胎（只投王室），待取經回來再告訴他佛陀心要——這即玄奘大弟子**窺基大師的前生**。（按：此為漢傳傳說，非經證，見§9標記。）

### 4.6 蓮花色比丘尼遇目犍連，入本心證阿羅漢〔行934–959〕
法師講一位命運極悲慘的女子（其一夫竟是自己的兒子，「命運殘酷到極點」），欲以色相引誘尊者目犍連。目犍連向她講出她的身份、並說空寂實相：「已被污染的身體來誘惑我，我本來就純白，我既入空性……」蓮花色聽完，突然之中「入本心」，空寂實相講完便當下證悟阿羅漢，成為蓮花色比丘尼。法師說「這是阿含經所講，絕對不會騙人」〔行958〕，並以此反問：她沒做過什麼法會，「我們為什麼做不到？——你的心有沒有真的放下？」（按：法師繫於《阿含》系，確切經卷未於本講指明，見§9標記。）

### 4.7 六祖逃難，惠明奪衣「不思善不思惡」〔行1089–1095〕
配合永嘉「不除妄想不求真」，法師講六祖惠能得法南逃、眾人爭奪衣鉢（法器）。將軍**陳惠明**（法師稱「五品將軍」，**canon作「四品將軍」**，見§5）已追及；六祖把衣鉢信物放在石上，惠明去拿卻提掇不動，方知六祖是大修行人，遂喚「仁者請出來，我不要東西、不會殺你，只求你教我怎麼修行」。六祖答：「不思善、不思惡，正與麼時，那箇是明上座本來面目？」惠明言下大悟。法師解：不思善不思惡＝不除妄想，因善惡與真妄都是二元對待〔行1094、1096〕。（✓ CBETA T2008／T2005，見§9。）

### 義理深入

**（一）四德如何收於一頌、又如何開出五止。** 體佛法師把《雜集論》這一頌讀成「四德的鎖鑰、五止的門樞」。頌中「不堅／堅覺」正是本經「世界／法界」的兩端，「深住於顛倒」是眾生病，「離煩惱所惱」是下手（能所雙放），「得最上菩提」是果（得而無得）。他特別在「離煩惱所惱」加一字讀成「離能煩惱、所煩惱」，把印度論頌的簡語，接到本經「相盡心澄」的能所雙泯上——這是他的釋讀，不是頌文原有〔行469、475〕。由此，四德之「行」（用）自然要「攝用歸體」，轉為五止之「止」（體）。

**（二）「當相即空、相盡心澄」為何是全部修法的樞紐。** 法師反覆說：五止不管哪一止，這一句是「最重要、最根本的止」〔行785〕。關鍵在**次序倒轉**：不是「修行讓相盡」，而是「知相本空→相自盡→心自澄」。修行只是「了了見」本具的相空，故「修而不修」〔行757、785〕。這正解了書名——「妄盡（相盡）」即「還源（心澄歸自性）」，五止六觀不外此〔行762、1173〕。

**（三）「入無所入」把整套修法定在「本具、非新得」。** 法師用華嚴「其量等虛空，一切眾生入而實無所入」與《入佛境界經》「敬禮無所觀」雙證：法界不是修來的目的地，而是本來現成的自家田地；「入」只是了了見〔行806、819、834〕。故他把「敬禮無所觀」直接接到普賢十大願第一願「禮敬諸佛」——所禮之佛即眾生心中本具之佛、即自性法身〔行1007、1009〕。這一步把《妄盡還源觀》的止門、《華嚴》的普賢行、乃至淨土的彌陀（平等即彌陀）縫合為一心〔行853、858〕。

**（四）真妄雙泯，是五止之「入」的最後一關。** 本經「妄即是真，更無別真而可入」，法師以永嘉《證道歌》全段落實：真妄善惡皆二元世界法，能討論真妄即已落世界；統名「無明」，其實只是自心變化之影像（幻化空身即法身）〔行1106、1111〕。故「不除妄想不求真」不是懈怠，而是入法界者的正見——「學人不了用修行，（深）成認賊將為子」〔行1130〕。這與本經「入與不入本來平等，同一法界」完全同旨，收束本講。

## 10. 法脈會通（連結地圖）

### 10.1 《妄盡還源觀》全架構（本講定位）

```
         自性清淨圓明體（一體）
                │ 性遇緣→轉為心
        ┌───────┴───────┐
   海印森羅常住用      法界圓明自在用（二用）
        │
   ┌────┼────┐
 普周法界 出生無盡 含容空有（三遍｜空有不二）
        │
 ┌──┬──┬──┐
隨緣 威儀 柔和 代眾生苦（四德｜行）
妙用 有則 質直
        │  《雜集論》結頌：於不堅堅覺·深住於顛倒·離煩惱所惱·得最上菩提
        ▼  ── 攝用歸體 ──
   ★ 五止門（本講：入門總說「入無所入」）★
        │
      六觀（未及）
```
**連結要點**：本講正處在「四德（行）→五止（止）」的關節；由「用」攝歸「體」，即從「行」轉「止」；書名「妄盡還源」＝「相盡（妄盡）·心澄（還源）」〔行54、604、762〕。

### 10.2 本經「入五止門」如何被諸經論照亮（連結表）

### 10.3 平等·寂靜·無相 三名相辨析〔行903、908〕

```
無相 ── 相是影像故稱無相（非「沒有相」）
寂靜 ── 影像不能干擾你，本自清淨，故寂靜（＝戒·屍羅四義：清涼安穩安靜寂滅）
平等 ── 一切皆心之影像，故物雖不齊（鑽石≠石頭）而「同是影像」即平等（平等即彌陀）
   三者同一件事，前提唯一：入法界（見性）；未入則自解讀「無相無念」皆背名相
```
**連結要點**：法師強調「無相寂靜平等」不是修來的、是本具的（故一切要加「本」——本師=本覺本性）；未入法界而奢談無相無念，「他完全不知自己在講什麼」〔行908、916〕。

### 10.4 世界 vs 法界（本講的抉擇軸）

| 面向 | 世界（不堅） | 法界（堅覺） |
|---|---|---|
| 體性 | 生滅·無常·國土危脆 | 不生不滅·自性 |
| 見 | 顛倒見（深住於顛倒） | 平等·寂靜·無相 |
| 修 | 攝用違體→世間法（生滅·邪法） | 攝用歸體→身受心不受 |
| 相 | 實有 | 鏡中花·水中月（當相即空） |
| 果 | 了無出期·三塗輪迴 | 得最上菩提·同一法界 |

## 11. 日常實踐（可操作）

1. **在家庭中隨緣妙用即菩薩道**：替家人服務就是隨緣（因與此家有緣），但內心「盡人事·聽天命·沒煩惱」；家庭主婦其實是大菩薩，「不是做給人看，是本來的責任」〔行232、235、241〕。
2. **該忿怒即忿怒、該柔和即柔和**：學佛不是註定被欺負；柔和質直是「心質直、對外柔和」，隨眾生根器而應，重點在「質直＝不離自體」〔行253、256、1167〕。
3. **檢查你的善是善德還是功德**：做善事、當委員、參加法會——是美德善德，但若還在「世界」裡（帶貪、求名），仍是有福德的鬼道因；歸體（見性）與否才分功德〔行451、496、649〕。
4. **離貪不是強忍，而是知假**：不用「勤修戒定慧、強忍不貪」（那是不了義、了無出期）；入法界知一切是幻，則「本無貪瞋癡可離」——如知水中月是假，自然不跳潭去撈〔行503、510、513〕。
5. **修行找法門先問「見地」**：五止六觀是「見地修」；沒有這見地，任你打坐百年不睡也是凡夫、皆旁門左道盲修瞎練〔行764、765、781〕。
6. **當相即空的當下用功**：面對任何相（人、事、鑽石、石頭），提起「這是我心現的影像、當相即空」，相即不能干擾你（相盡），心自澄——這就是妄盡還源的下手處〔行742、1001、1173〕。
7. **禮佛時知所禮是自性**：念「南無本師釋迦牟尼佛」，本師是本覺本性；禮阿彌陀即禮自心，怨恨眾生即與自己過不去〔行916、1021〕。

## 12. 延伸・參

- **前承**：一體·二用·三遍·四德已於前二十講講畢（本講開頭複習）〔行66、548〕；本講起講五止之「入」。
- **後接**：五止各止之名相（照法清虛離緣止·觀人寂怕絕欲止·性起繁興法爾止…）與六觀留待後講；下週因過年休息（法師赴彰化福慧寺紀念師公120歲冥誕、下下週再會）〔行1175〕。
- **一參問**：法師說「一切在見地之中，入是入無所入」——若「入」本無所入、法界本來現成，那麼「五止六觀」還修個什麼？（提示：本經答在「當相即空·相盡心澄而修止」——修的是「了了見」，是修而不修〔行785、1132〕。）
