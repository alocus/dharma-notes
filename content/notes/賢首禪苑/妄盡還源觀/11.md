## 1. 本講概要

本講以永嘉大師《證道歌》「**決定說，表真乘；有人不肯任情徵，直截根源佛所印，摘葉尋枝我不能**」四句開題〔行70〕，藉此點出全部《妄盡還源觀》的性格——它是「決定說」的一乘了義法，直指真如本心，不繞枝葉〔行88-96〕。

主軸落在《妄盡還源觀》「三遍」中的**第二遍「一塵出生無盡遍」**。體佛法師先立起全論的骨架:一個「**清淨自性圓明體**」（真如本性、本具不待修）〔行331-336〕，此一體起「**二用**」——海印森羅常住用、法界圓明自在用〔行404-406,459-476〕;二用之中又示「三遍」。第一遍已於上講講畢，本講詳釋第二遍:一微塵（一微念）依真起用，即能生出重重無盡、萬差別異的十法界〔行307-326,619-670〕。

貫串全講的教學母題有三:(一)**信**——建立不可動搖的信心是修行的第一法要,「信為道元功德母」〔行146,301〕;(二)**三般若的轉化**——從文字般若、經觀照般若、回歸實相般若,即「妄盡還源」〔行144-155,329-331〕;(三)**心即遙控器**——外在一切法界是心的變現,「三千大千世界一切唯心造」,做主的是自心〔行433-447,857〕。末段法師以自身罹骨癌親證「幻痛」的經歷,現身說「了生死本來即了，非修來」〔行942-968〕。

## 4. 故事・公案

### 4.1 永嘉大師 振錫繞三匝・一宿覺〔行253-279〕
永嘉大師去見六祖印證,拿著錫杖(錫杖有三箍,表「出三界」)進門,繞六祖三匝而立,不跪拜。六祖說:「一個出家人要具三千威儀、八萬細行,你從什麼地方來,生這麼大的我慢?」永嘉答:「**生死事大,無常迅速**」——生命週期那麼短,一口氣不來就往生了,我顧不得禮儀。六祖說:「你何不去體取那個無生、了達本無迅速呢?」永嘉一聽即轉,說:「我本來就知道——**體即無生,了本無速**。」一句話心心相印,永嘉放下錫杖,向六祖頂禮拜師。因只留一宿,世稱「一宿覺」。此即《證道歌》「摘葉尋枝我不能」「一超直入如來地」的真禪風格。
（✓ CBETA T2008《六祖大師法寶壇經》,見§9;壇經並記永嘉「因看《維摩經》發明心地…後於《維摩經》悟佛心宗」,與本禪苑講《維摩》有法緣。）

### 4.2 永嘉《證道歌》的「任情徵」挑戰〔行70-132〕
永嘉大師只活到49歲,留下《證道歌》給後人印證佛的心法。他提出證道歌後,很多人罵他狂妄——「哪有成佛這麼簡單、直接進去的?」但沒有人敢出來「任情徵」(拿經典來跟他辯論見地)。永嘉的態度是:你不要講你的修道、你的證悟(證量自說無憑),拿出你根據哪部經的見地來辯論,看合不合佛法;只會批判卻拿不出理論。「有人不肯任情徵,直截根源佛所印」——我所講是佛所印的心法,不是我自己的見地。證道歌盛行到明,清時因眾生根器不如前而衰。

### 4.3 神會禪師北傳受阻・安史之亂立正統〔行287-299〕
六祖五大弟子之一、被稱「天才兒童」的神會禪師,到北方傳六祖的心法(真禪),受到極大阻礙:教團與教團互相排斥,神會講的心法遭很多人毀謗,甚至差一點入獄。因為「教」須依政治為依歸,而心法無關政治人事。神會退到湖北(當時算南方)等待時局。不久安史之亂,國家紛亂、唐玄宗逃四川、長安洛陽幾成空城,神會利用時機到北方辦護國法會、超渡亡靈,取得人望與資金,才在北方立足;國亂後皇帝反省,又以神會為正統。所以第一個把達摩禪正式傳到北方的不是六祖,是神會。（法師據此點出:《妄盡還源觀》此時已在北方宮廷傳布。）

### 4.4 慧遠大師「沙門不拜君王」〔行293-295〕
法師由「教必依政治、皇帝主宰譯經」帶出:淨土宗慧遠大師特別提出「沙門不拜君王(不敬王者論)」——講心法所顯的宇宙真相不關政治,真正有格的出家人不向政治妥協、不依附政治,因為「不為名聞利養」「我講的是真理真相」。（史實對應:東晉慧遠《沙門不敬王者論》。）

### 4.5 賢首國師度武則天:金獅子・十面鏡〔行760-771〕
武則天看《華嚴經》看不懂。賢首國師(法藏)用兩個譬喻:
- **金獅子章**:指宮殿的金獅子問武則天「是金還是獅子?」武答不出。賢首說「既是金也是獅子——只看金是只看內涵沒看表象,只看獅子是只看表象沒看內涵」,此即「**性相一如**」。武則天由此開智慧。
- **八卦鏡(十面鏡)**:武則天仍不懂《華嚴》「重重無盡緣起法界」「出生無盡」。賢首做一組鏡子(八方加上下共十面),請她進去看:一個武則天卻從任何角度、上下都現出無量的武則天影像。武則天問「哪個才是真正的我?」賢首反問她,她答「站在這邊的才是真的我」——這即真如本性,八方上下無量的影像都是出生無盡的妙用,「凡所有相皆是虛幻」。武則天當下開悟,說出「無上甚深微妙法,百千萬劫難遭遇,我今見聞得受持,願解如來真實義」,以帝王之身跪拜賢首,取《華嚴經·法界品》賢首菩薩之名封他為「賢首國師」。

### 4.6 體佛法師求法歷程〔行103-116〕
法師自述近四十年前的求法因緣:台大哲學系教授楊政和(方東美嫡傳弟子,論文寫《華嚴經》)介紹他認識佛法,第一部碰到的經即《華嚴經》;在家皈依師是不識字卻字字直指禪的〔廣欽老和尚〕(法號傳禪);李炳南老居士告訴他淨土要義「一萬個念佛人只兩三個往生」(念表面佛非實相佛),震撼他;又見〔印順〕老法師;到美國經周宣德介紹去找〔宣化上人〕,宣化住地下室,第一個就講永嘉《證道歌》,能叫弟子隨口背證道歌。

### 4.7 骨癌親證「幻痛」〔行936-974〕
法師本以《楞嚴經》二十五圓通的**眼根**修行(娑婆世界靠聲,觀音耳根最利;而他用眼根)。有一天忽然體悟「原來眼睛看到的都是幻相」,雀躍地跑出去看山、看水、看電視、看人都是幻相,「六根門前放光動地」。同理眼、耳、鼻、舌皆幻,唯獨「身」痛最難過關。五年前他得骨癌,痛到醫生說非打嗎啡不行;他試一天嗎啡就不要了,要親證身痛為何是幻。最後真的體會:痛就像眼睛看得到、看不到一樣——「心認為不痛時就不痛,反而喜悅,那是三昧」。由此徹證《圓覺經》「知是空花,即無輪轉,亦無身心受彼生死,非作故無,本性無故」——不是修到了生死,是本來就了生死,眾生怕生死才有生死。之後不再打嗎啡。

### 4.8 韓德爾《彌賽亞》・喬治國王起立(西樂掌故)〔行383-389〕
法師論「宗教型態落伍不等於謗佛」時舉:西方宗教表現在音樂(不拜偶像,故以哈雷路亞讚上帝),東方表現在造像。韓德爾《彌賽亞》最精彩是〈哈雷路亞〉,當年喬治國王聽到時因感動而站起,眾人隨之起立,自此成不成文規定:凡演唱到〈哈雷路亞〉全體起立。法師以此說明「型態會被時代批判為落伍,但那與謗不謗佛無關」。

### 義理深入

**（一）出生無盡的樞紐:塵無自體,起必依真。** 法師以鏡喻扣緊原文:鏡中影像沒有自體,是鏡面(體)顯現的幻相;同理「塵」(最微細的一念)沒有自體,它的體是真如,「所以起必依真」〔行677-681〕。真如雖看不見,卻「具有恆沙眾德」,依真起用便「亦復萬差」——念頭有無量無邊,故生出的法界森羅萬差〔行731-734〕。這正是《妄盡還源觀》把「一塵」抬到與「一法界」同等地位的理由:一滴太平洋水含全洋成份,一塵即具真如全德〔行727-730〕。

**（二）一塵開十義——全論最凝縮的理論核心。** 法師特別把原文「由此一塵虛相能翳於真即是染…由塵性無生無滅依他似有即是大乘法」整段作為關鍵〔行320-324〕:同一個「塵」,不換對象,只隨觀照的角度,就同時是染/淨、真/俗、生死/涅槃、煩惱/菩提、小乘/大乘。這說明染淨生死並非在心外另有其物,全在「塵相如何被看」——「由此一塵虛相能翳於真即是染,由此塵相空無所有即是淨」〔行320〕。修行因此不在向外斷什麼、得什麼,而在轉觀照。故法師接《圓覺經》「知是空花即無輪轉」收攝:生滅相盡、空無有實即涅槃〔行322,966〕。

**（三）二用中的「華嚴」二字即文殊智+普賢行。** 法師把論題「法界圓明自在用(華嚴三昧)」拆為:華=文殊師利的智慧功德花(故「文殊是諸佛的老師」),嚴=普賢菩薩十大願的莊嚴行,兩者莊嚴中央毗盧遮那佛〔行478-515〕。原文「華有結實之用,行有感果之能…嚴者行成果滿契理稱真」正是此義。由此接回一體:心涵蓋本體(毗盧遮那),具華、嚴二大功德,故名「法界圓明自在用,完全沒有缺失」——即摩尼珠、如來藏裡親收得,本具而人不會用〔行515-518〕。

```
      普周法界        出生無盡        含容空有
      (上講)        (本講主文)       (預告下講)
      一即一切       心動生法界        空有一如
   〔行307,527〕   〔行307-326〕    〔行192,預告〕
```
連結要點:一微塵=一微念,依真如(體)起用;「普周法界」講一即一切(橫遍),「出生無盡」講一生無量(豎生),同是真如之妙用。

### 10.3 三金剛(嗡啊吽)=身口意=出生無盡的音聲原型

```

        ├ 嗡=回歸·皈依   ├ 啊=空性   ├ 吽=加持·降伏

```

### 10.4 一塵開十義(§8 核心)的等式鏈
```
同一「塵」，隨觀照角度而異名：
 虛相翳真=染 │ 空無所有=淨 │ 體同如=真 │ 緣生幻有=俗
 念念遷變=生死 │ 生滅盡空=涅槃 │ 妄心分別=煩惱 │ 體空緣盡=菩提

```
連結要點:染淨生死不在心外別有,全在「塵相如何被看」→ 修行=轉觀照(三般若)。

## 11. 日常實踐

1. **先立信,再修行**〔行146,301,348-354〕:沒有目標的修行如開車不知路、空耗油,是「盲修瞎練」。功課照做,但要「入本心」——把功課當作回歸自性圓明體的方向,不是相上的堆積。
2. **從文字般若入觀照般若**〔行144-155,199〕:讀經(文字)→念念觀照轉化習性(觀照)→呈現本具實相(實相)。念一句阿彌陀佛,也可從此觀照到本心。
3. **觀鏡中影像見實相**〔行207-232〕:回去觀照鏡子裡的影像——它現相卻無實體、空而不空。以此體會身心世界「色非色、空非空」,不再懷疑世間一切(含身心)是大圓鏡智影像。
4. **六度即心法,不在相上**〔行687-726〕:布施=能俱舍、心完全放下(錢本非你有);持戒=戒無戒相、心歸如來藏清涼寂滅;忍辱=本無辱可忍(無我相人相);精進=不懈怠、時常懺悔有無違背本心;禪定=行坐語默體安然。
5. **遇痛遇逆,觀其為幻**〔行942-968〕:身痛最難過關;於痛中觀「幻痛」,心不認為痛時觸覺仍在而心不動——但法師如實提醒:未入真三昧(如廣欽老和尚)者,拔牙該打麻藥仍打,「緣來則應,盡人事聽天命」,不必勉強〔行972-974〕。
6. **把握每週薰陶,認定遙控器在自己手中**〔行454-457,860-863〕:生命週期有限、無常難料;聽經薰陶如定心針,認清「幾迴生幾迴死,生死悠悠無定止」,做主的是自心。

## 12. 延伸・參

- **關聯講次**:本講為第二遍「出生無盡」;上講第一遍「普周法界」;下講預告第三遍「含容空有」〔行192,305,825〕。
- **相關概念延伸**:一即一切·重重無盡(華嚴事事無礙)、大圓鏡智與五方佛(唯識×密教)、三般若、常樂我淨四德。
- **一參問**:法師說「同一個真如本性,眾生共用一個,不是無限個」〔行820〕、「我們共用一個三昧(舞台)」〔行845-851〕。若心心相印是「共用一體」,則「我執著你這個影像做什麼」〔行205〕的無諍,與「各人福報不同、各投其業」〔行750-752〕的差別,如何在「一體」中同時安立?——即§8「即一即多、即同即異」一句,自參之。
