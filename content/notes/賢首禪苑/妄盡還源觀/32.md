## 1. 本講概要

本講是《妄盡還源觀》系列第32講，進入全書結尾的**「六觀」**（五止六觀之六觀）。體佛法師先總說：整部佛法的要義收攝在「止觀」二字——天台名之為摩訶止觀，《圓覺經》名之為奢摩他、三摩缽提、禪那（圓覺三法），而《華嚴》以六止六觀開演之〔行57-59〕。接著點出華嚴五祖傳承（杜順→智儼→賢首→清涼→宗密），並強調華嚴與《圓覺經》是三藏中唯二直說「**眾生本成佛**」的經〔行59-78〕。

本講的骨幹是賢首國師六觀原文的**第三觀「心境祕密圓融觀」**與**第四觀「智身影現眾緣觀」**：

- **前三觀是一體**：第一觀〈攝境歸心真空觀〉從外境入內心（真空），第二觀〈從心現境妙有觀〉從內心現外境（妙有），第三觀〈心境祕密圓融觀〉會通心境為一體〔行393-399、578、707〕。
- 法師的核心命題：**一切外境都是你心中的境（境不入心），如鏡中影、水中月，是假、是真空；心所現的境是妙有；真空妙有本不二**〔行401-435〕。以此貫通《心經》色空不二、《圓覺經》知幻即離、《金剛經》降伏其心與如夢幻泡影、般若「宴坐水月道場」三句、永嘉〈證道歌〉，最後歸於淨土「自性彌陀」與「大日如來（毘盧遮那）」。

一條總線索：**妄盡＝看破「心中影像」的誤認**；還源＝回歸自性清淨圓明體（無礙心現無礙境＝淨土）。修行不是滅除妄想，而是「善分別諸法相而不執著」〔行80-87、350-356〕。

## 2. 大綱（含行號）

1. **止觀總說**：摩訶止觀＝佛法要義；圓覺三法；華嚴六止六觀〔行57-59〕
2. **華嚴五祖與禪宗傳承**：杜順（文殊再來）→智儼→賢首（本經作者、武則天封國師）→清涼→宗密（華嚴五祖兼禪宗大祖師，融禪教與《圓覺》）〔行59-73〕
3. **眾生本成佛**：唯華嚴與《圓覺經》直說「現在就是佛」；開悟即「悟佛知見」，不難〔行74-78〕

## 4. 故事・公案（完整敘事）

### 4.1 目犍連被亂棍打死（作在心·殃在身的示現）〔行842-843〕
法師舉神通第一的**目犍連**尊者為例，說明「作在心，殃在身」：目犍連的死法有兩種傳說，一是山崩把他壓死，一是被外道用棍棒亂棍打死。神通第一者尚且色身受此殃，正說明肉體的生滅之殃由心所作、由業所感；但若心全放下，身再受殃也無感受，這叫「無業行」。（按：外道打死之說為經傳所載，✓見§5。）

### 4.2 蓮花色比丘尼——剎那證悟阿羅漢〔行844-864〕
法師完整講述**蓮花色比丘尼**極悲慘的人生：她第一次婚姻，丈夫在外討小老婆，女兒又失散；第二次改嫁，竟把失散多年的親生女兒帶回、成了自己前夫的妻子；後來落入紅塵賣身，最後嫁的丈夫竟是自己的兒子。她雖已四十卻風韻猶存、二十幾歲的臉孔，內心極痛苦，沉浸淫色之中。
一日**目犍連**從旁走過，蓮花色竟以美色引誘他；目犍連已入定性，當下呵責。蓮花色本是有善根、宿世修行者，只是此生在迷，聞呵責即懺悔。目犍連帶她見佛陀，佛陀為她講此因緣，並開示：「你這一輩子身雖遭受這些痛苦，但你的心只要不痛苦，這些痛苦也枉然、奈何你不得。」蓮花色**當下證悟阿羅漢**。
法師由此點出《壇經》名句「**悟則剎那間，迷經千百劫**」〔行859-861〕——修行是剎那的證悟，不是長期修來的；本來我們就是阿羅漢、就是佛，只是不知道而已。

### 4.3 蓮花色供養新鮮肉·比丘換僧衣〔行864-869〕
蓮花色證道後一生弘傳苦集滅道、奉侍佛陀。有人供養她一塊很新鮮的肉，她第一念想到的是轉供養佛陀。佛陀不在，一位弟子見肉新鮮想供佛，便與蓮花色交換條件：「你送我一件新僧衣，我才幫你轉達。」蓮花色歡喜同意。法師藉此指出：佛陀時代確有食肉（見於《阿含經》），但他鼓勵不吃肉——站在環保與因果立場（「吃牠半斤要還牠八兩」）；然「吃不吃肉跟成佛無關」〔行869〕。

### 4.4 貧女供燈·佛陀點出「大功德主」〔行1086-1116〕
佛陀法眼一開，看到一位老阿婆，什麼都沒做，卻說「她是這次法會的大功德主」。當時波斯匿王（按：經典多作阿闍世王，見§5·※）以無量油燈供佛，貧女僅以微薄之力供一盞燈。法師點明：古印度燈極貴（要燈芯、要油），窮人家沒有燈；供燈的真功德**不在供燈本身**，而在讓佛陀能講經、讓眾生看經典、開啟「無為法的心燈」。「我供養了有為法的燈，讓人家能開啟無為法的心燈」——這才是最大功德，而非塑佛像旁點滿蠟燭、「一盞燈五元十元、點越多功德越大」的迷信〔行1116〕。

### 4.5 佛陀的一天·日中一食的科學觀〔行1094-1117〕
法師描述佛陀一天：清晨起床帶眾托缽（以今日內湖到板橋為例，走路快也要三小時），托缽回總部集合共食（比丘僧團如共產：托到的東西大家分著吃，吃不完再供養貧者），食畢洗足、洗缽、洗衣、趺坐。一天時間如此，沒空再吃晚餐，故佛主張「日中一食、過午不食」——這是配合托缽作息的科學觀，不是「為過午不食而過午不食」。法師自陳63歲、色身有老態但精神很好，並強調「佛法最大的功德是能放下才叫功德」，非在相上的持守〔行1106-1108〕。

## 8. 本經解義（《妄盡還源觀》T1876 逐段）

> §8 依經文段次排列（第三觀→第四觀），為本講骨幹；§9 為支持性旁證層。全段原文取自 CBETA〔行126、128〕，無中間省略。

### 8A 心境祕密圓融觀（第三觀·完整原文）

> **[妄盡還源觀·三者]** ✓ CBETA T1876
> 三者、心境祕密圓融觀。言心者謂無礙心，諸佛證之以成法身；境者謂無礙境，諸佛證之以成淨土。謂如來報身及所依淨土圓融無礙，或身現剎土。如《經》云：一毛孔中無量剎，各有四洲四大海，須彌鐵圍亦復然，悉現其中無迫隘。或剎現佛身，如《經》云：華藏世界所有塵，一一塵中佛皆入，普為眾生起神變，毘盧遮那法如是。就此門中，分為四句，如《玄談疏》中說。如是依正混融，無有分齊。謂前兩觀各述一邊，今此雙融會通心境。故曰心境祕密圓融觀也。

| 言心者謂無礙心，諸佛證之以成法身〔行716、578〕 | ✓ | 無礙心＝眾生本有的、無障礙一切包容的心；用無礙心即成法身。是我們本來的那顆心，人為攀緣才變有礙 | 標「心」——成法身 |

**義理深入（第三觀）**：法師以「解深密」點題——賢首以「祕密」名之，其實不是祕密，是眾生本具、佛只令我們清楚明瞭，故名「深密」〔行449-576〕。第三觀所要證的是：**心與境是同一件事，境是心所變化出來的**，如鏡面與鏡中影非二〔行453、576〕。由此煩惱與快樂只是心現出的兩種影像，本質一模一樣，都是「空」（捨不得也取不得）〔行455〕。第一句「以無礙心成就法身，現無礙境（成就報身/淨土）」是重點：**本心本無礙，是人為攀緣（愛憎取捨）扭曲了無礙心才成穢土；無礙心現無礙境本即淨土**〔行578-616〕。故淨土不在他方——「淨土不離此方，此方不離淨土」，你心境改變，你的家庭當下即西方極樂〔行780-782〕。法師據此判《妄盡還源觀》為華嚴、唯識（唯識無境）、天台（一念三千）、禪、淨之**總持（陀羅尼）、總綱領**〔行784〕。

### 8B 智身影現眾緣觀（第四觀·完整原文）

> **[妄盡還源觀·四者]** ✓ CBETA T1876
> 四者、智身影現眾緣觀。謂智體唯一能鑑眾緣，緣相本空，智體照寂，諸緣相盡，如如獨存。謂有為之法，無不俱含真性，猶如日輪，照現逈處虛空，有目之流無不覩見，生盲之輩亦蒙潤益。令知時節寒熱之期，草木無情悉皆滋長，如來智日亦復如是。故曰智身影現眾緣觀也。

**義理深入（第四觀）**：法師先破題——**法身與智身之別**：法身指眾生本具之性（自性清淨圓明體），不是物質也不是精神，本身不會起作用；要起作用必須「轉換」為智身（智慧、心）〔行811-831〕。「心跟性是同樣的東西」，性碰緣即轉為智身而起用〔行831〕。因此常寂光淨土（法身）與實報莊嚴土（智身/心）都在當下、非修來〔行833〕；要修的不是佛性而是習性（最大的習性就是「妄認攀緣心為宇宙真相」）〔行835〕。第四觀的操作核心是「**觀＝看破**」：你只要知道心所現的森羅萬象是假的（只是影像），當下你的如來智日就如如迴照虛空——不管有沒有開法眼，它都在〔行1173-1175〕。由此貫通《金剛經》「一切有為法如夢幻泡影」與「一切賢聖皆以無為法而有差別」：能把有為法轉成無為法的那一剎那，才入「聖言量」；一味在有為法上用功（縱使捐盡全財、救全人類）頂多是好人、善機構，不成聖人〔行1074-1085〕。

## 10. 法脈會通（連結地圖）

### 10A 前三觀·真空妙有雙融（第三觀所會通）

```
        攝境歸心真空觀①            從心現境妙有觀②
        （從外境→內心，真空）      （從內心→外境，妙有）
                \                        /
                 \                      /
              ┌───────────────────────────┐
              │  心境祕密圓融觀③（雙融·會通心境）│
              │   無礙心→法身   無礙境→淨土      │
              └───────────────────────────┘
                          │
   印證：《心經》色即是空·空即是色（真空妙有本不二）✓T0251
```

**連結要點**：第一觀強調境（真空）、第二觀強調心（妙有），各述一邊；第三觀證「心境本一體」，故真空即妙有、妙有即真空——與《心經》「色即是空、空即是色」同一義〔行435-448、774-778〕。

### 10C 毘盧遮那＝大日如來·等式鏈〔行1136-1171〕

```
法身（自性清淨圓明體·性）
   │ 碰緣·轉換
   ▼
智身（心·智慧）── 能鑑眾緣 ──→ 現森羅萬象（影像·假）
   │                                   │ 知幻即離
   ▼                                   ▼
如來智日＝毘盧遮那＝大日如來（遍一切處）
   世間日：有陰影＝有五陰（色受想行識＝身心）
   心中日：無陰影＝無五陰（身心脫落·本無身心可脫落）→ 如如迴照虛空
```

**連結要點**：世間太陽是生滅法、必有陰影（五陰＝五蘊＝身心）；心中大日（毘盧遮那）無五陰，因「身心脫落、本無身心可脫落」而如如迴照虛空，當下即佛〔行1141-1161〕。

### 10D 淨土會通·自性彌陀

```
中峰國師三時繫念：我心即彌陀·此方即淨土（※X藏）
   ＋《壇經》何謂彌陀：悟人自淨其心 ✓T2008
   ＋蕅益偈：彌陀口裡念彌陀，不識彌陀怎奈何（※偈語）

```

## 11. 日常實踐（可操作）

1. **不是滅妄想，是不執著**：可以憧憬未來、緬懷過去，只要不執著，第六意識即清淨意識；把「不能想」當修行會停頓〔行80-87〕。
2. **看破煩惱＝知它是心中影像**：把當下最煩惱的事按順序列出（第一、第二、第三…），照見它們全是「因緣和合的眾緣、心中的影現」，知是影現即不再被縛〔行928-936〕。
3. **知幻即離的水月觀**：面對所愛、所惡、所度眾生，作「碧湖水月」觀——知是水中月，自然不去撈、不被牽動〔行463-469〕。
4. **以「還」為願，不以「討」為業**：面對他人來討債還債、報恩報仇，凡夫視為業障、菩薩視為大願（「我願意還」）；心不甘情不願的「發願」仍是業〔行788-796〕。
5. **受人輕賤時的轉念**：被人輕賤、欺負而心不報復、不反制，當下即《金剛經》「先世罪業則為消滅」〔行799〕。
6. **供養的正見**：供燈為開智慧心燈、供水為自勵「上善若水」、供花供果為學文殊放下（花）成普賢莊嚴（果）——皆是自性功德，非討好佛菩薩〔行1112-1126〕。
7. **世事無常即正常**：不必常想「來日方長」，要想「世事無常」；無常本是常，故一切都正常，心即能安〔行703-705〕。
8. **淨土在當下**：心產生無礙時，當下的家庭即西方淨土；不必等死後（「淨土不離此方」）〔行780-782〕。

- **一參問**：若「一切有為法如夢幻泡影」，則你今日列出的第一項煩惱，其「緣影」的緣起在哪一念「誤認」上起？——照見那一念，即是「知幻即離」的下手處〔行928-936、463〕。
