## 1. 本講概要

本講是《圓覺經》第20講，跨越兩個結構區塊。前半（約1/3）是**頓法四菩薩的總複習**：體佛法師重述佛陀對文殊（知是空花，本無身心受彼生死）、普賢（知幻即離）、普眼（身心幻垢、證得諸幻滅影像故，無方清淨）、金剛藏（非正問）四章的核心，強調「圓覺是在法界體悟，不是世間體悟」〔行58-60〕，並反覆點出全經樞紐——**「亦無身心受彼生死」**：眾生誤認有一個身心受生死，此誤認即名「妄」〔行68-72〕。

後半（約2/3）正式進入**第五位彌勒菩薩章**（漸法之始，其實仍是頓法）。彌勒三請、問四事：①輪迴根本為何？②輪迴有幾性（幾種差別）？③修佛菩提有哪些層次？④菩薩迴入塵勞（倒駕慈航）以何方便度眾〔行158-160〕。體佛法師依經文逐段開解：輪迴根本是**「恩愛貪欲」**四字〔行162〕；由「愛欲為因，愛命為果」而起違順憎嫉，落**三惡道→天人→增上善果（最高聲聞）**三層，皆輪迴故不成聖道〔行165-167〕；欲脫生死須「先斷貪欲及除愛渴」〔行344〕；末後以**二障（理障＝所知障／事障＝煩惱障）配五性（凡夫·二乘·菩薩·不定·外道）**收攝全章〔行476-590〕。

貫串本講的一條主線是**「正知見」**：入法界、入本心者為正知見（菩薩性）；心外求法、以世界為中心者為邪知見（外道性）。理障（礙正知見）比事障更根本——只除事障最高到聲聞，唯從理障入門方能顯住菩薩、圓滿成佛〔行514-526〕。體佛法師並插入大段**禪宗法脈與荷澤神會公案**（血脈論、證道歌傳燈偈、跑江湖、安史之亂香火錢、唐德宗奉七祖、胡適之評價、五更轉），以印證「佛陀血脈＝法界頓悟」的正知見一脈相承〔行181-414〕。

> 定位：本講＝【四頓法章複習】＋【彌勒章主文完整開演】。彌勒章偈頌與第六位清淨慧菩薩，明言留待下週〔行670-671〕。

## 3. 核心概念

| 概念 | 體佛法師釋義〔行〕 | 經教連結（已核驗） |
|---|---|---|
| **亦無身心受彼生死** | 全經樞紐。今天仍在輪迴，只因「認為我有身心受彼生死」，此認即誤會＝妄。了生死非修來，「非作故無，本性無故」——本來就沒有身心受生死〔行68-80〕 | 《圓覺經》文殊章 ✓ T0842 |
| **妄＝誤認** | 妄的意思就是誤認；最大問題是誤認有一個身心受彼生死〔行72〕 | 圓覺章「妄認四大為自身相，六塵緣影為自心相」✓ T0842 |
| **知幻即離** | 既知身心是幻，不需再作方便去觀，「知道它是幻就離了」——如見影子知幻即離，不必分析影子成分〔行84-88〕 | 《圓覺經》普賢章 ✓ T0842 |
| **證得諸幻滅（影像故）** | 「證」不是特別功夫，是「我明瞭了、清楚了、不再懷疑」；身心是幻，身心以外更是幻，因為都是影像〔行98-113〕 | 《圓覺經》普眼章 ✓ T0842 |
| **無方清淨・無邊虛空覺所顯發** | 證得皆幻的當下，無時間差，不管哪一方全部清淨，本心（圓覺自性）遍佈無邊虛空；此虛空是法界之虛空，非外在宇宙虛空〔行115-126〕 | 《圓覺經》普眼章 ✓ T0842 |
| **見分／相分（唯識）** | 眼能看因有見分；所現影像稱相分。你坐我前面＝我見分顯現的相分＝影像。眼瞎者亦能於見分現影像〔行102-104〕 | 師依唯識學釋圓覺「影像故」〔行138,520〕 |
| **恩愛貪欲＝輪迴根本** | 彌勒問輪迴根本，答即四字「恩愛貪欲」；一切輪迴在此〔行162,169〕 | 《圓覺經》彌勒章「由有種種恩愛、貪欲故有輪迴」✓ T0842 |
| **愛欲為因，愛命為果** | 最愛的是自己的身心；問世人最愛誰，到最後最愛自己〔行195-199〕 | 《圓覺經》彌勒章 ✓ T0842 |
| **淫／婬辨析** | 三點水「淫」＝總括，凡過分貪著皆名淫；女旁「婬」＝男女之婬，涵於淫之中。婬對白衣（在家）；重點在「過分且不合法律」之婬〔行169-179〕 | 師述・名相辨析 |
| **理障（＝所知障）** | 礙正知見。知見立知＝無明本；本見上再立一知見即所知障。不除則輪迴出不了，再努力頂多聲聞〔行490-526〕 | 《圓覺經》彌勒章「一者理障礙正知見」✓ T0842 |
| **事障（＝煩惱障）** | 續諸生死。執著身心所生的一切煩惱；心（合意不合意）與身（覺受違逆）皆屬事障。只除事障最高聲聞、不圓滿〔行496-514〕 | 《圓覺經》彌勒章「二者事障續諸生死」✓ T0842 |
| **正知見／邪知見** | 入法界、入心＝正知見；入世間、以世界為中心＝邪知見。眾生本正知見（眼所見哪樣不是影像）；差別在見地非修來〔行516-524〕 | 師依圓覺「礙正知見」開演 |
| **五性** | 凡夫（理事二障俱）／二乘（除事障存理障）／菩薩（二障俱除）／不定（聽什麼變什麼）／外道（心外求法）〔行490-567〕 | 《圓覺經》彌勒章「顯出五性差別不等」✓ T0842 |
| **不定種性** | 如來性有一特性：你聽什麼就變什麼——聽凡夫法成凡夫，聽菩薩性成菩薩，聽外道成外道〔行563-567〕 | 師述・呼應「一歷耳根，永為道種」〔行664〕 |

| **無為法＝無上；增上＝有為** | 增上還有一個「上」可上（增上慢），屬有為、屬聲聞外道法；無為當下即無生，無生叫無上，無為法才是佛法〔行324-337〕 | 呼應《法華經》增上慢〔行329〕 |

## 4. 故事・公案

### 4-1 荷澤神會——被奉為「七祖」的頓法傳播者〔行351-386〕

體佛法師為解「先斷貪欲及除愛渴」的「斷」不是斷滅、而是了解、是轉，特地引神會大師一段話，並完整鋪陳神會生平。

神會是六祖惠能五大弟子之一，稱**荷澤神會**〔行351-354〕。六祖門下五大弟子：南嶽懷讓（其弟子即「馬踏天下」的馬祖道一）、青原行思、永嘉玄覺、南陽慧忠國師、荷澤神會〔行354-360〕。當時參禪者「不是到湖南（南嶽）就是到江西（青原）」，故有「**跑江湖**」一語〔行357-358〕。

神會的志業，是把惠能的**南方禪頓教**傳到北方——當時北方以神秀大師的漸教為主〔行363〕。過程備受阻礙：被御史盧奕通緝，指其「聚眾謀反」，不得不南走〔行365〕。不久**安史之亂**爆發，郭子儀率軍討伐，軍費糧餉不足；因佛教在中國普遍流行、民間信「添香火錢有功德」，遂提倡出家、在家人捐香火錢充作軍餉，神會將所得捐給國家〔行365-368〕。亂平後**唐肅宗**大喜，引神會入宮聽其講經，神會藉此普傳南方禪；至**唐德宗**時代，朝廷召集諸禪師議定祖統，神會被奉為**七祖**〔行369-370,360〕。

宗密大師著《圓覺經大疏鈔》，其中屢屢提到神會〔行369-371〕。神會著作多已散失，僅存《顯宗記》（內含〈五更轉〉）〔行371〕。近代大文豪**胡適之**推崇神會為「南方禪（佛陀心法之禪）的積極提倡者、北方神秀漸教禪的終結者」〔行371-380〕，並歎：歷史最大失誤，就是後世禪門未能把神會的貢獻與精神傳播下去〔行383〕。體佛法師自陳其法脈認同：「不管我講哪一部經，都是以法界、以直接頓悟而入門」〔行386-389〕。
> 校勘・待考：安史之亂「香水錢／鬻度牒」以充軍餉之議，史書多繫於御史中丞裴冕（彭原），神會之角色在設戒壇度僧募資（見宗密《圓覺經大疏鈔》）。法師將發起歸於郭子儀，屬史事細節，列入校對待考，不影響「神會募資助國」之主旨。

### 4-2 達磨《血脈論》——白衣有婬欲能否成佛〔行181-189〕

體佛法師由「淫是講過度」帶出達磨祖師《血脈論》的一則問答。有人問達磨：白衣（在家人）能不能成佛？達磨答：白衣雖有婬欲，「成不成佛在見性而已，不在婬欲」〔行185-187〕。達磨並非鼓勵婬欲——他說：因為你是白衣，「當你見性的時候，你的婬欲自自然然就減」；因為見性者看一切都是影像，不會執著〔行187-189〕。
> ※《血脈論》未收於T系根本藏（存卍續藏X1218，題菩提達磨），此處為師轉述其意，非逐字經證。

### 4-3 五更轉——如來與煩惱不異居〔行389-414〕

神會《顯宗記》中〈五更轉〉，體佛法師略解：古代以更計時，五更即天亮、最光明時，喻成佛；由一更轉至五更「最放大光明」，故名〈五更轉〉〔行389-392〕。其首句：「**如來與煩惱（即妄想），不異居**」〔行391-394〕。「不異居」＝不會同時存在：悟時煩惱即是如來，迷時如來即是煩惱（隱而現為煩惱）〔行394-398〕。結論句：「**頓時眾生開如來法眼，令諸見性得免沉淪**」——頓（＝悟）的那一剎那，眾生就開如來法眼、見性、免脫沉淪（輪迴）〔行403-413〕。
> ※〈五更轉〉／《顯宗記》所引，未於T系根本藏獨立收錄（神會著作多存敦煌寫本／續藏），此為師轉述，非T系逐字經證。

### 義理深入

**（一）樞紐句「亦無身心受彼生死」——妄即誤認。** 體佛法師把文殊章這一句立為全經的門檻：人之所以了不了生死，全繫於是否還「認為有一個身心受彼生死」。「非作故無，本性無故」二句被他反覆強調——了生死不是修到的結果，而是本來就沒有生死可了〔行70-80〕。他因此區分兩層觀法：對聲聞說身是四大假合、心是六塵緣影，要一步步觀假；對大乘直入「身心即假」而不必經過程，此即頓〔行80-84〕。整個彌勒章的漸法（三層輪迴、二障五性），最後都要回歸到這一句頓法樞紐——「其根源就來自於兩個字：身心的執著」〔行241-243〕。

**（二）普眼章「影像故」是操作入口。** 法師特別把本講前半的重點壓在普眼章：「證得諸幻滅影像故」的「影像故」三字，是把身心是幻落實為可操作的下手處〔行98-113〕。他用唯識的見分／相分把它講穿：你所執著的一切都是心中見分所現的相分＝影像；一旦「我明瞭、不再懷疑」（＝證），當下無方清淨、無邊虛空覺所顯發，六根乃至八萬四千陀羅尼門一切清淨〔行115-132〕。到彌勒章講「如何斷愛」時，他明言要把普眼這一段「拿出來用」：斷愛＝放下身心＝觀身心與宇宙一切皆幻（因影像故）→心清淨→一切清淨〔行484-486〕。這是本講兩大區塊的接榫。

**（三）三層輪迴＝一個「愛」字的三種高度。** 經文①的三層——三惡道、天人、增上善果——被法師統一在「還有一個愛」上：凡夫愛名愛錢愛色，修行人愛清淨愛涅槃愛成佛，「同樣都是愛，還滋愛本」〔行340-342〕。最高的增上善果也只到聲聞，因為「以身心為真實去修行，要捨去身心」，是以有生為因、得有生之果〔行237-242〕。唯有「以無生為因」（因地即圓覺、即無生）才得無生之果，此即「因地不真，果遭迂曲」的反面〔行271〕。

**（四）二障配五性——理障（正知見）比事障更根本。** 彌勒章末的義理骨架被法師還原成一組可推演的邏輯（見§10圖）：理障＝所知障＝礙正知見，事障＝煩惱障＝續諸生死。關鍵斷語是「理障若除，事障必除；事障若除，理障未必除」——所以「理障除、事障存」在邏輯上不可能，屬非正問〔行534-536〕。由此，只從事障下手（離群索居、遠離塵勞）最高到聲聞、不圓滿；唯從理障（正知見＝入法界、知一切是影像）入門才顯住菩薩、圓滿成佛〔行512-526〕。這把全章導回一句：**正知見是了生死的真正關鍵。**

**（五）因地法行——出發點與回歸點都是圓覺。** 經文④的「因地法行」被法師接回文殊章「圓照清淨覺相」：頓漸不是世間意義的起點終點不同，而是「出發點在圓覺、回歸點也在圓覺」，只因利鈍而在圓覺大海之內分頓漸〔行604-610〕。「如來無上」＝菩提＝正修行路，三者同一，皆以本心為出發與回歸；「增上」則另有一個「上」可上，落入有為、聲聞、外道〔行614-618〕。末句「邪師過謬，非眾生咎」，法師轉為對說法者的重誡：不講心法、只講世間法（縱使勸善）即邪見，喜為人師而非正道者「背的因果會很大」〔行666-668〕。

## 10. 法脈會通

### 圖A：彌勒章「三層輪迴」——一個「愛」字的三種高度

```
              恩愛貪欲（輪迴根本）  愛欲為因→愛命為果〔行162,195〕
                        │  最愛＝自己的身心
                        ▼
        ┌───────────────┼───────────────────────┐
   ①違順憎嫉         ②知欲可厭            ③棄愛樂捨
   造種種業          捨惡樂善             還滋愛本
   （損人利己）       （行善助他）          （只愛清淨/涅槃/成佛）
        │                │                      │
        ▼                ▼                      ▼
     地獄餓鬼畜生       天  人               便現有為·增上善果
     ＝三惡道                                   最高＝聲聞
        └────────────── 皆輪迴故，不成聖道 ──────────────┘
                        （中間都還有一個「愛」字）
   斷法：先斷貪欲及除愛渴＝觀身心皆幻（影像故）→心清淨→一切清淨
```
連結要點：三層果報高低不同，病根同是「愛（對身心的執著）」；聲聞雖高，因「以身心為真、以有生為因」，故最高只到聲聞〔行237-242〕。

### 圖B：二障 × 五性（法師的推演邏輯，A＝理障，B＝事障）〔行526-536〕

```
   理障(A)＝所知障＝礙正知見（見地問題，較根本）
   事障(B)＝煩惱障＝續諸生死（執身心而起，較粗）

   ┌────────┬──────────┬──────────────┬──────────┐
   │  性     │  理障A    │  事障B        │  果位/歸屬 │
   ├────────┼──────────┼──────────────┼──────────┤
   │ 凡夫性  │  有       │  有           │ AB俱在     │
   │ 二乘性  │  有       │  已除         │ 存A除B→聲聞緣覺 │
   │ 菩薩性  │  已除     │  已除         │ 二障俱除(0) │
   │ 不定性  │  隨聞而定  │  隨聞而定      │ 聽什麼變什麼 │
   │ 外道性  │  心外求法（邪知見）        │ 遇邪見未得正悟 │
   └────────┴──────────┴──────────────┴──────────┘

   關鍵斷語：理障若除→事障必除；事障若除→理障未必除。
   ∴「理障除、事障存」＝非正問（邏輯不可能）〔行534-536〕
   ∴只除事障（離群索居）最高聲聞；唯從理障（正知見）入→菩薩→成佛
```
連結要點：正知見（入法界／知一切是影像）是了生死的真正閘門；事上苦修再久，理障不破頂多聲聞〔行514-526,555〕。

## 11. 日常實踐

1. **以「影像故」下手斷愛。** 遇到執著、比較、嫉妒時，回到「這是我見分所現的相分＝影像」；知它是影像、干擾不了我，心自清淨——不必先分析、再對治〔行98-113,312-318〕。
2. **檢查自己的「愛」在哪一層。** 行善求福報＝天人一條、仍是輪迴；連「愛清淨、愛涅槃、愛成佛」都是「還滋愛本」——目標不在人天、在了生死〔行226-242,340-342〕。
3. **先修正知見，再談用功。** 判準只有一個：入法界／入本心＝正；心外求法／以世界為中心＝邪。縱使勸善、講得很好，若與了生死無關即邪見〔行516-524,649-658〕。
4. **念佛回到本心。** 念佛是「念我的心、心跟佛本無二」，愈念愈清爽（入本心）；若心外求「阿彌陀佛垂憐加愛」則愈念愈煩惱，是邪見〔行545-553,557-559〕。
5. **臨命終回歸自性即淨土。** 「愛不深不墮輪迴，情不重不生娑婆」；二六時中安住本心，於虛幻相中做事而不被相干擾，當下即入佛性〔行459-461〕。
6. **擇師如擇命。** 善知識難遇；「成就與否，總在遇緣不同」。聽到菩薩性正知見法要珍惜（百千萬劫難遭遇），莫被「這邊也有道理、那邊也有道理」搖動〔行569-571,626-642〕。

## 12. 延伸・參

- **前後脈絡**：本講為【頓法四章複習】＋【彌勒章主文】；彌勒章偈頌與第六位**清淨慧菩薩**留待第21講〔行670-672〕。金剛藏章「三非正問」與「不定種性」宜對讀第19講。
- **相關法脈延伸**：達磨《血脈論》、神會《顯宗記·五更轉》、永嘉《證道歌》、宗密《圓覺經大疏鈔》、賢首《妄盡還源觀》（一體二用三遍）〔行120,181,369,389〕。
- **參問**：法師說「理障若除，事障必除；事障若除，理障未必除」，故「理障除、事障存」是非正問。試問：這是否等於說——真正的解脫關鍵永遠是「見地（正知見）」而非「工夫（離塵苦行）」？若見地已正而習氣（事障）猶在，圓覺經如何安立此人（提示：經文「二障已伏即能悟入菩薩境界」）〔行581-587〕？
