## 1. 本講概要

本講是《圓覺經》十二章中「金剛藏菩薩章」的正講。體佛法師先以近一半篇幅**溫故知新**，把前三位大士（文殊、普賢、普眼）佛陀所答之義依次複習——文殊章的「知是空花即無輪轉」〔行53〕、普賢章的「知幻即離，離幻即覺」〔行86〕、普眼章的漸次法「觀身心是假→從假入空→非幻不滅」〔行92-103〕——然後才切入第四位金剛藏菩薩的「三疑」。

法師點出全章關鍵：金剛藏是「示現挑戰」的大菩薩，明知故問、演一齣戲替未徹悟的眾生發問〔行135-137〕。三疑的實質是「**用輪迴心（攀緣心）去看圓覺**」，前提本身錯誤，所以佛陀不逐條回答，而是「解答一個法性以後你自然會懂」〔行197〕。佛以四喻（動目、定眼、雲月、舟岸）證明「不動者被會動者帶動」——是攀緣心在動、圓覺本不動〔行319〕；再以「幻翳空華」證明「本來無翳、本來無花」——眾生本無無明、本來成佛，三疑的相對待前提根本不成立〔行372〕；末以「銷金礦」證明佛性本具、成金不重為礦〔行542〕。

貫穿全講的一條主線是**「色類各有道」與「唯心所現、唯識所變」**：世界萬物本是無心的「常」，輪迴不是外境造成，而是第六、第七識攀緣心的「取捨」造成〔行283-285〕。法師又援宗密大師《圓覺經大疏釋義鈔》的「三疑＝疑自、疑師、疑法」框架，把金剛藏三疑對接到每一位學佛人自身的信心問題〔行210-222〕，並以「圓覺就是本心、就是阿彌陀、就是淨土」會通淨土與密咒〔行149-153,609-611〕。

## 2. 大綱

- **一、複習前三章（頓→漸的鋪陳）**〔行51-113〕

## 4. 故事・公案

### 4.1 愛迪生看實驗室大火〔行163-167〕
法師舉近代發明家愛迪生為例：有一天愛迪生的實驗室失火，眾人驚慌，愛迪生卻只是一直在看火，人家問他為什麼看火，他說「好不容易看到這樣壯觀的火焰」。法師對照：平常我們看別人家失火會緊張——第一怕延燒到自己家，第二「好在離得遠」卻仍擔心「若是我家怎麼辦」〔行165〕。愛迪生的態度證明：**火災本身不會造成人的痛苦，是自己的心在痛苦**〔行167〕。這印證「一切境界在心外，隨類各生色，色類各有道」——境界無染，是攀緣心在取捨。（法師舉例，非經典公案。）

### 4.2 蘇東坡「廬山煙雨浙江潮」〔行295-302〕
法師以蘇東坡詩開示「開悟不會怎麼樣」：詩云「廬山煙雨浙江潮」——廬山最美是煙雨，浙江最美是錢塘潮。「還沒有到的時候千般恨不消」，你想盡辦法要去體悟觀賞；「有一天你到了，別無事」，發現「依然是廬山煙雨浙江潮」〔行297-299〕。法師借此說明開悟前後「二六時中，吃飯睡覺，依然一樣」，差別只在「你的疑解開了」〔行302-304〕。（法師引用，屬詩偈開示。）

### 4.3 衣索比亞垃圾堆裡的孩子〔行574-577〕
有記者到衣索比亞，本想拍片回台灣告訴小孩「你們很幸福」，最後影片卻不敢發表——因為發現衣索比亞的孩子在垃圾堆裡追逐、很快樂，「比台灣幸福」〔行574〕。法師以此證明：**乾淨與不乾淨、煩惱與不煩惱，都是你的心在分別**，世界的東西（色類各有道）不會告訴你它乾淨或骯髒〔行577〕。（法師舉例。）

### 4.4 臥輪禪師 vs 六祖：有伎倆／無伎倆〔行539-540〕
法師引禪門公案對比：臥輪禪師偈「臥輪有伎倆，能斷百思想」；六祖惠能即答「惠能無伎倆」——為什麼「無伎倆」？因為「秉性而為，本來的自性就會想，所以不斷百思想」〔行539-540〕。法師以此糾正「修行＝斷念滅相分」的誤解：六祖除的妄想「不是不要想，是不要亂想」〔行539,745〕。（禪門公案，見《六祖壇經》機緣品。）

### 4.5 傅大士「夜夜抱佛眠」〔行448-452〕
承上一週所講，法師重提傅大士偈意：本心（諸佛如來、上帝）「天天跟你一起睡覺，天天跟你一起起床，你的語默…都跟你在一起，跟你鎮相隨，纖毫不相離」〔行448-452〕。以此說明「上帝與我同在」的圓頓義——上帝＝諸佛如來＝我的本心，當然與我同在。（法師引傅大士《心王銘》／〈獨自詩〉意，屬前講回顧。）

### 義理深入

**（一）三疑的共同病根——以輪迴心辨圓覺。** 法師反覆強調：金剛藏三疑不是「三個獨立的問題」，而是同一個結構性錯誤的三種表現——**用會動、會取捨的攀緣心去看本不動的圓覺**〔行317〕。佛陀「不用一個一個回答」，因為「你問的問題全部非正問、全部不對題」〔行365〕。四喻正是要證明：你看見水動、火轉、月走、岸移，並非水火月岸真的動，而是你的眼、你的舟在動〔行338-350〕。同理，圓覺本不輪迴，是攀緣心在輪迴，而攀緣心與圓覺「是同一件事」——攀緣心作主時圓覺不顯，放下攀緣心圓覺即顯〔行313-317〕。這是本章的軸心：**問題不在圓覺，在觀圓覺的那顆心。**

**（二）幻翳空華——把「相對待」連根拔起。** 法師指出金剛藏三疑的語言結構都是「相對待」的：有無明才需成佛、既本成佛何來無明、成佛後何時退回煩惱〔行480-490〕。佛以幻翳空華回應：翳與華「非相待」——不是「眼睛好了才沒有花、眼睛壞了才有花」，而是**本來就沒有病、本來就沒有花**，這是絕對，不是相對〔行478-482〕。由此正破第一疑的前提：「你卻告訴我眾生本無明，眾生哪有本無明？無明是你認為自己無明才無明」〔行384-386〕。前提錯，後面全錯——這是法師對全章最凝練的判語：「第一個前提錯，全部問的問題都錯」〔行464〕。

**（三）生死涅槃「同於起滅」的操作義。** 法師特別辨析「同於起滅」不是「同時存在」，而是「同時可操作」〔行512-515〕：迷時生死起、涅槃隱；悟時涅槃顯、生死滅。故「生死不離涅槃、涅槃不離生死」，關鍵只在「各位迷跟悟」〔行516〕。這把《圓覺經》的了義（生死涅槃猶如昨夢）落到修行者當下一念的迷悟抉擇上。

**（四）銷金礦與妙圓覺心——正答二三疑。** 第二、三疑（本成佛何來無明／如來何時復起煩惱）由「銷金礦」正答：金本在礦中、非銷才有（本具佛性）、成金不重為礦（成佛不退）、金性不壞（不復起煩惱）〔行631-635〕。再以「妙圓覺心本無菩提及與涅槃」點出**「本有即本無」＝真如**的深義——菩提涅槃若是「加進去的」就不是本來，正因本有故說「本無」〔行642-644〕。法師稱這是「這個翻譯太好了：真如＝本無」〔行644〕。

**（五）聲聞偏真 vs 圓覺大般涅槃——見地決定修法。** 末段法師用大篇幅辨聲聞緣覺：聲聞依「身是苦」而修苦集滅道、有「苦」可斷；緣覺依十二因緣、有「無明」可斷〔行662-674〕。凡「有對象可破」者所證皆偏真涅槃（一半）〔行676〕。而了義一乘：無明本是妄認、輪迴本是幻相，「沒有可斷不可斷」，直入本心即大般涅槃〔行682-685〕。故佛判聲聞「狹劣無識」不是貶低其人，而是指其「從世界而出發、還有對象可斷」〔行686〕。法師由此收於《楞嚴》「自心取自心…不取無非幻」與六祖「不染萬境而真性常自在」：**修行不是滅相分（斷念），而是「不取」「不染」**〔行722-745〕——這正是《圓覺經》圓頓與聲聞漸修的分水嶺。

## 10. 法脈會通

### 10.1 金剛藏三疑 ↔ 宗密三疑 ↔ 學佛人自身（連結地圖）

```
                    金剛藏三疑（圓覺經 T0842）
                    ┌──────────┬──────────┬──────────┐
       ①眾生本無明怎成佛   ②本成佛何來無明   ③如來何時復起煩惱
                    │          │          │
   宗密判 ─────────┼──────────┼──────────┤
   （圓覺經大疏釋義鈔）  疑自          疑師          疑法
                    │          │          │
   落到學佛人 ───── 我能否入理?   老師是否善說(正說)?  此法能否出離?
                    │          │          │
   佛以了義破 ───── 幻翳本無翳     以了義經＋講了義者為師  絕對出離
                    (本無無明)      (不離圓覺＝善說)     (圓覺是究竟中究竟)
                    │          │          │
                    └──── 破疑開信「信為道元功德母」→入信位→入地 ────┘
```
- **連結要點**：法師把金剛藏三疑與宗密「疑自／疑師／疑法」對接，再落到每位學佛人身上〔行210-242〕。三疑一破，信生（信為道元功德母）則必成佛；三疑不破，信不能出、落三大阿僧祇劫〔行143,222-224〕。

### 10.2 四喻 → 動／不動的等式（結構圖）

```
   會動（妄心＝輪迴心）          不動（圓覺＝本心＝不二＝金剛）
   ─────────────           ─────────────
   動目（眼在動）    ────►     湛水（水本靜）
   定眼（妄現轉）    ────►     旋火（火本一點）
   雲駛（雲在動）    ────►     月運（月本不動）
   舟行（舟在走）    ────►     岸移（岸本不動）
                    誤　認
   ⇒ 以輪迴心觀圓覺 → 圓覺「即同流轉」→ 便生三惑〔行319,346-365〕
```
- **連結要點**：左欄四物皆「會動的妄心」，右欄四物皆「本不動的圓覺」；眾生「用會動的來看不動的，這些不動的也會動」〔行358〕，於是誤生三疑。

### 10.4 聲聞／緣覺／圓覺——涅槃三層（辨析表）

| 乘 | 依何而修 | 所破對象 | 所證涅槃 | 病處 |
|---|---|---|---|---|
| 聲聞 | 依身（身是苦→世界是苦） | 苦（苦集滅道） | 偏真涅槃（一半） | 有對象可斷，斷不盡 |
| 緣覺 | 依攀緣心（無明） | 無明（十二因緣） | 偏真涅槃 | 肯定有無明可破 |
| 圓覺（一乘了義） | 直入本心 | 無可破（無明本妄認、輪迴本幻相） | 大般涅槃（本自涅槃） | 無病——不取、不染 | 
- **連結要點**：〔行662-705〕。「有對象就有疲憊，沒有對象怎麼會疲憊」——妙菩提門無疲憊，因它天天跟你在一起〔行686-688〕。

### 10.5 十二因緣（緣覺所修，法師展開）

```
無明 → 行 → 識 →(投胎)名色 → 六入(眼耳鼻舌身意)→ 觸 → 受(苦受/樂受)
  → 愛 → 取 → 有(煩惱)→ 生 → 老死 →(復始輪轉)
```
- **連結要點**：〔行666-672〕。緣覺「先肯定有一個無明」而修破無明；但了義法「無明是妄認而來，本來無無明」〔行682-684〕。

## 11. 日常實踐

1. **煩惱起時，回到「相分」上覺察**：煩惱從來不是外境，是「你自己產生的相分在煩惱」——把外境轉念即無〔行65,82〕。凡所有相皆是虛妄，不執相即現本心〔行503〕。
2. **保養身體 ≠ 修行**：身體屬「色類各有道」，該保養（讓色身多些時間了解真心），但「修到不會老、不會死」是佛說大邪見〔行470-472〕。
3. **念佛／持咒的正因**：都是「回歸本心」，不是求福報、求接引、求摸頭讚獎——那是「大愚痴」〔行178,606〕。福報也是「水中捉月爭拈得」，著相布施終不究竟〔行71,180-182〕。
4. **不亂想，而非不想**：六祖「除妄想」是「不要亂想」，不是斷念滅相；「一念不生」是不執著念，不是不生念〔行539,745〕。真性常自在＝不染萬境。
5. **以宗密三疑自我檢視**：常問自己——我學這個入理了嗎？我的老師（或所依的經）是否「不離圓覺」的善說？此法能否讓我出離？三疑消則信生〔行222-242〕。
6. **境界無美醜，美醜在心**：好夢壞夢都是夢，只要干擾不了你，「惡夢也是好夢」（永明延壽語意）〔行159-161〕。
