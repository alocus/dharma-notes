## 1. 本講概要

本講承第一講而來，分兩大段：

1. **緒論收尾——圭峰宗密何以「以圓覺為宗」**〔行115-295〕：法師接續介紹華嚴五祖**圭峰宗密**（荷澤神會禪法脈＋清涼澄觀華嚴法脈）如何發揚《圓覺經》。核心是宗密自述「**余心宗圓覺**」「**念念因圓，念念果滿**」——因的當下就是果、因果不二，這才是「圓頓法」〔行195-210〕。宗密感慨當時「**顯性之教沉埋，名相之宗鼓舞**」〔行210〕，遂立志「**黜小抑權，顯頓張圓**」〔行256·274〕，把性（宗）用教來發揚。並旁及其兩大著作《禪源諸詮集》（主禪教合一）、《原人論》（三教之主皆聖人，而了生死之圓頓法唯在佛家）及其對宋明理學（二程、陸九淵、朱熹、王陽明）的影響〔行307-393〕。

2. **正式進入圓覺經序分**〔行395-760〕：法師逐句開講「**如是我聞，一時婆伽婆入於神通大光明藏三昧正受……於不二境現諸淨土**」。他點出圓覺經序分之**三大特異**：無說法之「地點」（不在靈鷲山、祇樹給孤獨園，而在**神通大光明藏**）、佛號用**婆伽婆**（不指名釋迦，彰「依法不依人」）、以「**如**」字為綱（「如」＝眾生本成佛的真平等）〔行530-538〕。並以六祖風幡「仁者心動」、毗舍浮佛偈、僧肇〈物不遷〉、華嚴〈菩薩問明品〉「各各不相知」層層會通，闡明「神通大光明藏」即圓覺、即自性清淨圓明體，最後歸到「**自受用／他受用→於不二境現諸淨土**」〔行736-740〕。

貫串全講的命題：**圓覺不是漸修所成的果，而是本自現成的自性**——「虛空本無空華，真金理無重礦」〔行258-262〕、「始知眾生本成佛」〔行428〕，這是了義中的了義、剎那成佛之法。

## 4. 故事・公案（全程敘事）

### 4.1 永嘉大師「一宿覺」——憑《法華》《維摩》而證〔行128-135〕〔行323-325〕
永嘉玄覺（永嘉大師，世壽四十九）住溫州（上海旁），為印證己悟，以古代之不便交通，經浙江、江西、福建到廣州見六祖。對話不到十分鐘（老實講不到一小時），六祖便印可、永嘉更確定己之證量，遂以六祖為師。六祖留他住一晚，故稱「一宿覺」。法師強調：永嘉之悟**不是六祖教的**，是憑《妙法蓮華經》與《維摩經》兩部經為他作證。他後來寫《證道歌》，是了義中的了義。法師又補：永嘉本欲託玄策帶問題請六祖答即可，卻親自走一趟——為的是**聆聽六祖的語言**（「此方真教體，清淨在音聞」）〔行323-325〕。

### 4.2 安史之亂與睢陽張巡許遠、荷澤護國水陸大法會〔行157-181〕
荷澤神會七歲悟禪、有神童之稱，勇敢北傳南宗頓禪卻屢遭北方勢力阻礙，一再失敗。他等待時機——**安史之亂**爆發：胡人節度使叛變，長安、洛陽失守，唐玄宗逃四川、殺楊貴妃。北方幾破，南方江南亦幾破，賴**張巡、許遠**死守睢陽城（城破仍守住南方，郭子儀軍隊才得以鞏固江南，斷安史入南之路）。今民間拜二人為「二王廟」；張巡城中無糧，殺其妻分食將士，故凡供奉張巡必配祀張夫人為妃。荷澤見安史之亂民不聊生，啟建一次**護國水陸大法會**（古代水陸非年年定期，唯國難或亡靈眾多之因緣才啟建）募款換糧、賑濟難民。此善行看在唐肅宗、代宗眼中，遂請神會入宮聽南頓法——他成了南禪傳入北方五祖法脈中的第一人。法師並藉此點「超度」真義：**心清淨、心安靜，就達到超度的效果**〔行173〕。

### 4.3 宗密自證圓覺——「余心宗圓覺，念念因圓念念果滿」〔行195-210〕
法師「盡量引原文」，述宗密看了圓覺後說：「**余（宗密自稱）心宗圓覺**」——以圓覺為宗。何以故？「**念念因圓，念念果滿**」：一念的「因」圓，念念的「果」就滿；因的當下就是果，故**因果不二**，這才是圓頓法。法師以此收束「圓頓」的定義：不是修因等果，而是因即是果、當下現成。

### 4.4 黃蘗三巴掌、麤行和尚→斷際禪師〔行329-337〕
太子李忱（後之唐宣宗）見黃蘗禪師禮佛，被打三巴掌。後裴休奏請為高僧賜聖號，宣宗記恨，封黃蘗為「**麤（粗）行和尚**」——說他打人三巴掌、行為粗野。裴休是黃蘗弟子（《傳心法要》即裴休所編），大膽把封號改為「**斷際禪師**」，事後才稟宣宗。宣宗初不悅（你敢改我聖旨），裴休解：他打你三巴掌是「斷你三際」——斷你過去、現在、未來，讓你能當下成佛，這是你累劫修來的福報。宣宗聞之大喜，讚改得好。

### 4.5 裴文德（法海）出家、老僧一炷香消萬劫糧〔行342-369〕
宰相裴休最聰明的兒子裴文德未冠即中狀元、被封翰林。裴休不願子在官場養貪瞋癡，鼓勵他出家（宰相之子本該培養為宰相，竟勸其現出家相）——「先頓悟成佛，再來度眾生，才是裴家要的人才」。裴文德即後之**法海禪師**（白蛇傳中與白蛇鬥法的那位法海，非六祖門下之法海）。師父無德禪師令他自小沙彌做苦役、挑水擔柴。法海心生抱怨、每天滴咕，被老和尚聽見，喚來說：「**老僧一炷香，能消萬劫糧**」——這一炷是心香，我已證悟，讓你挑萬劫水糧供養亦消得。法海當下跪拜懺悔。法師以永嘉「四事供養敢辭勞，萬兩黃金亦銷得，粉骨碎身未足酬，一句了然超百億」印之——重點在「**一句了然超百億**」〔行366〕。

### 4.6 六祖風幡「仁者心動」、印宗剃度頂禮〔行582-605〕
六祖二十四歲離黃梅，在獵人隊中隱十五年（真正的苦修——與天天打獵之人相處而能圓融安穩），因離北愈遠愈安全，遂至嶺南，途中還曾被追殺、躲山壁、遭放火。後至廣州，聽印宗老和尚講經。有人爭論「風動／幡動」，一人說旗動、一人說風動；這位貌不驚人的在家人起立：「**非風動，非幡動，是仁者心在動**」。印宗震動，罷講留他，問「你是何許人、為何知心在動」，六祖答「**本自具足，本來就這樣**」（不是引哪部書，而是本來如是）。印宗方知即隱十五年、有法脈的六祖，遂為這位尚未受具足戒者剃度，並率眾向他三頂禮、請六祖主法。法師讚：能講出「心動」還能演出《六祖壇經》，才是**禪教合一**——真禪師一定講得出教理。

### 4.7 憨山大師的梵志公案、被充軍與復興曹溪〔行647-680〕
憨山德清（明四大高僧，示現全身舍利，如六祖）因捲入明神宗萬曆宮廷立儲事被充軍嶺南（廣東）。古代充軍者臉上黥字（如《水滸傳》宋江、武松），受戒點三點亦此類表徵。憨山至嶺南見六祖金身，發願復興**曹溪**（六祖祖庭）。其少時母親有意培養讀書，他問「讀書為何」——答科舉、當宰相；再問當宰相之後如何——答退休；他遂問「有沒有一種行業永不退休」，母答「有——**入不動地，永不退休**（入佛位）」，憨山即言「那我要成佛」，母親竟送他剃度（「既我兒有大丈夫之志，我答應你成佛」）。法師請大眾為憨山之母鼓掌〔行662〕。憨山苦修久悟不出，一日聞一公案：一梵志（修行人）離鄉久歸，鄉人不識，有人問「你是不是當年離家去修行的那個人」，答「**也是也不是**」——憨山竟由此大徹大悟。此句對應華嚴〈菩薩問明品〉「各各不相知」與僧肇〈物不遷〉（見§8）。

### 4.8 陳惠明奪法脈、不思善不思惡〔行718-726〕
將軍陳惠明追六祖欲奪回法脈。六祖知逃不了，故意將衣缽放石上任其取；陳惠明卻提之不起（《六祖壇經》云「舉之不動」）。法師破解：不是衣缽真重、不是示現神通，而是陳惠明**良心發現**——「這真是五祖法脈，我這樣奪人家的太過分」，故覺得重。六祖遂主動現身，陳惠明求開示，六祖只答：「**不思善，不思惡，正與麼時，還你本來面目**」——善惡、罪福、好壞是非皆攀緣心之覺受，合而為一、守一，即回歸自性、即道。

**義理深入**

**（一）「神通大光明藏」是全經的說法之「處」，也是全經的宗旨。** 法師特別點出圓覺序分之異於他經：金剛經有「舍衛國祇樹給孤獨園」、法華有「靈鷲山」，圓覺卻**無實際地點**〔行534-538〕，因為它是「在圓滿覺性的法身寂靜處講出的經」〔行560〕。這一「無地點」不是遺漏，而是宗旨的直接顯示——說法之處即是所說之法：神通大光明藏＝圓覺＝自性清淨圓明體。法師隨即用一串別名把它與各宗會通（楞伽「一心寂滅」、妄盡還源觀「自性清淨圓明體」、如來藏清淨心、華嚴「一真法界」、起信論「眾生心」），並以六祖「何期自性」五句與「鏡子」譬喻落實：鏡本自清淨、本不生滅、本不動搖、本自具足、能現萬像——正是「寂照」二字，寂而常照、照而常寂〔行552-558〕。

**（二）「如是我聞」的「如」＝真平等＝本經的入門關。** 法師把序分第一字「如」抬到全經綱領的高度：只有「眾生本成佛」才平等，凡有「我已成、眾生未成」之見，心即不平等〔行414-416〕；真清淨連「清淨」二字也不立〔行418〕。這與圓覺正文「**始知眾生本成佛**」〔行428〕、與序分「是諸眾生清淨覺地」「平等本際」完全一貫。故「如是我聞」不只是阿難的作證套語，更是叫讀者當下回歸「本自是佛」的真我（常樂我淨的我）、以參與者身分入會〔行436-462〕。

**（三）「婆伽婆」不指名，彰「依法不依人」。** 序分不寫「世尊」「釋迦牟尼佛」而用「婆伽婆」，法師解為：圓覺的道理是「究竟成佛人講出來的話，不需指名是誰」〔行530-532〕——有此境界者一律稱佛，故「圓覺多麼特殊」。這正是四依法「依法不依人」在經文開端的落實，也回應了上半講宗密「余心宗圓覺」之所以能成立：宗所依者是法（圓覺自性），非某一人。

**（四）「於不二境現諸淨土」＝自受用起他受用。** 法師以序分末句作本講的落點：從「不二境」（自性寂滅、不生不滅）現出淨土，是「自受用」轉「他受用」的結果〔行736-740〕。他嚴分「心淨土」與「人間淨土」：人間是五濁惡世不會變成淨土，唯有你的心淨土才是淨土〔行742〕；沒開悟的人也有自受用他受用——那是貪瞋痴，現出的是餓鬼、畜生、地獄〔行744〕。此句同時預告下一講「不二」正文。

## 10. 法脈會通（結構圖）

### 10.1 「神通大光明藏＝圓覺」——各宗別名等式〔行541-552〕

```
   神通大光明藏（圓覺經序分·說法之處）
        ＝ 圓  覺（圓滿覺悟）
        ＝ 自性清淨圓明體（華嚴·妄盡還源觀 T1876）
        ＝ 一心寂滅（楞伽經 T0670）
        ＝ 如來藏清淨心
        ＝ 一真法界（華嚴經 T0279）
        ＝ 眾生心／法界（大乘起信論 T1666「所言法者謂眾生心」）
        ＝ 何期自性（六祖壇經 T2008：清淨·不生滅·不動搖·具足·能生萬法）
```
**連結要點**：這是全講最核心的「等式串」——說法之「處」即所說之「法」。故圓覺經無地點，因法身寂靜處即神通大光明藏；六祖五句與「鏡子」譬喻是它的白話註腳（寂照）。

### 10.2 三聖圓融觀——以華嚴解圓覺〔行297-299·432-434·754-756〕

```
                大方廣的「大」＝ 毘盧遮那佛（法身·中）
                        ╱                ╲
      文殊（智）── 你懂自性清淨圓明體 ＝ 入信位
      普賢（行）── 把文殊智用在日常生活 ＝ 入地行
                        ╲                ╱
           文殊智＋普賢行 合  =  毘盧遮那 = 三聖圓融無礙
```
| 三聖 | 表 | 圓覺十二章對應〔行754-758〕 | 定位 |
|---|---|---|---|
| 毘盧遮那 | 大（法身·體） | 全經所依之圓覺體 | 中 |
| 文殊師利 | 方廣·智 | 〈文殊章〉——聞之入信位即成佛（上上根） | 第一主角 |
| 普賢 | 方廣·行 | 〈普賢章〉——依之起行即入地 | 第二主角 |

**連結要點**：此觀出清涼澄觀，宗密極契而用以解圓覺；法師「賢首禪苑」講堂背景即取「文殊—毘盧遮那—普賢」三聖之義〔行754〕，故本經下講先講文殊、普賢兩章。

### 10.3 宗密「黜小抑權·顯頓張圓」——判教梯階〔行256-295〕

```
  華嚴五教：  小 → 始 → 終 →【 頓 → 圓 】
              └──黜·抑──┘     └─顯·張─┘
   （小/始還在「空花裡做文章」）   （虛空本無空花·真金理無重礦）
                                        │
   宗密：念念因圓 → 念念果滿（因即是果，因果不二）〔行195-210〕
                                        │
   反例：因地不真 → 果招迂曲（因不真，果必不圓滿）〔行264〕
```
**連結要點**：圓頓法「入信位即入佛位、知因即知果」〔行264〕，故不需一直講次第；「眾生本成佛，講圓頓法他聽得懂，不需再這些次第」〔行268〕。

### 10.4 「境↔心」相依——毗舍浮佛偈 × 各各不相知 × 物不遷〔行607-712〕

```
  本來只有「自性清淨圓明體」一物（本無心）
        │  因境 → 才生「心」（心本無生，因境有）
        ▼
  心不自心，因境故心 ── 境不自境，因心故境（相依而起，皆無自體）
        │
        ├─ 毗舍浮佛偈：假借四大以為身，心本無生因境有，
        │              前境若無心亦無，罪福如幻起亦滅
        ├─ 華嚴問明品：湍流/大火聚——各各不相知，諸法亦如是
        ├─ 僧肇〈物不遷〉：境不遷（動的是心，不是境）
        └─ 電影譬喻：一秒24張底片，張張不相知 → 快到成「動態」
                 → 生滅同時（一千二百兆次）→ 不生不滅 → 悟無生
```
**連結要點**：凡夫見「湍流不息」的動態，開悟者見「每一靜態剎那相續」＝各各不相知；由此知「動的是心不是境」，一切外境干擾不了你——這就是「神通大光明藏」的受用。

### 10.5 自受用／他受用 → 現諸淨土〔行736-744〕

```
   開悟 ──┬── 自受用：自己頓悟，沒煩惱（不生不滅本身的寂滅）
          └── 他受用：於不二境現「不生不滅·永恆不變」的淨土
                          → 自性彌陀·唯心淨土（沾邊者亦能成佛）

   未悟 ──┬── 自受用：貪瞋痴（自己受）
          └── 他受用：現餓鬼·畜生·地獄
```
**連結要點**：同一「自受用·他受用」結構，悟則現淨土、迷則現三惡道——「境是因為什麼才會有境」，全在自心（自心取自心）〔行718·744〕。

## 11. 日常實踐（可操作要點）

1. **煩惱是攀緣心設定的需求**：老、賠錢之所以煩惱，是因先設定「該年輕、該富有」；知「本來就生老病死、多少不增不減」，煩惱自然沒有——不是去「斷」煩惱（斷煩惱即無明，越斷越煩）〔行80-91〕。
2. **看萬物皆合掌念彌陀＝練「如」**：看到任何人、甚至小狗都「阿彌陀佛」，習慣到起心動念皆彌陀，即證真平等（我心即彌陀、此方即淨土）〔行422-426〕。
3. **諦聽＝放下主觀意識**：來聽法先放下今天的不開心、批判、成見（全是幻影），才聽得進、才與本心相契；有主觀意識來聽是「雜聽」，坐著也不耐煩〔行452-454〕。
4. **辨「懺悔」與「後悔」**：懺悔＝把留在心中的罪惡感從根拔起（罪福如幻，起亦滅，不再做也不再回想褒貶自己）；後悔＝一再留著罪惡感到死，死後仍帶著這心去輪迴。修行沒有「後悔」二字〔行625-631〕。
5. **修行不玩神通**：修到透視眼看血管，不如買個血壓機（花五毛錢）；把「玄」放進佛法會遮蔽自性——佛法全是道理，沒有玄〔行728-734〕。
6. **不求外在靈驗**：玄天上帝踏龜蛇是「已降伏貪痴」的表法，不是顯靈保佑；著相問「哪間靈哪間不靈」即迷。瘟疫、戰爭不會因求拜而止，那是世俗諦的無常（本來就有）〔行635-641〕。
7. **心淨土，非人間淨土**：不要幻想把五濁惡世造成人間淨土；把善惡罪福放下的那天，就是自性淨土成熟之日〔行718·742〕。
8. **語言大於文字、要聽經**：文字易誤解，語言更能開悟（此方真教體，清淨在音聞）；如發課本仍要老師講解——故不能只看經、要聽經、不能離開老師〔行316-327·510〕。

- **參問**：法師說圓覺「無地點——在神通大光明藏講」〔行538〕，又說「翻開經典你就在法華會上（儼然未散）」〔行460-462〕。若說法之「處」即所說之「法」（自性），那麼讀者「當下即在會中」的條件是什麼？（提示：法師答——你要以「參與者」而非「旁觀者」的心「諦聽」，放下主觀意識、回歸常樂我淨的真我〔行452-458〕。）
