## 1. 本講概要

本講是《圓覺經》第 24 講，進入正宗分**第七位·威德自在菩薩章**。前六章已依次由文殊、普賢、普眼、金剛藏（頓法四位）與彌勒、清淨慧（漸法二位）鋪陳「眾生本具圓覺自性」與「隨順覺性」之次第；威德自在菩薩承此再問：既然無修無證，落實到修行「一切方便漸次，并修行人總有幾種」，求最簡捷之門〔行226〕〔行333〕。佛答以**圓覺三法**——奢摩他（止）、三摩鉢提（觀）、禪那（靜慮）——並強調三法共同的前提是「悟淨圓覺、以淨覺心」，即**稱性而修（悟後起修）**，否則皆為「迷中修、盲修瞎練」〔行517〕〔行519〕。本講時間所限，只圓滿細講第一法奢摩他〔行613〕。

貫串全講的一條主線：**一切修行法門（念佛、持咒、止觀）都只是「方便有多門」，其唯一歸元是「回歸自性」**。體佛法師以此串起淨土（截流正信念佛、蕅益彌陀要解、中峰三時繫念、觀音勢至授記因緣）、華嚴（賢首國師妄盡還源觀「性起繁興法爾止」）、禪（六祖遊戲三昧）、天台三觀、楞嚴三法，證成「禪淨密一體、圓覺三法即成佛總關」〔行231〕〔行391〕〔行482〕。

## 3. 核心概念

| 概念 | 體佛法師釋義〔行〕 | 經教連結（已驗證） |
|---|---|---|
| **隨順覺性** | 眾生與佛三無差別、本已自證圓滿覺性；本無修無證，因未到程度、隨菩薩問而起修證，此回歸覺性之過程即名隨順覺性〔行237-270〕 | 《圓覺經》清淨慧章分凡夫／菩薩未入地／如來隨順覺性 ✓ T0842 |
| **圓覺三法** | 任何人成佛都不離的三個漸次法門：奢摩他(止)、三摩鉢提(觀)、禪那(靜慮)〔行231〕〔行472-475〕 | 「圓攝所歸循性差別當有三種」✓ T0842 |
| **悟淨圓覺·以淨覺心** | 三法共同前提：先體悟眾生本具圓覺自性，以不生不滅之圓覺本心為正行；不然即「迷中修·盲修瞎練」〔行517-521〕 | 三段經文開頭皆同此八字 ✓ T0842 |
| **稱性而修（悟後起修）** | 悟→以淨覺心為正因→洗淨習性→圓證自覺心而成佛，四階段合稱稱性而修；對比「迷中修」修再久亦無本得〔行523-537〕 | 師承法義，繫於 T0842 三法前提 |
| **奢摩他（止）** | 以「靜」為修行前導；此靜非作意之靜，而是見地：知世間一切皆從覺性出、皆是影像故干擾不了我〔行544-591〕 | 「以淨覺心，取靜為行；由澄諸念，覺識煩動，靜慧發生，身心客塵從此永滅，便能內發寂靜輕安；由寂靜故，十方世界諸如來心於中顯現，如鏡中像。此方便者名奢摩他」✓ T0842 |
| **靜（取靜為行之靜）** | 不是修一個靜的境界（越修越不靜），而是「證諸幻滅、以影像故」的智慧——凡所有相皆虛幻，念頭全是影像〔行546-560〕 | 呼應清淨慧章「證諸幻滅」；金剛經「凡所有相皆是虛妄」✓ T0235 |
| **覺識煩動·阿賴耶** | 靜慧發生後覺知：煩動生滅之念皆從第八識阿賴耶（藏識，攝六七識分別執著）所現之無明生滅相，亦是幻相〔行562-595〕 | 圓覺經奢摩他段「覺識煩動」✓ T0842 |
| **身心客塵·身心脫落** | 身心如客棧之客人（生死交錯、四大剎那變），不是主人翁（覺性）；智慧觀照令身心脫落，進而「本無身心可脫落」〔行570-575〕 | 「身心客塵從此永滅」✓ T0842 |
| **寂靜輕安** | 因用靜修行、進入寂靜，煩惱重擔一切放下、自在無比；此時十方如來與我合一〔行576-582〕 | 「便能內發寂靜輕安；由寂靜故，十方世界諸如來心於中顯現，如鏡中像」✓ T0842 |
| **威德自在** | 自在=本心，本心本來自在；唯自性不生不滅之功德才稱威德，非世間權勢財力（可滅有生滅）〔行218-233〕 | 《心經》「觀自在」✓ T0251；藏傳大威德金剛=文殊忿怒尊 |
| **承佛圓音** | 圓=正，圓音=正音=入法界；一切從法界流、還歸法界〔行272-275〕 | 華嚴「無不從此法界流，無不還歸此法界」（澄觀《華嚴經疏》引 ✓ T1735） |
| **覺受 vs 覺性** | 覺受會痛（依四大假合神經而起、是幻化）；能「知痛」的覺性本身不痛。凡夫從痛生煩惱造業，修行是體悟此見地而非修到不痛〔行173-206〕 | 師述觀法，繫圓覺「幻垢」義 |

## 4. 故事・公案

### 觀世音・大勢至授記因緣——威德王與獅子遊戲金光王佛〔行359-391〕

體佛法師以此因緣詮釋「遊戲如來大寂滅海」與「無量印善巧法門」即回歸自性之六度萬行。**（本則出《觀世音菩薩授記經》T0371，宋·曇無竭譯；師講之人名與канон略有出入，見下「※」與 §12 校勘。）**

師述：過去有一國王（師稱「勝威王」），在「獅子遊戲金光王佛」時代求法，問：能否傳我一法，令我威德自在、悠遊菩提道？佛授以「**無量印善巧法門**」——告訴他：一切法本不生不滅，故無一法讓你「特別執取」、亦無一法讓你「特別不執取」；你就在此無所限制中，以國王身行六度萬行，時時迴向無上菩提（回歸真心本性），即成度眾生的法船、離生死的橋樑〔行362-370〕。國王依此修，忽於左右現二蓮花，各生一菩薩：一名「寶上」、一名「寶嚴」——寶上即**觀世音菩薩**、寶嚴即**大勢至菩薩**〔行378-380〕。二菩薩往見獅子遊戲金光王佛，說「今日未帶鮮花七寶來供養」，佛言：你回歸無上菩提、回歸自性的當下，已供養盡虛空遍法界的鮮花了〔行381-383〕。師結：這位成佛的父親就是**阿彌陀佛**，兩子即觀音、勢至，合稱**西方三聖**，此即淨土法門之來歷〔行384〕。

**※ 與 T0371 canon 的出入（保留師語、附正）：**
- 父王名：師稱「勝威王」；canon 作「**威德王**」（與本章「威德自在」正好呼應）。
- 二童子名：師稱「寶上／寶嚴」；canon 作「一名**寶意**、二名**寶上**」〔T0371〕。
- 蓮花出處：師稱「從左右脇現」；canon 作「其王左右有二蓮花，**從地踊出**」。
- **父王身分**：師稱父王即「阿彌陀佛」、成西方三聖；但 T0371 明文「爾時威德王者豈異人乎？**我身是也**」——即**釋迦牟尼佛**的過去生，二童子「今觀世音及得大勢菩薩摩訶薩是也」。師的「西方三聖」框架屬淨土會通的引申，與本經字面所指的「威德王＝釋迦」不同，宜分辨。

### 「獅子遊戲」之名的演繹〔行386-388〕
師釋佛號何以加「遊戲」二字：森林中唯獅子出來時如同遊戲、閒庭漫步，其他動物見之驚怖；牠想吃你就吃你、不想吃就放你一條路——以此表心性之自在無畏，故名「獅子遊戲」。

### 影子公案（自設譬喻）〔行130-136〕
師設問：若有人說「我今天心情不好，因為跟影子吵架、還辯輸了」，我們會笑他是大愚痴者。可是佛告訴我們真相：眾生不正是每天跟影子（幻相）吵架、鬥爭、分別、計較高下嗎？「回頭是岸」——回哪個岸？回本心這個岸，那就是阿彌陀佛〔行139〕。

### 義理深入

**(一)「隨順覺性」與「無修無證而起修證」的張力，本講予以會通。** 師指出經文常見矛盾：有時教修、有時教無修無證。其解：因「本來就圓滿覺性，何必修、亦無證」〔行244〕；然眾生「雖已成佛，卻是糊塗佛」〔行249〕，故隨菩薩問而「起一個修證的心」，此起修證即有漸次，漸次之目的正是回歸覺性——「當你回歸隨順覺性的過程，稱為隨順覺性」〔行268-270〕。串連起來即不矛盾。這是本章「方便隨順其數無量，圓攝所歸」在修證論上的落點。

**(二)「圓攝所歸，循性差別當有三種」是本章的樞紐句。** 師強調三法（奢摩他／三摩鉢提／禪那）並非三種外加的技術，而是「循性差別」——依同一圓覺自性、隨根性差別而開的三門，故三段經文開頭一律是「悟淨圓覺，以淨覺心」〔行511-521〕。師由此立下全經最嚴的判準：**未先悟自性而修者，一律是「迷中修、盲修瞎練」**，並明言「這不是貧僧所講的話，是諸佛如來的法要」〔行519〕。此即「稱性而修（悟後起修）」四階段：悟淨圓覺→以淨覺心為正因→洗淨習性→圓證自覺心而成佛〔行521-525〕。

**(三)奢摩他之「靜」被重新定義為見地而非境界。** 一般以為修止是修出一個安靜的境界，師反覆糾正：「你怎麼修靜？越修越不靜」〔行554〕。真正的「取靜為行」是「證諸幻滅、以影像故」——知一切念頭、煩惱皆是自性所現之影像（幻相），因其是幻故干擾不了我，此即靜〔行550-560〕。順此，「由澄諸念」不是斷念，而是明照諸念皆幻；「覺識煩動」是進一步照見這些幻相之源即第八識阿賴耶；「靜慧發生／身心客塵永滅」是照到身心亦客塵、脫落乃至本無身心可脫落；終至「寂靜輕安、十方如來心於中顯現如鏡中像」〔行562-585〕。整條奢摩他的次第，被師收攝為普賢章一句「知幻即離、離幻即覺」的展開〔行554〕。

## 11. 日常實踐

1. **念佛先明「念什麼佛」**：一句阿彌陀佛是「回歸自心」的提醒（南無=回歸），非求相上神通福報、非等佛來救贖；「自心取自心」〔行67-71〕〔行86〕〔行308-310〕。
2. **老實念佛的檢驗**：不是一天十萬遍的數量，而是「我就是佛、一句彌陀肯定我與佛無分別、西方在我心」〔行308-310〕；否則「彌陀口裡念彌陀，不識彌陀怎奈何」〔行313-315〕。
3. **痛時的參法**：痛時參「覺受會痛、覺性不會痛；能知痛的『知』不痛」〔行181-185〕；不從痛裡起煩惱、抱怨、損人利己（造業）〔行193-195〕；不執著幻化的覺受，當下回歸自性〔行199-204〕。
4. **修奢摩他（止）的下手處**〔行601-613〕：①先認取自有覺性(回歸自性)；②取「靜」為導行——見一切森羅萬象皆影像(凡所有相皆虛妄)；③知幻即離，一切放下(由澄諸念)；④照見煩動之念源自阿賴耶無明生滅、亦是幻，干擾不了我；⑤自性智慧油然生，身心如客塵脫落，乃至本無身心可脫落；⑥寂靜輕安、十方如來與心合一如鏡中像。師建議可作打坐法門〔行613〕。
5. **回頭是岸**：每天觀照「知幻即離、離幻即覺」，回頭回的是本心這個岸〔行139〕〔行142〕。
