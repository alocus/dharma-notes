## 1. 本講概要

本講是《圓覺經》系列第七講，前半承接、後半開新。前半以**文殊智**（第一大士）的結論「知是空花，即無輪轉」為軸，反覆申明**佛法不假外求、往內見本心才是了義**〔行79–81〕；後半正式進入**第二大士普賢菩薩章**，法師以「文殊是智、普賢是行」立骨——文殊深觀法性得根本智，普賢據此智而起「稱事重重無盡」的差別行〔行411〕。

普賢章的教學核心是**普賢三疑與佛陀三答**。普賢代眾生問出三個層層相逼的疑問：(1) 既然身心、修行皆幻，豈非「以幻修幻」？(2) 若諸幻性一切盡滅則無有心，誰為修行？(3) 眾生本不修行、久居幻化而不自知，如何令其解脫〔行284–286〕〔行445–475〕？佛陀的三答是全講最珍貴處：(1) **無妨以幻修幻**——了幻而未究竟者，正可依幻身幻心修；(2) **覺心不動,誰為修行**——以「鑽木取火，火出木盡而地不動」喻覺性如地不隨幻滅；(3) 為不自知的眾生開出頓法——**知幻即離，不作方便；離幻即覺，亦無漸次**〔行501–544〕〔行593–597〕。

貫串全講的方法論是**「以幻攝一切法門」**：法師把「如幻三昧」會通密宗大手印／大圓滿（普賢王如來→金剛薩埵百字明）、淨土（自性彌陀、實相念佛）、《大悲咒》《往生咒》（回歸自性、自啟大悲），並用一段罕見的**跨宗教對讀**——《聖經·加拉太書》「我已與基督同釘十字架」——來旁證「十字架＝縱橫普周法界的本心、身與世界皆無我」〔行353–370〕〔行609–615〕。末段法師自陳癌末之身仍講經，示現「緣來則緣應、不違世緣入究竟」，把普賢行落到日用〔行629–647〕。

**through-line**：文殊智見「一切是幻」，普賢行問「幻中如何修」；佛答「知幻即離、離幻即覺」——**因地即果、頓中之頓**。以幻修幻不礙入法界，覺性如地本不動,一切幻滅而不入斷滅，此即普賢的「如幻三昧」。

## 4. 故事・公案

**（1）六祖獵人隊十五年·三十九歲離隊（唐代平均壽命）**〔行132–143〕
法師以《六祖壇經》開頭因緣起講：六祖得法脈後在獵人隊隱居十五年，三十九歲才離開；對唐代而言已屆中晚年（唐朝平均壽命約四、五十歲，因含戰爭、飢荒、夭折）。法師旁引白居易、韓愈世壽，及《圓覺經》主角**宗密大師**約活六十餘、**永嘉大師**四十餘不到五十，以「因緣所生法」看待肉體壽命，收於「最重要是法身慧命」〔行143〕。（宗密：華嚴五祖、荷澤宗，《圓覺經大疏》作者，題經為「大方廣圓覺修多羅了義經」〔行460〕。）

**（2）韋刺史請六祖·「總清淨性」**〔行145–156〕
《壇經》緣起：六祖在大梵寺（法師稱「大莊嚴寺」），韋刺史率出家在家及官員聽法，開頭請六祖以一句話指示修行方向。六祖停頓思考後說出「總清淨性」——「總」＝任何時間地點、行住坐臥皆是；「清淨」非世間骯髒對立之淨；「性」＝本心自性、本自清淨、言語道斷心行處滅。法師會通此性即《楞伽》「寂滅一心」、《華嚴·妄盡還源觀》賢首國師「自性清淨圓明體」、《圓覺》「圓覺（圓滿覺性）」〔行153–156〕。（按：韋刺史請益一段見《壇經》，「總清淨性」為法師述壇經之語意。）

**（3）諸法無行經·喜根比丘與勝意比丘**〔行261–265〕
《諸法無行經》記：喜根比丘常說「貪瞋癡性即是菩提性」「貪瞋癡性無障礙」。勝意比丘修頭陀行、得四禪，不以為然，心想「我這麼用功算什麼」，遂毀謗喜根比丘。法師點出：因毀謗（障礙）罪而墮地獄——「是佛讓他下地獄，還是勝意比丘自己下地獄？」自己障礙自己的智慧,當然地獄一條〔行261–263〕。後勝意聽到喜根所說偈語而大徹大悟；喜根比丘已成佛,而此勝意比丘**即後來的文殊師利菩薩**〔行263–265〕。（諸法無行經 T0650「貪欲之實性，即是佛法性」✓。）

**（4）悲華經·普賢菩薩改名因緣**〔行373–400〕
《悲華經》記：有一菩薩發願「誓於濁穢世界行菩薩道而使其嚴淨」，且要勝於諸菩薩（即發心比諸菩薩更深入究竟）。寶藏佛（寶藏如來）對他說：「以是因緣，汝應改名，名為普賢」——普賢之名由此而來〔行377〕。法師釋義：「普」＝平等、「賢」＝佛／聖；普賢是「從菩薩眼中看出去,所有眾生都是佛」，因見眾生自性本佛（是心是佛），故勝於諸菩薩、更究竟〔行379–381〕。（悲華經 T0157：「以是緣故，今改汝字名為普賢……號智剛吼自在相王如來」✓。）

**（5）法華經·常不輕菩薩**〔行383–391〕
《法華經·常不輕菩薩品》：常不輕見任何眾生（乃至乞丐、好人壞人）皆跪拜頂禮，說「我不敢輕於汝等，汝等皆當作佛」。有出家人、菩薩以為他瘋，打他罵他，他仍不改、對每一位都頂禮。法師點明：常不輕不是看外相（空花假影像），也不是看意識心、六塵緣影，而是看到眾生的**自性——自性即佛、即如來**〔行389–394〕。以此引出「若練習用你的心看螞蟻、蟑螂、老鼠皆是阿彌陀佛,道業可成」，即普賢十大願導歸極樂的實義〔行394–400〕。（法華經 T0262「我不敢輕於汝等，汝等皆當作佛」✓。）

**（6）三獸渡河·香象渡河**〔行422–427〕
一條河，三獸渡：兔子太輕，隨波逐流；馬渡比兔易，拼命游泳卻腳不夠長、踏不到河底，仍不實際；唯**大象（香象）腳直接踏到河底、腳踏實地而過**。法師以此喻淨土「一句六字洪名（自心彌陀）走到底」——香象渡河，直接踏底。此喻亦見普賢騎大象之表法：大象**任勞任怨**（任勞易、任怨難，任怨方是真菩薩），且**直接畢竟入法界、毫不保留**，故名普賢行〔行415–429〕。

**（7）童年怕影子**〔行244–250〕
法師自述：民國四十幾年（西元一九五○年代）的台灣，都市路燈昏暗、電線桿皆木造。傍晚燈開卻不亮，走出去常有影子。母親騙他「別亂跑，你看有人跟著你」，他信以為真、不敢出門玩。後來有人告訴他「那是你的影子，不要怕」，從此大膽出去玩——「都假的，你怕它什麼」。法師以此喻：現在的我們就是當年怕影子的小孩，佛陀正是那個告訴我們「那是你的影子」的人〔行248–250〕。

**（8）法師自證·得癌症與發願**〔行629–649〕
法師自陳：講經緣起於母親往生——老菩薩（一九二七／民國十六年生）交代骨灰撒海，法師卻決定安放北海福座塔位，因而耿耿於懷；當夜夢見母親來問「不是要你撒在海中嗎」。法師解此夢：不是母親來託,而是「自心有罣礙、自心顯現的夢境」——**夢是自心取自心,假名為夢**〔行631–634〕。此後多年講經，數位聽眾得癌症往生，私下有人說「陳老師自己沒得癌症,卻叫我們放下」；法師當時即發願「不然讓我自己來得癌症,講話才有說服力」。果然不久真得罕見癌症、無藥可醫；出院四個月即抱病講經、中間未做任何醫療,以印證「身心脫落、覺性不動、它是假的怕什麼」〔行637–643〕。今復發至癌末，則「回歸中」——緣來則緣應、不違世緣入究竟,能保色身則醫療,目的只為續法身慧命、行菩薩責任〔行645–649〕。

**（9）國王問佛·「你本來就是佛」**〔行742–746〕
佛到一國，國王問「有沒有法讓我快速成佛？」佛在他耳邊悄悄說幾句話,國王當下成佛。國王的叔叔問國王「佛跟你說什麼？」國王也悄悄轉述,那人也成佛。迦葉、阿難等有點不滿:「我們隨佛修行這麼久,這法門一講他們就成佛,我們為何還沒？」請佛慈悲相告。佛說:我跟他講——**「你本來就是佛」**。法師以此收「念念因圓念念果滿、因果不二、進去是佛」〔行746–748〕。（法師述為「經典裡的話」；屬教理化公案，未逐字對某一 T 號核驗。）

**（10）跨宗教·加拉太書「與基督同釘十字架」**〔行350–370〕
法師讀《聖經·加拉太書》「我已經與基督同釘在十字架上……現在活著的不再是我,乃是基督在我裡面活著」,自陳很受感動。他解「聖經密碼」＝實相：**十字架＝我們的心**（縱橫普周法界的符號,圓滿出去、回歸回來,交點即本心）；「我已釘在十字架上」＝人無我,「世界也釘在十字架上」＝法無我（依報亦心所生）；耶和華無形象＝自性本無形象。法師並推測:耶穌年代（西元後一世紀）正值大乘佛法盛行,地理上兩河流域近印度,或受大乘影響,「他講的全部都是心法」〔行353–370〕。（按:此為法師個人以佛理讀聖經的旁證,非佛典;《加拉太書》為基督宗教經典,不對 CBETA 核驗;耶穌受佛法影響為法師個人推測,明確標「我個人認為」〔行368〕。）

### 義理深入（依 T0842 普賢章脈絡）

**一、普賢三疑的內在結構——三疑同源於「幻」。** 法師反覆點明:第一疑「以幻修幻」與第二疑「幻滅無心誰修」都從「已知是幻」出發;第三疑則反向,從「眾生不知是幻、久居幻化」出發〔行473–475〕。三疑逼出一個兩難:若身心修行皆幻,修無可修;若幻盡則無心,亦修無可修;若不知是幻則永陷輪迴。這正是上根器者深觀「知是空花」後必然生起的疑情——法師強調「你沒有諦聽,根本不會有這個疑問」〔行433〕,把三疑定位為「入法界過程中的真問題」,而非文字戲論。

**二、佛陀三答的樞紐是「覺性如地、不入斷滅」。** 對第一疑,佛答「無妨以幻修幻」〔行503〕——關鍵玄機在「你已了解身心是幻、修行是幻,但還沒完全從幻境解脫」,故可依幻身幻心修;若不了幻而修,則不可〔行506〕。對第二疑,佛以鑽木取火喻覺性:木、火（幻身幻心）燒盡俱滅,唯「地」（覺性）不動〔行532–534〕;所以「誰為修行」的答案是——修不是修一個東西,而是讓你認知那本不動的覺性〔行524〕。對第三疑,佛開頓法「知幻即離,離幻即覺」,直接告訴眾生宇宙真相〔行536〕。三答收束於經文「諸幻雖盡,不入斷滅」——這一句是全章的保險栓:以幻修幻、遣之又遣,最終不落斷滅頑空,因佛性永恆〔行728–730〕。

**三、倒裝句與「三遣」是普賢章最深的兩處。** 法師特別標「一切眾生種種幻化,皆生如來圓覺妙心」為倒裝句:不是幻化生出圓覺妙心,而是圓覺妙心能生一切幻化,即六祖「何期自性,能生萬法」、即真空妙有〔行651–655〕。而「三遣」（遣心→遣遠離→遣遣）表面是漸次,實則從頓法裡開出漸次:根本頓法是「沒有東西讓你離」,一切本是空花、空中本無花,你要離它什麼〔行706–710〕?法師會通《金剛經》「應無所住而生其心」:無住的最高層次是「無所住」——沒有東西讓你住〔行714–720〕。三遣遣到「得無所離」,正是頓法的自我完成。

**四、「知幻即離,不作方便;離幻即覺,亦無漸次」是普賢章的心髓,也是全經頓法的定盤星。** 法師判此為「頓中之頓」〔行544〕:它不用身體修、不用一般想像的修,而是用**見地**修。因此《楞嚴》說「相法（漸次之法）不是佛說」,佛所有的法都是頓法〔行548〕;圓覺自性一定要頓悟,不能「回去慢慢悟」〔行550〕。但法師隨即補上不可誤解處:**佛性頓悟不用修,習性卻要漸修**〔行562〕——累劫第八識種子（經驗值）一直認定身心是真,雖一念已知大法,習性仍執身心,故如戒菸須時間漸放。這一「頓悟見地／漸修習性」的二分,正解消了普賢「漸次修習」之問與佛「亦無漸次」之答的表面矛盾。

## 10. 法脈會通

### 10-1 普賢章「如幻三昧」的跨門會通（連結網）

法師把《圓覺》普賢章的「如幻三昧／知幻即離」當作一切了義法門的共同心髓,向各宗放射:

```
                     ┌──── 華嚴 ────  華嚴大法（宗密:圓覺與華嚴無二）
                     │
                     ├──── 禪 ─────  何期自性能生萬法／應無所住而生其心
                     │
  圓覺·如幻三昧 ──────┼──── 密 ─────  大手印·大圓滿·普賢王如來→金剛薩埵百字明
  「知幻即離,          │
   離幻即覺」          ├──── 淨土 ───  自性彌陀·實相念佛·三時繫念（一句彌陀＝本心）
                     │
                     ├──── 咒 ─────  大悲咒（自啟大悲）·往生咒（南無阿彌多婆夜＝回歸自性往生）
                     │
                     └──── 般若 ───  一切賢聖皆以無為法而有差別
```

| 圓覺本句 | 法師援引 | 該引文如何詮釋本句 | 核驗 |
|---|---|---|---|
| 一切眾生種種幻化,皆生如來圓覺妙心 | 六祖「何期自性,能生萬法」 | 圓覺妙心即能生萬法的自性,真空妙有 | ✓ T2008 |
| 知幻即離,不作方便 | 金剛經「應無所住而生其心」;無住→無所住 | 無所住＝沒有東西讓你住＝得無所離 | ✓ T0235 |
| 諸幻雖盡,不入斷滅 | 金剛經「一切賢聖皆以無為法而有差別」 | 幻盡入無為法而非斷滅頑空 | ✓ T0235 |
| 應當遠離一切幻化虛妄境界（三遣） | 密宗大手印/大圓滿·百字明 | 遣至無所離＝普賢王如來·金剛薩埵之究竟 | 名相會通（未逐字核） |
| 如幻三昧·見眾生皆佛 | 淨土·自性彌陀 | 看螞蟻蟑螂皆阿彌陀佛＝濁世行菩薩道使其嚴淨（淨土） | 名相會通 |

### 10-2 輪迴機轉圖（起信論三細六粗）——本講的「病理學」

```
 自性(菩提) ──因境故心──▶ 本心 ──一念不覺──▶ 三細 ──境界為緣──▶ 六粗 ──▶ 輪迴/生死
   │                        │              │(業相→轉相→境界相)  │(智→相續→執取→計名字→起業→業繫苦)
   │                        │              鏡·能生萬法          把鏡中影像當真而分別執取
   └───────── 知幻即離、離幻即覺（圓覺頓法）逆流而返 ─────────────────┘
```
**連結要點**:輪迴＝把「鏡中影像（境界相）」當真而起分別執取;圓覺頓法不從六粗一節節倒修,而是「知幻即離」一刀斬入——知是空花即無輪轉。此即「文殊智（見病理）＋普賢行（開藥方）」的合一。

## 11. 日常實踐

1. **知幻即離**:境界（順逆、毀譽、悲歡離合）現前時,當下認取「這是心中影像、是空花」,即離,不必另作方便——這是本講給的頓法操作〔行538〕〔行762〕。
2. **任勞更任怨**:任勞易、任怨難;一切怨都是自心幻影,能任怨即入普賢行——別把「有功德」當動機去勉強任勞〔行415–420〕〔行516–520〕。
3. **實相念佛/三時繫念**:一句阿彌陀佛是提醒「當下這顆心即是彌陀」,非嘴上硬念十萬遍;念是提醒你「我就是阿彌陀佛」,方為真念佛,免「波波度一生」〔行754–760〕。
4. **看眾生的自性**:練習對螞蟻、蟑螂、老鼠乃至一切人,看其自性（是心是佛）而非高卑貴賤,道業可成——常不輕、普賢的行門〔行394–400〕。
5. **緣來則緣應、不違世緣入究竟**:修習性不在找清靜處慢修,而在勇敢隨世緣無障礙;心隨萬境轉而「轉處實能幽」——隨流認得性,無喜亦無憂〔行772–778〕。
6. **佛性頓悟、習性漸放**:一念已信本心,不必因舊習仍在而自責;如戒菸,給自己時間、在日用中一次次消習性〔行562–570〕。

## 12. 延伸・參

- **前後講連結**:本講上承第六講〈文殊章〉結論「知是空花,即無輪轉」〔行300〕;下接第八講——法師預告下週先總複習普賢重宣偈頌,再進入第三大士**普眼菩薩**（身心脫落、「本無身心可脫落才是真脫落」）〔行479〕〔行722〕〔行784〕。
- **延伸閱讀**:《圓覺經大疏》（宗密）判圓覺與華嚴無二;《大乘起信論》三細六粗全文（T1666）;《諸法無行經》喜根／勝意本末（T0650）;《悲華經》普賢改名全段（T0157 line 536）。
- **一參問**:普賢問「若諸幻性一切盡滅則無有心,誰為修行？」佛答「覺心不動」。試自問:此刻能知「這是幻」的,是那個會滅的幻心,還是那不動的覺心？——若答得出,便知「知幻即離」離的是什麼、覺的是什麼。
