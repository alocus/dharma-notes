## 1. 本講概要

本講進入〈普眼菩薩章〉。前兩章文殊、普賢已把「圓覺」的頓法講盡——文殊智令知「知是空花即無輪轉」，普賢行令行「知幻即離，不作方便；離幻即覺，亦無漸次」。普眼菩薩（體佛法師釋為「平等眼」，即觀自在、即心佛眾生三無差別的境界）出於大悲，明知眾生本頓、本已住持、本無方便，卻「偏要問漸次」，替末世將悟未悟的眾生請佛「假說方便」〔行149〕〔行435〕。

佛陀因此開示漸次法的第一門——**「先依如來奢摩他行，堅持禁戒，安處徒眾，宴坐靜室，恒作是念」**，教眾生於止觀中先觀「四大假合」之身、再觀「六塵緣影」之心，體證「此身畢竟無體」「畢竟無有緣心可見」〔行498〕〔行677〕〔行705〕。

貫串本講的一條主線：**頓法無方便、無漸次，但為末世眾生「假說」一條可操作的止觀之路**——依奢摩他（止）→ 堅持禁戒（心戒）→ 宴坐靜室（入法界之定）→ 恆作是念（觀身心皆幻）。體佛法師大量引維摩、楞嚴、壇經、華嚴、妄盡還源觀為此門作證，並以神秀／慧能公案對照「一塵不染」（漸）與「無塵可染」（頓）的分野。

## 4. 故事・公案

### 4.1 神秀與慧能——「一塵不染」與「無塵可染」〔行245–291〕
唐代五祖門下有兩位大菩薩示現。**神秀**是首座和尚，五祖不在時代講經，德高望重、長相高大、得皇帝青睞、活到一百多歲，福報智慧俱足。另一主角**慧能**（體佛法師依《壇經》原文用「獦獠」，指未受教化的南方人），家貧不識字、只會砍柴，見五祖自言「我來作佛」，被派入廚房舂米，因身輕綁石於腰以增重舂米。

神秀夜書偈於南廊壁：「身是菩提樹，心如明鏡臺，時時勤拂拭，勿使惹塵埃」。五祖令門人誦持，言「依此偈修，免墮惡道」，卻三更喚神秀入堂告以「**未見本性，只到門外，未入門內**」。慧能聞童子誦此偈，知其未見性，另作一偈（請人代書）：「菩提本無樹，明鏡亦非臺，本來無一物，何處惹塵埃」。

五祖表面不理慧能，實則「以杖擊碓三下」暗示三更入室，密授《金剛經》，至「應無所住而生其心」慧能言下大悟，得衣缽。因「魔強法弱」，五祖親划槳護送慧能出黃梅（湖北），慧能後隱獵人隊十五年，三十九歲方出。

體佛法師的判語：若以世間分數，神秀九十五、慧能九十九；但**站在佛法，神秀「不及格」，慧能「一百分」**——因神秀仍「有身有心」、要令對象清淨故求「一塵不染」（永不可能，塵仍會染）；慧能已悟身心如空花、根本「無塵可染」（無對象可住，即《圓覺》知是空花即無輪轉、亦無身心受彼生死）。「不入三惡道」是及格獎、非滿分〔行263–271〕。

> ✓ 核驗：神秀偈、慧能偈、五祖「未見本性，只到門外」、擊碓三下、「應無所住而生其心」、「何期自性」皆合 CBETA T0008／T2008 六祖大師法寶壇經、T0235 金剛經。「獦獠」為《壇經》原字。

### 4.2 央崛摩羅——殺九十九人聞法頓悟〔行423–429〕
一位受外道邪法影響者，其法謂「須殺滿一百人功德乃圓」。他見人即殺，殺到九十九人、最後一個對象竟是自己的母親。佛陀出面勸阻，他轉而欲殺佛，佛言「你要殺我可以，先聽我講法，聽完再殺」。講畢，此殺人魔一聞頓悟，證初果羅漢。體佛法師以此說明《楞嚴經》「**理則頓悟，乘悟併銷；事非頓除，因次第盡**」——理上一悟即消，但習性須於一次次六根接觸六塵的考驗中「漸修」，讓那「還不相信」的心從不信到全信。

> ✓ 核驗：「理則頓悟，乘悟併銷，事非頓除，因次第盡」✓ CBETA T0945 楞嚴經〔行427〕。央崛摩羅（央掘魔羅）為佛世實有人物。

### 4.3 維摩詰教舍利弗「真宴坐」〔行605–649〕
佛欲遣十大弟子探維摩詰之疾，無人敢往。智慧第一的**舍利弗**述其緣故：昔日他在林中樹下宴坐（打坐），維摩詰忽至，告其「你是身在打坐、身體入定——真正的入定是**大定無出入**！有出有入即是二法。」舍利弗問「何謂宴坐？」維摩答以一段話（詳§8末引），核心是「**不於三界現身意…不斷煩惱而入涅槃**」——身雖在三界，心住法界，故行住坐臥無時不定；不斷煩惱（煩惱是覺性所現幻影，轉之非斷之）而本自涅槃。舍利弗恍然，自愧不任詣彼問疾。體佛法師借此證佛所教「宴坐靜室」不是要找安靜之處，而是心入法界——吵雜處亦是靜室。

> ✓ 核驗：維摩宴坐段（不於三界現身意…不斷煩惱而入涅槃，是為宴坐）✓ CBETA T0475〔行618〕。

### 4.4 鳩摩羅什頂禮小乘之師〔行464–466〕
鳩摩羅什大師初學小乘，後入大乘。返喀什米爾時，其德高望重之師父見他進來，反而「右繞三匝、向他頂禮」。羅什言「師父不敢當」，師父答：「我是你師父沒錯，但你已學大乘菩提心、佛陀的心法，我就要向你頂禮——因為心法是心王、一切法之首，佛陀成佛靠此法。」體佛法師以此說明「成就與否，總在遇緣不同」——所學是心法（頓法）或旁邊的相似佛法，結果迥異。

### 4.5 虛雲老和尚·杯落開悟〔行781〕
體佛法師以〔虛雲老和尚〕開悟為「分別性」作證：老和尚開悟時聞杯子墮地「噗通」一響——他清楚聽到、了了分明（分別性在），而「虛空粉碎、大地平沉」、一念不生（不落分別心）。以此說明真心「本來就一念不生、本來離相」，卻於相離相、於念離念。

### 義理深入

**（一）普眼「明知本頓而偏問漸次」的大悲——因地不真，果遭迂曲。** 體佛法師反覆點出：普眼菩薩並非不懂，他「知道眾生本頓、本已住持、本無方便」，卻替將悟未悟者請佛「假說」〔行435–437〕。關鍵在——他問的「漸次」不離本心。以台北往屏東為喻：佛已說「屏東就在這裡（圓覺果地）」，普眼問的是「我知道屏東在哪，怎麼去比較方便快速」，仍是問屏東（果地），只問修行方法；若問一個花蓮（另一目標），就是「因地不真、果遭迂曲」——種瓜得瓜，因地從圓覺自性入，果地必從圓覺自性得〔行155–157〕〔行312–314〕。這正是本章「漸次法其實仍是頓法」的樞紐。

**（二）「正方便、正思惟」的定義決定整條漸次路的方向——入心即正。** 佛法凡言「正」「善」，非世間正邪善惡之對待，而是「入法界、入心」〔行333〕。所以「正方便」是「入心的方便」，「正思惟」是「站在心（法界）的角度」去思惟「什麼叫做心」，而非用頭腦（意識心）思惟世間萬象〔行335〕。這一義界，使後面「奢摩他—禁戒—宴坐—恆作是念」全部收攝於「入心」一事，而非外在坐姿與時數之經營（正如維摩斥舍利弗「身在打坐」）。

**（三）漸次門的實修內核＝止觀雙運，先觀身幻、次觀心幻。** 佛答的「先依如來奢摩他行…恒作是念」是一條可操作的觀法：止（放得下）與觀（看得破）如鳥雙翼同時振動〔行533〕。觀的所緣，佛明白給出——先觀「此身四大和合…當在何處」令不執身（眾生最難破的第一關，破之則此生煩惱去三分之二〔行701〕），再觀「六根四大中外合成…畢竟無有緣心可見」令不執心。體佛法師強調：這與《楞嚴》佛令阿難「微妙揣摩」你的身心是什麼，是同一件事——皆是「正思惟」〔行771–773〕。觀到身心俱幻，即自然「知幻即離，不作方便；離幻即覺，亦無漸次」——漸次法最終仍導歸普賢頓法。

## 10. 法脈會通

### 10.1 圓覺漸次門 ←→ 各經印證（連接圖）

```
                 《圓覺·普眼章》佛答漸次門
                「先依奢摩他 → 堅持禁戒 → 宴坐靜室 → 恆作是念（觀身心皆幻）」
                                │
     ┌──────────┬──────────┼──────────┬──────────────┐
   奢摩他(止)   禁戒(心戒)   宴坐         恆作是念(觀)     果：知幻即離
     │            │          │            │                │
  儒家大學     尸羅四義    《維摩》宴坐   《楞嚴》微妙揣摩   《圓覺·普賢》
  止定靜安     清涼寂滅    不於三界      若離前塵有分別性   知幻即離
  慮得         =本心;      現身意;       即真汝心;         不作方便
 (止觀=思惟修) 三昧耶戒    行住坐臥皆定  分別影事=輪迴種    離幻即覺無漸次
```
**連結要點**：整條漸次門在體佛法師的講法裡不是外在坐姿，而是「入心（法界）」一事的展開——每一步都被別經印證為「心住法界、觀身心幻」，故「漸次法其實仍是頓法」。

### 10.2 「無塵可染 vs 一塵不染」等式鏈〔行263–398〕

```
神秀(漸)：有身有心 → 求令對象清淨 → 「一塵不染」→ 塵仍會染 → 不及格(不入門)
   ‖(對照)
慧能(頓)：身心如空花 → 根本無對象可住 → 「無塵可染」→ 應無所住 → 一百分
   ‖(圓覺印證)
圓覺文殊智：知是空花即無輪轉，亦無身心受彼生死 → 無塵可染 → 如幻三昧
   ‖(楞嚴印證)          ‖(維摩印證)
都攝六根淨念相繼      能善分別諸法相，於第一義而不動
（六塵皆影，無塵可染）（分別性在而不落分別心）
```
**連結要點**：法師以此鏈說明——煩惱必有「對象」（兒子、老公、錢、疾病、戰爭…）〔行388–390〕；佛法不替你解決對象，而令你知對象如夢如幻、「無塵可染」，是為「無受＝接受」〔行396〕。

### 10.3 第一義諦 ＝ 阿彌陀佛 ＝ 密嚴淨土（等式）〔行795–809〕

```
維摩「於第一義而不動」→ 第一義諦(本性不動)
        │當下了悟
   ┌────┴────┐
 阿彌陀佛 ＝ 毘盧遮那（超越時空之本性四字名）
        │
   密嚴國土 ＝ 此方即淨土，淨土即此方
        │臨終
 四大解、六根滅、六塵無、緣心不可得 → 剩「分別影事」
   知其為影 → 歸密嚴國土（文成印壞，當下往生）
   停留其上 → 再攬四大六根 → 輪迴
```
**連結要點**：體佛法師以此收攝全講——《圓覺》「畢竟無有緣心可見」與《楞嚴》「分別影事」是同一件事；知影即淨土，執影即輪迴。故謂「《圓覺經》是禪的經，也是淨土的經」〔行816〕。

### 10.4 妄盡還源觀·菩薩四德（賢首國師）〔行509–521〕

| 四德 | 體佛法師釋義〔行〕 | 對應圓覺漸次 |
|---|---|---|
| 隨緣妙用 | 隨世緣而知一切世緣皆假（夢中而知夢）〔行511〕 | 恆作是念·知幻 |
| 柔和質直 | 內心質直（＝直心＝菩提心），對外柔和有禮〔行513–515〕 | 直心＝本心 |
| 威儀有則 | 自心本顯，一切謙卑〔行518〕 | 堅持禁戒·心戒 |
| 代眾生苦 | 講圓覺大法令眾生知一切如夢幻，即最好的布施〔行518〕 | 大悲心 |

**連結要點**：一體（自性清淨圓明體）→ 二用（普周法界·出生無盡）→ 三遍 → 四德，是妄盡還源觀的層階；法師以此把「菩提心＝直心・深心・大悲心」與圓覺漸次門縫合。

## 11. 日常實踐

1. **聞法先「諦聽」**：坐下聽經／讀經前，先放下第六意識的二元批判與「想聽自己想聽的」主觀，用本心聽——當下攀緣心放下，本心即顯〔行439–445〕。
2. **修「恆作是念」的觀身法**：靜坐時先止（制心一處），再逐一觀身之地（髮毛爪齒皮肉筋骨髓腦）、水（唾涕膿血津液…大小便利）、火（暖氣）、風（動轉），觀到不再執身為我——破此第一關，此生煩惱去三分之二〔行677〕〔行693–701〕。
3. **煩惱起時，回到「對象皆幻」**：一切煩惱必有對象；問自己「這對象是不是如夢如幻？」既是幻，無塵可染〔行386–396〕。
4. **守「心戒」**：不僅守外在戒相，更守「戒無戒相」的本心戒——一起批判、抱怨、意見（失清涼），即刻懺悔回歸，「不怕念起，只怕覺遲」〔行580–588〕。
5. **於相離相、於念離念**：真如自性一定起念（分別性、了了分明是真心之用）；不必斷念（斷念是木頭），只在見聞覺知上不再加主觀愛憎——「不染萬境，真心常自在」〔行779–791〕。
6. **臨終正念**：知四大必解、六根必滅、所剩「分別影事」只是影像，干擾不了我；當下發願往生，「文成印壞」，不必依賴他人助念〔行801–816〕。

## 12. 延伸・參

- **相關講次**：第九講（三聖圓融觀·澄觀清涼國師·宗密）為本講「普眼＝心佛眾生三無差別」之伏筆〔行192〕；圓覺三法（奢摩他·三摩缽提·禪那）將於〈威德自在章〉詳說，本講先開「奢摩他」一門〔行506〕。
- **延伸閱讀**：《維摩詰經·弟子品》舍利弗宴坐段（T0475）；《楞嚴經》卷一七處徵心、卷四覺明空昧、卷五大勢至圓通（T0945）；《六祖壇經》神秀慧能公案（T2008）。
- **一參問**：普眼「明知本頓而偏問漸次」——若我已聞「知是空花即無輪轉」，為何仍須「先依奢摩他、恆作是念」觀身心皆幻？（提示：理則頓悟，事非頓除，因次第盡〔行427〕。）
