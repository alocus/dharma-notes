## 1. 本講概要

本講進入《圓覺經》十二菩薩章的第三位——**普眼菩薩章**。前二章（文殊、普賢）是「從因入果、頓修頓悟」的直接法：文殊章示「**知是空花**」、普賢章示「**知幻即離**」，重點全在一個「知」字（佛境界知＝般若智慧）〔行57-59,148,187〕。但普眼菩薩「演一齣戲」，替中下根眾生三請佛陀開示**漸次法／方便法**〔行218-220〕。

體佛法師以《楞嚴經》的「**楞嚴三摩提／如幻三昧**」為橋樑，把普眼章的漸次修行判為**假觀→空觀→中觀**三重次第〔行266-301〕：

1. **假觀**——依奢摩他宴坐，觀身是四大假合、觀心是六塵緣影（落謝影子），故「幻身滅」〔行278-291〕。
2. **空觀**——幻身滅故幻心滅、幻塵滅、幻滅亦滅，假到盡處即入空〔行312-319〕。
3. **中觀**——「**幻滅滅故，非幻不滅**」，那個不滅者即圓覺自性（華嚴稱自性清淨圓明體、楞嚴稱妙明真心、楞伽稱寂滅一心、淨土稱阿彌陀佛）〔行319-323,405-407〕。聲聞只到假、空而不入中，故被佛呵為「焦芽敗種」〔行298-301〕。

後半闡發全章高潮——**清淨的連鎖**：覺圓明→心清淨→塵→根→識→六塵→四大→十二處→十八界→二十五有→乃至八萬四千陀羅尼門，「**一切清淨**」〔行419-427,599-620,663-684〕。師強調：經文用「次第」文字書寫，其實是「**同時清淨**」——「一門深入，入一無妄，則六合根」（引楞嚴「元依一精明，分成六和合」）〔行535-537,595〕。末後以「**如來藏**＝如（不變）＋來（隨緣）＋藏（含染淨諸法）」的架構收攝全講，說明六道流轉與出離皆是「自心取自心」，一切盡在隨緣〔行690-730〕。

**貫串線**：整部《圓覺經》十二菩薩後十位都繞著一個「知」字說；普眼章的漸次法，目的仍是回歸「知空花即幻」的頓法〔行212〕。

## 4. 故事・公案

### 4.1 永嘉大師一宿禪〔行129-131〕
永嘉大師已自證道，其《證道歌》乃「經典為他作證」。他去參六祖，六祖並未特別教他什麼，一見即欲走，六祖留他一宿，故稱「**一宿禪**」，傳為佳話——六祖只是為他印證。師以此說明真正的師父是「引導各位法身慧命進入法界者」，故「一日為師終身為父」。（永嘉玄覺撰《證道歌》✓CBETA T2014）

### 4.2 提婆達多陷害佛陀——佛身受心不受〔行236-246〕
提婆達多是佛陀堂弟，與阿闍世王子結合：慫恿王子政變害死其父（頻婆娑羅王），事成後拜提婆達多為國師，使之成為僧團領袖以排斥釋迦牟尼佛。且每一事都要佛陀的命——推大石壓佛、放狂象踐佛。師以此證明「佛陀還在龐大的因果業力之中」，並非天天過幸福美滿生活；然而對佛陀而言祂真的幸福美滿，因為「**身受心不受，受諸受祂以無所受**」，恆常入三昧（楞嚴大定），本心從未離。

### 4.3 琉璃王屠釋迦族・目犍連缽收靈魂〔行650-660〕
琉璃王要屠殺釋迦族，這是龐大的因果業力。佛陀前兩次出面攔阻（隨流認得性），第三次便不再阻擋，默然。目犍連尊者問佛為何不擋，佛默然；目犍連站在世界（聲聞）角度，用神通把釋迦族靈魂全部裝進一個缽，送到忉利天。屠殺完畢後他告訴佛已救下釋迦族，佛說「請把寶盒掀開」——一看全變成血水了。師以此說「**不敵業力**」：世間相上的因果業力，不是任何人乃至佛菩薩有能力去轉的。（公案，見校對；忉利天為經典地名）

### 4.4 文殊問佛「滅業障罪」〔行656-659〕
文殊菩薩問佛陀：「您時常講『有可以滅業障罪』？」佛說「有」——所謂滅業障罪，就是**了知本性本來無罪無報、本來清淨**。世間相上有沒有罪報？有，但那是身在世界必經的生老病死、成住壞空、因果，而因果也是夢境，知幻即離、醒來才是重點。師指此典故出自《諸法無行經》。（※ 出處待考，見校對）

### 4.5 善星比丘墮地獄〔行471-473〕
善星比丘「他講三句、佛陀講一句」，即好與講實相者相抵觸、反駁。師說：講實相的人只要跟他抵觸，只有死路一條——不是佛叫你下地獄，是你自己下地獄，因為毀謗正法；我執越深，三惡道隨你去。反顯阿難之偉大在「從不排斥、從不反駁」。

### 4.6 六祖度陳惠明——不思善不思惡〔行628-640〕
陳惠明本是四品將軍，率眾追及六祖欲奪衣鉢，然衣鉢提掇不動，遂求法。六祖只教一句話：「屏息諸緣，勿生一念…**不思善，不思惡，正與麼時，那箇是明上座本來面目？**」惠明言下大悟。師以此說：六祖沒教他念佛、修禪，只是「把意識心轉換為本性的那一剎那，還你本來面目」，即回歸本心。陳惠明是六祖一生第一位度化、示現的菩薩。（《六祖壇經》✓CBETA T2008）

### 4.7 房融譯《楞嚴經》〔行248-256〕
師講《楞嚴經》「看楞嚴像看白話文」卻文字艱深太美，原因是譯筆出自宰相**房融**。古代科舉制度中能當到宰相、又是那一科進士考試的主考官，所有考上的進士都是他的門生，其文學造詣不必懷疑（如同得諾貝爾獎者不必再問學問好不好）。故《楞嚴經》文學造詣極高、有時難懂是因文字太美太艱深。（史載般剌蜜帝譯、房融筆受，見校對）

### 4.8 宗密見圓覺痛哭流涕〔行222-224,686-688〕
宗密大師（華嚴五祖）本是學禪之人，讀《圓覺經》後「又進入到華嚴世界」，並以其師澄觀大師（華嚴四祖）的**三聖圓融觀**來解釋《圓覺》——「用圓覺來解釋華嚴，再用華嚴來解釋圓覺」。師說宗密見《圓覺》後痛哭流涕，那種痛哭非世間情感，是難得、感恩此經，因為它是「頓法中的頓法」、修行的大法要。

### 4.9 農夫插秧——退步原來是向前〔行603-607〕
禪宗悟道者偈：「**手把青秧插滿田，低頭便見水中天；六根清淨方為道，退步原來是向前。**」師親到中部一地印證農夫插秧確是往後退著插。「退步」即放下，越放下就是越向前、道越增長；「低頭」即謙卑，謙卑才能看到那一片天。（禪門悟道偈，作者師言已忘，見校對）

### 義理深入

**一、漸次的真相是「假空中」，而非階梯。** 普眼菩薩明知無漸次，卻為中下根「演一齣戲」三請方便〔行218-227〕。師以楞嚴三摩提（如幻三昧）判普眼章漸次為假→空→中三觀〔行266-301〕：奢摩他宴坐先觀身四大假合、心六塵緣影（假）；四大分解、無塵可得、緣心不可見（空）；而經文「幻身滅→幻心滅→幻塵滅→幻滅亦滅→**非幻不滅**」的層層滅法，正是把「能滅所滅」一併滅盡，最後逼顯那個「不滅者」——圓覺自性（中／第一義諦）〔行310-323〕。師特別指出：聲聞只到假、空而不入中，故楞嚴中佛呵之為「焦芽敗種」〔行298-301〕。這一判攝把普眼章從「次第修證」還原為「頓門的方便化現」——漸次的終點仍是文殊、普賢的那個「知」〔行212〕。

**二、菩薩義的兩層：脫落身心 → 本無身心可脫落。** 「對離幻垢說名菩薩」是第一層（身心脫落、不住）；「垢盡對除，即無對垢及說名者」是第二層（本無身心可脫落、無住）〔行380-401〕。師以「不住」與「應無所住而生其心」對舉——前者尚有能脫之對象，後者連對象都無，才是入地菩薩、悟無生法忍。六祖一聞「應無所住而生其心」即言「我就是這樣子」，正是此境〔行401〕。這使《圓覺》的菩薩定義與《金剛經》的「通達無我法者，如來說名真是菩薩」完全一致〔行371-378〕。

**三、清淨連鎖的關鍵字是「識」，機制是「同時」。** 覺圓明→心→塵→根→識→四大→十二處→十八界→二十五有→陀羅尼門，經文用「故」字層層相因，讀來像次第；師反覆強調其實是「**同時清淨**」〔行616-620,733-735〕。何以同時？因為「元是一精明，分成六和合」——六根同出一心，一門深入、入一無妄，則六合根一一清淨〔行535-539〕。而全鏈的樞紐在「識清淨」：前五識只了別，第六意識起判斷取捨、含第七識俱生我執（四大煩惱長相隨），此我執一放下，識即清淨、全鏈即清淨〔行457-491〕。故「一根清淨」的功德能遍及二十五有乃至八萬四千法門，反之「一根不清淨」則全鏈不清淨——即輪迴〔行642-644〕。

**四、如來藏收攝全講：一切盡在隨緣。** 師以「如來藏＝如（不變／真如）＋來（隨緣來去）＋藏（含藏染淨諸法）」總結〔行692-708〕。六道流轉不是佛或閻羅王懲罰，而是「自心取自心」——你取如來藏的染，染就帶你入三界（背覺合塵）；你在染中不染（妄盡還源／染而不染），淨就顯，即金剛不壞、自性清淨圓明體〔行710-724〕。因此《圓覺》普眼章的「一切清淨」與「六道輪迴」是同一如來藏的兩面功德，出不出三界「隨便各位」〔行726-730〕——這正呼應本經一開始的「知幻即離」：知，則離；不知，則隨染流轉。

### 普眼章核心全文（CBETA T0842 逐字，無省略，供對照）

普賢章（本講複習所本）：

**《圓覺經》普賢章**
> 善男子！知幻即離，不作方便；離幻即覺，亦無漸次。一切菩薩及末世眾生依此修行，如是乃能永離諸幻。

普眼章・依奢摩他假觀：

**《圓覺經》普眼章**
> 善男子！彼新學菩薩及末世眾生，欲求如來淨圓覺心，應當正念遠離諸幻，先依如來奢摩他行，堅持禁戒，安處徒眾，宴坐靜室，恒作是念：『我今此身四大和合，所謂髮毛、爪齒、皮肉、筋骨、髓腦、垢色皆歸於地，唾涕、膿血、津液、涎沫、痰淚、精氣、大小便利皆歸於水，暖氣歸火，動轉歸風。四大各離，今者妄身當在何處？』即知此身畢竟無體，和合為相，實同幻化。四緣假合，妄有六根；六根、四大中外合成，妄有緣氣，於中積聚，似有緣相假名為心。善男子！此虛妄心若無六塵則不能有，四大分解無塵可得，於中緣塵各歸散滅，畢竟無有緣心可見。

普眼章・幻滅次第與摩尼寶珠喻（假空中・菩薩義）：

**《圓覺經》普眼章**
> 善男子！彼之眾生幻身滅故幻心亦滅，幻心滅故幻塵亦滅，幻塵滅故幻滅亦滅，幻滅滅故非幻不滅；譬如磨鏡垢盡明現。善男子！當知身心皆為幻垢，垢相永滅十方清淨。善男子！譬如清淨摩尼寶珠，映於五色隨方各現，諸愚癡者見彼摩尼實有五色。善男子！圓覺淨性現於身心隨類各應，彼愚癡者說淨圓覺實有如是身心自相，亦復如是；由此不能遠於幻化。是故我說身心幻垢，對離幻垢說名菩薩；垢盡對除，即無對垢及說名者。

普眼章・清淨連鎖（本講後半主軸）：

**《圓覺經》普眼章**
> 善男子！此菩薩及末世眾生，證得諸幻滅影像故，爾時便得無方清淨，無邊虛空覺所顯發。覺圓明故顯心清淨，心清淨故見塵清淨，見清淨故眼根清淨，根清淨故眼識清淨，識清淨故聞塵清淨，聞清淨故耳根清淨，根清淨故耳識清淨，識清淨故覺塵清淨；如是乃至鼻、舌、身、意亦復如是。善男子！根清淨故色塵清淨，色清淨故聲塵清淨，香、味、觸、法亦復如是。善男子！六塵清淨故地大清淨，地清淨故水大清淨，火大、風大亦復如是。善男子！四大清淨故，十二處、十八界、二十五有清淨。彼清淨故，十力、四無所畏、四無礙智、佛十八不共法、三十七助道品清淨，如是乃至八萬四千陀羅尼門一切清淨。

## 10. 法脈會通

### 10.1 「假空中」三觀對照——本經漸次的三家印證

```
              普眼章漸次法（體佛法師判：如幻三昧 = 楞嚴三摩提）
                              │
        ┌──────────────┬──────────────┬──────────────┐
      【假】           【空】          【中】
   奢摩他宴坐         四大分解        非幻不滅
   觀身四大假合       無塵可得        ＝圓覺自性
   觀心六塵緣影       緣心不可見      ＝第一義諦
        │                │               │
   起信論奢摩他定義   聲聞所止（呵）   佛令入中
   （不依形色氣息…）  焦芽敗種         大乘勝義諦
```

| 本經句（普眼章） | 師之判攝 | 印證教典 | 該引文如何詮釋 | 核驗 |
|---|---|---|---|---|
| 依奢摩他行・四大和合 | 假觀 | 《大乘起信論》 | 「若修止者，住於靜處端坐正意，不依氣息、不依形色、不依於空、不依地水火風，乃至不依見聞覺知。」＝奢摩他的正定義 | ✓T1666 |
| 四大分解無塵可得 | 空觀 | 《楞嚴經》聲聞呵責 | 聲聞只到空、被呵焦芽敗種 | 師述（見校對） |
| 非幻不滅 | 中觀 | 《華嚴》自性清淨圓明體／《楞嚴》妙明真心／《楞伽》寂滅一心／淨土阿彌陀佛 | 皆同一「不滅者」的異名 | ✓T0842／✓T0945 |

**連結要點**：師判普眼章漸次＝假→空→中；聲聞止於假空，大乘必入「非幻不滅」之中。

### 10.2 圓覺自性的異名等式（師反覆使用的等式鏈）

```
非幻不滅 ＝ 圓覺自性 ＝ 自性清淨圓明體（華嚴）
         ＝ 妙明真心（楞嚴）  ＝ 寂滅一心（楞伽）
         ＝ 阿彌陀佛（淨土）  ＝ 如來藏 ＝ 金剛（不二、不壞）
```
〔行405-407,503-508,692-716〕 一體異名：師強調「都是一樣的東西，是眾生本具」〔行407〕。

### 10.3 清淨連鎖・同時清淨（一根即六根）

```
   自性（元是一精明）
        │ 碰境 → 心
   覺圓明 → 心清淨 → 塵清淨 → 根清淨 → 識清淨（★關鍵：放下第六/七識我執）
        │（一門深入・入一無妄・則六合根）
        ▼  ── 同時，非次第 ──
   六塵 → 四大（地水火風）→ 十二處 → 十八界 → 二十五有（三界依報）
        ▼
   十力・四無畏・四無礙智・十八不共法・三十七助道品 → 八萬四千陀羅尼門（總持）
        ▼
   一切清淨  ＝  入法界（世界不變，而世界變法界）
```
〔行419-427,535-539,599-684,733-735〕 反向：一根不清淨 → 全鏈不清淨 → 輪迴之中轉〔行642-644〕。

### 10.4 如來藏三義（結講）

```
如來藏  ┌─ 如 = 不變（真如） ── 本性無罪無報、金剛不壞
        ├─ 來 = 隨緣來去 ──── 隨染入染界（背覺合塵→三界）／隨淨則淨
        └─ 藏 = 含藏染淨諸法 ─ 六趣＝自心取自心（隨染）
                              妄盡還源＝染而不染（淨顯，自性清淨圓明體現）
```
〔行692-724〕 **連結要點**：出三界與否，皆「自心取自心」，一切盡在隨緣。

## 11. 日常實踐

1. **看人一律「阿彌陀佛」**——不看相看如來（本心）。看每個人乃至貓狗山河都是阿彌陀佛（無量光無量壽＝本心），心才能平等，不落「這好人那壞人」的著相〔行344-349〕。「南無」是回歸自己本心，故對自己念「南無阿彌陀佛」更圓滿〔行349〕。
2. **持名念佛＝保任本心**——藉「阿彌陀佛」四字回歸自性，天天提醒「我心即彌陀、彌陀即我心」，這才是持名念佛的用意〔行123-125,506〕。
3. **修假觀空觀於日常**——心情不好時，觀「六塵緣影是落謝影子、是假的，怎會不好？」；照顧身體但知其四大假合、隨緣而不執著，不堪用時就捨〔行270-272,289-291〕。
4. **了了分明而不起我執**——痛就是痛、甜就是甜、了了分明（真心）；不加「我」的取捨批判即無煩惱（如知血糖高就不吃甜，了了分明卻不煩惱）〔行477-490〕。
5. **盡人事聽天命・隨緣不變**——扮演好當下角色，了脫因果而非逃避因果（照樣承受，但不受因果干擾）；不必去「改造世界」，把世界回歸法界即可〔行234-236,563-567〕。
6. **一門深入**——六根任一門深入、入一無妄即六根同時清淨，不必一一次第修〔行535-537〕。
7. **謙卑放下即向前**——「退步原來是向前」：越放下、道越增長；不以我執與佛法道理相抗〔行605-607〕。
8. **當最後一世**——聞圓覺即當下作最後一世眾生（非死後），每次諦聽都是「最後一次」，總有一次等到你〔行226-228,403〕。
