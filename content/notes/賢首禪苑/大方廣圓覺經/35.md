## 1. 本講概要

本講是《圓覺經》十二菩薩問答的最後一位——圓覺菩薩章的收尾，講完即進入流通分（賢善首菩薩問經名）。體佛法師以「這第35講我們到底得到了什麼」開場，把全經濃縮為**兩件其實是一件的事：鏡子（本心／真空）與鏡子所現的影像（妙有／幻有）**〔行69〕，並自始至終用一個貫串的譬喻——**冰與水**——來說明凡夫與佛的差別：水碰緣結成冰（五蘊凝結、我執堅固），冰不離水性（眾生本具佛性），修行就是「妄盡還源」——讓冰融化回水〔行149-163、192-198〕。

在這個框架下，法師逐句解圓覺章結尾的兩段家經文：（一）**「遍修三種勤行精進，即名如來出現于世」**——真修圓覺三觀者，如來即出現於世〔行218、291-301〕；（二）**「若後末世鈍根眾生……當勤懺悔，常起希望，先斷憎愛嫉妒諂曲，求勝上心」**——鈍根者須以懺悔除業障〔行301-336〕。再以重宣偈「圓覺汝當知……佛境便現前」作總結〔行473-475、481-487〕。

為了讓「懺悔」不流於形式，法師插入**悟達國師與晁錯／袁盎一千餘年冤親債主、迦諾迦尊者以三昧水化人面瘡**的長篇公案〔行348-424〕，並整理悟達國師《慈悲水懺》的**懺法七心 + 觀罪性空**〔行432-457〕。最後以《大乘起信論》「一念不覺生三細、境界為緣長六粗、生住異滅」補明「無始業」的結構〔行491-563〕，再把**圓覺三觀**逐一配上宗密大師的觀名（泯相澄神觀／起幻離相／絕待靈心），作方法上的具體總結〔行578-817〕。

核心見地：學佛學的是**見地（智慧）**而非知識；佛法只解決煩惱、了生死，不教滋生之道〔行91-99〕；一切法**隨緣而無自性**，故顯發幻有差別相，終歸畢竟空寂真性〔行232-286〕。

## 4. 故事・公案

### 4-1 悟達國師與晁錯・袁盎——一千餘年的冤親債主、迦諾迦尊者以三昧水化人面瘡〔行348-424〕
這是本講最長的公案，法師用它說明「冤親債主、懺悔、般若光明化冰」的全過程。

**歷史前因（西漢七國之亂）**：晁錯是漢景帝倚重的大臣（景帝為太子時以晁錯為師）〔行350-354〕。他為皇帝著想，主張削藩、中央集權，把諸侯國的權力與名號削除〔行350-352〕。其心「如冰心一樣堅固」，認定這才是忠於皇帝、忠於王朝〔行352-354〕。另一大臣袁盎主張相反：諸侯皆先王劉邦所封、與皇帝有血統關係，只要納稅朝貢即可長治久安——其主張「宛如冰心一樣堅固」，兩人都是冰、都很堅固〔行363-365〕。景帝先聽晁錯，引發七國之亂（吳、楚、趙、膠東、膠西、淄川、濟南）〔行367-370〕。七國軍隊逼近，洛陽（長安陪都）將失守，長安危急，賴梁王孤軍抵抗〔行370-372〕。袁盎乘機告訴景帝「都是晁錯的錯」，勸皇帝向七國道歉退兵、須殺晁錯以謝天下〔行374-376〕。晁錯五更早朝，被馬車載到東市腰斬——當時三大酷刑之一（另有五馬分屍），可怕在受刑者意識仍知覺、看著自己下半身抽動〔行376-378〕。

**結成「我執之冰」**：晁錯死後心不甘、不願投胎，一直在鬼道；鬼道壽命極長，自西元前二世紀到西元後九世紀對他而言只是「一輩子還沒死」〔行378-382〕。他是有福德、幾近鬼神合一之鬼，執著「都是袁盎害的」，不敢怪皇帝〔行380-382〕。

**袁盎十世高僧**：袁盎則世世投胎為人，佛教傳入後其阿賴耶受佛法智慧薰習，連續十世當高僧〔行388〕。至唐懿宗（第九世紀）時，成為悟達國師，受賜沉香寶座（沉香極貴），內心起了驕傲心〔行388-393〕。阿賴耶「一點一清空就像千年暗室一燈全亮；反之一念驕傲則暗室重現」——傲慢起現行，般若仁王之光消退，晁錯乘虛而入〔行394-398〕。冤魂進入悟達膝蓋，長出人面瘡，每痛一次如刀割，正是當年腰斬之痛，且天天在痛，晁錯要他痛到死〔行406-408〕。

**迦諾迦尊者以三昧水化瘡**：有一長癩瘡、衣衫破舊的比丘尼來訪，悟達國師（貴為國師，一般人見方丈都難）竟親自引她入內——可見其心已恢復阿賴耶般若智慧、達「怨親平等」〔行408-415〕。比丘尼說吸膿可癒，悟達毫不猶豫欲以舌吸其膿——已做到怨親平等、了知眾生皆佛〔行415〕。比丘尼指引他到雙樹林下取水洗瘡即癒；此比丘尼即迦諾迦尊者，是證悟的大阿羅漢〔行417〕。以三昧水（＝本心）一洗，晁錯一千餘年的執著之願、之恨，被悟達國師的般若光明超度融化〔行417-422〕。膝瘡痊癒後，悟達國師感悟而撰《三昧水懺》〔行424〕。**法師的用意**：冤親債主再深，放下執著即生般若光明，光明照耀下自性本明，冤結自解、對方心中之冰亦化——這才是真懺悔〔行426-430〕。

> 校勘・附註：史載此國師為唐·知玄（悟達國師），所撰為《慈悲水懺法》（T1910，律部類）。人面瘡故事見於水懺緣起與後世傳記，屬感應傳說，非史傳信史；法師取其表法義。〔行417-424〕

### 4-2 耶穌基督被釘十字架——真空妙有的當下、寂照不二〔行137-145〕
法師以此為「聖者入真空妙有當下」之例（明言不因宗教不同而自高，進入真空、了佛性自性清淨圓明體者皆稱無上）〔行143〕。耶穌前一天已知次日將被釘，故有最後的晚餐作叮嚀交代（如《圓覺經》流通分之流通真理）〔行137〕；祂不逃跑，因知離開與不離開都在妙有中、一切皆假〔行139〕。十字架之痛是眼耳鼻舌身意對色聲香味觸法的妙有覺受〔行139-141〕；同被釘的兩旁盜匪一直抱怨怨恨，唯耶穌說「我要用我的血洗刷眾生的罪惡」，於妙有當下發大慈悲、大菩提心而體會真空〔行141-143〕。

### 4-3 目犍連、舍利弗早於佛往生——漢傳／藏傳表法之別〔行200-210〕
佛陀仍健在、仍講經時，神通第一的目犍連與智慧第一的舍利弗（兩大上首、大師兄）即已往生，令許多弟子起退心〔行200-202〕。目犍連傳被棍棒打死（一說山崩壓死），站在生命立場屬意外而死；大眾疑惑，佛陀因此講了許多宇宙真相〔行208-210〕。法師以此帶出表法：**漢傳（顯教）佛像旁常為阿難、迦葉二尊者——代表佛色身滅後傳教傳法者（經典由迦葉「如是我聞」結集）；藏傳（密宗）佛像旁為目犍連、舍利弗——表現佛色身仍在時的相狀**〔行202-208〕。二聖雖比佛更早往生，卻早已體悟「水」（真空），這才是生命最精彩處〔行208-210〕。

### 4-4 顏回不改其樂——鈍根與知識無關〔行305〕
顏回沒有什麼知識、生活清苦，「回也不改其樂」——法師以此說明鈍根／利根與世間知識、生命際遇無關；很多科學家、高收入、有知識者卻是鈍根〔行303-305〕。緊接引二十二祖偈「心隨萬境轉，轉處實能幽」——一切都在心，修行是修心，最怕自己的問題找不出來〔行305〕。

### 義理深入

**（一）「即名如來出現于世」——佛不是被崇拜的神，而是覺性的現前。** 法師把這句從「崇拜對象」翻轉為「修證事實」：真修三觀、覺性現前處，如來就出現於世〔行291-301〕。他順勢破除神格化——佛陀連釋迦族被屠殺都無法保護、目犍連舍利弗意外早逝，佛不改變人的際遇、不保佑升官發財〔行199-210、825-827〕；佛之偉大在於「開藥者」——知眾生病、對症下藥，經典全是藥，須有病才吃該藥，一部對症之經即足〔行145-149〕。這與「如來出現於世」互為表裡：佛的「出世」不在天上顯靈，而在你我覺性當下的現起。

**（二）「當勤懺悔，常起希望」——懺悔是換種子，不是換心情。** 法師嚴格區分兩種懺悔：法會當下的輕安是氣氛感染、暫時而不真〔行339-341〕；真懺悔是把阿賴耶無始劫「我執生滅」之種懺掉、播下圓覺般若之種並「常起希望」讓它成熟〔行332-339、459-461〕。「常起希望」不是空盼，而是確信阿賴耶已薰的菩提種只要遇善知識即起現行、剎那必到〔行334、461〕。由此接上悟達公案與懺法七心（§4-1、§11），把「懺悔」從儀式提升為阿賴耶種子工程。

**（三）「三種淨觀，隨學一事……漸次求證」——冰化水的三帖藥可以輪用。** 法師強調三觀「本質一樣、方法互用」，此觀不得復習彼觀，只要心不放捨即必成佛〔行467-471〕。他把《圓覺經》十二菩薩中三觀所佔的三位（威德自在初提三觀、辯音演為二十五輪、圓覺再作漸次總結）連成一線，說明佛「最後結束還不放過三觀」的用意——這是諸佛成佛的漸次法之寶〔行309-314、475-477〕。並點出聲聞道（不知冰即水，硬把冰變水）與菩薩道（本來是水、悟無生）方向不同〔行314-318〕。

**（四）重宣偈「圓覺汝當知」——呼喚的是你的自性。** 法師把偈首「圓覺」由專名擴為「圓覺自性」，使全偈成為對每位聞法者自性的直接呼喚：你能聽到第35講，絕對是「參與者」，此經為你而說〔行481-487〕。於是「懺悔無始業、正思惟、非彼所聞境畢竟不可取、三淨觀、勤心懺、諸障消滅佛境現前」不再是對古人的教誡，而是對讀者自性當下的指令。

## 10. 法脈會通

### 10-A 一以貫之：真空／妙有＝體／用（法師的中心軸）

```
                    本心 = 真空 = 不生不滅 = 眾生本具
                    （鏡子 / 大海 / 水 / 圓覺自性）
                              │ 隨緣（寂照不二）
                              ▼
        妙有 = 幻有 = 生滅 = 差別相（影像 / 森羅 / 冰）
                              │
        ┌──────────┬──────────┬──────────┐
        凡夫：執影像=實         聖者：知影像=幻化
        （有「我」→結冰）       （本無我→融冰成水）
```

**連結要點**：一切問題只在「鏡子」與「影像」二者；凡夫執影像為實（有我→結冰），聖者知影像為鏡之幻化（無我→水）——差別只在「見地／智慧」〔行85、246-248〕。

### 10-B 冰→水的因果鏈（起信論 × 圓覺三觀 × 妄盡還源）

```
圓覺自性(寂滅不生·水)
   │一念不覺（晃動）
   ▼
一念不覺生三細 ── 業相(生相無明/波動) → 轉相(能見相/見分) → 境界相(所見相/相分)
   │境界為緣（六根觸六塵成識）
   ▼
長六粗 ── 智相 → 相續相 → 執取相 → 計名字相 → 起業相 → 業繫苦相
   │
   ▼
生·住·異·滅（四相輪轉六道 = 結冰越深）
   ▲                                   │妄盡還源（融冰）
   └──── 圓覺三觀：奢摩他/三摩鉢提/禪那 ┘  從滅相除起 → 異相→住相→生相無明
                                          （生相無明可寂照不二）
```

**連結要點**：《圓覺經》偈「懺悔無始業」的「無始業」＝《起信論》一念不覺生三細之「業相」；修行即「妄盡還源」——先滅「起業相／業繫苦相」（滅相），漸次還源，最後只餘生相無明，亦以寂照不二化之〔行491-565〕。此即賢首國師《妄盡還源觀》，也就是冰化水〔行194、582〕。

## 11. 悟達國師懺法七心 + 觀罪性空（《慈悲水懺》）〔行432-457〕

法師據悟達國師《三昧水懺》整理懺法應發之心，並以「冰／水」貫串：

| 序 | 心 | 內涵（法師釋）〔行〕 |
|---|---|---|
| 1 | **慚愧心** | 我本是水，為何還是冰？佛已成水（故稱佛），我為何還在冰中受苦？無此第一心，後面都白懺〔行432-435〕 |
| 2 | **恐怖心** | 成為冰即受三界火宅折磨，在生滅中生活必苦，不用懷疑〔行436-438〕 |
| 3 | **出離心** | 非指自殺離世，而是出離「冰的相狀」——冰冰相撞必恐怖，不想再當冰〔行438-440〕 |
| 4 | **菩提心** | 代眾生苦：把見地告訴眾生，法一定要傳、不可阻擋（唯此一帖藥可解脫）〔行440-442〕 |
| 5 | **怨親平等心** | 一切都是影像、平平等等，即性德之顯現（性德平等）〔行442-444〕 |
| 6 | **報佛恩心／報善知識心** | 這些實相皆佛所告、善知識所傳；無人講則永當冰，故發極恭敬心〔行444-449〕 |
| 7 | **觀罪性空** | 徹底改變的一觀：罪本空（阿賴耶種子遇緣現相，種子本身亦假）；「罪從心起將心懺，心若亡時罪亦亡」〔行449-453〕 |

**觀罪性空≠無因果**：因果是生命相狀（緣起緣滅）確有；觀罪性空是「身受因果的當下，心不受」＝身受心不受＝以無所受受諸受→進入三昧（故名三昧水懺）〔行453-457〕。「端坐念實相是名真懺悔」「重罪若霜露，慧日可消除」——用般若智慧懺，此才是懺悔；一直如此懺，阿賴耶菩提種子力量越大，遇善知識即相應，只是時間問題〔行457-461〕。

## 12. 日常實踐

1. **生氣當下進入空性**：修行過程「可以生氣，但不能讓你更生氣」——一句話／一動作進來，覺察「原來是一個我在防衛抵抗」，用見地告訴自己「本來無我、本來無一物」，先入奢摩他（取靜），再去應對（三摩鉢提）；練到根本沒有生氣＝證悟無生〔行180-186〕。
2. **六根觸六塵先覺「我」**：讚美則喜、誹謗則怒，都是「用我跟對方對沖」——兩塊堅冰相撞必粉碎；先覺識煩動，莫以我執抵抗〔行178-180、175〕。
3. **奢摩他日課（正思惟觀身心）**：行住坐臥、睡前皆可——先觀身四大假合，四大敗壞時「我何在」；次觀心六塵緣影（攀緣心），緣影分開時「心何在」→脫落身心；四威儀皆宜〔行602-630、676〕。
4. **禪那數息（配呼吸觀）**：吸（生息）時觀山河大地真氣、諸佛如來入我心；呼（滅息）時觀阿賴耶貪瞋癡習氣全部呼出清空；於呼吸生滅中見「息」＝不生不滅。或吸「皈依南無」、呼「阿彌陀佛」，一句佛號即入息〔行802-815〕。
5. **三摩鉢提憶念修德**：憶念佛菩薩不是觀其形象，而是憶念其「修德功德」（如觀音耳根圓通「入流亡所」、上同慈力下同悲仰）；出現任何境界（含夢見佛菩薩）皆「不取不捨」，因其只是阿賴耶影像，越信越易著魔〔行715-744〕。
6. **隨流認得性・盡人事聽天命**：生老病死、事業成敗皆緣起緣滅、短暫來去，不必喜憂；於面對接受的當下認取真心本性，把菩提種子熏習鞏固——「隨流認得性，無喜亦無憂」〔行324-334、678-680〕。
7. **常起希望・心懺**：即使已接受圓覺也要心懺，放下「我都懂了」的驕傲諂曲（容器要空才能受法）；確信阿賴耶已薰的菩提種遇善知識必起現行〔行461、823-825〕。

- **本經前後脈絡**：本講為〈圓覺菩薩章〉（第十一位菩薩）收尾；下一講即最後一位〈賢善首菩薩章〉——問經名、云何奉持、修習功德、護持流通，並金剛力士護法（流通分）〔行59、831-833〕。三觀首見〈威德自在菩薩章〉、演為二十五輪見〈辯音菩薩章〉、本章總結，可回看該三講〔行309-311〕。

- **一參問**：法師說「一部對症之經即足」〔行147〕，又說圓覺三觀「三種本質一樣、隨學一事即可」〔行467-469〕。那麼對「我這塊冰」，此刻最對症的是奢摩他（破我執）、三摩鉢提（破法執）、還是禪那（直入本心）？如何從自己「生氣當下先想到我」的實況，判斷該先服哪一帖？
