## 1. 本講概要

本講進入《圓覺經》十二菩薩中第八位——**辯音菩薩**章，開始鋪陳全經最具規模的「漸次法」：**二十五輪清淨定輪**〔行253〕。體佛法師先以一組總綱定調：佛法是圓頓法，但「圓頓不離漸次」，漸次的目的正是為了圓頓，故有「方便有多門，歸元無二路」——方便有多門即漸次法，歸元無二路即圓頓法〔行61-69〕。十二菩薩前四位（文殊、普賢、普眼、金剛藏）問圓頓法，後四位（彌勒、清淨慧、威德自在、辯音）問漸次法〔行63-67〕；而所有法門總歸只有三個門：**奢摩他、三摩鉢提、禪那**〔行69〕。上一講威德自在菩薩問出這三法，本講辯音菩薩則把三法作排列組合，開展為二十五輪〔行108-110、248-250〕。

在正式進入經文前，法師用了近半場，以禪門祖師的論述為橋樑，把「心與法的關係」講透——這是進入二十五輪的鑰匙。核心是**大珠慧海《頓悟入道要門論》**的四番問答（要修何法→頓悟法；何謂頓悟→頓者頓除妄念、悟者悟無所悟；從何起修→從根本修；何謂根本→心即根本）〔行73-96〕，再引《六祖壇經》「本心生萬種法」「心生種種法生，心滅種種法滅」〔行121〕、《維摩詰經》「心淨則佛土淨」〔行232〕、《心經》「照見五蘊皆空」〔行189〕，證成一條主線：**煩惱來自法塵，法塵來自心，心的根源是自性（圓覺）；不入本心，學法無益**〔行175-177、221〕。

正文部分，法師逐句解「一切如來圓覺清淨本無修習及修習者」（圓頓義，眾生本成佛）與「依於未覺幻力修習」（漸次義，三法皆是幻法），再逐輪講解第一至第十輪。過程中穿插如來藏三德（空／不空／空不空＝天台空假中）〔行493-519〕、宗密三觀名相（泯相澄神觀／起幻銷塵觀／絕待靈心觀）〔行483-491〕，以及「開悟不等於世間全知」的重要辨正〔行499-505〕。第十一至二十五輪留待下一講〔行687-688〕。

## 4. 故事・公案

**（一）大珠慧海《頓悟入道要門論》四番問答**〔行73-96〕
馬祖道一的學生慧海禪師，世稱大珠和尚，大徹大悟，著《頓悟入道要門論》流傳千古，為修禪修淨者必讀。論的開宗明義章即設四問：問「要修何法才能解脫？」答「唯頓悟一門即能解脫。」問「何謂頓悟？」答「頓者，頓除妄念；悟者，悟無所悟。」問「從何而修？」答「從根本修。」問「何謂根本？」答「心為根本。」法師以此四問四答，把整部《圓覺經》要旨——不除滅妄念、本自清淨無所悟、以心為根本——一線貫穿，指出真正大徹大悟的聖者從經典引出的論述反而更直接（如八十《華嚴》八十萬字讀之難得其要，祖師一句直指重點）〔行98-102〕。

**（二）趙州自焚、南泉投鑰**〔行88-92、213〕
趙州和尚把自己關在屋裡放火自焚，火燃起後，南泉法師往失火的房子裡丟進一把鑰匙；趙州拿鑰匙開門跑了出來。眾弟子如看一齣戲，有人當下開悟，有人不解。法師解此公案：兩位都是大禪師、古佛再來，示現的是「自修自度，佛不度你，你度自己」——火（煩惱）是自己製造的，鑰匙一開走出去就沒有了，修行始終是修自己，別人無法代替。同時點出南泉即「南泉斬貓」的那位大禪師〔行90〕。

**（三）澄觀·清涼國師——七帝之師**〔行379-381〕
當時的皇帝一聽澄觀大師（華嚴四祖）講法，就說「我聽你一講，我的心好清涼」，從此稱他「清涼國師」，他是七位皇帝的老師。法師以此證：佛陀的「本住法、自心自證法」是第一手從真心流出的語言文字，你只要諦聽就會生清涼意——因為「心佛眾生三無差別」〔行377-381〕。

**（四）蕅益大師「不識彌陀怎奈何」**〔行467-469〕
念佛若不知「什麼是佛」，喊破喉嚨也枉然。蕅益大師（古佛再來）有句：「念佛時不識彌陀怎奈何，你不知道自己是彌陀，臨危怎麼出娑婆。」念阿彌陀佛是念自己的本心（無量壽即無量光即本心），把煩惱去除，不是求阿彌陀佛來替你解煩惱〔行467-471〕。

**（五）慧遠廬山結社·法藏比丘成阿彌陀佛**〔行638、665-667〕
慧遠大師成立廬山念佛結社；華嚴宗從一祖到五祖成立道場，天台成立道場，六祖禪門廣度眾生——這些是地球上有生滅的有形眾生道場〔行638-640〕。而《無量壽經》《阿彌陀經》中的法藏比丘，斷煩惱（禪那，必先用奢摩他）成佛後號阿彌陀佛，建立西方極樂世界讓眾生回歸成佛；釋迦牟尼佛在娑婆世界建立華藏世界、講經四十九年——這正是二十五輪第十輪「先入本心、再起變化度眾生」的示現〔行663-667〕。

**（六）六祖不識字·法海禪師記錄**〔行503-505〕
法師破斥「開悟後世間法都會」的迷思：六祖若還在，你拿一部經給他念，他不會從「如是我聞」念下來；《六祖壇經》是六祖口述、法海禪師記錄修正，文字之美是因為法海不是六祖。六祖大徹大悟後也不會因此識字、不會突然講流利的義大利文、英文、法文——世間法沒學就是不會〔行503-507〕。「無所不知」指的是出世間的本心功德（鏡子胡來胡現），不是世間知識全知〔行499-512〕。

**（七）摩尼寶珠在袖**〔行587〕
佛法是大道至簡，只要有信；不信者稱一闡提，「你自己是佛卻不承認，怎麼成得了佛」。如摩尼寶珠就在自己袖子裡，你永遠不知道它在，怎麼找得到——喻眾生本具佛性而不自知〔行586-587〕。

**義理深入**

**（一）「本無修習及修習者」——圓頓為體，漸次為用。** 法師把二十五輪的第一句抬到全章之首：「一切如來圓覺清淨本無修習及修習者」〔行315〕。這是圓頓法的斬釘截鐵——眾生本具圓覺、本成佛，故根本沒有「要修的法」與「能修的人」；佛法最高義是「無修」〔行317〕。他隨即以六祖「何期自性，本自清淨…能生萬法」〔行319〕與《證道歌》「絕學無為閑道人，不除妄想不求真」〔行319〕互證。然而下一句「依於未覺幻力修習」〔行325〕立刻補上漸次：因為眾生「未覺」，佛才不得不施設方法，而這些方法（三法）本身也「全部都是幻」〔行329〕。二十五輪因此不是二十五條不同的路，而是「一輪」（回歸本心）在未覺眾生根性差別上的二十五種幻力方便——「修一法等於修二十五法，一即一切、一切即一」〔行250-253〕。

**（二）三法即空假中，皆以淨覺心為本。** 法師把三法配天台三觀與如來藏三德：奢摩他＝取靜＝空觀＝泯相澄神觀；三摩鉢提＝起幻智＝假觀＝起幻銷塵觀；禪那＝絕待入本心＝中觀＝絕待靈心觀〔行483-519、531〕。三者都必須「依淨覺力／圓覺力」，離開圓覺（自性本心）三法無法成就，且三法本就是圓覺自性所生、用來「教導菩薩」的〔行363-365〕。故無論從哪一門進去（空/假/中），都是進入同一本心——「只是門開得不一樣，不是都進去嗎」〔行521-527〕。

**（三）單修三輪的根器差別。** 單修奢摩他純用靜力，以般若靜慧照見身心妄念皆生滅、皆客塵，久修永斷煩惱、脫落身心，「不起於座便入涅槃」（行住坐臥當下回歸本心）〔行389-401〕。單修三摩鉢提最變化多端：任持一段相應的大乘經句、佛號（阿彌陀＝無量壽無量光即本心）、咒語（唵嘛呢叭咪吽、準提咒、穢跡金剛咒）起幻智破煩惱，內發大悲輕安度如幻眾生〔行422-445〕。單修禪那則是利根直入，不取靜也不用幻智，直接見「非幻不滅」的如來藏本心，煩惱斷盡便證實相〔行455-463〕。三法殊勝平等，「哪一種進去都稱單修」〔行527-529〕。

**（四）第四至第十輪——以奢摩他（A）為主軸的排列組合。** 法師用 A（奢摩他）、B（三摩鉢提）、C（禪那）作記號〔行475、671-673〕：單修即 A、B、C 三輪；本講第四至第十輪全部以 A 為主軸——AB、AC（互修二法）、ABC、ACB（三修）、A齊BC、齊AB後C、齊AC後B（齊修）。他反覆點明：既然以 A 為主，「不用 B 也可以直接用靜慧入禪那」〔行675〕，界線「分得不清也不需要怎麼分」，差別只在見地〔行652〕。其中第八輪「復度眾生建立世界」被法師標為本講功課核心，並以法藏比丘建西方、釋迦建華藏世界、佛與六祖之修法（第十輪）作最高示現〔行613、663-667〕。第十一至二十五輪（以 B、C 為主軸）留待下一講〔行687-688〕。

## 10. 法脈會通

**（一）本講中心鏈條——法塵→心→自性（圓覺）**

```
外境(四大假合)
     │ 六根接觸
     ▼
法塵 = 相分 ──需先有── 見分 ──需先有── 心
（永嘉:心是根法是塵）        （有心就有見分）
     │ 二元愛憎取捨
     ▼
煩惱 = 無明（妄心本寂、法塵本空 ← 宗密都序）
     │ ↑ 頓除妄念＝知幻即離（非滅妄）
     ▼
心 ─── 根源 ───▶ 自性 = 圓覺 = 如來藏 = 圓照清淨覺相 = 自性清淨圓明體
（大珠:心即根本）        （賢首國師《妄盡還源觀》語，行358）
```
連結要點：法從心生、心從自性生，故「法、心、自性是同一件事」〔行353〕；不入本心，學法無益〔行221、415〕。


## 11. 日常實踐

1. **知幻即離，不作滅妄。** 妄念、煩惱一起，只需「知道它是妄念，它干擾不了我」，回歸一心，不要再起一個「我要滅妄」的第二妄〔行84、286-288〕。
2. **選一法即可成就。** 二十五法抽到哪一種，這輩子專修那一種即可（法師建議真做二十五個籤，三七日求哀懺悔後隨手抽取）〔行112-116、401-403〕；不必貪多，三法乃至一句佛號、一句咒即足〔行144〕。
3. **煩惱時起幻智（三摩鉢提）。** 煩惱一起，任持一句與你相應的：一句佛號（阿彌陀佛＝念自己本心）、一段《心經》（觀自在菩薩／照見五蘊皆空／心無罣礙）、一句咒（唵嘛呢叭咪吽＝身心如蓮花、不著空有的圓覺自性），即可破煩惱〔行422-443〕。
4. **轉感覺，不轉物。** 好人壞人、淨土穢土都是自心所判，「轉感覺就好了，轉物體才難」〔行184、236〕；被一句罵所縛，是被法塵綁，知其本空即當下解脫〔行187〕。
5. **聽經即諦聽——放下主觀，回歸一心。** 聽法時把自己所學（念佛、四念處、密法等主觀）暫放下，莫起批判妄念，一心諦聽即契心〔行296-305〕。
6. **念佛要識本心。** 念佛是念自己的無量壽無量光本心、藉佛號回響喚起本心般若光明除煩惱，非求佛替你解煩惱〔行467-471〕。

## 12. 延伸・參

**校勘・待考**
- **何期自性順序與字**〔行319-321〕：師誦「本自清淨／本不生滅／能生萬法／本自具足」且作「本不動搖」；《壇經》T2008 作「本自清淨／本不生滅／本自具足／本無動搖／能生萬法」。義同，字序與「無/不」異——保留師語並註canon。
- **「無不從此法界流」**〔行348〕：師稱「《華嚴經》總歸一句」，實出澄觀《華嚴經疏》T1735，非八十《華嚴》本文——屬疏非經。
- **大珠《頓悟入道要門論》、達磨《血脈論》、蕅益語**：屬卍續藏（X）或祖語，非CBETA T-series root，本講標 ※；經義正確，僅無 T-root 可核。
- **「即見如來／則見如來」「聚會／俱會」「兩者／兩種」「妄心／妄念·法塵/塵境」**：師誦與canon的微異，皆保留師語＋canon對照（見§9）。
