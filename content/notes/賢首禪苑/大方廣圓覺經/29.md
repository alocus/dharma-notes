## 1. 本講概要

本講是《圓覺經》十二菩薩章的第九章〈淨諸業障菩薩章〉開講。體佛法師開宗把《圓覺經》全經判為三大階段，並先以「大方廣佛華嚴」的經題拆解，把**文殊（智）＋普賢（行）→毘盧遮那佛**這條華嚴主軸，收攝為《圓覺經》的**圓覺三法（奢摩他／三摩缽提／禪那）**，作為進入本章的見地基礎〔行54〕〔行59〕〔行80〕〔行94〕。

本章的正文核心是佛答淨諸業障菩薩「覺心本性清淨，因何染污」之問——教眾生如何辨識**根本無明（發業無明）**與**枝末無明（結業無明）**兩重迷，並層層剖出修行人最隱微的執著：**破四相（我、人、眾生、壽者）入賢聖，再破四見（同名而細）方回歸圓滿究竟成佛**〔行180〕〔行182〕〔行478〕〔行647〕。法師反覆以《金剛經》前半破枝末無明（四相）、後半破根本殘習（四見）作對照，是本講最重要的跨經連結〔行286〕〔行596〕。

貫串全講的實修口訣是：**用真如處理，不用因緣處理**〔行432〕〔行435〕——碰境界時不順因緣相續去回應（會引發阿賴耶種子、鞏固輪迴），而回歸自性（奢摩他取靜）→發智慧（三摩缽提以幻除幻）→能所雙亡（禪那）。並以「留惑潤生／留著根本無明入人道度眾」收束大悲輕安的意義〔行275〕〔行280〕。

## 4. 故事・公案

**（1）電影《美麗人生》——集中營父子的「遊戲」**〔行126–138〕
法師舉一部電影（納粹德國時代猶太人入集中營；未點名，即《Life is Beautiful／美麗人生》）：主角帶著幼子被關進集中營，為護兒心，告訴他「我們是來玩一個遊戲，不管別人怎麼對我們，都是遊戲的過程，只要你內心不慌亂、不屈服、挺過去，就能得到大獎——一輛真正的坦克車」。孩子信以為真，全程被毆打侮辱都視為遊戲的一部分，如如不動。最後父親被德軍抓走槍斃的那一剎那，孩子仍無動於衷（父親臨行仍叮囑這是遊戲的一環）。結局1945年聯軍攻入，集中營被打破，美軍坦克車緩緩開進——孩子「得到了坦克車」。法師以此證「一切是唯心造」：逆境是否成為逆境，全在你的心；「我相信這位導演一定聽過《圓覺經》，他懂得這個道理」〔行138〕。並勉：日常再大的逆境也不會超過二戰猶太人的逆境，能用那孩子的心來遊戲人間，還怕什麼〔行138〕〔行140〕。

**（2）《法華經》譬喻品·三車喻**〔行192–194〕〔行216〕
火宅之中以鹿車、羊車、牛車誘子出離，牛車即一乘法；「還是要回歸一乘，回歸一乘就是本心」〔行194〕。法師稱此為《法華》最精彩一段（並提及胡適亦論及譬喻品）〔行192〕。

**（3）《法華經》·衣中摩尼寶珠**〔行194–196〕
一人喝醉酒，衣袖裡藏有摩尼寶珠而不自知，淪為乞丐；後有人告訴他「你有摩尼寶珠，為何淪為乞丐」。喻自性功德（如來藏之寶）本具而不會用〔行196〕。

**（4）《法華經》·窮子喻（大富長者與拔糞者）**〔行196–210〕〔行282〕
富可敵國的大富長者，幼年與子失散。一日瞥見一名拔糞的年輕人，眼神一認即知是己子，卻不能直說（子必不信）。長者遂設方便：先派侍者假扮拔糞者與他同工，再引介他去大富家當園丁（仍是卑下工作），而後一階一階提拔，終令他管理長者一切財物、當上「執行長」。臨終時，長者請來國王與眾大富，當眾宣布：「這位執行長就是我的兒子，本來就要繼承我的財產。」法師點出：這正是《法華》《圓覺》《楞嚴》《華嚴》最重要的一句——「他就是我的DNA，他等於我」；佛一開始不能對窮子直說「你就是我兒子」（不信），到某階段才宣布「我就是他、他就是我」〔行210〕；對應佛說法四階段，先教凡夫提升（阿含、方等），般若涅槃才直告「你本來就是佛」〔行212〕。

**（5）《楞嚴經》·富樓那問佛「清淨本然，云何忽生山河大地」**〔行495–556〕
法師引《楞嚴》公案：富樓那問佛——您說真心本性本然清淨、周遍法界（比虛空更大不知幾萬倍），為何忽然現出有相的山河大地、且山河大地變異不已？佛的回答，法師濃縮為「迷真取妄」「妄本無因，因迷故」〔行507〕〔行509〕〔行512〕：在一念不覺、迷的當下就現相了；相之所以輾轉不失，是「境界為緣長六粗」。此問直到六祖「何期自性，能生萬法」一句方得徹底解答〔行554〕。

**（6）六祖聞《金剛經》「應無所住而生其心」言下大悟**〔行547–556〕
五祖夜為惠能說《金剛經》，至「應無所住而生其心」，惠能言下大悟，說出「何期自性，本自清淨……能生萬法」。法師以「本不動搖（沒有二、無動靜相）、本不生滅（生滅是二元）、能生萬法」逐句對應本章「本無我、本無為、本成佛、本不二」〔行545〕〔行547〕。

**（7）般若經·射箭喻**〔行384–386〕
射一個微小之物很難命中（機率極小）；若以箭射大地，則百發百中、隨便射隨便中。喻：發菩提心（回歸本心、見地清楚）後，修任何法門皆「百發百中」〔行386〕。並引《觀無量壽經》念佛法門第一前提是發菩提心〔行386〕。

**（8）師自述·多發性骨髓瘤與「明醫／庸醫」**〔行421–425〕
好醫生把脈或X光後，若確知無法醫，會坦白相告（如醫生告訴法師「師父，這個（多發性骨髓瘤）不能醫了」），這叫明醫；庸醫明知無法卻叫你花大錢做無益之事、自己得利。喻佛之偉大在於「告訴你問題，也一定告訴你方法」〔行421〕〔行428〕。

**（9）針灸忘我·圓覺「我相」譬喻**〔行484–492〕
（圓覺經正文自帶之譬喻，法師展開）：人身體康健時「百骸調適」，看電影、聽音樂、念經而「忽忘我身」（渾然忘我、時間飛逝）；一旦四肢弦緩、攝養乖方（生病），中醫為你針灸、艾灸，「哎唷」一痛，「則知有我」——由痛證出有我。喻我相之微細：乃至證於如來清淨涅槃，只要還有一個「能證之心」，皆是我相〔行492〕。

**（10）酒杯酒味喻（悟跡未亡）**〔行633〕
酒杯的酒已全倒掉，聞起來還有酒味——喻已到入地菩薩程度，卻仍存一絲「我能了悟的心」（悟跡），真心尚有瑕疵、未回歸本性；但「方向正確，自自然然回歸妙覺」，無所謂〔行633〕〔行635〕。

**（11）騎腳踏車喻（最後不用力自然到達）**〔行707–709〕
剛起步要用力踩（般若智慧要出來、用力去除四相）；車子跑起來後就不用力了，只要目標對，會自動到達。喻破四見的最後階段「不用出力，它自己到達」——越用力想「我有一個能怎樣」反落能所〔行709〕。

## 8. 本經解義（大方廣圓覺經·淨諸業障章逐段）

### 8-A 序分長行（染污之由）

**淨諸業障菩薩之問（本講開講由此起）** ✓CBETA T0842〔行274(canon)〕
> 於是淨諸業障菩薩在大眾中即從座起，頂禮佛足右繞三匝，長跪叉手而白佛言：「大悲世尊！為我等輩廣說如是不思議事一切如來因地行相，令諸大眾得未曾有，覩見調御歷恒沙劫勤苦境界，一切功用猶如一念，我等菩薩深自慶慰。世尊！若此覺心本性清淨，因何染污，使諸眾生迷悶不入？唯願如來廣為我等開悟法性，令此大眾及末世眾生作將來眼。」說是語已五體投地，如是三請終而復始。

**佛答·染污之由** ✓CBETA T0842〔行178／305(師讀)〕
> 「善男子！一切眾生從無始來，妄想執有我、人、眾生及與壽命，認四顛倒為實我體，由此便生憎愛二境。於虛妄體重執虛妄，二妄相依生妄業道，有妄業故妄見流轉，厭流轉者妄見涅槃。由此不能入清淨覺，非覺違拒諸能入者，有諸能入，非覺入故。是故動念及與息念皆歸迷悶，何以故？由有無始本起無明為己主宰，一切眾生生無慧目，身心等性皆是無明，譬如有人不自斷命。是故當知！有愛我者我與隨順，非隨順者便生憎怨，為憎愛心養無明故，相續求道皆不成就。

**義理深入（序分）**：法師把這段長行讀成一條「迷的因果鏈」：**根本無明（一念不覺·為己主宰）→生無慧目（誤認身心為我）→憎愛二境（隨順則愛、違則憎）→養無明·相續求道皆不成就**。關鍵在「非覺違拒諸能入者……非覺入故」一句——他反覆強調覺性「不出不入、不拒諸相」，把整章的修行落點定在「**回歸不出不入的覺性**」，而非「動念取涅槃」或「息念滅妄」的任一邊〔行321〕〔行325〕。並以《楞嚴》「譬如虛空體非群相而不拒彼諸相發揮」印證：體（不變）不礙用（隨緣），凡夫只在「變」上用心，故永在變中；覺者知變從不變出，故時時「常起真如」——這正是奢摩他（取靜為行）〔行327〕〔行337〕〔行339〕。

### 8-B 云何我相

**圓覺·我相** ✓CBETA T0842〔行280(canon)／480(師讀)〕
> 「善男子！云何我相？謂諸眾生心所證者。善男子！譬如有人百骸調適忽忘我身；四支絃緩，攝養乖方，微加鍼艾，則知有我。是故證取方現我體。善男子！其心乃至證於如來，畢竟了知清淨涅槃皆是我相。

**義理深入（我相）**：法師在此立起本章的判準——**圓覺的標準是「妙覺」，不是破身見的賢聖**。凡夫的我相是「執五蘊身心為我」，破之即入聖賢（《金剛經》前半）；但聖者仍有「能證之心（我證）」，此即《圓覺》所謂「其心乃至證於如來……皆是我相」，別名我見。他配合《楞嚴》「性空真色，清淨本然，周遍法界」與六祖「本自清淨」，指出本然「無我」是性德、非修來——「本無我、本無為、本成佛、本不二」〔行495〕〔行545〕；富樓那之問（清淨本然云何忽生山河大地）與六祖「能生萬法」正在此處會通〔行503〕〔行554〕。

### 8-C 云何人相

**圓覺·人相** ✓CBETA T0842〔行282(canon)／566(師讀)〕
> 「善男子！云何人相？謂諸眾生心悟證者。善男子！悟有我者，不復認我，所悟非我，悟亦如是。悟已超過一切證者，悉為人相。善男子！其心乃至圓悟涅槃俱是我者，心存少悟備殫證理，皆名人相。

**義理深入（人相）**：法師點出四相之細，全是「以我相為主」的展轉——我見是「執有一個我」，人見是「執有一個無我」，「你執著你是無我，變成你又有一個我」〔行584〕。這就把《金剛經》「無法可得、無阿耨多羅三藐三菩提可得」讀通了：前半教人「不住色布施」還在相上，後半連「我能證無為」的概念都要破，故「一切賢聖皆以無為法而有差別」——破四相已是賢聖、入無為法，但「以無為為主、以我已入無為」仍是人相〔行600〕。

### 8-D 云何眾生相

**義理深入（壽命相）**：這是四相中最細一層。法師先給粗相：壽者相是「執一期一期生命週期（幾歲活到幾歲、死了又投胎）」，破之即知「回歸自性的無量壽」、已入聖者〔行665〕〔行669〕。細相（壽者見）則是入聖之後：明了「我見、人見、眾生見三見都是垢」，卻「還有一個能覺塵垢的覺心存在」〔行671〕。由此他把《金剛經》「無佛可成、無阿耨多羅三藐三菩提可得」讀成本章結論——「你想成佛的心、想證悟的心、我已離垢的心，全部都要斷掉，才是四見全免、回歸決然的無我」〔行673〕〔行681〕。並以騎腳踏車喻收束：起步要用力（般若智慧去四相），最後回歸圓覺自性「不用出力，它自己到達」；越用力想「我有一個能怎樣」，越落能所、達不到目標〔行707〕〔行709〕。

**四相→四見·粗細二層總表**（本章骨架）

```
                     粗相（破→入賢聖·金剛經前半）        細相（破→回歸圓滿究竟佛·金剛經後半）
  我相 / 我見  ──▶  執五蘊身心為我                       其心乃至證於如來清淨涅槃（能證之心）
  人相 / 人見  ──▶  計我者·趣於別趣                       悟「無我」而執無我·悟跡未亡（能悟之心）
  眾生相/眾生見──▶  我心生善惡哀樂·變異相續               能所已放下·而「存有所了」（能了之心）
  壽者相/壽者見──▶  執一期生命週期                       知三見皆塵垢·而「能覺塵垢」（能覺之心）
        │                     │                                        │
     破四相                入賢聖·入無為法              一切賢聖皆以無為法「而有差別」
     破四見                回歸「本無我·本無為·本成佛·本不二」的圓滿究竟妙覺
```
**連結要點**：四見與四相同名，差別只在——四相破的是「執身心為我」，四見破的是「悟／證／了／覺」之後殘存的那一絲「能……之心」（悟跡未亡）。破四相是《金剛經》前半（無為法），破四見是《金剛經》後半「無阿耨多羅三藐三菩提可得」〔行596〕〔行673〕〔行681〕。

**（三）根本無明／枝末無明·三障 因果鏈**

```

   └▶ 生三細：業相(波動) → 轉相(能見/見分) → 境界相(所見/相分)
        └▶ 五蘊身心幻相生（未執取）── 此仍是「根本無明」

                  └▶ 誤認身心為我 → 我執 → 愛憎取捨
                       └▶ 三障：惑障(疑/見地不夠) → 業障(身口意造·善惡皆障) → 報障=苦障

```

## 11. 日常實踐

1. **碰境界時「用真如處理，不用因緣處理」**：遇到讓你愛或恨的人事，先不順著因緣相續去回應（越處理越在意、越引發阿賴耶種子、越鞏固輪迴），而回歸自性（奢摩他取靜）看它「覺識煩動」、是虛幻，不再投入〔行432〕〔行435〕〔行439〕。
2. **觀外境更觀自心**：把世局變化看作「無常其實是常」（如春夏秋冬必循環），再回觀「原來是我心相續變異所現」——不觀外境而觀自心的起滅〔行156〕〔行160〕。
3. **以幻取幻**：把「凡所有相皆是虛幻」用在自心——能除的心也是幻、所除的相也是幻，能所雙亡即入禪那〔行164〕〔行347〕。
4. **念佛先發菩提心、回歸不變**：念阿彌陀（無量光壽）是「用可變的佛號回歸不變的自性彌陀」，不是求一個可變的佛來帶你去淨土；淨土在自心（心淨國土淨）〔行353〕〔行386〕。
5. **破四相不自傲、破四見不著急**：粗四相一破已是賢聖，但莫沾沾自喜（悟跡未亡仍是我）；細四見「不用造作去除」，方向對了如騎腳踏車自然到達〔行596〕〔行707〕。
6. **經典是佛最寶貴的舍利**：一句了義經文即一部經精髓，「一經通，萬經通」；圓覺懂則心經、金剛經皆通，故要諦聽契心、不看熱鬧〔行168〕〔行251〕。

- **本講範圍界定**：本講至「云何壽命相……存我覺我亦復如是」止；「末世眾生不了四相……」以下（以賊為子喻、說病為法、降伏煩惱漸次成就等）法師明言留待下講圓滿結論〔行711〕。
- **相關講次**：第28講已講「眾生無明的原因·佛告文殊」為本講前提〔行180〕〔行182〕；圓覺三法之判在威德自在章〔行82〕。
