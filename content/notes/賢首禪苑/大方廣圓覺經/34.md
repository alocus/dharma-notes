## 1. 本講概要

本講是《圓覺經》十二菩薩章的第十一位——**圓覺菩薩章**。體佛法師指出：威德自在菩薩章時，圓覺三法（奢摩他／三摩鉢提／禪那）的「理相」已介紹完畢；圓覺菩薩「意猶未盡」再問一次，佛遂就**行門的下手處**（實修操作）重新開示〔行56-58〕。故本講「完全是在實修」，法師再三叮嚀「請各位一定要仔細聽」〔行56〕。

全講的骨幹是三段：
1. **生命相狀 vs 生命本質**——開場白，建立整部圓覺的立足點：眾生所執的財富、權力、情感皆是「生命相狀」，由業力決定、虛幻無常；真正要回歸的是不生不滅、在凡不減在聖不增的「生命本質（實相／本體）」〔行74-121〕。
2. **安居法**——經文「若經夏首，三月安居……」的逐句解義；辨大乘安居（示現安居）與聲聞安居之別，並旁徵易經「先王以至日閉關」與禪宗「未破初參不入山，不至重關不閉關」〔行125-359〕。
3. **圓覺三法的行門**——奢摩他（以靜為行、觀身心如影像）、三摩鉢提（以幻除幻、憶想十方如來自熏成種）、禪那（了知身心皆礙、數息觀生住異滅、於息見不生滅）三種淨觀的具體操作〔行360-750〕。

貫串全講的核心命題：**圓覺、阿賴耶、生命相狀三者的關係，以及「一念心性可以淨化一切」**——以三昧禪師度龍王公案為證〔行383-411〕。

## 3. 核心概念

| 概念 | 體佛法師釋義〔行〕 | 經教連結（已驗） |

| **生命本質／本體** | 生命最深層不變、不生不滅、眾生本有之實相；在凡不減、在聖不增；異名：如來、自性、本心、阿耨多羅三藐三菩提、清淨自性圓明體〔行100-102〕 | 六祖「何期自性，本自清淨；何期自性，本不生滅；何期自性，本自具足；何期自性，本無動搖；何期自性，能生萬法」✓ CBETA T2008 |

| **奢摩他** | 三觀之「空／止」（天台）；以「靜」為行，回歸生命本質之空，把生命相狀空掉；成就「內發寂靜輕安」〔行378-381, 422-434〕 | 《圓覺經》威德章「取靜為行；由澄諸念，覺識煩動，靜慧發生，身心客塵從此永滅，便能內發寂靜輕安」✓ CBETA T0842 |

| **客塵** | 身心來來去去、假的東西；藉奢摩他智慧令「身心客塵從此永滅」〔行451-453〕 | 《圓覺經》「身心客塵從此永滅」✓ CBETA T0842 |

## 4. 故事・公案

### 4.1 三昧禪師度江西龍王廟龍王（蕅益大師講）〔行383-411〕
> **註**：轉述者，轉錄逐字稿作「萬益大師」，係「蕅益大師」（明·智旭）之同音訛寫，見§校對。

江西某湖有一龍王廟，甚靈：凡經過此湖的船若不停靠碼頭向龍王祈求供養，機率很高會翻船或遭厄運，故行人口耳相傳，過湖必虔誠奉獻。一日三昧禪師（一位入本心的成就者，「聽到三昧就知道他入本心」）搭船經此，眾人皆去朝拜，唯獨他這位出家人不拜鬼神、如如不動〔行383-393〕。

龍王顯靈附身於通靈的廟公身上，責問「怎麼只有那個出家人沒來」，並恭敬請三昧禪師前來。禪師深知「我們世界的現象界裡還有其他現象界，這不是迷信，是實相本來就有這樣的境界」，遂前往〔行391-393〕。龍王先向禪師頂禮，說「你不認識我嗎？幾輩子以前我們兩個是同修」〔行395〕。

龍王自述因緣：兩人同為出家修行人，但**起心動念不同**——「你是以柔和的心起修，一念當下一法界全動，你的法界就是柔和的法界」；「我一切的當下是瞋恨為主，當時我很看不起別人、太有主觀意識、很容易生氣，我這一瞋就佈滿全法界，就投胎好幾世」。因曾當出家人有大福報，故投胎為龍王（畜生道之高乘、有大福報，故人拜他）；但「一念的瞋念沒有除」，故只要有船經過而不打招呼，他一生氣，對方必遭殃——「因為我這個法界可牽動另一個法界」〔行397-403〕。

見到三昧禪師使龍王回想起佛陀所教的圓覺法：「我應該要入本心，我應該要柔和才對」。禪師當下為他講圓覺法，龍王聽完頂禮，並請禪師隔日到後山一看。次日果見一條長四五米的蟒蛇死於該處（龍蛇一體，龍王已脫龍王身、回歸法界），三昧禪師以出家之禮安葬〔行405-407〕。

**法師點題**：「脫離了龍王身，回歸到法界，就在一念間」；「一念的心性可以淨化所有的圓覺，可以把阿賴耶的所有一切全部淨化掉」〔行409〕。故有「一句彌陀，能滅千百億劫重罪」之理〔行411〕（按：此為師述，非直引；經據見§9）。

### 4.2 道樹禪師：「妖魔鬼怪變化有盡，我不聞不問無窮」〔行341-353〕
道樹禪師在深山修行，因是出家人，山神樹神一大堆山妖特別「投其所好」——先示現佛菩薩（出家人一定喜歡佛菩薩），當禪師對佛菩薩示現無動於衷，就轉而示現妖魔鬼怪〔行341-343〕。晚年，弟子問他：「這些顯現的妖魔鬼怪為什麼現在都不來了，甚至離開？」禪師答：「**彼（妖魔鬼怪）變化有盡，我不聞不問無窮**」——妖魔鬼怪再怎麼變化也就這樣而已（一會兒佛菩薩、觀音、釋迦牟尼佛來），可是我始終不聞不問，最後它們頂禮而離開（若非頂禮離開，就是頂禮後成為護法）〔行346-352〕。

**法師點題**：此正是經文「非彼所聞，一切境界，終不可取」的實修——「你隨著變化下去就完蛋了，你的圓覺法在這裡就破掉了」〔行352-354〕。

### 4.3 赤子之心・娘生面〔行222-235〕
小孩出生時「本無生」，阿賴耶雖有薰習種性但「還沒有用」——沒用阿賴耶時用的就是本心〔行225-227〕。戰爭時大人怕得要死，小孩被媽媽抱著照樣睡覺；肚子餓就叫，給他吃就好〔行227-229〕。若有富有人家（住洋房、有私人飛機）要認養一個貧困家庭的小孩，這小孩仍緊抱媽媽不願去——大人覺得「好笨」，但這正是「**娘生面**」（娘還沒生我出來的本來面目）：小孩「還是本心出發」，等大了才「很考慮了」〔行231-233〕。法師強調：不是學小孩的幼稚，而是學那顆赤子之心〔行235〕。

### 4.4 須菩提涕淚悲泣・舍利弗頓成大阿羅漢〔行256-263〕
解空第一的須菩提，聽《金剛經》至第十四品時「涕淚悲泣」（哭得很嚴重、連鼻涕都流出來）——大阿羅漢為何如此？因他未曾聽佛講此法，他只知「從有來修」，已修到苦與無明皆無（故稱解空第一），但這種空要聽到真正《金剛經》後才是圓滿的空性〔行256-259〕。智慧第一的舍利弗（聲聞乘阿羅漢），聽佛講《法華經》方便品、譬喻品後「馬上成為大阿羅漢」，並未特別回去苦修——因佛已直接告訴他實相的智慧〔行260-263〕。

### 4.5 摩尼寶珠・窮子喻〔行264-268〕
法師引《法華經》譬喻：「你有一個摩尼寶珠你不知道，淪為乞丐；你只要知道有它，就成為富可天下的人」；「你本來就是大富長者兒子，你不知道淪為扒糞者，你現在知道，本來就要繼承他的財產」〔行264〕。此即「摩尼珠人不識，如來藏裡親收得」（永嘉證道歌）——摩尼珠就在我們本心裡，人人具備〔行266〕。舍利弗、須菩提、迦葉這些大阿羅漢一聽此番話，只要入信位，「我有一個摩尼寶珠（生命的本質），在當下就圓滿了」〔行266-268〕。

### 義理深入

**（一）安居——把「閉關」從躲藏拉回到心性。** 法師花大量篇幅辨「閉關」真義：世人一想修行就想閉關，「觀念錯誤」〔行148〕。他先溯易經「先王以至日閉關」——先王（聖人）於冬至（一陽生）齋戒沐浴、洗滌身心、懺悔一年所作，以便來年新開始，這才是閉關本義〔行132-146〕；再引禪宗「未破初參不入山，不至重關不閉關」——未入空性（初參）就入山是「死路一條」，因阿賴耶熏習種子未變，一入山反更執著；未從空入假（重關）也不宜閉關，因你「還會受動搖」，「必須要歷事練心」〔行148-163〕。故經文的「安居」在圓覺是「安心居住於大圓覺心性」，且「有眾生請求度化時必須出關」（如蕅益大師）〔行156-163〕。這把安居從「地點的躲藏」提升為「心性的安住」，正是大乘安居「以大圓覺為伽藍」的實義。

**（二）聲聞與大乘不是直線的兩段，而是兩個方向。** 法師破斥「不學小乘不足以學大乘」為「不了義的話」〔行167〕：不是爬到半山叫小乘、繼續爬叫大乘，而是「兩個不同的方向」——小乘在山腰盤旋（從「有」修，斷苦成聲聞、斷攀緣成緣覺），大乘「直接從這邊進去」〔行169-174, 246〕。關鍵在「本」字：聲聞「從有去除掉苦」，大乘「一下就告訴你本無苦，所以叫無生」；「本無無明——你回歸本心，何其自性本自清淨，哪有一個無明」〔行250-252〕。這也解釋了須菩提涕淚、舍利弗聞法即成大阿羅漢：他們只欠「實相的智慧」這臨門一句，一聽即入〔行256-263〕；乃至阿羅漢執「有三界可出」（偏真涅槃），回歸「本無三界可出」剎那即成大阿羅漢（大般涅槃）〔行283-287〕。

**（三）三法行門的統一結構：以淨覺心為體，三種輕安為驗。** 法師把三法整理成一個可操作、可檢驗的結構：三者出發點同（淨覺心／本心），否則「全部都是外道」〔行559, 659〕；差別在下手方便與所發輕安不同——奢摩他以「靜」觀身心如影像→寂靜輕安；三摩鉢提以「幻」熏佛菩薩功德種子→大悲輕安；禪那以「了知身心皆礙」直入→寂滅輕安（無生法忍）〔行744-746〕。而三者共同的收尾都是「非彼所聞，一切境界，終不可取」——防的正是楞嚴五十陰魔（道樹禪師「變化有盡，我不聞不問無窮」即此）。最後以起信論「不依氣息」與金剛經「法尚應捨，何況非法」收束：數息只是方便，「究竟目的是回歸自心的禪那」〔行746-750〕。

**（四）一念心性淨化一切——全講的證。** 三昧禪師度龍王公案是本講的義理高峰：龍王「一念瞋佈滿全法界」故墮龍身，「一念柔和」則回歸法界，「就在一念間」〔行397-409〕。這印證了普眼章「一身清淨故多身清淨」——法界隨一念心性而染淨。故奢摩他修的正是「把阿賴耶不斷的種子回歸空性」，而阿賴耶種子「全部都是假的、概念而已」，「一念之間可以全部清空」〔行414-418〕，此即懺法「罪從心起將心懺，心若滅時罪亦亡」〔行418-420〕。

## 10. 法脈會通

**（A）圓覺三法 ＝ 天台三觀 ＝ 三種輕安（結構圖）**

```
                     ┌─── 淨覺心／本心（三法共同出發點，否則是外道）───┐
                     │                                                 │
   奢摩他 ───────────┼─── 三摩鉢提 ─────────────┼─── 禪那 ────────────┤
   (天台：空／止)     │   (天台：假)              │   (天台：中／寂滅)    │
   下手：以「靜」為行  │   下手：以「幻」除幻       │   下手：了知身心皆礙   │
   觀身心如影像       │   憶想十方如來自熏成種      │   數息·於息見不生滅    │
   → 覺識煩動·靜慧    │   → 佛菩薩功德種子入阿賴耶  │   → 如器中鍠般若發用   │
   成：內發寂靜輕安    │   成：內發大悲輕安          │   成：內發寂滅輕安     │
                     └───────────────┬─────────────────────────────┘
                                     │
                 共同收尾：「非彼所聞，一切境界，終不可取」
```

## 11. 日常實踐

1. **辨相狀與本質**：面對財富、權力、情感的得失起伏時，提醒自己這是「生命相狀」（由業力、虛幻無常），把注意力轉向不生不滅的「生命本質」——「你距離開悟已經快到那個階段了」〔行237〕。
2. **奢摩他·對境觀影像**：生活中一定會對境起心、產生情緒；情緒一出，當下觀它「是影像故」——不隨它再引發阿賴耶種子的糾纏，「可以回應，可是心不理不睬」〔行481-486〕。
3. **看見「覺識煩動」**：生氣時知道自己在生氣、驕傲時知道自己在驕傲——「知道他在生氣的人，只要有修養就會停止生氣」〔行443-445〕。
4. **三摩鉢提·憶想佛菩薩/多聽經**：憶念佛菩薩形象與功德，或多諦聽佛經、善知識法——把般若智慧種子熏入阿賴耶；「諦聽就進去，不諦聽聽歸聽不進去」〔行620〕。
5. **禪那·數息見不生滅**：一呼一吸從1數到10、10回到1，中間盡量不夾雜妄想；細看呼吸的生住異滅，並體會呼吸間的「息」是不生不滅——「我們都在見佛性，只是不知道而已」〔行717-721〕。
6. **一切境界終不可取**：打坐修行中若現佛光、佛菩薩、妖魔、靈感，一律不執取——「來就來啊，與我何相干，反正都假的」；「魔來斬魔，佛來斬佛」〔行329-331〕。
7. **臨終念阿彌陀**：臨終時阿賴耶如電影快速播放，站在本心角度看它、專注一句阿彌陀佛（＝本心、無量光無量壽的圓滿覺性），不隨情節起波動投胎〔行516-524〕。
